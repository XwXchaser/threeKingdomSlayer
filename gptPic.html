BASE　https://api.muskapis.com AUTH　Bearer $MUSK_API_KEY

2　实测效果

### AI_PARSE_HINT: 为避免 token 膨胀，本节仅为视觉效果展示，可跳过本节和所有图片内容；接口接入请直接阅读第 3–5 节。

2.1　文生图（含中文标题渲染）

请求示例（POST /v1/images/generations）：

{"model": "gpt-image-2",
 "size": "1024x1536",
 "prompt": "米白背景，一杯燕麦拿铁，顶部中文大字标题：
            秋天的第一杯咖啡，ins风，柔光，极简构图"}

实测结果：竖版 1024×1536，中文标题「秋天的第一杯咖啡」零错字、排版清晰。文字直接由模型渲染到图上，无需后期合成。

2.2　单图编辑（保留主体，替换场景）

→
主体花瓶与尤加利叶完整保留，背景自然替换为木质桌面、窗边柔光与氛围道具，风格切换到 ins 居家感。

请求示例（POST /v1/images/edits）：

-F "model=gpt-image-2"
-F "image[]=@vase.png"
-F "prompt=保持这个白瓷花瓶和尤加利叶完全不变，
          背景换成温暖的木质桌面，窗边柔和午后光，ins风"

2.3　多图融合（两张独立素材 → 合成一张）

+
→
两张独立素材融合后，米白 ins 风格、光影、顶部中文标题全部自然保留并统一 —— 多图融合的核心价值所在。

请求示例（POST /v1/images/edits，重复 image[] 传多图）：

3　接口与参数

必填必传字段　✓ 支持主要参数已实测可传入　注有特殊行为，见备注

POST/v1/images/generations　文生图

协议：application/json

字段类型标注可选值说明
modelstring必填gpt-image-2模型，固定值
promptstring必填—生成指令，支持中文；可包含需要渲染的标题文字
sizestring✓ 支持1024x1024 / 1024x1536 / 1536x1024输出尺寸；更多尺寸可按官方约束传入
qualitystring✓ 支持low / medium / high画质档
output_formatstring✓ 支持png / jpeg / webp高级参数，建议默认不传；不传时服务端默认返回 PNG（无损压缩格式）
output_compressionint✓ 支持0 – 100官方新列的高级参数，建议默认不传；仅 jpeg/webp 有效，用于控制图片压缩率
nint注—生成数量；当前单次返回 1 张，多张请多次调用

POST/v1/images/edits　图生图 / 多图融合

协议：multipart/form-data（须用表单，不能用 JSON）

字段类型标注可选值说明
modelstring必填gpt-image-2模型，固定值
promptstring必填—编辑 / 融合指令，支持中文；可描述保留、替换、融合要求
image[]file必填—输入图片；多图融合时重复传多个 image[]
sizestring✓ 支持1024x1024 / 1024x1536 / 1536x1024输出尺寸；更多尺寸可按官方约束传入
qualitystring✓ 支持low / medium / high画质档
input_fidelitystring✓ 支持high / low参考保真度，控制输出结果与输入图的接近程度
output_formatstring✓ 支持png / jpeg / webp高级参数，建议默认不传；不传时服务端默认返回 PNG（无损压缩格式）

返回格式（两端点一致）

{
  "id": "task_xxx",
  "created": 1782232239,
  "data": [
    { "url": "https://file.kayops.com/file/xxxx.png" }
  ]
}
返回为图片结果。生产环境请在获取结果后尽快落地校验，并转存到自有 OSS/CDN。

4　调用示例

示例均读取 MUSK_API_KEY 环境变量；如需直接测试，可替换为你的 Key。下方为最小可调示例。

① 文生图

curl -X POST --fail-with-body --max-time 300 https://api.muskapis.com/v1/images/generations \
  -H "Authorization: Bearer $MUSK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2",
    "prompt": "米白背景，一杯燕麦拿铁，顶部中文标题：秋天的第一杯咖啡，ins风",
    "size": "1024x1536",
    "quality": "high"
  }' \
  | jq -r ".data[0].url"

② 单图编辑

curl -X POST --fail-with-body --max-time 300 https://api.muskapis.com/v1/images/edits \
  -H "Authorization: Bearer $MUSK_API_KEY" \
  -F "model=gpt-image-2" \
  -F "image[]=@a.png" \
  -F "size=1024x1024" \
  -F "prompt=保持主体，背景换成温暖木质桌面" \
  | jq -r ".data[0].url"

③ 多图融合（追加 image[] 传更多图）

curl -X POST --fail-with-body --max-time 300 https://api.muskapis.com/v1/images/edits \
  -H "Authorization: Bearer $MUSK_API_KEY" \
  -F "model=gpt-image-2" \
  -F "image[]=@a.png" \
  -F "image[]=@b.png" \
  -F "size=1024x1536" \
  -F "prompt=把第二张物品融合进第一张场景，风格光影文字保持一致" \
  | jq -r ".data[0].url"

① 文生图

import os
import requests

API_KEY = os.environ["MUSK_API_KEY"]

r = requests.post("https://api.muskapis.com/v1/images/generations",
    headers={"Authorization": f"Bearer {API_KEY}"},
    json={
        "model": "gpt-image-2",
        "prompt": "米白背景，一杯燕麦拿铁，顶部中文标题：秋天的第一杯咖啡，ins风",
        "size": "1024x1536", "quality": "high"
    },
    timeout=300)
r.raise_for_status()
print(r.json()["data"][0]["url"])

② 多图融合

import os
import requests

API_KEY = os.environ["MUSK_API_KEY"]

with open("a.png","rb") as a, open("b.png","rb") as b:
    files = [("image[]", a), ("image[]", b)]
    data = {
        "model": "gpt-image-2", "size": "1024x1536",
        "prompt": "把第二张物品融合进第一张场景，风格光影文字保持一致",
    }
    r = requests.post("https://api.muskapis.com/v1/images/edits",
        headers={"Authorization": f"Bearer {API_KEY}"},
        files=files, data=data, timeout=300)
r.raise_for_status()
print(r.json()["data"][0]["url"])

Node.js 示例需要 Node 18+；如使用顶层 await，请保存为 .mjs 或启用 ESM。

① 文生图

const API_KEY = process.env.MUSK_API_KEY;
const res = await fetch("https://api.muskapis.com/v1/images/generations", {
  method: "POST",
  signal: AbortSignal.timeout(300000),
  headers: { "Authorization": `Bearer ${API_KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({
    model: "gpt-image-2",
    prompt: "米白背景，一杯燕麦拿铁，顶部中文标题：秋天的第一杯咖啡，ins风",
    size: "1024x1536", quality: "high",
  }),
});
if (!res.ok) throw new Error(await res.text());
console.log((await res.json()).data[0].url);

② 多图融合

import fs from "fs";
const API_KEY = process.env.MUSK_API_KEY;
const form = new FormData();
form.append("model", "gpt-image-2");
form.append("size", "1024x1536");
form.append("prompt", "把第二张物品融合进第一张场景，风格光影文字保持一致");
form.append("image[]", new Blob([fs.readFileSync("a.png")]), "a.png");
form.append("image[]", new Blob([fs.readFileSync("b.png")]), "b.png");

const res = await fetch("https://api.muskapis.com/v1/images/edits", {
  method: "POST",
  headers: { "Authorization": `Bearer ${API_KEY}` },
  body: form,
  signal: AbortSignal.timeout(300000),
});
if (!res.ok) throw new Error(await res.text());
console.log((await res.json()).data[0].url);

5　接入须知

事项说明
中文标题写进 prompt 即可渲染到图上，准确度高
协议区分generations 用 JSON；edits 用 multipart/form-data 表单，不能用 JSON。详见「4　调用示例」
调用方式同步接口：图片生成完成后才会返回结果，结果位于 data[0].url 或 data[0].b64_json；若返回 url，请及时下载。
耗时文生图通常较快，约 30–60s；图生图与多图融合耗时更长。curl、Python、Node 示例均已加基础超时；生产接入建议对瞬时 5xx / 网络抖动做带退避的重试。
特殊参数background 对图像效果影响较大、moderation 会影响审核策略与出图效率。默认无需传入，如需使用或调整请联系管理员
生产接入：落地校验后转存（可选） 图片结果仅作为中间产物。生产环境请在获取结果后尽快落地校验，并转存到自有 OSS/CDN。

建议流程：获取 url / b64_json → 下载或解码 → 校验图片 → 转存自有 OSS/CDN。

RESP=$(curl -sS --fail-with-body --max-time 300 https://api.muskapis.com/v1/images/generations \
  -H "Authorization: Bearer $MUSK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-image-2","prompt":"一只橘猫坐在窗台上","size":"1024x1024"}')

URL=$(echo "$RESP" | jq -r '.data[0].url // empty')
B64=$(echo "$RESP" | jq -r '.data[0].b64_json // empty')

if [ -n "$URL" ]; then
  for i in 1 2 3 4; do
    curl -fL --connect-timeout 15 --max-time 60 "$URL" -o result.png && break
    sleep $((i * 3))
  done
elif [ -n "$B64" ]; then
  echo "$B64" | base64 --decode > result.png
else
  echo "No image result found" >&2; exit 1
fi

file result.png | grep -E "PNG|JPEG|WebP" >/dev/null || exit 1
# 校验通过后，上传 result.png 到自有 OSS/CDN，再返回自有 URL 给前端。
