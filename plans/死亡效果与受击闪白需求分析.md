# 死亡效果与受击闪白需求分析

## 需求 1：受击闪白效果修复

### 当前问题

在 [`Enemy.TakeDamage()`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs:465-486) 中，`hitFlashTimer = HIT_FLASH_DURATION` 在 `Die()` 调用之前设置。但 [`Update()`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs:131) 的第一行检查 `if (!initialized || state == EnemyState.Dead) return;` — 一旦 `state = EnemyState.Dead`，`Update()` 立即返回，**闪白计时器永不递减**，[`UpdateAlpha()`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs:711-744) 不会被调用，闪白效果不会渲染。

秒杀场景下（同一帧受伤 + 死亡），闪白在逻辑上设置了 `hitFlashTimer`，但因为 `state == Dead` 跳过了所有 Update 行为，所以玩家看不到任何视觉效果。

### 方案A — 在 `TakeDamage()` 中同步应用闪白（推荐）

在 `TakeDamage()` 中、调用 `Die()` 之前，**立即通过 `MaterialPropertyBlock` 设置闪白颜色**，不依赖 Update 循环：

```csharp
public void TakeDamage(float damage, DamageType damageType = DamageType.Stab)
{
    if (state == EnemyState.Dead) return;

    float multiplier = GetDamageMultiplier(damageType);
    float finalDamage = damage * multiplier;

    currentHealth -= finalDamage;
    OnDamageTaken?.Invoke(this);

    // BUG FIX: 同步应用闪白（立即设置颜色，不依赖 Update 循环）
    // 这样即使敌人秒杀死亡，闪白效果也在死亡前被渲染
    ApplyHitFlashImmediate();

    // 如果未死亡，通过 Update 循环过渡恢复
    if (currentHealth > 0f)
    {
        hitFlashTimer = HIT_FLASH_DURATION;
    }

    if (currentHealth <= 0f)
    {
        Die();
    }
}

private void ApplyHitFlashImmediate()
{
    if (renderers == null || renderers.Length == 0) return;
    foreach (var renderer in renderers)
    {
        renderer.GetPropertyBlock(mpb);
        mpb.SetColor("_Color", Color.white); // (1,1,1,1) 全白全透明
        renderer.SetPropertyBlock(mpb);
    }
}
```

这样无论敌人是否死亡，闪白颜色都会在受伤瞬间被设置。如果敌人死亡，`Die()` 触发后敌人进入 `Dying` 状态（死亡弹起动画），闪白颜色在动画开始时可见。

### 方案B — 让 `Update()` 在 Dead 状态下仍执行闪白

移除 `state == EnemyState.Dead` 检查，改为仅跳过状态更新逻辑，但仍执行 `UpdateAlpha()`：

```csharp
private void Update()
{
    if (!initialized) return;

    if (state != EnemyState.Dead)
    {
        switch (state) { /* ... 状态更新 ... */ }
    }

    // 闪白计时器和渲染始终执行
    if (hitFlashTimer > 0f) hitFlashTimer -= Time.deltaTime;
    UpdateAlpha();
}
```

方案 A 更可靠，因为即使 `Update()` 因某些原因未执行（如对象被禁用），闪白仍在受伤瞬间生效。

### 方案C — 延迟死亡

在 `Die()` 中不立即设置 `state = EnemyState.Dead`，而是进入一个 `Dying` 状态，在闪烁持续期间（0.15s）保持活跃，然后才真正死亡。这会影响到 `Column.RemoveEnemy()` 和 `EnemyManager` 的死亡回调链，改动较大。

### 结论

**推荐方案A**，影响最小、最可靠。与需求2的死亡弹起效果天然兼容——闪白在 `TakeDamage()` 中同步应用，死亡后在 `Dying` 状态中玩家能看到闪白颜色叠加在弹起动画上。

## 需求 2：死亡弹起效果

### 效果描述

> 敌人死亡后，沿 Y 轴正方向弹起，Z 轴 Rotation 随机旋转，受重力影响坠落离开屏幕。

### 设计思路

#### 新增枚举值 `Dying`

在 [`EnemyState`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs:6-14) 中新增一个状态：

```csharp
public enum EnemyState
{
    Idle,
    Moving,
    Attacking,
    Stunned,
    Launched,
    Dead,
    Dying  // 新增：播放死亡弹起动画中
}
```

#### 状态流程

```
Die() 被调用
  ↓
OnDeath?.Invoke(this)        → EnemyManager 从 Column 移除敌人引用
  ↓
state = EnemyState.Dying      → 开始死亡弹起动画
  ↓
设置随机参数：
  - velocityY = Random.Range(minSpeed, maxSpeed)
  - spinSpeedZ = Random.Range(minSpin, maxSpin) * (±1 随机方向)
  - gravity = 9.8f
  ↓
每帧 Update() 中的 Dying 分支：
  - velocityY -= gravity * Time.deltaTime
  - transform.localPosition += (0, velocityY, 0) * Time.deltaTime
  - transform.localRotation += (0, 0, spinSpeedZ) * Time.deltaTime
  ↓
当 transform.localPosition.y < 屏幕底部阈值（如 -10f）
  → enemyPool.ReturnEnemy(this)  →  ResetEnemy()
```

#### 关键参数

| 参数 | 类型 | 建议值 | 说明 |
|------|------|--------|------|
| `deathMinUpSpeed` | float | 3f | 弹起最小初速度 |
| `deathMaxUpSpeed` | float | 5f | 弹起最大初速度 |
| `deathMinSpin` | float | 200f | Z轴最小旋转速度（度/秒） |
| `deathMaxSpin` | float | 500f | Z轴最大旋转速度（度/秒） |
| `deathGravity` | float | 9.8f | 模拟重力加速度 |
| `deathBottomThreshold` | float | -10f | Y值低于此阈值时回收敌人 |

建议将这些参数放在 [`EnemyConfig`](threeKingdomSlayer/Assets/Scripts/Core/EnemyConfig.cs) 或 [`StageConfig`](threeKingdomSlayer/Assets/Scripts/Core/StageConfig.cs) 中，以便不同类型敌人有不同的死亡效果表现。

#### 参数随机化

为保证视觉多样性：
- 初速度 `velocityY = Random.Range(3f, 5f)`
- 旋转速度 `spinSpeedZ = Random.Range(200f, 500f) * (Random.value > 0.5f ? 1 : -1)`
- 正负方向随机，使不同敌人旋转方向不同

#### 与现有系统的集成

##### 修改点 1：[`Enemy.cs`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs) — `Die()` 方法

```csharp
public void Die()
{
    if (state == EnemyState.Dead || state == EnemyState.Dying) return;

    // 先触发死亡事件（让 EnemyManager 从 Column 中移除引用）
    OnDeath?.Invoke(this);

    // 然后进入死亡弹起状态
    state = EnemyState.Dying;
    // 设置随机参数
    float upSpeed = Random.Range(deathMinUpSpeed, deathMaxUpSpeed);
    float spinSpeed = Random.Range(deathMinSpin, deathMaxSpin) * (Random.value > 0.5f ? 1f : -1f);
    // ...
}
```

注意：**`OnDeath` 必须在设置 `state = Dying` 之前触发**，因为 `EnemyManager` 的死亡回调中 `Column.RemoveEnemy()` 会检查敌人是否存活。

##### 修改点 2：[`Enemy.cs`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs) — `Update()` 方法

新增 Dying 状态分支：

```csharp
private void Update()
{
    if (!initialized) return;

    // 即使 Dying 状态也要执行闪白
    if (state != EnemyState.Dead)
    {
        switch (state)
        {
            case EnemyState.Stunned:   UpdateStun();    break;
            case EnemyState.Launched:  UpdateLaunch();   break;
            case EnemyState.Moving:    UpdateMovement(); break;
            case EnemyState.Attacking: UpdateAttack();   break;
            case EnemyState.Dying:     UpdateDeath();    break;
            case EnemyState.Idle:
            default: break;
        }
    }

    // 闪白逻辑（Dying 状态也执行）
    if (hitFlashTimer > 0f) { /* ... */ }
    UpdateAlpha();
}
```

##### 修改点 3：[`Enemy.cs`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs) — 新增 `UpdateDeath()` 方法

```csharp
// 死亡弹起物理参数
private float deathVelocityY;
private float deathSpinSpeedZ;
private float deathGravity = 9.8f;
private float deathBottomThreshold = -10f;

private void UpdateDeath()
{
    // 模拟重力
    deathVelocityY -= deathGravity * Time.deltaTime;
    
    // 应用 Y 轴运动
    Vector3 pos = transform.localPosition;
    pos.y += deathVelocityY * Time.deltaTime;
    transform.localPosition = pos;
    
    // 应用 Z 轴旋转
    transform.localRotation *= Quaternion.Euler(0, 0, deathSpinSpeedZ * Time.deltaTime);
    
    // 检查是否离开屏幕
    if (pos.y < deathBottomThreshold)
    {
        EnemyPool.Instance?.ReturnEnemy(this);
    }
}
```

##### 修改点 4：[`Enemy.cs`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs) — `Initialize()` 方法

在初始化中重置死亡相关参数：

```csharp
public void Initialize(EnemyConfig cfg, int col, int row)
{
    // ... 现有代码 ...
    deathVelocityY = 0f;
    deathSpinSpeedZ = 0f;
    // ...
}
```

##### 修改点 5：[`Enemy.cs`](threeKingdomSlayer/Assets/Scripts/Enemy/Enemy.cs) — `ResetEnemy()` 方法

回收时确保状态正确重置：

```csharp
public void ResetEnemy()
{
    state = EnemyState.Dead;  // 注意：从 Dying 回收时设为 Dead
    currentHealth = 0f;
    // ...
}
```

##### 修改点 6：[`EnemyManager.cs`](threeKingdomSlayer/Assets/Scripts/Enemy/EnemyManager.cs) — 死亡回调

确保 `OnEnemyDied` 事件在 `state = Dying` 之前被触发，让 `Column.RemoveEnemy()` 正常执行：

```csharp
// 在 OnDeath 回调中：
// 1. Column.RemoveEnemy() 执行（此时 state 还是 Idle/Attacking 等）
// 2. EnemyManager 记录击杀数
// 3. Die() 继续执行，设置 state = Dying
// 4. 死亡弹起动画播放
// 5. 动画结束时 ReturnEnemy()
```

### 无需修改的文件

- **`Column.cs`** — `RemoveEnemy()` 在 `OnDeath` 事件中触发，敌人状态仍为 `Idle/Attacking`，不影响列逻辑
- **`ColumnManager.cs`** — 同上，不关心敌人死后的状态
- **`StageController.cs`** — 不关心敌人视觉效果
- **`EnemyPool.cs`** — `ReturnEnemy()` 接口不变，由 `UpdateDeath()` 在动画结束时调用

### 注意事项

1. **死亡回调链顺序**：`OnDeath` 事件必须在 `state = Dying` 之前触发，否则 `Column.RemoveEnemy()` 中的 `enemies.IndexOf(enemy)` 可能因为状态变化而找不到敌人
2. **Dying 状态下禁止交互**：`Dying` 状态的敌人不应再受到攻击、移动或攻击玩家。`TakeDamage()` 中的 `if (state == EnemyState.Dead) return;` 应改为 `if (state == EnemyState.Dead || state == EnemyState.Dying) return;`
3. **对象池回收时机**：`Dying` 状态的敌人在 Y 值低于阈值时调用 `pool.ReturnEnemy(this)`，而不是在 `Die()` 中立即回收
4. **碰撞体处理**：死亡弹起期间建议禁用碰撞体，避免与玩家或其他敌人发生碰撞
5. **渲染排序**：弹起后 Z 轴旋转 + Y 轴上升，敌人可能与其他敌人重叠，建议暂时提升渲染顺序（Sorting Order）

### 备选方案：使用协程

```csharp
private Coroutine deathCoroutine;

public void Die()
{
    if (state == EnemyState.Dead || state == EnemyState.Dying) return;
    OnDeath?.Invoke(this);
    deathCoroutine = StartCoroutine(DeathAnimationCoroutine());
}

private IEnumerator DeathAnimationCoroutine()
{
    state = EnemyState.Dying;
    float velocityY = Random.Range(3f, 5f);
    float spinSpeed = Random.Range(200f, 500f) * (Random.value > 0.5f ? 1 : -1);
    float gravity = 9.8f;
    float threshold = -10f;

    while (transform.localPosition.y > threshold)
    {
        velocityY -= gravity * Time.deltaTime;
        Vector3 pos = transform.localPosition;
        pos.y += velocityY * Time.deltaTime;
        transform.localPosition = pos;
        transform.localRotation *= Quaternion.Euler(0, 0, spinSpeed * Time.deltaTime);
        yield return null;
    }

    EnemyPool.Instance?.ReturnEnemy(this);
}
```

协程方案不需要修改 `Update()`，代码更简洁。但需要注意：
- 回收时需要停止协程（`StopCoroutine`）
- 从对象池取出时协程可能仍在运行，需要在 `Initialize()` 中停止
