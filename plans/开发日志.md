### 3. BUG 修复（3 个）

#### 3.1 EnemyPool 回收 BUG

| 字段 | 内容 |
|------|------|
| **类型** | fix |
| **范围** | `EnemyPool.cs` |
| **描述** | `enemyId` 在 `ResetEnemy()` 之后读取导致始终为 -1 |
| **详细说明** | `ReturnEnemy()` 中先调用了 `enemy.ResetEnemy()`（将 `config` 置 null），然后才读取 `enemyId`，导致所有敌人被错误地回收进 `pools[-1]` 池。修复：将 `enemyId` 读取移到 `ResetEnemy()` 之前 |

#### 3.2 敌人攻击不扣血

| 字段 | 内容 |
|------|------|
| **类型** | fix |
| **范围** | `EnemyManager.cs` |
| **描述** | `OnEnemyAttackPlayer()` 中 `PlayerState` 引用被注释掉 |
| **详细说明** | 敌人攻击玩家时未实际调用 `PlayerState.TakeDamage()`，导致玩家不掉血。修复：实际调用 `PlayerState.Instance?.TakeDamage(damage)` |

#### 3.3 StageController null 引用

| 字段 | 内容 |
|------|------|
| **类型** | fix |
| **范围** | `Enemy.cs` |
| **描述** | `GetAlphaForRow()` 中 `StageController.Instance` 为 null 时静默使用默认值 |
| **详细说明** | 在编辑器测试或场景未正确挂载时，`StageController.Instance` 可能为 null，原代码静默使用默认透明度数组，不利于排查问题。修复：添加 `Debug.LogWarning` 警告日志 |

### 6. 编译错误修复：Enemy.Die() 访问权限

| 字段 | 内容 |
|------|------|
| **类型** | fix |
| **范围** | `Enemy.cs` |
| **描述** | `Enemy.Die()` 调用 `EnemyManager.OnEnemyDied()` 但该方法为 `private` |
| **详细说明** | **错误信息**：`error CS0122: 'EnemyManager.OnEnemyDied(Enemy)' is inaccessible due to its protection level`。**根因**：`EnemyManager.OnEnemyDied()` 是 `private` 方法，但 `Enemy.Die()` 中直接调用了 `EnemyManager.Instance?.OnEnemyDied(this)`。**修复**：移除 `Enemy.Die()` 中对 `EnemyManager.OnEnemyDied()` 的直接调用。死亡流程改为完全通过事件驱动：`Enemy.Die()` → 触发 `OnDeath` 事件 → `EnemyManager` 通过 `RegisterEnemy()` 时订阅的 `enemy.OnDeath += OnEnemyDied` 处理回收、列移除、事件通知。提交 `c81687f` |
