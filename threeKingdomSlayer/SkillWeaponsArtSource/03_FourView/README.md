## 对齐口径

- 四个正交视图用**同一套缩放**，主体高度统一 **928 px**，画布 384×1024，上下留白 ≥48 px，顶端与底端高度对齐。
- 统一高度取四图主体高度的**中位数**（不是平均值）：左侧视图在它自己的原图里占得更高，用平均值会超出画布被裁断。
- 「右侧」是刃口侧视的薄刃线；「左侧」由单独的生成补出（**不是右图的水平镜像**：斧头不对称，左侧近观者的是厚斧背与交叉皮带）。

## ⚠ 已知差异（需美术验收，不当作几何通过）

1. **顶视 / 底视给的信息有限**：生成器画的是**柄端的端面**（尖头 + 圆环），而不是斧头沿 Y 轴的端向投影
   ⇒ **没有给出斧头的 X 宽 / Z 深比例**（那正是顶底视最该提供的数据）。
   建模时这部分需按 §3.1 的数字（刃宽 1.28 / 斧背厚 0.22 / 刃口 0.03）自行把握。
2. 左 / 右两侧的**远侧结构与遮挡**未严格对应（生成图不是精确投影）。
3. 四图**不是同一模型的几何投影**（四张各自生成）⇒ 只能当造型与配色参考，不能当比例验收。
