## 对齐口径

- 四个正交视图用**同一套缩放**，主体高度统一 **928 px**，画布 384×1024，上下留白 ≥48 px，顶端与底端高度对齐。
- 统一高度取四图主体高度的**中位数**（不是平均值）：左侧视图在它自己的原图里占得更高，用平均值会超出画布被裁断。
- 「右侧」是刃口侧视的薄刃线；「左侧」由单独的生成补出（**不是右图的水平镜像**：斧头不对称，左侧近观者的是厚斧背与交叉皮带）。

1. **画风已过时**：这批视图出自概念图 v6（褐锈旧货），而**正确的画风是 v7 / v8**

2. **顶视 / 底视给的信息有限**：生成器画的是**柄端的端面**（尖头 + 圆环），而不是斧头沿 Y 轴的端向投影
   ⇒ **没有给出斧头的 X 宽 / Z 深比例**（那正是顶底视最该提供的数据）。
   建模时这部分需按 §3.1 的数字（刃宽 1.28 / 斧背厚 0.22 / 刃口 0.03）自行把握。
3. 左 / 右两侧的**远侧结构与遮挡**未严格对应（生成图不是精确投影）。
4. 四图**不是同一模型的几何投影**（四张各自生成）⇒ 只能当造型与配色参考，不能当比例验收。

## ★ 为什么不再用 AI 出视图（2026-11-14 实测）

**内容安全策略会拦「亮银白的大刃」**：

| 情形 | 结果 |
|---|---|
| 旧画风（暗铁锈）的图当编辑参考 | ✔ 能过 |
| 新画风（亮银白大刃）的图当编辑参考 | ✘ 400 `content_policy_violation` |
| 含「刀」的图当参考 | ✘ 400 |

且生成器也做不出**大刃武器的端向投影**（顶/底视一律画成刀/矛尖）。

⇒ **结论：视图改为人工制作**。AI 这边交付：
- **概念图 v8**（`../02_Concept/axe_concept_v8_raw.png`）—— 画风与造型定稿；
- **PBZ 头部特写**（`../01_Reference/pbz/juxiongfu_axe_head_zoom.png`）—— **形状的唯一权威**；
- **游戏实机色卡**（`../01_Reference/style/game_palette_board.png` 等）—— **画风的唯一权威**；
- **需求文档** `Locus/knowledge/design/weapon-3d-art-spec-axe-and-chain.md` §3.0（配色分档）/ §3.1（尺度）/ §4.1（形态）。
