## 视频①动作时间提案（6秒）

| 时间 | 动作读点 |
|---|---|
| 0.0–0.3秒 | 从骑乘姿态开始，迅速受到一次正面不可见致命重击；不挥枪攻击或长时间待机。 |
| 0.3–1.5秒 | 胸肩先后仰、头盔抬起、腰背后弓；马同步抬头收颈、压耳、张嘴并急抬一前蹄。 |
| 1.5–2.5秒 | 骨盆向画面右侧脱离鞍座、双靴脱镫，短暂经过v2的动作轮廓，不插入静帧。左手松缰，持枪臂被动随惯性移动，不做主动举枪或第二次攻击。 |
| 2.5–4.2秒 | 重心下落而非匀速漂浮，头肩滞后、背肩先着地并带动髋部落定，双膝自然弯曲；长枪顺着持枪手松开的动作落在身体外侧。马以1至2个紧凑支撑步向左准备，避免四蹄贴地滑行。 |
| 4.2–5.5秒 | 骑手四肢、红缨和裙甲收稳；长枪接地、枪缨收尾。不得趴卧、坐起、撑地、重复弹跳或重新抓缰。马保持警觉，完成接近v3的受惊支撑相。 |
| 5.5–6.0秒 | 简短可读的交接区间，骑手不再恢复；马仍有细微关节和重心变化，准备接后续逃跑，但不在本段完整跑离或淡出。 |

这些时间是提示词目标，不是模型保证的帧点。收尾不延长成一秒以上的整幅冻结，也不靠慢动作悬浮填满时长。
