# 1. 输入、玩家属性与基础攻击

## 1.1 输入类型

输入由 `Assets/Scripts/Player/InputManager.cs` 管理，支持鼠标和触摸。

| 输入 | 触发条件 | 对应攻击 |
|---|---|---|
| 点击 | 未达到蓄力时间，且未形成滑动 | 戳击 Stab |
| 未蓄力垂直滑动 | 近似垂直方向 | 招架 Parry |
| 未蓄力其他滑动 | 未达到蓄力时间 | 斩击 Slash |
| 蓄力后点击 | 按住达到最低蓄力时间后松开 | 穿刺 Pierce |
| 蓄力后垂直滑动 | 蓄力完成且接近垂直方向 | 挑飞 Launch |
| 蓄力后水平滑动 | 蓄力完成且接近水平方向 | 横扫 Sweep |
| 蓄力后斜向滑动 | 蓄力完成但不满足水平/垂直阈值 | 斩击 Slash |

### 主要输入参数

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `longPressDuration` | 0.3 秒 | 进入长按状态 |
| `minChargeTime` | 0.5 秒 | 蓄力攻击最低蓄力时间 |
| `swipeThreshold` | 30 像素起，按 DPI 修正 | 最小滑动距离 |
| `maxSwipeDuration` | 0.25 秒 | 有效快速滑动的最长时间 |
| `minSwipeSpeed` | 180 像素/秒 | 最低滑动速度 |
| `swipeRearmDelay` | 0.1 秒 | 连续滑动重新识别间隔 |
| `chargeMovementTolerance` | 20 像素 | 长按时允许的轻微移动 |
| 垂直角度阈值 | 30° | 挑飞/招架判定 |
| 水平角度阈值 | 30° | 横扫判定 |

输入会在暂停、三选一、路线奖励等待、对话阻塞和特定特殊状态下被屏蔽。QTE 活跃时，输入优先交给 QTE 系统。

## 1.3 基础攻击

当前张飞攻击配置位于 `Assets/Prefabs/UI/Skills/` 下的对应技能资产。

| 攻击 | 主要作用 | 伤害 | 范围 | 动作时长 | 架势伤害 | 大招能量 |
|---|---|---:|---:|---:|---:|---:|
| Stab 戳击 | 指定列穿透、可触发击退/疾病 | 20 | 1 排 | 0.45 秒 | 0 | 10 |
| Slash 斩击 | 横向范围攻击、方向性推移 | 8 | 1 排 | 0.50 秒 | 0 | 10 |
| Pierce 穿刺 | 指定列纵向穿刺、蓄力爆发 | 20 | 3 排 | 0.50 秒 | 0 | 15 |
| Sweep 横扫 | 大范围横扫、蓄力联动 | 5 | 3 排 | 0.55 秒 | 0 | 12 |
| Launch 挑飞 | 全范围伤害、削韧、浮空 | 2 | 1 排 | 0.60 秒 | 50 | 8 |
| Parry 招架 | 弹反飞行物，或范围削韧/打断 | 0 | 1 排 | 0.20 秒 | 10 | 5 |

> 当前采用动作锁定模式：实际出手限制主要使用 `actionDuration`，而不是旧模式下每个技能独立倒计时。空挥和命中后的具体资源结算仍由攻击类型分别处理。

### 攻击特殊机制

- **Stab**：按点击位置选择列，单列穿透；可触发击退；如果染病已武装，下一次 Stab 命中会附加疾病。
- **Slash**：根据左右滑动决定方向，命中后可产生方向性推移。
- **Pierce**：指定列攻击多个排；会释放已经积累的蓄力冲击波。
- **Sweep**：范围攻击；会释放蓄力类冲击波。
- **Launch**：造成架势伤害；架势不足时浮空；骑兵冲锋中或位于最前排时会被特殊处理。
- **Parry**：优先反弹附近普通飞行物；QTE 飞行物不会被普通招架反弹；没有可反弹飞行物时对敌人造成削韧和打断。

# 2. 三选一升级机制与已入池技能

## 2.1 选择流程

```text
经验宝石到达经验条
→ 达到升级阈值
→ 游戏暂停
→ 从当前有效池抽取3个选项
→ 玩家选择
→ 应用技能/属性
→ 若有连续升级，继续选择
→ 全部完成后恢复游戏
```

当前规则：

- 三选一每次显示3个选项；
- 选项期间暂停游戏；
- 同一技能再次出现时提升等级；
- 达到最大等级后不再进入候选；
- 被动技能最多6个不同技能；
- 主动技能最多4个不同技能；
- V2 统一池会排除旧式 `Item` 类型奖励；
- 稀有度权重为 Common 60%、Rare 35%、Legendary 5%。

### 骑兵

骑兵脚本为 `Assets/Scripts/Enemy/CavalryEnemy.cs`。

- 只能在前方路径满足条件时开始冲锋；

- 默认冲锋完成后尝试回撤；
- 冲锋期间累计2次有效直接受击会落马；
- 冲锋中或位于最前排时被Launch命中会落马；

# 4. Boss QTE系统

## 4.1 QTE在Boss战中的定位

Boss QTE由 `QTEController`、`QTEDisplay`、`QTEAttackConfig` 和 `QTEConfig` 共同组成。QTE不是普通攻击输入，而是Boss发动特殊攻击时，强制玩家在屏幕提示的时间窗口内完成点击或滑动操作。

Boss QTE的基本流程：

```text
Boss行动调度选择QTE
→ Boss进入QTE攻击状态
→ 播放QTE前摇/攻击演出
→ 屏幕显示QTE指示器
→ 玩家点击或滑动
→ 判定成功/失败
→ 播放格挡、受击或结果动画
→ Boss返回Idle并进入QTE冷却
```

QTE系统状态机：

| 状态 | 作用 |
|---|---|
| `Idle` | 没有进行QTE |
| `PerformingQTEAttack` | 播放前摇、等待QTE阶段开始或下一段QTE出现 |
| `QTEJudging` | 当前QTE处于判定流程 |
| `QTEEnding` | 播放成功/失败后的收尾动画 |
| `QTECompleted` | 本轮QTE完成，准备回到Idle |

Boss处于QTE状态时，普通战斗手势会被QTE系统拦截，避免玩家的点击或滑动同时触发普通攻击。

## 4.2 当前Boss QTE配置

当前Boss QTE数据：`Assets/ScriptableObjects/QTE/BossQTEData_104.asset`

| 参数 | 当前值 |
|---|---:|
| QTE攻击数量 | 2种 |
| 执行顺序 | TripleStab → Sweep → 循环 |
| 首次QTE冷却 | 3秒 |
| QTE间基础冷却 | 3秒 |
| 是否循环 | 是 |

不同Boss阶段可以切换不同的 `BossQTEData`。Boss进入阶段时，`QTEController`会切换当前QTE配置并重置攻击索引。

## 4.3 玩家如何应对QTE

### 点击型QTE

玩家需要在屏幕中出现的点击指示器范围内点击。

判定要求：

- 点击发生在当前判定窗口内；
- 点击位置落在当前QTE指示器的Rect范围内；
- 必须按照多个QTE段的顺序完成；
- 当前段成功后才会进入下一段。

当前TripleStab配置为3次连续点击：

| 段数 | 指示器位置 | 预警时间 | 判定时间 | 成功效果 |
|---:|---|---:|---:|---|
| 1 | 屏幕约30%宽度、60%高度 | 2秒 | 1秒 | 不造成架势伤害，弹反对应箭矢波 |
| 2 | 屏幕约50%宽度、65%高度 | 2秒 | 1秒 | 不造成架势伤害，弹反对应箭矢波 |
| 3 | 屏幕约70%宽度、60%高度 | 2秒 | 1秒 | 不造成架势伤害，弹反对应箭矢波 |

TripleStab的视觉和实际防御逻辑是：Boss进行连续三段攻击，同时每段产生一波箭矢；玩家必须依次点击三个屏幕指示器，成功后对应箭矢波会被弹反。

### 滑动型QTE

玩家需要沿屏幕指示器所要求的方向快速划过指示器。

判定条件：

1. 滑动轨迹必须与指示器矩形区域相交；
2. 滑动速度必须达到配置的最低速度；
3. 滑动方向必须在允许角度范围内；
4. 必须发生在有效判定窗口内。

当前Sweep QTE配置：

| 参数 | 当前值 |
|---|---:|
| QTE类型 | Swipe |
| 目标方向 | 180°，即向左 |
| 角度容差 | 180°，当前实际允许范围非常宽 |
| 最低速度 | 50像素/秒 |
| 预警时间 | 0.8秒 |
| 判定窗口 | 1.2秒 |
| 成功架势伤害 | 40 |
| 成功大招能量 | 20 |
| 失败伤害 | 20 |

Sweep QTE的实际操作表现为：屏幕出现横向滑动指示器，玩家快速横向划过指示器区域。成功后玩家执行对应的格挡/反击表现，Boss进入Blocked收尾；失败或超时则进入Hit分支。

## 4.4 QTE视觉表现

### 指示器入场

QTE指示器由 `QTEDisplay`管理：

- 生成在Battle HUD的QTE Frame中；
- 指示器从框体上方滑入；
- 当前默认入场时间为0.15秒；
- 指示器默认尺寸由每个 `QTEConfig.indicatorSize`决定；
- 指示器出现后作为UI元素接收点击判定；
- QTE Frame带有遮罩，用于限制指示器显示区域。

当前指示器尺寸：

| QTE | 指示器Prefab | 尺寸 |
|---|---|---|
| 点击1/2/3 | `QTE_Click_Indicator_1/2/3.prefab` | 416×416 |
| Sweep滑动 | `QTE_Swipe_Indicator.prefab` | 800×160 |

### 成功表现

成功后会：

- 当前指示器播放成功结果特效；
- 显示成功结果图；
- 指示器滑出并销毁；
- 播放QTE成功音效 `QTE_Block`；
- TripleStab会弹反对应的箭矢波；
- Sweep会播放玩家的滑动/格挡视觉；
- 成功QTE会增加大招能量；
- 非防御型QTE成功时会对Boss造成配置中的架势伤害。

当前格挡视觉为：

- 矛/枪型视觉从摄像机下方弧形扫入屏幕中央；
- 视觉物体同时绕自身Z轴旋转；
- 使用三帧精灵进行切换；
- 末尾逐渐淡出；
- 该表现位于摄像机空间，不依赖玩家世界坐标中的普通攻击判定。

### 失败表现

失败可能由以下情况造成：

- 点击错误位置；
- 滑动方向错误；
- 滑动速度不足；
- 滑动轨迹没有穿过指示器；
- 超过判定窗口；
- 严格模式下，在指示器完成入场前提前输入。

失败后：

- 指示器短暂染红；
- 显示失败结果图或失败特效；
- 指示器退场；
- 防御型QTE中，箭矢继续飞向目标；
- 非防御型QTE会在Boss收尾动画对应时机结算失败伤害；
- Sweep QTE会切换到Boss的Hit/FollowUp分支；
- QTE完成后Boss恢复正常行动。

## 4.5 两种QTE攻击

### TripleStab：多段防御型QTE

资产：`Assets/ScriptableObjects/QTE/QTEAttackConfig_TripleStab.asset`

特点：

- 3个连续点击段；
- 每段之间分别延迟0秒、0.3秒、0.6秒；
- 使用Boss开始、循环、结束三段动画；
- 每段生成7支箭组成的箭矢波；
- 箭矢飞行时间约1.5秒；
- 箭矢水平散布范围约4；
- 属于防御型QTE；
- 成功不是对Boss造成架势伤害，而是弹反对应箭矢波；
- 任一段失败，整轮防御结果视为失败；
- 当前配置不可被普通眩晕打断：`interruptibleOnStun = false`。

TripleStab的玩家应对重点是：**按顺序点击三个指示器，而不是使用普通Parry攻击。**普通Parry不会反弹QTE专用飞行物。

### Sweep：蓄力横扫格挡QTE

资产：`Assets/ScriptableObjects/QTE/QTEAttackConfig_Sweep.asset`

特点：

- 单个滑动判断；
- 使用Start、Happen、Blocked结果动画；
- QTE阶段会根据判定窗口调整Boss动画速度；
- 成功后加速播放剩余攻击动作，再切换到Blocked动画；
- 失败后切换到Hit分支；
- 成功会对Boss造成40点架势伤害；
- 成功增加20点大招能量；
- 失败伤害为20；
- 可被眩晕打断：`interruptibleOnStun = true`。

## 4.6 QTE与普通Parry的区别

| 项目 | 普通Parry | Boss QTE |
|---|---|---|
| 触发方式 | 玩家普通垂直滑动 | Boss进入QTE后屏幕出现专用指示器 |
| 目标 | 普通飞行物或范围内敌人 | 当前QTE段、QTE箭矢或Boss特殊攻击 |
| 输入 | 普通垂直滑动 | 点击指示器或按指示滑动 |
| 是否受QTE流程控制 | 否 | 是 |
| 能否反弹QTE飞行物 | 不能 | 可以，需完成对应QTE |
| 成功后果 | 普通削韧/反弹 | 弹反箭矢、Boss架势伤害、动画分支、大招能量 |
| 输入期间普通攻击 | 仍可按普通规则处理 | 严格模式下被QTE系统拦截 |

## 4.7 QTE中断与特殊情况

以下情况可能中止当前QTE：

- Boss被打入眩晕；
- Boss被挑飞；
- Boss死亡；
- Boss退出QTEAttacking状态；
- 阶段切换导致QTE数据切换。

中止时系统会：

- 清理QTE指示器；
- 清理QTE箭矢波；
- 停止QTE动画；
- 恢复动画速度；
- 解除严格输入锁；
- 让Boss退出QTE攻击状态并进入正常行动调度。

## 4.8 当前QTE规则的注意点

- 当前Boss QTE默认数据是循环执行TripleStab和Sweep；
- TripleStab属于防御型QTE，成功主要是弹反箭矢，不直接削Boss架势；
- Sweep属于攻击/格挡混合型QTE，成功会削Boss架势；
- 普通Parry明确跳过带有 `isQTEProjectile` 标记的QTE飞行物；
- 当前QTE指示器的预警和判定时间由各个 `QTEConfig`独立配置；
- 当前Sweep角度容差配置为180°，实际判定非常宽松，后续如需强调方向识别应重新评估该参数；
- QTE成功/失败的视觉结果由QTEDisplay负责，Boss动画分支由QTEAttackConfig和Animator负责，伤害/架势结果由QTEController负责。

# 5. 局内奖励系统

## 5.1 经验与升级

```text
敌人死亡
→ 生成经验宝石
→ 宝石飞向经验条
→ 宝石到达后增加经验
→ 达到等级阈值
→ 触发三选一
```

经验宝石由 `Assets/Scripts/Core/ExpGemManager.cs` 管理，支持：

- 世界坐标生成；
- 飞向经验条右端；
- 多颗宝石同时飞行时自动加速；
- 智慧提高最终经验；
- 新对局清理所有飞行中的宝石。

## 5.2 击杀里程碑奖励

代码支持三种奖励：

| 类型 | 当前状态 |
|---|---|
| Coin | 已实现，增加本局铜钱 |
| Heal | 已实现，回复玩家生命，不超过最大生命 |
| RandomUpgrade | 未实现，仅输出日志占位 |

每个里程碑由击杀阈值和奖励列表组成，可以一个阈值同时配置多种奖励。

### 已配置资产中的示例

| StageConfig | 里程碑 | 通关铜钱 |
|---|---|---:|
| `Assets/Resources/StageConfigs/Stage_1.asset` | 5击杀+30；20击杀+50；50击杀+100 | 247 |
| `Assets/Resources/StageConfigs/testStage.asset` | 5击杀+30；10击杀回血20；20击杀+50并回血25；35击杀回血40；50击杀+100 | 100 |
| FakeStage01当前战斗资产 | 未配置击杀里程碑 | 0 |

## 5.3 连击系统

连击由 `Assets/Scripts/Core/ComboManager.cs` 管理。

当前配置：

| 项目 | 当前值 |
|---|---|
| 计数方式 | 每个被命中的敌人计数 |
| 同帧重复命中 | 同一敌人同一帧只计一次 |
| 基础断连时间 | 3秒 |
| 当前阈值 | 20连击 |
| 当前Buff | `combo_damage` |
| 当前效果 | 伤害乘以1.1，即提升10% |

连击窗口会随着连击数提高而缩短：

| 连击区间 | 断连时间 |
|---|---:|
| 1–9 | 3.0秒 |
| 10–19 | 2.5秒 |
| 20–29 | 2.0秒 |
| 30–39 | 1.7秒 |
| 40以上 | 1.5秒 |

断连后：

- 连击归零；
- 当前连击Buff移除；
- 已触发阈值清空；
- 再次达到阈值可以重新触发。

海浪、旋风等控制技能如果对敌人产生有效命中/控制判定，也可以参与连击。

## 5.4 普通敌人掉落

### V1

V1规则下，普通敌人可以按概率掉落旧式道具，受掉落率加成影响，道具栏满时进入弃置流程。

### V2

当前Battle场景为V2，因此：

- 普通敌人跳过旧式道具掉落；
- 主动技能通过经验三选一获得；
- Boss奖励通过Boss三选一获得；
- 旧式药水和敌人道具掉落不作为当前V2核心奖励。

## 5.5 Boss奖励

当前Boss死亡流程：

```text
Boss死亡
→ 播放死亡动画
→ 生成Boss包子
→ 包子飞向玩家
→ 玩家回复生命
→ 触发Boss三选一
→ 等待选择结束
→ 允许波次/节点继续推进
```

当前Boss包子：

- 默认回复20点生命；
- 以屏幕空间飞行到玩家；
- 到达后调用玩家回血。

V2 Boss三选一：

- 从主动技能池中收集候选；
- 主要使用Rare和Legendary候选；
- 普通敌人不会触发同样的Boss奖励流程；
- 奖励弹窗、弃置弹窗和经验宝石收集结束前，路线不会继续推进。

## 5.6 铜钱

铜钱来源：

1. 击杀敌人：读取敌人的 `coinReward`；
2. Stage通关：读取 `StageConfig.clearCoinReward`；
3. Fake Route最终结算：读取路线Stage的 `clearCoinReward`。

铜钱流程：

```text击杀/通关获得本局铜钱
→ Battle UI显示
→ 通关或返回主菜单时结算到存档
```

重新开始和强退不会正常结算本局铜钱。

# 7. 当前局内循环

```text
输入点击/滑动
→ Stab / Slash / Pierce / Sweep / Launch / Parry
→ 伤害、架势、击退、浮空、打断
→ 敌人死亡
→ 铜钱 + 经验宝石 + 大招能量
→ 连击增长并触发Buff
→ 经验达到阈值
→ 三选一构建主动/被动Build
→ 推进波次或进入Boss战
→ Boss死亡后包子回血 + Boss三选一
→ 等待奖励流程结束
→ 路线选择
→ 进入下一个节点
```

当前局内成长的主要方向：

- 基础攻击流：疾风、拔苗助长与基础攻击；
- 蓄力流：铁壁、震荡、冲击波与蓄力攻击；
- 位移流：专注、海浪、旋风、Launch和Parry；
- 火系协同：蛇形喷射 + 火龙舌；
- 疾病流：染病 + Stab。

# 8. 需要继续确认的边界
