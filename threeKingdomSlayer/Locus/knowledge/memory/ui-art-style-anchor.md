## 2.1 项目里其实有**两套 UI 语言**，别混

| | 落地页 / 菜单（hub V9） | 战斗 HUD |
|---|---|---|
| 承托 | 手绘**笔刷**破边（实测主色：朱红笔刷 `#9A0101`、紫墨笔刷 `#221A27`、暗铜框 `#201B18`–`#27211D`） | 平面近黑块面（`#1A1A1E` / `#0C0D10`） |
| 描边 | 旧铜 / 描金 | **米白细描边** `#F2EDE0` / `#E8E4DC` |
| 质感 | 绘画笔触、有破边与软光 | **零材质、零笔刷、零渐变** |
| 用词 | 「笔刷」「铜铁包边」「暖金亮光」 | 「简洁白边」「令牌」「平面近黑」 |

**关键**：
- 「**简洁白边**」＝ 战斗 HUD 那一套（近黑 + 米白细描边），**不是**落地页的笔刷铜牌。
- 天赋页是从**落地页**进的（`HubTalentEntry` → `TalentTree` 场景），但用户指定它走「简洁白边」→
  所以**以 HUD 令牌为准**，落地页笔刷语言不套用。
- 想给生图当「材质锚」时，**直接用已部署的实物**（如 `hud_slot_token.png`）比用概念图准得多。
  实物板也避免了概念图里那些厚重金属/笔刷把模型带偏。

## 3. 战斗界面元素密度

- 战斗 HUD 的令牌是 **62×96 的小图标容器**（技能槽），**不是面板底座**；
- 战斗画面里一个 UI 元素只允许「一块近黑 + 一圈米白」；
- 落地页全页只有 6 个 UI 元素，只有 1 个强对比主按钮；
  天赋页是从落地页点进去的**覆盖层**，视觉权重应低于落地页，不是高于。

## 4. 生图后必做的校准

把生成的 UI 元素与项目 UI 实物**并排放大比对**：描边宽度（px）、描边亮度、色值必须落在 §2 那一档。
不达标就调提示词重来 —— 不要靠"看起来还行"放行。

## 5. 生图接口的两个坑（2026-11-02 踩到）

1. **图片 CDN 可能不可达** —— `img.huaruics.com`（154.44.9.199）从本机 TCP 443/80 全超时，
   而 `api.muskapis.com` 正常。接口默认返回 `url`，下不到图。
   → **每次都带 `response_format: b64_json`**，让接口直接回 base64，绕开 CDN。
2. **先落盘响应 JSON，再下载图片** —— 反过来会在下载失败时把 url 一起丢掉
   （2026-11-02 因此白丢一次付费生成）。
   另：把「三个令牌并排」当锚图时，横排本身会暗示「三列」，
   导致模型把节点树排成三条竖链 —— 锚图改成**单个元素**。
