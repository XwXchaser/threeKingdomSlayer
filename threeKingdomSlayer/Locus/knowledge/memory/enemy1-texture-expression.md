# Enemy1 面部表现约束

用户最终明确选择 **“立体脸＋专用表情贴图”**：脸、眼窝、鼻部、脸颊和下颌需要合理的立体结构；眼睛、眉毛及嘴部表情使用为该模型绘制的专用 UV 贴图，不使用独立浮起的眼球/眉毛或表情骨骼。后续表情变化可考虑图集帧切换。

用户说“五官不应该直接用贴图”后，经澄清选择保留眼睛贴图方案，并非要求全部实体五官。禁止直接裁切概念图整张脸贴到头部，否则会把参考图的头盔、衣领、透视和光影一起烘进脸上。v03 曾出现这种错误；v04 虽改用专用表情图，但脸颊外挂块、鼻子及整体造型仍不合格，不能作为正确实现范例。

适用当前 Enemy1 模型实验；正式 Prefab 未获替换授权。静态造型通过后再推进绑定和动作。
