# 照参考图搭场景 · 标准流程（2026-10-24 定）

> 目的：把「读图 → 摆位 → 落地」变成**可重复的流程** ✅，不是每次从零理解一遍 ✅。
> 核心分工（用户口径 ✅）：**参考图给位置关系** ✅，**米制靠游戏自身** ✅，**部署靠脚本** ✅。
> 已跑通的样例：N3 村落 ✅（`memory/n3-reference-element-map.md` ✅）。

## 六步流程

| 步 | 做什么 | 产出落在哪 | 工具 |
|---|---|---|---|
| ① **读图** | 列出画面里的元素 + 各自**位置关系**（左/右、前/后、相对大小 ✅） | 元素清单（写进 ④ 的表里 ✅ 或单独 md ✅） | 人/AI 读图 ✅（手绘 2.5D **不要反算米数** ✅） |
| ② **对素材** | 每个元素映射到**该节点自己的素材集** ✅；**缺素材 → 记进缺口清单** ✅（不生成 ✅、不借用别处素材 ✅） | 表里的 `skipped[]` ✅ | `Art/<节点>/…` ✅ |
| ③ **定标尺** | 该段街道的宽度 / 元素的世界尺寸（**从既有内容与地形贴图推** ✅，不是从画里量 ✅） | 表里 `origin` + 各条目的米制坐标 ✅ | `slice_manifest.json` 里有**世界尺寸** ✅（例：H1 宽 9.17m ✅） |
| ④ **写摆放表** | 一条 = 元素 + 素材 + 坐标 + 缩放 ✅；层名 = 分组 ✅；`skipped` = 缺口 ✅ | `Authoring/Placement/{名字}.json` ✅ | 手写/生成 ✅ |
| ⑤ **生成** | 表 → 规格 → prefab；**逐件比对必须 0** ✅ | `Assets/RouteData/YSceneSpecs/{名字}.asset` ✅ + prefab ✅ | `Tools/Y 场景规格/⑥ 节点 prefab 生产` ✅ ／⑧ 全段表化 ✅ |
| ⑥ **验收** | **街景机位渲染 vs 参考图**（并排 ✅，人眼判位置关系 ✅）+ 逐件比对 0 ✅ | `Library/Locus/tmp/segment_compare/` ✅ | ⑦ 预览段 prefab ✅（编辑器里按游戏位姿摆出来看 ✅） |

**⑦ 缺口怎么处置**：看视觉效果再决定 ✅ —— 要补就**照本节点画风生成**素材 ✅（项目有 gpt-image 流程 ✅ + 切片流程 ✅）；
不补就**留在 `skipped` 里** ✅（记录在案 ✅，下个节点不用重新发现一遍 ✅）。

## 规矩（踩过的坑 ✅）

1. **只用该节点自己的素材集** ✅ —— 拿别的节点的素材顶上去 = 越界 ✅（2026-10-24 犯过 ✅：望楼/营门/军帐/破车/断旗/木栅取自 `Architecture/` 与 `Props/N1/` ✅ → 已撤 ✅）。
2. **手绘 2.5D 参考图只给位置关系** ✅ —— 超广角低机位 ✅、近处占画面一半 ✅、主体压在灭点附近 ✅ → **反算米数不可信** ✅。
3. **米制用游戏自己的** ✅ —— 街道宽度按地形贴图 ✅、元素世界尺寸按 `slice_manifest.json` ✅。
4. **表是唯一来源** ✅ —— prefab 是生成物 ✅；同一内容**不留第二份** ✅（手摆副本 = 第二个事实来源 ✅）。
5. **不激活的旧残留不进表** ✅（运行时本来就不激活 ✅ —— 见 `memory/y-junction-scene-legacy-inventory.md` ✅）。
6. **非本节点素材要单列一层并写明** ✅（例：`Existing Vegetation (NOT N3 art - kept from accepted build)` ✅）→ 不想要整层删掉即可 ✅。

## 表的字段（摆放表 v2 ✅）

```jsonc
{
  "nodeId": "N3", "space": "local",           // local = 相对父容器的局部坐标 ✅
  "origin": [0,0,0], "rootRotation": [0,0,0], // 节点根在场景里的位姿 ✅（段 prefab 靠它 ✅）
  "skipped": [                                 // 缺口清单 ✅（读图读到、素材没有的 ✅）
    { "element": "近左旗杆（红旗）", "reason": "N3 素材集里没有旗杆",
      "note": "画面最左缘、房前；补素材时放在 x≈-5.6 / z≈13" }
  ],
  "items": [                                   // 一条 = 一个物件 ✅
    { "id": "N3_House_Left_Long_Near", "layer": "Street Houses (read from reference)",
      "kind": "sprite", "spriteName": "N3_H2_LongHouse_v1", "asset": "<资产路径>",
      "material": "YSampleScenery_E0Route", "materialPath": "<材质路径>",
      "at": [-5.6, -0.02, 14.0], "rotation": [0,0,0], "scale": [0.85,0.85,0.85], "sortingOrder": 0 }
  ]
}
```

`kind` = `sprite` ✅ / `mesh` ✅ / `group` ✅（只带变换的容器 ✅）。
`at` 是**相对父容器**的局部坐标 ✅（`layer` 决定父容器 ✅）—— 局部值才精确 ✅（世界换算会引入 ~1e-5 误差 ✅）。

## 验收怎么算过 ✅

| 判据 | 口径 |
|---|---|
| 数据 | 逐件比对 **0** ✅（位置/旋转/缩放/精灵/网格/材质/sortingOrder ✅） |
| 画面 | 街景机位渲染与参考图并排 ✅ → **位置关系**对不对 ✅（比例可后调 ✅） |
| 缺口 | `skipped` 逐条有交代 ✅（素材缺 ✅ / 非本节点素材 ✅） |
