# 局内属性词表：经验升级"加什么"（草案）

> **状态：草案 / 未确认。** 本文件只定义"升级能加什么"，**不含数值、不含张数上限、不含抽取权重**。
> 用途：作为经验升级属性池的内容底稿；定稿前需与武器、暗源、饰品三条线咬合。
> 边界口径（本轮用户确认）：**只做纯增益，不做「加 A 减 B」的代价卡**。

## 1. 三条来源线与属性边界

| 来源 | 触发 | 占槽 | 叠加 | 改变什么 | 结束 |
|---|---|---|---|---|---|
| **属性** | 经验升级 | 不占 | 可叠（有软上限） | **纯数值** | 本局清除 |
| **影之武装** | 精英 / Boss 宝箱 | 主动槽 | 不叠，替换 | 打法（主动释放） | 本局清除（解锁资格保留） |
| **饰品** | 精英 / Boss 宝箱 | 被动槽 | 不叠，替换 | 规则（条件 / 触发 / 转化） | 本局清除（解锁资格保留） |

判定原则：

1. **属性只做连续量**——能按百分比或固定值累加的东西；不能描述成"一条规则"。
2. **规则留给装备**——条件乘区、触发条件、传播、破盾、反弹、转化，一律不进属性池。
3. 属性不创造新的操作方式，只放大已有操作（窗口、速度、伤害、生存）。
4. **一张卡只改一个属性**，便于玩家比较，也便于上限与软锁管理。
5. 纯增益下"减"只有三种语义：减受伤、减冷却、减耗能，全部是正面效果。

### 1.1 明确不进属性池

| 内容 | 归属 | 理由 |
|---|---|---|
| 主动 / 被动 / 道具槽位、复活次数、不屈、三选一选项数 | 局外天赋 | 改结构而非数值，且属于跨局成长 |
| 铜钱获取 | 局外经济 | 放局内会鼓励刷钱而不是战斗 |
| 减敌人防御 | 饰品（嵌伤护符） | 需要敌方减伤口径，属于规则 |
| 死亡传播、破盾、反伤、弹反、条件增伤 | 饰品 / 影之武装 | 机制，不是连续量 |
| 主武器招式与连招 | 局外（主武器成长） | 连招不进局内三选一 |

## 3. 现状对照

现有局内属性词表由 `Assets/Scripts/Data/UpgradeStatIds.cs` 单一真源定义，共 **14 条**：

`max_health` / `damage_reduction` / `guard_break_threshold` / `attack_power` / `damage_percent` /
`attack_speed` / `crit_rate` / `crit_damage` / `attack_range` / `cooldown_reduction` /
`exp_bonus` / `item_drop_rate` / `item_damage_bonus` / `charge_damage_reduction`

局外天赋另有一套 12 条（`TalentStatService`）：复活次数、道具槽、主动槽、被动槽、架势伤害、
击杀后攻击 CD、三选一选项数、铜钱获取、连击阈值、不屈、升级等级上限、生命上限。

**两套词表只有 `max_health` 一条重合。**

缺口（本词表要补的维度）：移动、资源（暗源）、影之武装、持续伤害、操作（窗口 / 蓄力）、位移强度。

## 4. 三个结构问题（定稿前必须处理）

### 4.1 `attack_range` 被三张卡共用

`StabRangeBoost` / `SweepRangeBoost` / `Bamiaozhuzhang` 三个资产都写 `statId = attack_range`，
实际效果完全相同 ⇒ 玩家分不清"突刺射程"与"横扫射程"。
需二选一：拆成按招式的射程，或合并成一张通用"射程"卡。

### 4.2 两套属性词表并存

局内 14 条、局外 12 条，各写各的。必须决定：
**共用一套词表**（便于统一数值出口，但需处理局内 / 局外同条属性的叠加），
还是**两套并行**（需明确规定同条属性同时出现时是加法还是乘算）。

### 4.3 属性卡的可叠性与实例模型

目标要求"可叠加、有软上限"，但当前 `_appliedUpgrades` 是 `Dictionary<upgradeId, int>`
⇒ 同一 id 只能有一个等级，**同一张卡抽两次不能独立持有**。
这是"可叠"落地的实现前提（卡片实例模型见 `design/weapon-system-design.md` §7）。

## 5. 待定

1. 每条的初始张数上限与局外抬升幅度（数值设计）。
2. 每条属性同时来自属性卡与饰品时的叠加口径（加法 / 乘算 / 取高）。
3. 脱战回复、控制概率两条是否进入首版池。
4. 架势伤害是否下放局内（现为局外专用）。
5. 词表条目与现有 36 个 `UpgradeDefinition` 资产的对应关系：复用、改名还是重建。

## 6. 与武器、暗源的耦合（后续必读）

- **武器决定命中次数**：双刀"一次攻击两段"、弓"一箭穿透多排"，都会改变每次命中的暗源收益
  （当前为命中 +1、击杀 +3）。⇒ 武器规格与暗源数值必须一起定，不能先定武器再补暗源。
- **属性不能绕开武器手感**：攻速对双刀是挥砍间隔、对弓是拉弓时间，同一属性在不同武器上语义不同，
  描述文案与数值尺度需按武器区分。

## 附：本轮同时确认、待并入武器设计文档的口径

- 属性卡只做纯增益（本文件 §1 已采用）。
- **双刀**：攻击频率快，每次攻击打两下，**两段独立结算**（各自判暴击、各给一次暗源与连击）。
- **弓**：蓄力**两者结合**——1/2/3 级按倍率放大伤害，最高级额外换成穿透箭。

以上三条为已确认方向；具体招式表、数值与动作素材尚未设计。
