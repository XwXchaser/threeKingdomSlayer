# v2-system-understanding

## Summary
V2 版本系统理解文档：记录玩家与敌人的全部能力、主动技能与被动技能差异、三选一流程、池结构、Build 流派设计、5 级数值重设计。在理解变化时持续更新。完整数值方案见 design/numerical-balance-draft.md。

# V2 版本系统理解

## 版本开关

`ActiveSkillInventory._ruleVersion`（`ItemRuleVersion` 枚举）在 Battle 场景 Inspector 上设置：
- `V1_LimitedItem`：消耗品道具、血量药水、敌人道具掉落
- `V2_ActiveSkill`：冷却制主动技能、无药水、无敌方道具掉落

V2 关键变化：
- 道具栏从 `ItemInventory`（消耗品）变为 `ActiveSkillInventory`（永久冷却技能）
- `HealthPotionManager` 禁用
- `EnemyManager.TryDropItem()` 跳过
- Boss 掉落从道具池切到 `ActiveSkillPoolConfig`（仅 rare/legendary）
- 升级三选一合并 `UpgradePoolConfig` + `ActiveSkillPoolConfig`

## 零、V2 数值重设计目标（用户定义）

### 0.1 核心愿景

为玩家提供完整的 **~30 分钟** 关卡体验，通过技能 build 选择形成差异化玩法，敌人强度随波次平滑递增。

### 0.2 设计目标

#### 一、技能池净化
- 移除纯数值被动（神力）——避免数值依赖，鼓励机制选择
- 移除 V1 道具依赖技能（谋略/捡漏/敛财/连刺）
- 同一技能不共存被动版+主动版——三选一中不应出现同名混淆
- 定时被动（自动释放）与主动（手动释放）冲突的技能，保留主动版
- 测试资产不入池

#### 二、Build 流派设计
玩家在三选一中逐步构建两个差异化流派：

| 流派 | 核心思路 | 标志技能 |
|------|---------|---------|
| **位移流** | 击退+浮空控场，主动技能快速循环 | 海浪、旋风、专注 |
| **蓄力流** | 蓄力减伤→累积→爆发 | 铁壁、冲击波(赋予下次)、震荡 |

火系协同（蛇形烈焰灼烧→火龙舌暴击）作为跨流派通用选项。

#### 三、等级压缩
- 10 级技能 → 5 级（每级提升翻倍，关键节点 Lv3/Lv5 有质变）
- 机制类/范围类 → 2-3 级（Rare 稀有度，每级大跳跃）
- 纯数值类 → 移除（神力）或严格控幅（疾风 10%/级、智慧 8-12%/级）

#### 四、体验节奏目标
**核心原则：30 分钟内无超过 2 波（~4 分钟）的升级真空期，玩家全程感知到阶梯式成长。**

| 阶段 | 波次 | 节奏目标 | 描述 |
|------|------|---------|------|
| **开局** | 波 1-3 | 高频成长 | 每 20-30 秒一次升级，快速填满前 4-5 个被动槽。玩家在短时间内体验多次选择，感受 build 雏形建立 |
| **中盘** | 波 4-9 | 稳定填充 | 每 30-45 秒一次升级。开始获得主动技能（含 Boss 掉落），升级关键技能等级，build 方向明朗 |
| **终盘** | 波 10-15 | 收束冲刺 | 每 45-60 秒一次升级。技能趋近满级，Legendary 旋风由 Boss 掉落，满级后出现「回复 20 点 HP」选项 |

**节奏保障原则：**
- 击败一整波敌人应稳定获得 **至少 1 次** 升级（不可出现打完一波毫无成长的挫败）
- 智慧（经验加成）应加速升级但不应失控——全满智慧比无智慧最多提前 3-4 波满级
- 满级后不意味着停止成长——「回复 HP」提供生存续航，Boss 掉落提供最后一块 legend 拼图
- 经验曲线不应是简单的线性或指数，应是 **阶梯式放缓**：前期每级需求低（鼓励快速成型）、中期平稳（持续填充）、后期走高（让终盘 skill cap 有成就感）

**升级总次数计算：**
- 玩家持有 6 被动 + 4 主动 = 10 个技能
- 按 4 个 5 级被动 + 2 个 2 级被动 = 24 次被动升级
- 按 3 个 5 级主动 + 1 个 3 级主动 = 18 次主动升级
- **合计约需 42 次升级机会**
- ⚠️ **当前方案 B 的 Lv15 上限（15 次升级）严重不足，需重新设计等级上限至约 Lv45-50**

#### 五、主动/被动定位
- **主动技能**：强力、长 CD（10-20s）、手动释放的爆发招式
- **被动技能**：偏弱、短 CD/常驻、自动生效的持续辅助
- **专注被动**：百分比减少主动 CD，串联位移流快速循环

#### 六、Boss 战斗设计目标

**核心原则：每次 Boss 战（波 3/6/9/12/15）维持在 45-90 秒，玩家构筑合理时不会超过 2 分钟，构筑差时不应低于 30 秒。**

**血量标尺：**
- Boss 血量 = 该波次玩家预期 DPS × 目标时长（60-75 秒中位值）
- 需按玩家持有不同等级的神力/疾风计算 DPS 区间，取中位数 build 作为基准
- Boss 血量随波次递增：不仅要跟上敌人 multiplier，还要单独有 BossHP 乘区（因 Boss 已经是独立 prefab 104，可直接改 prefab 或通过 WaveConfig 覆盖）

**阶段机制：**
- 当前已有 `BossPhaseData` 系统（`triggerHealthPercent` 锁血转阶段），应被充分利用
- 每个 Boss 波应有 **3 个阶段**（100%→66%→33% 血量触发）：
  - **阶段 1（100-66%）**：基础攻击模式，给玩家适应窗口
  - **阶段 2（66-33%）**：新增 1 个 C 技或远程技能，攻击频率提升，霸体帧增多
  - **阶段 3（33-0%）**：狂暴——攻击速度 +50%，SuperArmor 常驻（仅 Parry 可打断），架势回复加速
- 转阶段演出：0.5 秒无敌 + 红色脉冲描边 + 强制击退周围敌人（清出空间）

**QTE 节奏：**
- 每次 Boss 战应出现 **1-2 次 QTE**，作为高风险高回报的破局点
- QTE 成功 → 削大量架势 + 眩晕 + 伤害窗口
- QTE 失败 → Boss 恢复架势 + 短暂攻击加速
- QTE 权重随阶段提升：阶段 1 低概率，阶段 2 中概率，阶段 3 高概率（作为玩家绝地反击机会）

**架势-眩晕循环：**
- Boss 架势值应设计为：构筑合理的玩家在 **2-3 次 Parry** 后破架势
- 眩晕时长随波次递增：波 3 = 2s，波 6 = 2.5s，波 9 = 3s，波 12 = 3.5s，波 15 = 4s
- 眩晕期间玩家可安全输出（无风险窗口），是 DPS 爆发时机
- 眩晕结束后架势重置为满值，但 Boss 进入 2 秒易伤期（受伤 ×1.3）

**Boss 掉落：**
- Boss 死亡必定掉落三选一（稀有度 Rare 起步），候选来自 `ActiveSkillPoolConfig`
- 波 3 Boss：保证出现第 1 个 Rare 主动
- 波 6/9 Boss：可能出 Legendary 旋风
- 波 12/15 Boss：Legendary 权重翻倍，作为终盘奖励

**数值验证方法：**
- 用"标杆 build"反算：假设玩家在波 N 拥有 [神力 LvX, 疾风 LvY, Stab 伤害 = Z]，计算对 Boss 的 DPS
- Boss 血量 = DPS × 65 秒（中位值）
- 若计算得出 Boss 血量 > 当前 prefab 104 的合理范围，则需调整 Boss 自身数值或增加 Boss 专属 multiplier

## 一、玩家能力

### 1.1 基础攻击（6 种）

| 攻击 | 目标 | 特殊行为 |
|------|------|---------|
| Stab（戳击） | 单列穿透 | 击退波；受 stab_range_boost 延长 |
| Slash（斩击） | 横扫范围 | 方向性侧推；受 sweep_range_boost 扩大 |
| Pierce（穿刺） | 单列全排 | AttackWave；附带蓄力冲击波 |
| Sweep（横扫） | 全范围 | AttackWave；附带蓄力冲击波 |
| Launch（挑飞） | 全范围 | 削韧+浮空；30%概率眩晕抵抗敌人 |
| Parry（招架） | 近距弹反/全范围 | 双模式：弹反飞行物 或 范围伤害+削韧 |

伤害计算：`cfg.damage * UpgradeEffectManager.GetDamageMultiplier()`，再扣减拔苗助长副作用惩罚。

### 1.2 被动升级（三类）

#### Numeric（数值型）
永久累加器。获取时递增，升级时再次递增。

| 效果 | 查询方法 |
|------|---------|
| 神力（damage_multiplier） | `GetDamageMultiplier()` |
| 疾风（attack_speed） | `GetAttackSpeedMultiplier()` |
| 延长（stab_range_boost） | `GetStabRangeBonus()` + 伤害惩罚 |
| 波长（sweep_range_boost） | `GetSweepRangeBonus()` + 伤害惩罚 |
| 铁壁（charge_damage_reduction） | `GetChargeDamageReduction()` |
| 反伤（charge_reflect_shield） | `AbsorbDamage()` 状态机 |
| 地刺（spike_trap） | 委托 `SpikeTrapController` |
| 智慧（exp_multiplier） | `GetExpMultiplier()` |
| 谋略（item_damage_bonus） | `GetItemDamageBonus()` |
| 捡漏（item_drop_rate） | `GetItemDropRateBonus()` |
| 敛财（on_kill_chance） | 击杀概率掉落 |
| 震荡（charge_hit_shockwave） | `ConsumeChargeHitShockwave()` |

#### AttackPassive（攻击计数触发）
`PassiveTriggerModule` 监听 `AttackSystem.OnAttackPerformed`。每个被动独立计数，达到阈值触发效果并复位。

| 效果 | 行为 |
|------|------|
| 虚幻武器（passive_phantom_weapon） | 按 phantomLevels 配置执行多步幻影攻击 |
| 回旋波（passive_return_wave） | 折返冲击波，往返各命中一次 |
| 连锁弹射（passive_chain_bounce） | 弹射冲击波，最多 N 次弹射 |
| 箭矢齐射（passive_arrow_volley） | 向最近 N 个敌人发射追踪箭 |

#### TimedPassive（定时触发）
`TimedPassiveModule` 在 Update 中倒计时，归零时触发效果并重置。

| 效果 | 行为 |
|------|------|
| 烈焰喷射（passive_timed_aoe） | 对指定列喷火 |
| 箭雨（passive_timed_arrow） | 对 N 排发射箭雨 |
| 旋风（passive_timed_cyclone） | 随机挑 N 个敌人浮空 |
| 冲击波（charge_shockwave） | **队列型**：累积层数，蓄力攻击时一次性释放 |

### 1.3 主动技能（V2 独有）

通过 `ActiveSkillInventory` 管理，`ActiveSkillRunner` 执行。

**获取**：三选一升级弹出（合并自 `ActiveSkillPoolConfig`）或 Boss 掉落（仅 rare/legendary）。
**槽位**：`HeroConfig.itemSlotCount`（默认 2）。
**升级**：再次选到同一技能 +1 级，刷新 CD 配置。
**激活**：点击 HUD 槽位 → 检查 CD、timeScale、对话锁定 → 执行效果。

| 技能 | 效果 |
|------|------|
| 烈焰喷射（FireAoe） | 对指定列喷火，读 timedAoeLevels |
| 箭雨（ArrowRain） | 对 N 排发射箭雨，读 timedArrowLevels |
| 旋风（Cyclone） | 随机挑 N 个可浮空敌人浮空，读 cycloneLevels |

## 二、敌人能力

### 2.1 设计哲学（机制教学递进）

V2 关卡使用 6 种非 Boss 敌人 + Boss 变体，按机制复杂度递进引入：

| 引入顺序 | 敌人 | 机制教学 | 设计定位 |
|---------|------|---------|---------|
| 1 | **101** 持剑杂兵 | 基础战斗 | 最简割草单位，让玩家熟悉 Stab/Slash/Pierce 等基础攻击 |
| 2 | **103** 长枪兵 | **霸体（C技）** | 引入 SuperArmor 概念——红色描边=不可打断，教会玩家识别并闪避/Parry |
| 3 | **106** 固定落点弓 | **远程 + Parry 弹反** | 后方冷箭，落点固定可预测。教会玩家用 Parry 格挡飞行物 |
| 4 | **105** 随机落点弓 | **远程（进阶）** | 与 106 本质相同但落点随机散布，更难预测。血量更低(8)作为平衡 |
| 5 | **104/107/108** Boss | **全部机制综合 + QTE** | 霸体+远程+多阶段+QTE，是对玩家掌握所有机制的终极检验 |

**教学节奏**：前 4 波应逐步引入 101→103→106→105，让玩家在 Boss 战（波 3）之前已见过所有基础机制。Boss 则是这些机制的组合体。

### 2.2 敌人详细数据

| 敌人 | HP | 伤害 | 攻速 | 移速 | 射程 | 占据 | 特殊 |
|------|-----|------|------|------|------|------|------|
| **101** 持剑杂兵 | 16 | 10 | 0.08 | 0.3 | 1 | 1 | 普攻，无 C 技 |
| **103** 长枪兵 | 30 | 15 | 0.2 | 0.2 | 1 | 1 | CAttack 霸体，动画 "CAttack" |
| **105** 随机弓 | 8 | 5 | 0.3 | 0.2 | 3 | 1 | 远程，落点随机散布 |
| **106** 固定弓 | 16 | 5 | 0.3 | 0.2 | 3 | 1 | 远程，落点按列固定 |
| **104** Boss | 500 | 10 | 0.2 | 0.3 | 2 | 5 | 3 阶段 + QTE + 霸体 |
| **107** Boss(W3) | 500 | 10 | 0.2 | 0.3 | 2 | 5 | 1 阶段，无霸体 |
| **108** Boss(W6) | 500 | 10 | 0.2 | 0.3 | 2 | 5 | 2 阶段，Phase2 起霸体 |

### 2.3 状态
`Idle → Moving → Attacking → Stunned / Launched / Dead`
Boss 额外：`BossState { None, Approaching, InCombat }`，`QTEAttacking`。

### 2.4 攻击
- 循环 `attackSequence`（多步攻击链）
- C 技含霸体帧（红色描边）
- 远程敌人发射 `EnemyProjectile` 飞行物
- Boss 有多阶段系统（`BossPhaseData`），血量阈值切换

### 2.5 V2 差异
敌人行为与 V1 完全相同，仅 `EnemyManager.TryDropItem()` 在 V2 下跳过普通掉落。

## 三、三选一流程

1. 触发：`PlayerState.OnLevelUp`（等级事件）或 Boss 死亡
2. 暂停：`Time.timeScale = 0`
3. 抽卡：
   - 按稀有度权重（0.80 / 0.15 / 0.05）滚动
   - 过滤：已满级、未满足前置条件的排除
   - V2：合并 `UpgradePoolConfig` + `ActiveSkillPoolConfig`
4. 展示：`UpgradeChoicePopup`（3 张卡）
5. 确认：首次选中 → 再次点击同卡确认
6. 应用：`UpgradeEffectManager.ApplyUpgrade()`
7. 恢复：`Time.timeScale = 1`

## 五、主动技能 vs 被动技能

| 维度 | 主动技能 | 被动技能 |
|------|---------|---------|
| 触发 | 玩家手动点击 HUD 按钮 | 自动（攻击计数/定时） |
| 冷却 | 独立 CD（秒），随等级降低 | 无 CD，按 interval 间隔自动触发 |
| 槽位 | 受 slotCount 限制（默认 2 个） | 无数量限制 |
| 获取 | 三选一 / Boss 掉落 | 三选一 |
| 升级 | 再次选中 +1 级，刷新 CD | 再次选中 +1 级，刷新阈值/间隔 |
| 暂停行为 | 暂停/QTE/对话期间锁定不可用 | TimedPassive 继续运行；AttackPassive 因攻击暂停自然停止 |

关键差异：主动技能提供"爆发窗口"——玩家在正确时机手动释放获得高收益；被动技能提供"稳定输出"——自动生效、积少成多。

- 部分技能不适合 10 级长线成长（如机制类技能），每级提升感被稀释

- 例如：原来平缓的 3→6→10 关键节点，压缩为更少但更显著的阶段

### 6.5 技能角色分类

按技能在战斗中的功能角色分组，同一组技能互斥或互补，影响池设计和玩家 build 路线。

#### 一、核心数值型（Common，适合早入池）

提供稳定的全局加成，无触发条件，选到即生效。是 build 的「骨架」。

| 技能 | effectType | 作用 | 设计定位 |
|------|-----------|------|---------|
| **神力** | damage_multiplier | 所有攻击伤害提升 | 通用伤害核心，每级可感知 |
| **疾风** | attack_speed | 攻击速度提升 | DPS 放大器，与神力协同 |
| **智慧** | exp_multiplier | 经验获取提升 | 投资型技能，越早拿越赚 |

特点：纯数值，等级段可以较长（5 级），Common 稀有度，每级提升应在 8-12% 区间。

#### 二、定时 AOE 型（Common/Rare，中盘主力输出）

按固定间隔自动触发范围效果，不依赖玩家操作。是 V2 被动伤害的主要来源。

| 技能 | effectType | 触发 | 设计定位 |
|------|-----------|------|---------|
| **烈焰喷射** | passive_timed_aoe | 定时，指定列喷火 | 稳定单体列输出 |
| **箭雨** | passive_timed_arrow | 定时，多排落箭 | 覆盖多排 |
| **旋风** | passive_timed_cyclone | 定时，随机挑敌人浮空 | 控制+打断 |
| **地刺** | spike_trap | 定时，生成地刺陷阱 | 延迟范围伤害 |

特点：行为类，等级段应短（4-5 级），每级提升应体现在频率↑、范围↑、伤害↑。其中旋风是唯一控制型，适合 Rare。

#### 三、蓄力联动型（Rare，操作奖励）

与玩家蓄力攻击（Pierce/Sweep）绑定的附加效果。需要玩家主动蓄力才能触发，是高操作回报技能。

| 技能 | effectType | 触发条件 | 设计定位 |
|------|-----------|---------|---------|
| **冲击波** | charge_shockwave | 蓄力攻击释放 | 队列累积→一次性爆发 |
| **震荡** | charge_hit_shockwave | 蓄力命中时 | 蓄力击中时附加冲击波 |
| **铁壁** | charge_damage_reduction | 蓄力期间持续生效 | 蓄力时减伤 |
| **反伤** | charge_reflect_shield | 蓄力期间被击中 | 蓄力时吸收伤害并反弹 |

特点：高操作门槛、高回报。等级段应短（5 级），Rare 稀有度。铁壁/反伤是防御向，冲击波/震荡是进攻向。

#### 四、范围改造型（Rare，机制改变）

改变攻击的排数/范围，但有副作用惩罚。是「高风险高回报」的技能。

| 技能 | effectType | 作用 | 惩罚 |
|------|-----------|------|------|
| **延长** | stab_range_boost | Stab 攻击排数 +N | 伤害 -X% |
| **波长** | sweep_range_boost | Sweep 攻击排数 +N | 伤害 -X% |

特点：升级应同时扩大收益（更多排）和减轻惩罚（降低扣减）。等级段短（3 级），Rare。

#### 五、攻击触发型（Rare，AttackPassive）

依赖 `AttackSystem.OnAttackPerformed` 事件计数触发。攻击频率越高，触发越频繁，与疾风强协同。

| 技能 | effectType | 当前状态 |
|------|-----------|---------|
| **箭矢齐射** | passive_arrow_volley | 10 级，per-level 配置，未入池 |
| **虚幻武器** | passive_phantom_weapon | 5 级，弃用 flat 字段 |
| **回旋波** | passive_return_wave | 5 级，弃用 flat 字段 |
| **连锁弹射** | passive_chain_bounce | 5 级，弃用 flat 字段 |

特点：需迁移到 per-level 配置后才能入池。等级段 5 级，适合 Rare。

#### 六、V1 道具依赖型（V2 不适用）

这些技能依赖 V1 的道具掉落系统（药水/道具），V2 下效果为空或极弱。

| 技能 | effectType | V2 状态 |
|------|-----------|---------|
| **谋略** | item_damage_bonus | V2 无道具→无效 |
| **捡漏** | item_drop_rate | V2 无掉落→无效 |
| **敛财** | on_kill_chance | V2 无掉落→无效 |
| **连刺** | unlock_attack | 5 级相同数值+无图标→不可用 |

**结论：此组在 V2 池中应全部排除。**

#### 七、主动技能（Rare/Legendary，爆发窗口）

玩家手动释放，有独立 CD。与被动定时 AOE 形成「被动持续输出 + 主动爆发」的双循环。

| 技能 | 稀有度 | CD 范围 | 设计定位 |
|------|--------|---------|---------|
| **烈焰喷射** | Rare | 12→8s | 低 CD 高频爆发 |
| **箭雨** | Rare | 14→10s | 中 CD 多排覆盖 |
| **旋风** | Legendary | 15→10s | 长 CD 强控+高伤 |

特点：CD 递减是升级主要收益。Legendary 应在 Boss 掉落中独占出现。

#### 分组与池策略总结

| 组 | 技能数 | V2 入池 | 稀有度 | 推荐等级 |
|----|--------|---------|--------|---------|
| 核心数值 | 3 | ✔ 全部 | Common | 5 |
| 定时 AOE | 4 | ✔ 全部 | Common/Rare | 4-5 |
| 蓄力联动 | 4 | ✔ 冲击波/震荡/铁壁 | Rare | 5 |
| 范围改造 | 2 | ✔ 全部 | Rare | 3 |
| 攻击触发 | 4 | ✔ 箭矢齐射（先迁移） | Rare | 5 |
| V1 依赖 | 4 | ✕ 全部排除 | — | — |
| 主动技能 | 3 | ✔ 全部 | Rare/Legendary | 5 |

**入池总数：11-12 被动 + 3 主动 = 14-15 个不同技能。** 满槽（6+4=10）后剩余 4-5 个技能可用于升级而非新获得，配合回复 HP 兜底。

### 6.6 重分级最终建议

核心原则：**机制/行为类技能 → 少等级、高稀有度、大跳跃。纯数值类技能 → 可保留较长等级段但每级应有可感知的提升。**

| 技能 | 建议等级 | 建议稀有度 | 理由 |
|------|---------|-----------|------|
| **冲击波** | 5 | Rare | 蓄力队列机制，关键节点 Lv1→3→5 |
| **震荡** | 5 | Rare | 蓄力命中机制 |
| **旋风** | 3-4 | Rare | 浮空控制，当前数值需重写 |
| **烈焰喷射** | 5 | Common | 定时 AOE |
| **箭雨** | 5 | Common | 定时 AOE |
| **箭矢齐射** | 5 | Rare | 攻击计数 AOE |
| **地刺** | 5 | Common | 机制类，10 级太散 |
| **延长** | 3 | Rare | 排数扩展+惩罚，3 段够用 |
| **波长** | 3 | Rare | 同上 |
| **敛财** | 3 | Rare | 概率类，需要梯度 |
| **神力** | 5-10 | Common | 纯数值可多级，但要审视总幅度 |
| **疾风** | 5 | Common | 总 +150% 太高，压缩到 5 级+15% 每级=+75% |

主动技能保持 5 级，稀有度不变。

### 6.4 与关卡节奏的关系

30 分钟关中玩家预计获得 ~15-25 次升级。如果池内多数技能是 5 级、少数 3 级：
- 玩家会在中盘开始遇到"选项已满级"的排除，候选范围缩小
- 需要足够多的不同技能（至少 8-10 个入池）避免候选枯竭
- Rare/Legendary 权重 0.15/0.05 搭配 Boss 掉落保证稀有技能在后期出现

此节与第三项（30 分钟关调整）联动，暂不独立决策。

## 八、被动/主动技能削减与转化分析（用户审定版）

### 8.0 设计原则（用户定义）

1. **主动与被动应相辅相成**，形成可辨识的 build 流派（如火系：被动灼烧→主动暴击）
2. **主动技能 = 强力、长 CD 的爆发招式**，玩家在关键时刻手动释放
3. **被动技能 = 偏弱、短 CD / 常驻的辅助效果**，提供持续输出或机制改变
4. **纯数值被动（如神力）不应存在**——会造成数值依赖，不利于 build 多样性
5. **同一技能不应同时存在被动版和主动版**——造成混淆和价值冲突
6. **多维成长原则**：技能升级不应只有伤害数值增加。单纯堆伤害会导致与敌人难度曲线匹配困难、升级感知钝化。每个技能应根据其定位，在以下维度中选择 2-3 个作为升级方向：

| 成长维度 | 说明 | 适用技能类型 |
|---------|------|-------------|
| **冷却/间隔减少** | CD 缩短或触发间隔降低，提升技能释放频率 | 主动技能（CD）、TimedPassive（interval） |
| **范围扩大** | 影响列数/排数增加，覆盖更多敌人 | 定时 AOE、主动爆发 |
| **伤害增加** | 基础伤害值提升（温和，非主要维度） | 所有技能 |
| **DoT/持续效果** | 新增或增强灼烧等持续伤害 | 火系、控制型 |
| **机制解锁** | 在某等级解锁新行为（如暴击条件、落地伤害） | Legendary、蓄力联动 |
| **控制时长延长** | 眩晕/浮空/击退持续帧数增加 | 旋风、海浪 |
| **叠加/层数增加** | 可累积的充能层数提升 | 冲击波、震荡 |
| **惩罚减轻** | 范围扩大类技能的副作用（伤害扣减）减轻 | 延长、波长 |

**每级应有可感知的变化**：如果某级只有 +5% 伤害，玩家在战斗中无法感知该升级的价值。升级应在至少一个维度上产生玩家可察觉的行为变化（即便数值提升温和，配合 CD 缩短/范围扩大也能让玩家感受到质的提升）。

### 8.2 Build 流派设计（用户定义）

V2 版本存在两个核心 build 流派，技能之间通过协同强化各自的玩法风格。

#### 位移流
核心思路：通过击退/浮空控制敌人位置，创造安全输出空间。依赖主动技能高频释放。

| 角色 | 技能 | 类型 | 说明 |
|------|------|------|------|
| 核心主动 | **海浪** | 主动(Rare) | 击退波，每级 +1 影响行范围（共 3 级） |
| 核心主动 | **旋风** | 主动(Legendary) | 浮空控制 |
| 核心被动 | **专注**（新建） | 被动(Common) | 减少主动技能 CD，实现快速循环 |
| 辅助被动 | 疾风 | 被动 | 更高攻速→更多攻击触发机会 |
| 可选被动 | 拔苗助长 | 被动(Rare) | 攻击范围扩大，远程推人 |

#### 蓄力流
核心思路：依托蓄力攻击（Pierce/Sweep），叠加防御与爆发奖励。

| 角色 | 技能 | 类型 | 说明 |
|------|------|------|------|
| 核心被动 | **铁壁** | 被动(Common) | 蓄力时减伤，保证安全蓄力 |
| 核心被动 | **冲击波** | 被动(Rare) | **改为"赋予下次蓄力攻击"**：累积层数→下次蓄力释放冲击波→消耗后重新累积 |
| 核心被动 | **震荡** | 被动(Rare) | 蓄力命中时附加冲击波（每次蓄力攻击均触发） |
| 辅助被动 | 疾风 | 被动 | 缩短蓄力前摇 |

#### 通用技能（不绑定流派）

| 技能 | 类型 | 说明 |
|------|------|------|
| 智慧 | 被动(Common) | 经验加速，策略投资 |
| 地刺 | 被动(Common) | 持续陷阱，独立伤害 |
| 蛇形烈焰喷射 | 被动(Common) | 短 CD 喷火 + 灼烧 DoT |
| 火龙舌 | 主动(Rare) | 直线火焰，灼烧暴击 200% |
| 箭雨 | 主动(Rare) | 大范围 AOE |
| 虚幻武器 | 主动(Rare) | 幻影爆发（暂不入池） |
| 拔苗助长 | 被动(Rare) | 攻击范围扩大，2 级 |

#### 流派内协同

- **位移流**：专注减 CD → 海浪+旋风快速循环 → 疾风提攻速 → 拔苗助长扩大范围
- **蓄力流**：铁壁减伤 → 安全蓄力 → 冲击波累积层数 → 蓄力攻击时冲击波(消耗)+震荡同时爆发
- **跨流派（火系）**：蛇形烈焰（被动灼烧）→ 火龙舌（主动暴击），不绑定流派

### 8.6 节奏影响

- 9 被动 + 5 主动 = 14 个独特技能
- 被动槽 6 个 → 玩家可拿全部被动后仍有 3 个需升级
- 主动槽 4 个 → 玩家可拿全部主动后仍有 1 个需升级
- **位移流路线**：专注(减CD)→海浪+旋风快速循环，配合疾风+拔苗助长
- **蓄力流路线**：铁壁→冲击波(赋予下次)+震荡，配合疾风
- 火系协同（蛇形烈焰灼烧→火龙舌暴击）不绑定流派，任何 build 可选
- Rare 被动（拔苗助长/冲击波/震荡）自然在中后期出现
- Legendary 旋风通过 Boss 掉落或 Legendary 池 5% 概率
- 专注作为 Common，早期入池让位移流尽早成型

### 8.8 专注（cooldown_reduction）数值设计

设计思路：Common 稀有度，5 级。早期给甜头，中期加速，后期质变。满级时 CD 接近减半，让位移流实现快速循环。

| Lv | 每级 | 累计 | 海浪(10s) | 箭雨(14s) | 旋风(10s) | 火龙舌(20s) |
|----|------|------|-----------|-----------|-----------|-------------|
| 1 | 8% | 8% | 9.2s | 12.9s | 9.2s | 18.4s |
| 2 | 10% | 18% | 8.2s | 11.5s | 8.2s | 16.4s |
| 3 | 10% | 28% | 7.2s | 10.1s | 7.2s | 14.4s |
| 4 | 12% | 40% | 6.0s | 8.4s | 6.0s | 12.0s |
| 5 | 12% | 52% | 4.8s | 6.7s | 4.8s | 9.6s |

节奏：Lv1-2 积累期（~10-18%，体感不明显但铺垫），Lv3 开始可感知（~28%，海浪从 10s→7.2s），Lv4-5 质变（海浪 ~5s 一次=每波可放 2-3 次）。

与位移流协同：满专注下海浪 4.8s + 旋风 8.6s ≈ 交替释放，形成持续的击退+浮空循环。
