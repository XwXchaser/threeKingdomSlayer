# 主武器名单与定位总表（草案）

> **状态：名单与定位已确认，数值与招式细节未定。**
> 本文只记录"有几把武器、每把为什么存在、差异在哪"，不含完整招式表与数值。
> 已确认口径（本轮用户定）：
> - 主武器共 **5 把**：长枪、双刀、弓箭、大刀、单手剑。
> - **不再开发"新特征型"武器**；后续同类扩展走**换皮**与**出招方式变体**，不新增机制。
> - 每把武器有**专属大招**，且**初始架势上限不同**（重武器更稳、双刀最低）。

## 1. 为什么是这五把

五把覆盖了五种互不重叠的玩家决策，剩下的差异用换皮与招式变体解决：

| 武器 | 它回答的问题 | 玩家的核心决策 |
|---|---|---|
| 长枪 | 怎么稳定地打准一个目标 | 接哪条连段 |
| 双刀 | 怎么在最短时间里贴脸打满 | 什么时候冒险贴身 |
| 弓箭 | 怎么在安全距离解决威胁 | 蓄到几级、什么时候放 |
| 大刀 | 怎么用一次决策清掉一片 | 什么时候起手、什么时候放弃 |
| 单手剑 | 怎么把敌人的攻击变成自己的回合 | 防还是招架、什么时候松手反击 |

## 3. 逐把定位

### 3.1 长枪（已实装）

单列精准 + 连段，收尾技才覆盖全列。稳定输出的基准线，也是"武器差异"的对照组。

### 3.2 双刀

攻击频率快，**每次攻击打两下、两段独立结算**（各自判暴击、各给一次暗源与连击）。
代价：架势最低、贴脸才有输出、单体压制强但清场弱。

### 3.3 弓箭

蓄力**两者结合**：1/2/3 级按倍率放大伤害，最高级额外换成穿透箭。
远程主力，但近身无手段；蓄力即站桩。

### 3.4 大刀

劈砍武器，**没有刺**。普攻即为全列劈砍，另有一招**单列劈砍**用于单点（慢、伤害最高）。
蓄力的收益是**削韧**而不是伤害或换招——它是破防/眩晕流的核心。
代价：极慢、单体效率低、容错最低。

### 3.5 单手剑

**以防御为起点的反击武器**：防御吸收伤害后，在防御收招硬直中输入攻击可打出反击。
详见 §4。定位是"把敌人的攻击变成自己的回合"，与招架的"用时机换强收益"形成两种不同的防守流派。

## 4. 单手剑的反击机制

### 4.1 触发链

```text
按住防御 → 吸收伤害（累积破防值）
  → 松开防御 → 进入「防御收招硬直」
  → 硬直中输入攻击 → 触发反击招式（替代普通攻击）
  → 反击：高伤害 + 高削韧 + 起手短暂无敌
```

- **必须实际吸收过伤害**才进入可反击状态；空防不触发（防止"无脑按防御刷反击"）。
- 反击窗口 = 防御收招硬直期间；错过则回到普通出招。
- 防御期间仍在累积破防值 ⇒ 反击机会是用"被破防的风险"换来的。

### 4.2 与招架的区别（两者不能互相替代）

| | 招架 | 防御反击 |
|---|---|---|
| 触发 | 出招窗口内精确格挡 | 防御吸收伤害后松手 |
| 时机 | 极窄窗口 | 防御期间任意时刻 |
| 收益 | 削韧 / 破势 / 弹反飞行物 | 高伤反击 + 高削韧 |
| 风险 | 空放有长后摇 | 防御期间累积破防，满了被破防硬直 |

⇒ 招架偏"高风险高回报"，单手剑反击偏"承受换回合"。两条防守路线并存，不合并。

### 4.3 工程面（现状核对）

- 现有 `PlayerGuard` 的状态只有 `None / Defending / Broken`，**没有"防御收招硬直"**；
  `PlayerWeaponStance` 只管姿态表现（举枪 / 回落 / 防御保持）。⇒ 反击需要一个新状态与输入钩子。
- 现有破防阈值是**玩家全局值**（`PlayerGuard.Threshold`，120），武器不参与。
  要"每把武器初始架势上限不同"，需在武器配置上新增基线并接入该阈值。
- 大招目前挂在 `HeroConfig.ultimateSkillConfig`（`Zhangfei_BerserkUlt`），不是武器。
  要"每把武器不同大招"，需迁到武器配置。

## 6. 大招的分配原则

- 每把武器一个**专属大招**，类型不能重复：
  - 长枪 = **增益型**（狂怒：一段时间强化自身）
  - 大刀 = **爆发型**（一次大范围重击，建议"裂地"）
  - 单手剑 = **反击型**（待定：连环反击 / 一闪）
  - 双刀、弓箭 = 待定
- **慢武器的单次命中必须给更多大招能量**：能量按命中次数结算，
  大刀一刀打中五人只算一次，否则"越慢越攒不出大招"，与设计意图相反。
