## 2. 核心问题

1. **一击必杀**：敌 101（持剑杂兵）基础 100 ATK = 玩家 100 HP，一击毙命。testStage 第 2 波 3× 下骷髅兵也 30 伤害，4 击死。
2. **BOSS 时间过长**：500 HP vs 10-20 伤害技能，无升级辅助下需 25-50 次攻击。
3. **升级池空洞**：Rare/Legendary 池为空，流派构建无材料。
4. **数值梯度粗糙**：部分升级每级增量恒定（+5% 伤害），部分倒退（幻影武器伤害比逐级降低），部分先退后进（旋风间隔 Lv2 变长）。
5. **无流派耦合**：前置条件系统已有但未使用，升级间无协同。

---

## 3. 设计目标

- **20-30 分钟一局**：从杂兵到 BOSS 的难度曲线平滑。
- **技能驱动**：玩家靠主动技能 + 被动触发输出，而非平A。
- **三流派可辨识**：连击位移流 / 蓄力流 / 道具流（新），各有核心升级和配套组件。
- **容错率适当**：杂兵不应一击秒杀，BOSS 技能应有反应窗口。

## 4. 敌人波次数值框架

### 4.1 基础原则
- 敌人 HP 按波次线性递增，保证杀敌节奏稳定（普通杂兵 2-3 次技能内击杀）。
- 敌人 ATK 按波次温和递增，保证普通杂兵 5-8 次攻击击杀玩家（给反应和回复空间）。
- 攻速倍率保持 1.0（靠敌人类型的固有攻速区分节奏）。

### 4.2 建议倍率曲线
以 3 波为一段落，每段增量递进：

| 波次 | HP 倍率 | ATK 倍率 | 说明 |
|---|---|---|---|
| 1 | 1.0× | 1.0× | 热身 |
| 2 | 1.3× | 1.15× | |
| 3 | 1.6× | 1.3× | 小怪群压力 |
| 4 (BOSS) | BOSS 独立 | BOSS 独立 | |
| 5 | 2.0× | 1.5× | 第二段 |
| 6 | 2.4× | 1.7× | |
| 7 | 2.8× | 1.9× | |
| 8 (BOSS) | BOSS 独立 | BOSS 独立 | |
| ... | ... | ... | |

### 4.3 敌人 101 特别处理
- 基础 ATK 从 100 降至 **20-25**，仍为最高伤杂兵但不再一击秒杀。
- 增加明显的前摇动画/音效提示（已有慢攻速 0.08，但需视觉可读）。

### 4.4 BOSS 数值
- BOSS HP 应在玩家有 1-2 个伤害升级后，约 30-60 秒内可击杀。
- 建议 BOSS HP 基准：**300-400**（配合阶段触发）。
- BOSS ATK：单次 **15-25**，给玩家 4-7 次容错。

## 5. 升级等级梯度设计

### 5.1 通用原则
- 每级增量应有**边际递增**感受（后期每级比前期更值），而非纯线性。
- 稀有度区分：Common 5 级、Rare 5 级、Legendary 3 级。Rare 单级效果 ≈ Common 2 级的强度。
- 所有百分比加成改为**乘法叠加**（当前已是）。

## 6. 流派 Build 设计

### 6.1 现有流派

#### A. 连击位移流
- **当前入池核心**：地刺（spike_trap）、击退波（push_wave）、聚拢波（convergence_wave）
- **玩法**：通过多次攻击累计触发位移/计数效果，控制敌人位置并造成范围伤害。
- **待完善**：连刺（on_attack_stab）、幻影武器（phantom_weapon）等计数触发升级当前未入池，后续补充。

#### B. 蓄力流
- **当前入池核心**：铁壁（charge_damage_reduction）、反伤盾（charge_reflect_shield）、冲击波（charge_shockwave）、震荡（charge_hit_shockwave）
- **玩法**：保持蓄力状态，靠减伤/护盾吸收伤害，触发冲击波清场。
- **前置链建议**：铁壁 Lv2 → 反伤盾入池；铁壁 Lv3 → 冲击波入池；反伤盾 Lv2 → 震荡入池。

### 6.2 新流派：道具流
- **设计方向**：以道具（Item 类升级）为核心，通过使用道具主动释放技能或获得增益。
- **当前入池道具**：包子（health_potion / 回复 50 HP）、海浪（wave）、持续旋风（item_cyclone）、伤害加成（test_damage_boost）
- **待设计内容**：
  - 更多道具类型（如范围炸弹、临时护盾、时间减速）
  - 道具充能/刷新机制（击杀刷新？时间冷却？）
  - 道具栏扩容（当前 itemSlotCount=2）
  - 道具增强型升级（如「道具伤害 +X%」、「道具使用次数 +1」）
- **与现有流派的协同**：
  - 连击位移流 + 道具：位移聚怪后丢范围道具清场
  - 蓄力流 + 道具：蓄力间隔期使用道具补输出/回复

### 6.3 通用/跨流派
- **神力**（damage_plus / 伤害+）：全流派通用。
- **疾风**（attack_speed / 攻速+）：全流派通用。
- **智慧**（exp_boost / 经验+）：加速升级节奏。

### 6.4 组合协同（展望）
- **蓄力 + 连击**：铁壁蓄力吸引火力 → 地刺/击退波控场清杂。
- **道具 + 蓄力**：蓄力间隔丢道具补输出，反伤盾 + 回复道具提升续航。
- **道具 + 连击**：位移聚怪 → 范围道具一波清。

### 7.2 后续入池规划
- **连击位移流扩展**：将连刺、幻影武器等计数触发升级加入 Rare 池。
- **蓄力流扩展**：当前 Common 池已包含铁壁四件套，后续可升 Rare 变体。
- **道具流扩展**：新增道具类型加入 ItemPoolConfig，及道具增强型升级加入数值池。

### 7.3 前置条件
- 使用已有 `prerequisites` 系统，配置流派核心前置链（见第 6 节）。
- 未满足前置的升级不进入候选池。
- 已满级的升级从池中移除。

## 8. 实施路线

1. **第一阶段**：修复明显数值错误
   - 敌 101 ATK 100 → 20
   - 幻影武器伤害比正向递增
   - 旋风间隔正向递减
   - Rare 池加入内容

2. **第二阶段**：按本文档调整全部升级梯度数值
   - 逐项修改 UpgradeDefinition 的 numericLevels
   - 配置前置条件

3. **第三阶段**：调整波次倍率与敌人基础数值
   - 按第 4 节框架配置 Stage_1 和 testStage
   - 调整敌人 prefab 基础数值

4. **第四阶段**：制作 20-30 分钟测试关
   - 按难度递进配置敌人类型、波次、BOSS
   - 实测记录通关数据

5. **第五阶段**：迭代调优
   - 根据实测反馈微调数值
   - 补充 Legendary 升级

## 9. 待讨论/待定

- 是否需要玩家 HP 随等级成长？（当前固定 100）
- 是否需要敌人防御/护甲系统？（当前无）
- 大招能量获取是否合理？（Stab 每次 10，100 能量 = 10 次 Stab = 约 3s 充满）
- Legendary 升级方向：强化现有流派极致？还是独立超模单件？
- 是否引入敌人类型相克（如某技能对盾兵伤害减半）？
- 道具流：道具栏是否需要扩容？道具是否能通过升级增强？道具冷却/充能机制？
