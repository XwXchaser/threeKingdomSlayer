# V2 数值平衡设计草案

> V2 最终池（14 技能）的 5 级数值重设计。10 级→5 级压缩 + 多维成长原则。
> 与 `design/v2-system-understanding.md` 联动。
> 池权重已归一化（2024-07），具体资产数值写入进行中。

## 0. 玩家侧与敌人侧联动基线（当前权威口径）

### 0.1 玩家成长目标
- 对局总时长约30分钟，最多持有6个被动与4个主动。
- 约需42次有效技能升级完成所持技能满级；目标在流程约70%处完成，之后升级转为立即回复20点生命。
- 前期升级快、后期逐渐放缓，任意连续两波内至少出现一次升级，避免阶梯式成长断档。
- 技能升级优先通过CD、触发间隔、范围、层数与机制变化建立感知，伤害增长只作为其中一个维度。

### 0.2 玩家构筑
- 蓄力流：铁壁、震荡、主动冲击波；以蓄力风险换取集中爆发。
- 位移流：海浪、旋风、专注；以高频控制、打断、阵型重排与Boss削韧换取安全输出。
- 火系协同：蛇形烈焰施加灼烧，火龙舌对灼烧目标必定造成200%暴击；作为跨流派组合。
- 海浪与旋风均为零HP伤害主动，命中计入Combo并保留受击反馈；其价值不应折算为直接DPS。

### 0.3 敌人定位
- 101：最基础的割草杂兵。
- 103：只使用CAttack的霸体教学杂兵。
- 106：固定轨迹远程单位，教学Parry处理箭矢。
- 105：随机轨迹的进阶远程单位。
- 104及变体107/108：综合霸体、QTE和阶段机制的Boss。Trial不使用102。

### 0.4 数值倒推顺序
1. 先固定玩家各阶段的预期技能数量、等级和输出/控制能力。
2. 再配置普通波次的敌人组合、HP与伤害，使两条核心Build均有发挥空间。
3. Boss HP按对应波次玩家预期有效DPS乘目标战斗时长反推；合理构筑下每次Boss战目标45–90秒。
4. 首次Boss仅1阶段且无转阶段，后续提升至2阶段，最高难度使用3阶段；阶段差异承担机制难度，HP仅承担时间标尺。
5. 位移主动对未Stun Boss不直接位移，改为按最大Poise百分比削韧；对已Stun Boss，旋风可执行击飞。

### 1.4 技能强度预算
- 主动技能单次释放价值 ≈ **0.5~2 × Stab单次(10伤)**，按 CD 放缩；长CD高上限、短CD稳定。
- 被动技能 DPS 档位 ≈ **5-15**（Stab 的 15%-45%）；单一被动不应超过玩家平A的一半。
- 杂兵 HP 基准：101=16、102/103=30、105=8、106=16（随波次乘 healthMultiplier）。
- 主动技能 CD 期间 DPS 近似 = 单次伤害 ÷ CD（实际因时机损失打折扣）。
- 满级被动 + 满级主动组合的预期 DPS 应对标 Boss 波次所需（45-90s 目标）。

## 2. 设计原则

### 2.0 技能强度评估框架（五维度）

评估一个技能的强度，不能只看伤害数值。必须从以下五个维度综合考量：

| 维度 | 说明 | 对强度的影响 |
|------|------|-------------|
| **冷却/间隔** | 技能多久触发一次 | CD越短→DPS越高，且控制/打断频率越高。**减少CD是加强，增加CD是削弱。**CD调整应成为数值平衡的一线手段，与伤害调整同等重要。 |
| **伤害** | 单次或DPS | 直接影响击杀速度 |
| **特殊机制** | 灼烧DoT、暴击条件、击退、浮空、削韧等 | 提供额外价值，可能超越纯伤害的贡献 |
| **射程/范围** | 覆盖的列数/排数 | 范围越大→命中敌人越多→总输出和控制面越大。范围是乘法器。**缩小范围是有效削弱手段，扩大范围是有效加强手段。** |
| **Hit数与硬直压制** | 每次触发命中多少次 | **高hit技能可持续造成受击硬直，使非霸体敌人无法攻击**。这是"挂机"问题的隐藏原因之一。降低hit频率或减少范围可缓解此问题。 |

**平衡调整优先级**：当技能过强时，不应只砍伤害。应先检查：
1. 范围是否过大？（缩小列数/排数）
2. 间隔是否过短？（增加CD/interval）
3. hit数是否过高导致永久硬直？（降低频率或增加间隔）
4. 最后才考虑降低伤害

同理，**减少CD是一种有效的加强手段**——当玩家获得-CD升级时，不仅是DPS提升，也是控制频率和生存能力的提升。

### 2.1 多维成长原则
每级提升至少在 2 个维度上产生可感知变化。维度池：伤害↑、**CD/间隔↓（加强）**、范围↑、DoT↑、机制解锁、控制时长↑、层数↑、惩罚↓。

**重要**：减少CD/间隔是一种有效的加强手段——提升DPS的同时也提升控制频率和生存能力。数值平衡时，CD调整应与伤害调整同等对待，不可只盯着伤害数字。

### 2.2 5 级压缩原则
- 原 10 级技能：关键节点 Lv1/3/5 对应原 Lv2/6/10，中间 Lv2/4 做平滑过渡
- 每级跨度约为原来的 2-2.5 级，确保"升一级就感到变强"

### 2.3 流派平衡原则
- 蓄力流（铁壁+震荡）：高爆发、需要蓄力窗口
- 位移流（海浪+旋风+专注）：高频控制、安全输出
- 火系协同（蛇形烈焰+火龙舌）：跨流派通用、条件暴击
- 同一稀有度技能单级强度接近，Rare 单级 ≈ Common 1.5-2 级

### 2.4 数据约定
- floatValue 字段：百分比用小数（0.08 = 8%），程序累计叠加
- 伤害值：整数，对标玩家基础 Stab=10
- **所有面向玩家展示的时间数值必须配置为正整数秒**：主动技能冷却、定时被动触发间隔、持续时间及类似可见计时器均不得使用小数。时间成长通过整数秒级差异表达；若必须保留子秒内部表现，应拆分为不向玩家展示的技术参数，不能复用玩家可见的CD/间隔字段。
- **DoT总伤害约定**：灼烧、疾病等配置中的伤害值表达完整持续时间内的总伤害，而非每秒伤害。每个DoT效果须自行固定一个内部跳字间隔；该间隔可为小数秒，但不得随技能等级或总伤害变化。单次跳字伤害=`floor(总伤害÷持续时间内跳字次数)`；配置总伤害时应优先选择可被跳字次数整除的整数，避免卡面总伤害与实际结算不一致。DoT跳字不打断攻击、不触发受击动画；灼烧用红色，疾病用紫色，二者可共存。
- **疾病叠层与传播**：主动重复施放会把武装层数累积到下一次Stab，并将其一次性附加到首个实际命中目标；同一目标被玩家再次附加时累加层数并重置完整疾病时长。死亡传播携带当前层数到上下左右相邻1格，接收目标重置时长但取原有层数与传入层数的较高值，避免多条死亡传播发生指数叠层。
