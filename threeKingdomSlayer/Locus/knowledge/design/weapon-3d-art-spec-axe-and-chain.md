## 0. 一句话任务

做两件**三国战场风格的 3D 兵器模型**（游戏里是 3D 网格 + 单贴图 + 项目自带着色器）：
一把**抡斧**（技能「抡斧劈砍」用），一把**追命锁链**（技能「追命锁链」用）。
两件都要**基础档**配色（朴素、耐用、不要金色），并各出一套**四视图图稿**供建模／验收用。

| 物件 | 玩法定位 | 交付目标 |
|---|---|---|
| **抡斧（巨斧）** | 技能1「抡斧劈砍」：抡起大斧劈砍，**无视盾牌减伤 + 必定破盾** | 一把厚重的单刃大斧 3D 模型 + 四视图 |
| **追命锁链（锁镰）** | 技能2「追命锁链」：发射带铁链的镰刀，把**最远、最弱**的敌人拉到面前 | 一把带链的弯钩镰 3D 模型 + 四视图（链身见 §3.2） |

⚠ **本项目之前用 AI 生成过若干版造型图，全部判定不合格并已废除**（见 §9 红线）。
本需求书的形状描述是从 **PBZ 官方立绘实测**得到的，**以本文件为准，不要参考任何历史生成图**。

## 3. 造型规范

### 3.1 抡斧

**整体**：厚重的**单刃大斧**，长柄（柄约占全长 **58%**，斧头约 42%），重心靠近斧头。

**斧头**（★ 本项目最容易做错的地方，逐条对）：

- **一整块实心厚钢板**，从柄端**向一侧张开**。
- **刃口是一条平滑连续的圆弧** —— 从上方那只角绕过右侧一路弯到下方的尖端。
  ★ 要**平滑连贯、中途不拐弯**；不要直线斜边、不要折角、不要尖三角。
- **圆弧以内是实心金属**（厚度可读、有分量）。
  ★★ 「圆弧」说的是**刃线的走向**，不是**外轮廓的挖空** —— **不是空心月牙片、不是薄钩刃、不是镂空**。
- **断面是上厚下薄的楔形**：斧背厚重，刃口收成一条锋利的刃线。
  ★★ 这是**斧与铲的根本区别**：等厚的平板刃面会读成**铲子**。
- **斧背厚钝**，正面（不切的那一面）就是一块干净的厚钢。
- **柄端下方单独垂着一根长尖喙刺**（像鸟喙／倒钩，长约头宽的一半，明显突出）。
- **柄尾**有一组两三个小的钢制倒钩尖刺（不是三叉戟）。

**柄**：

- 深冷褐偏暖的**旧木**，长杆。
- 近斧头处与杆身中段各有一道**暖棕偏红褐的旧皮革缠握**。
- 柄与斧头的**连接处**有**钢制环箍** + **一到两条皮革绑带**（把柄和头固定住）。
  ★★ 绑带与箍**只允许出现在连接处**，**绝不要横跨到刃面或斧背上**。

**静态姿态**：整把**竖直正立**、握把在下、斧头在上端并向 +X 一侧张开，刃口那条圆弧朝右下。不要斜放。

### 3.2 追命锁链

**整体**：一把**内侧开刃的弯钩镰**（单刃），加一段可平铺的链身。

**镰头**：

- 内侧开刃的弯钩，**镰尖朝 +Y**。
- 镰刃根部一个**带缺口的上扬爪形头**（像爪／兽头）。
- 根部有一枚**大连接环**，链身挂在它上面。
- 握杆是**分叉的**，缠着**深棕偏红褐的旧皮革**，皮绳上串着几枚**暗铁小环**与**新月形小片**。
- 握杆**下端收细**，带几道暗铁金属箍，**末端一个小挂环**。

**链身**：

- **8~9 节**闭合**椭圆链环**，环径一致。
- ★ **节与节之间要有交叠关系**（像真链），**不是实心粗绳**，截面要细。
- 链尾有一个**大连接环**。

**静态姿态**：**链自然下垂**（略带弧度），不是笔直绷紧、也不是缠绕成一团。

### 3.3 链身走「单环平铺」路线（已定）

- 链身**不需要骨骼蒙皮**。交付**单个链环**的静态模型／贴图（256×256 PNG+Alpha）即可，
  运行时由程序骨链（9 节）按链环平铺摆放。
- 需要「链节有厚度、会扭转」的蒙皮链时再另说，**本轮不做**。

## 4. 尺度与坐标（★ 模型必须满足，否则接不进工程）

### 4.1 世界单位基准

- Unity 场景单位 = 米。
- `Main Camera` 在 `(0, 3, -10)`，垂直 fov 60 ⇒ **在玩家所在深度（z≈0）可视高度 ≈ 11.55 世界单位**。
- 现有长枪 `FantasySpear3D` 全长 **10.8**（几乎满屏）⇒ 这是"长杆兵器"的尺度上限。

### 4.2 本项目建议尺寸

| 物件 | 全长 | 关键尺寸 | 备注 |
|---|---|---|---|
| **大斧** | **3.2** | 斧刃最大宽 **1.28**、斧背最厚 **0.22**、刃口处 **0.03**、握把直径 **0.14** | ≈ 屏高 28%；刃宽:握把径 ≈ **9 : 1** |
| **锁镰（镰头）** | **0.9** | 刃宽 **0.85**、刃厚 **0.16** | 镰头比斧小一号 |
| **链环（单个）** | — | 外径 **0.26**、厚 **0.09** | 可平铺复用 |

> ⚠ **宁可略小也不要大**：模型是"玩家手持／飞出的道具"，过大会挡住战场读数。
> ⚠ **按上表出图，不要用比例去凑。** 最终落位可由 Prefab 缩放微调。

### 4.3 轴向与原点（★ 最容易做错的一项）

- 模型本地 **+Y = 刃口／尖端方向**（大斧：从握把指向斧头，刃口那一端；锁镰：指向镰尖）。
- **模型原点 = 握持点 / 连接点**：
  - 大斧 ⇒ 原点在**握把末端**（手握的位置）；
  - 锁镰 ⇒ 原点在**链环与链身的连接点**。
- **正面观察方向 = 模型的 +Z 面朝观察者**；左右由 ±X 决定。
- ⚠ 长枪 prefab 的根节点在**杆的中段**（双手长杆的特殊处理），**斧／镰不要照抄**：
  单手武器的旋转支点就在手里，原点放握持点，旋转才自然。

### 4.4 四视图的观察方向（出图稿时用）

| 视图 | 观察者 | 画面右 | 画面上 |
|---|---|---|---|
| 正面 FRONT | 在 +Z，朝 −Z 看 | +X | +Y |
| 右侧 RIGHT | 在 +X，朝 −X 看 | −Z | +Y |
| 背面 BACK | 在 −Z，朝 +Z 看 | −X | +Y |
| 左侧 LEFT | 在 −X，朝 +X 看 | +Z | +Y |

- **正交投影**，不透视缩短、不倾斜；四张必须**同一个静止姿态**、同一比例。
- ⚠ **左／右不是水平镜像**：斧头不对称，左右两面结构不同（刃口、喙刺、绑带位置都能区分）。

## 5. 配色分档

### 5.1 基础档（本轮要做）

**零鎏金、零黄铜、零金色高光。** 材质与配色关系以**画风权威**（实机色卡）为准：

| 部位 | 颜色 |
|---|---|
| 斧头本体 / 斧背 / 环箍 / 喙刺 / 柄尾倒钩 | **冷蓝灰的钢**（带一点蓝紫倾向），受光面亮、暗面深一档，边缘干净利落 |
| 刃缘 | **亮银白**的一条锋利薄刃线（整件武器最亮的地方） |
| 柄 | **暖棕**旧木（不是近黑） |
| 皮革（缠握 / 绑带） | **暖棕偏红褐**（不是黑褐） |

整体气质：**明亮、高对比、色彩分区清楚**，与本游戏的三国战场美术同一调子；朴素耐用、战场上用旧了的重兵器。

### 5.2 高级档（以后再做，本轮不做）

鎏金／黄铜配件 + 朱红缠握 + 暖棕橙木 + 朱红识别色。
★ 可挂技能等级做递进（`AxeSmashLevelConfig` / `ChainPullLevelConfig` 本来就有 L1/L2/L3 三级，每级一个 `weaponPrefab` 即可）。

### 5.3 基础档不要做的

❌ 褐锈铁 / 大片锈迹 / 脏污做旧感 / 灰蒙蒙的低饱和 / 照片写实 / 近黑木 / 黑褐皮 / 任何金色或铜色金属件。

## 8. Prefab 结构与工程接法

**Prefab 结构**（照抄已有的 `FantasySpear3D.prefab`）：

```
Axe3D / ChainSickle3D（根）
 ├─ MeshWeaponVisual        ← 必须
 │    renderers[]           ← 全部 Renderer（含 SkinnedMeshRenderer）
 │    modelRoot             ← 模型根（可指向子节点）
 │    tipAnchor             ← 刃尖 / 镰尖
 │    tailAnchor            ← 握把末端 / 链尾端
 │    fadeMaterial          ← 淡出用材质槽
 └─ (可选) WeaponTasselDynamics ← 提供 Length（需 weaponTip / weaponTail 两个锚点）
```

- ⚠ **`tipAnchor` / `tailAnchor` 是硬要求**：姿态系统的"矛头指向 + 矛头落点"解算、`Length`、格挡判定都依赖它们。
- ⚠ 若不加 `WeaponTasselDynamics`，`MeshWeaponVisual.Length` 会退化为 0 ⇒ 姿态解算失效 ⇒
  **要么加，要么在 Prefab 里把两个锚点补好**。

**接法（模型到位后本项目这边做，不用制作方管）**：

## 9. ★ 红线（不要做什么）

**形状类**
1. ❌ 不要**月牙铲／铲子／锹** —— 等厚的平板刃面 + 顶部水平弧边 = 铲子。
   斧是**上厚下薄的楔形**，刃口收成一条刃线。
2. ❌ 不要**空心月牙片／薄钩刃／镂空** —— 圆弧是**刃线走向**，不是外轮廓挖空。
3. ❌ 不要**直棱斜边／尖三角／折角** —— 刃口要**平滑连续**。
4. ❌ 不要**薄片** —— 斧头是**实心厚钢板**，厚度要可读。
5. ❌ 不要**铆钉排、纹章、雕花、装饰铁片、附加铁条** —— 斧背只留钢面本身的锻打纹理与明暗分档。
6. ❌ **绑带／箍不要横跨刃面或斧背** —— 只在柄与斧头的连接处。
7. ❌ 锁链的链环不要做成**实心粗绳**，要有节间交叠、截面要细。

**配色类**

8. ❌ 基础档不要**鎏金／黄铜／古铜／铜环／金色高光**。
9. ❌ 不要**褐锈铁／大片锈迹／脏污做旧感／灰蒙蒙低饱和／照片写实**。
10. ❌ 不要**近黑木／黑褐皮** —— 要暖棕木 + 暖棕偏红褐皮革。

**交付类**

11. ❌ 不要自带材质（必须用项目自带 `Custom/WeaponColorUnlit`）。
12. ❌ 不要 UV 壳（一套 0..1 覆盖整把）。
13. ❌ 不要骨骼动画片段（动作由代码驱动）。

## 11. 已知坑

1. **四视图不是 3D 投影认证**：对齐不等于精确投影，建模时以**本文件的轴向与尺寸**为准，必要时自己量。
2. **不要用镜像冒充左侧**：水平翻转会让链环交叠、斧背与喙刺的位置出错。
3. **链环不能建成实心粗绳**：有厚度、有交叠，但截面要细。
4. **`tipAnchor`/`tailAnchor` 缺了 ⇒ 姿态解算直接失效**（`Length` 退化为 0）。
5. **新字段只改 C# 默认值不生效**：域重载会保留 ScriptableObject 内存值 ⇒ 数值/引用必须写进 `.asset` 并 `SaveAssets()`（本项目这边处理）。
6. **图生四视图要逐张生成**：一次出多视图会把比例和细节带歪；一张一次、失败先分析不重发。
7. **武器模型会被 2D 精灵遮挡**：3D 在透视相机下靠**深度**排序，`sortingOrder` 压不过 2D 精灵 ⇒ 必要时把道具的 z 往相机方向挪。
