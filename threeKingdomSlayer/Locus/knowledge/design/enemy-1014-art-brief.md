再出一张**他和现有兵种并排的组图**，用来确认他属于同一支曹军、同一个画风、同一个体型家族。

| 物件 | 玩法定位 | 交付目标 |
|---|---|---|
| **投壶兵（1014）** | 远程单位：扔带毒的陶壶。**毒可以被防御吸收吗？不能** —— 防御只免直伤，毒照扣 | 1 张正面**身份图**（绿幕）+ 后续动作帧用的形象定稿 |

## 3. 当前画风（口径，摘自已验收样本）

> 完整版见 `design/art-style-guide.md`；这里是给制作方的执行摘要。

**这是"高清像素化的三国战场动作美术"。** 不是低分辨率复古像素，不是马赛克滤镜，不是照片写实。

**核心六条**

1. **形体**：短壮、厚重、有战斗分量。头相对身体有分量、宽肩、紧凑的胸腹腰胯、**短而结实的腿**、厚实的手脚、站姿稳。
   —— **"Q 化的是比例，严肃的是战斗感"**（不软萌、不玩具感）。
2. **像素是组织方式，不是滤镜**：**成簇的明暗色块**、清楚的受光面与暗部、阶梯状轮廓、缩到 1/4 仍然能读的剪影。
   ⇒ 禁止"只加随机碎像素"、禁止"把普通插画套像素化滤镜"。
3. **材质能分辨**：金属（冷灰蓝灰主体 + 深色缝隙 + **锐利银白高光** + 明确的甲片厚度与层叠）、布料（**大面积色块** + 折面，不铺细密织纹）、皮革（暖棕黄褐、边缘厚、带扣腰带护腕结构清楚）、木材（纹理方向 + 破损边缘 + 铁件铆钉）、土石（粗粝块状，不铺均匀噪声）。
4. **冷暖关系**：角色 = **冷铁灰 / 蓝黑甲片** + **暖棕皮革** + **朱红识别色**（围巾 / 缨带 / 旗）+ 少量银白灰白高光。
   场景 = 暖黄土 / 赭色底 + 冷蓝灰远山天色。**红是识别色，不能平均撒满画面。**
5. **边缘**：轮廓清楚、偏深，**不要统一纯黑描边**；边缘干净，**禁止灰边 / 白边 / 无意义柔化光晕**。
6. **面部**：表情简洁可读，情绪来自**眼神 / 头部角度 / 握拳 / 站姿 / 武器方向**的组合。
   1011 用兜鍪 + 眼缝 + 橙色发光眼表达敌意，**不靠复杂人脸**；新角色可以有不同面部设定，但**战斗身份优先**。

**画风基准样本（已验收，最权威）**：`Assets/Sprites/Enemy/Enemy1_1/Enemy_1011_idle1.png`
—— 黑漆兜鍪 + 红色飘带缨 + 封闭面甲 + 橙色发光眼 + 冷蓝灰板甲 + 暖棕皮革 + 朱红围巾与腰带 + 亮银白剑刃。

**明确禁止**：清新花园 / 明亮绘本 / 软萌圆润 Q 版 / 阴暗哥特 / 仙侠水墨 / 欧美奇幻骑士 / 现代军服 / 照片写实 / 3D 塑料感 / 低分辨率简笔像素 / 模糊 / 无意义噪点。

### 4.3 逐个画风描述（画的时候要区分得开）

**1011 重甲刀兵**（家族基准，不要重新设计）
黑漆兜鍪（顶部一撮红缨飘带）+ 封闭面甲 + **橙色发光眼缝** + 冷蓝灰板甲（肩甲 / 胸甲 / 裙甲分层，甲片厚度可读）+ 暖棕皮革（腰带 / 护腕 / 靴子）+ **朱红围巾 + 腰带垂布** + 右手握**亮银白直剑**（冷蓝灰剑身、暖棕木柄、金色护手）。
⇒ 家族里最重、剪影最"方"的一个。

**1012 兜鍪贼兵（山贼版）**
**宽檐斗笠**（不是盔）+ **红头巾**系带 + 露出凶悍人脸 + 米色交领布衣 + 皮革肩带 / 腰带 / 护腕 + 暗棕裤 + 灰白绑腿 + 刀。
⇒ 家族里最"布衣"的一个；**不要**把他画成重甲。

**1013 督战旗手**
束起的头发用**深色布头巾 + 皮质护额（带铆钉）**勒紧（**不戴盔**）+ 黑色络腮胡、方脸、粗眉、**闭嘴怒视** + 米白/浅灰**交领布袍** + 外披**深蓝灰短身轻甲片**（只有肩胸几块小甲片，**不是全身重铠**）+ 深棕皮带（方扣）+ **宽绑带式皮革护腕** + 暗棕裤 + 灰白绑腿 + 厚底战靴。
**长杆方旌旗**：深色木杆，杆顶**平的素木杆顶（不带矛尖、不带金属帽、不带任何装饰）**，杆身有三处红色绑带；挂一面**方形暗赭红布旗**，旗布自杆顶顺风向**身后飘展**、**不横向展开**（已部署素材里旗向画面右侧展开）。
**双手握杆，杆竖直高举过顶**。旗、杆、双手、双脚完整可见，**不遮脸**。
⚠ **已部署素材的旗面带一圈浅金色回纹边框** —— 那是组图阶段**自发产生**的偏差（设计意图是**素面无图案**），**没有修掉**。
⇒ **不要把这条金边当家族语言继承**：1014 的陶壶一律**素陶**（见 §6.1 / §9 红线 4）。
⇒ 家族里唯一**带高道具**的 ⇒ 他的画布是 1440²，**总高（量到旗顶）≈ 普通兵 1.25×，身宽与普通兵相当**。

**1051 弓手**
**汉末裹巾法**：额头一道窄布带 + 脑后打结、两端垂在颈后；头顶束发。
**下半脸遮口鼻（半蒙面）**，布下**不画嘴 / 唇 / 牙**。
眉细长外端上挑、左高右低、眉心浅竖纹；窄三角眯缝、右眼比左眼更紧；**双眼正视玩家**、冷而黏滞；颧骨高、颧下收紧。
粗麻短衣（撕口下摆）+ 破旧深棕皮背心（**无胸甲**）+ 皮护腕 + 束腰带铁扣 + 左腰刀鞘短刀 + 一处朱红/暗红旧布条 + 深色布裤 + 腿绑 + 露趾绑脚鞋。
**右手木弓** + **左肩后箭袋 3–4 支箭羽**。
⇒ 家族里装备最轻的一个。

**1021 轻装楯兵**
**曹军轻装楯兵**（露脸、布衣皮甲、小楯）。
**风霜老卒脸**：半垂窄眼、平直浓眉、眉心浅纹、宽阔风化的鼻、颊下浅灰胡茬、**嘴必须闭上**（双唇抿成硬线、嘴角略下压）、下颌颊肌绷紧。**不是黑络腮胡，不是武将**。
素色**深布帽 + 发髻 + 垂布带** + 交领**灰米布袍** + 肩胸几块**深色小甲片** + 暖棕皮革护腕 + 深棕裤 + 灰白绑腿 + 厚底战靴。

## 5. 1014 形象规范

### 5.1 定位

**曹操麾下的基层投壶兵**：随军推进的汉末军人，手上是**带毒的陶壶**，不是刀兵、不是射手、不是旗手、不是武将。
—— **一个会投掷的轻装步兵**，装备比 1011 轻、比 1051 重（因为要走近战距离投掷）。

### 5.2 逐部位

## 6. 陶壶（投掷物）规范

> 这是 1014 的**签名道具**，也是玩家在屏幕上真正会盯着看的东西。**它现在完全不存在**（用的是弓手的箭）。

### 6.1 形态

**一只汉末民用的粗陶壶（投壶用的那种"壶"）**：

- **器形（★ 以已验收 v2 造型为准）**：**略扁的圆腹**（最宽处在中下部）+ **收束的短颈** + 一圈**小壶嘴**；**单手可握**、约人物本体高 1/5。
  **不要**细颈花瓶、不要双耳大罐、不要葫芦、不要酒壶的高足。
  ⚠ 已验收图上是**单把小水壶**（无两侧对称环耳）；制作方可在不改变「小、单手可握、素陶」三条的前提下自定挂绳/提手。
- **表面**：**素面粗陶** —— 暖土黄 / 灰褐的陶土底，**没有釉、没有彩绘、没有花纹**。
  可以有：轻微的**烧制色斑**、**粗砂质感**、一两道**暗色裂纹**、**口沿与流口的磨损**。
- **系绳**：颈部一道**麻绳/皮绳**（暖棕），绳上可系一小段**暗红布条**（呼应角色的识别色）。
- **毒的表现**：**不要**把壶做成绿色或发光的怪物道具。
  毒是**机制**，视觉上交给**特效**（毒雾 / 滴落 / 命中时的绿褐色烟）。
  ⇒ **壶本身保持素陶**，只在**命中后**由特效表达"有毒"。

### 6.2 尺寸（硬要求）

| 项 | 目标 | 换算 |
|---|---|---|
| **壶身直径** | **0.60 – 0.70 世界单位** | **115 – 135 px**（@1108² / PPU 16 / scale 0.08316832） |
| 高度（含颈与流口） | **0.75 – 0.85 世界单位** | **145 – 165 px** |
| 相对角色 | 约为**角色身高的 1/5** | —— |
| 屏幕上必须看得清 | 缩到 1/4 仍能认出"这是个壶" | —— |

⚠ **太大了会变成"炸弹"、太小了会看不见**。壶是有威胁的道具，玩家要能在飞行中一眼认出它、并瞄准它打落。

### 6.3 投掷动作线

投壶兵的攻击 = **抡臂 + 向前抛出**（不是拉弓、不是掷矛）。
建议的动作阶段：**持壶（idle）→ 抡起（蓄力）→ 脱手投出（命中帧在此）→ 收势回 idle**。
脱手瞬间手里要**没有壶**、空中出现壶 ⇒ 需要"投出"这一帧的专门设计。

| **道具自发长出装饰** | 1013 的旗面在**两轮组图里都**自发多出金回纹边框 —— 且**已部署素材里还留着**（没修掉） | 道具一律**素面**；1014 的壶**不要**花纹、彩绘、釉；**不要把 1013 旗上的金边当家族语言继承** |
| **手性 / 侧性画反** | 1021 的盾被画到画面右（人物左手），**文字描述与负面词都无效** | 画完后**逐帧核对**手 / 侧；必要时**镜像基件**（镜像会连脸一起镜像，所以只当"身体 / 装备 / 持握侧"的参考） |
| **单张图画风被磨平** | 1021 的单张身份图脸比组图里更平滑 | **先出并排图定家族与画风，再做单张身份图** |
| **裁切不能当定稿** | 1013 的组图裁切件量出**旗杆总高 1.53×**（设计目标 1.25×），折算到游戏**超出画布** | 并排图是**比例研究参考**，**不能直接裁切成游戏素材** |
| **画风不随母本继承** | 把"已部署帧"当动作母本时，模型继承的是**姿态几何**，不是画风 | 画风永远以**已验收资产**为准 |
| **道具横向压邻列** | 弓 1.58 列、旗面 1.57 列、盾 1.51 列 | **列距只有 2.6 世界单位**；1014 的壶是圆的，本体不占宽 ⇒ 保持壶在身前 |

### 8.1 身份图（绿幕锚图）

| 禁止 | 地面、投影、场景、其它角色、文字、UI、水印、棋盘格、渐变底 |

### 8.2 精灵帧（下一阶段，本轮只交形象）

| 项 | 值 |
|---|---|
| 画布 | **1108 × 1108**（1013 因旗杆高用了 1440²；1014 的壶小，用 1108²） |
| PPU | **16** |

| 落位 | 脚底对齐到统一基线（家族实测 871–925 px；**1014 目标 895**），中心 x ≈ 474.5–521（家族实测 521–546） |
| 写盘 | **只覆盖 PNG 字节，保留 `.meta`**（GUID / 导入设置不变） |

### 8.3 动作（本轮**不做**，仅列范围）

按项目规矩，新兵种的美术产出顺序是 **① idle 形象 → ② 关键动作 → ③ 剩余通用动作**。

| 阶段 | 动作 | 优先级 |
|---|---|---|
| ① | **idle**：**当前未完成** —— v3 只给了站军姿概念图；**6 帧呼吸/重心微移循环待做**（家族做法见 `Enemy1014ArtSource/00_Reference/idle_loop_reference_1012_1051_1021.png`，6 帧几乎静止） | **最高（当前卡点）** |
| ①′ | ★ **idle 静帧概念稿 v1 已出**（"轻抛小水壶把玩"）：`Enemy1014ArtSource/02_IdentityImages/1014_idle_toss_v1_greenscreen_1024.png`（落位：主体高 695 / 脚底 894 / 中心 474.0）；对照图 `1014_idle_pose_compare.png`；记录见 `plan/session-handoff-20261114.md` §7.14.9 | 待用户验收 |
| ② | **投掷（attack）**：抡起 → 脱手 → 命中帧 | 次之（玩法识别度） |
| ② | 受击（hitLeft / hitRight / hitFlash） | 次之 |
| ③ | 通用动作 | walk / dead / 击飞链（rise / fall / getup） |

> ★ **idle 与投掷的衔接要求**：idle 的持壶手位要给投掷起手留空间（右手持壶、肘略屈、重心后坐），能自然接到「抡起 → 脱手投出」。
> ⚠ **idle 姿态的任务书与待拍板项见 `plan/session-handoff-20261114.md` §7.14**（含工程侧实测约束、本体高口径差异、可用资产与坑）。

## 9. 红线（不要做什么）

**形制类**
1. ❌ 不要**弓、箭袋、旗、旗杆、刀、剑、枪、盾** —— 1014 的识别物**只有陶壶**。
2. ❌ 不要**兜鍪（1011）、宽檐斗笠（1012）、下半脸蒙面（1051）、发光面甲** —— 脸要露出来。
3. ❌ 不要**全身重甲** —— 1014 是轻装投掷兵。
4. ❌ 不要**陶壶带花纹 / 彩绘 / 釉 / 发光 / 绿色** —— 素陶，毒交给特效。
   ⚠ 也**不要**照抄 1013 旗面那条浅金回纹边框（那是历史遗留缺陷，不是家族语言）。
5. ❌ 不要**细颈花瓶 / 葫芦 / 高足酒壶 / 双耳大罐** 形制。
6. ❌ **手性要指定**：陶壶在**画面左（人物右手）**，并在交付前逐帧核对。

**比例类**

7. ❌ 人物本体高**不要超出 0.94 – 0.99 × 1011**（648–682 px）。
8. ❌ 总宽（含投掷臂与壶）**不要超过 2.6 世界单位**（列距）。

**画风类**

9. ❌ 不要**柔滑渲染 / 渐变过渡 / 塑料高光 / 笔触感** —— 要和 1011 一样的色簇笔法。
10. ❌ 不要**比前五位更细腻 / 更平滑 / 更"绘制感"** —— 单张图最常见的失败。
11. ❌ 不要**低分辨率简笔像素 / 模糊 / 随机碎像素 / 马赛克滤镜**。

**交付类**

12. ❌ **不要保留失败样本** —— 只交最终稿（本项目已按同口径清掉武器任务的 15 版生成样本）。
13. ❌ 不要自带材质 / 不要改导入设置（工程侧统一处理）。

## 11. 已知坑（制作方请注意）

1. **不要拿离线稿 / 旧图冒充实机现状** —— 本文档引用的图都标了类别（实机 / 已部署精灵 / 参考 / 现状占位）。
2. **1014 的现状图是"占位"不是"定稿"**：`battle_enemy_1014.png` 里是**弓手的旧素材**（106 弓箭手），
   `battle_enemy_1014_projectile.png` 里是**箭矢**。它们的作用是让你知道**屏上体量**与**占位现状**，**不是画风参考**。
3. **画风基准只有一个**：1011 已部署 idle + 实机截图。**不要**拿 1014 的现状占位图当画风参考 —— 那是旧素材。
4. **并排图不能直接裁切进游戏**（§7.5），它只用来定家族与画风。
5. **陶壶的"毒"是机制不是造型** —— 别把壶做成毒气弹。
6. **本项目之前用生成接口做的造型样本已全部废除**（用户口径："这些造型都太垃圾了，全部废除"）。
   **不要去 `C:/Users/steam/Pictures/gptGen/` 找历史生成图当参考** —— 那些目录多数已不存在，且是被否掉的。
