## 1. 这套界面是干什么的（功能需求）

玩家打开天赋页，是为了**决定"这一局我要走哪条路"**。

```
天赋页
├─ 三个大页面（横向切换）
│   ├─ 页 1 · 基础数值   ← 改玩家属性（生命 / 复活 / 槽位）
│   ├─ 页 2 · 招式解锁   ← 解锁新的招式（重攻击、终结技）
│   └─ 页 3 · 三选一解锁 ← 解锁局内三选一里会出现的技能
│
├─ 每页下面若干条「分支」
│   └─ 每条分支 = 一条起始路线，分支上挂着节点（从起点往下走）
│
└─ 每个节点 = 一个可购买项
     ├─ 图标（表达这是什么）
     ├─ 名称（文字）
     ├─ 价格（铜钱）
     └─ 状态：锁定 / 可买 / 已解锁
```

**8 条分支（最终信息架构）**

| 页 | 分支 | 节点 |
|---|---|---|
| 基础数值 | 战斗向 | 破阵（攻击附带架势伤害）/ 追击（击杀后攻击 CD 缩短）/ 运筹（三选一变四选一） |
| | 生存向 | 铁血（生命上限 +30）/ 连击精通（连击阈值下降）/ 不屈（濒死无敌） |
| | 经济向 | 聚财（铜钱获取 +30%）/ 巧思（主动槽 +1）/ 博学（被动槽 +1） |
| 招式解锁 | 点线 | 指向突刺 C2 → 枪突收尾 C4 |
| | 划线 | 横扫位移（Slash）→ 后续衍生（待定） |
| 三选一解锁 | 蓄力流 | 入门 → 铁壁 / 震荡 / 冲击波 |
| | 位移流 | 入门 → 专注 / 海浪 / 旋风 / 染病 |
| | 火系 | 蛇形喷射 → 火龙舌 |

## 3. 美术风格：**由你提出**

本文只给**功能需求**与**不可协商的技术约束**，**不给风格方案**。
三方旧口径（简洁白边 / 刀锋单色暖铜 / 落地页笔刷铜牌）已全部作废 —— **不要参考它们，也不要参考项目里任何现成素材**。

### 3.1 不可协商的技术约束

| 约束 | 说明 |
|---|---|
| 平台 | 1080 × 1920 竖屏；素材按 **2×** 出 |
| 透明 | PNG 透明背景，**无白底 / 棋盘格 / 背景场景** |
| 九宫格 | 需要拉伸的必须九宫格（边距见 §4 清单）；不拉伸的填 0 |
| **可染色** | **连线必须出纯白**（颜色由代码染色）；节点框底图**不要自带强色调**（代码会叠一层色，叠完会脏） |
| **三态同族** | 锁定 / 可买 / 已解锁三张节点框**必须是同一形状家族**，靠亮度与描边区分，**不要用不同形状** |
| 图标 | 单一视觉焦点；透明底；**不写文字与数字**；**不画人物立绘** |
| 尺寸 | 见 §4 清单（正方形画布 + 12% 安全边距等） |
| 目录 | 统一 `Assets/Sprites/UI/Talent/` |

### 3.2 需要你自行分析并提交的内容

| 提交物 | 内容 |
|---|---|
| **风格方案** | 你的分析结论：这套界面应该是什么气质、用什么材质与描边、为什么 |
| **材质样板** | 面板底 / 节点框三态 / 详情卡 / 按钮，各一张并排，**标明色值** |
| **色值表** | 承托色 / 描边色（锁·可买·已解锁三态）/ 文字色（亮·暗） |
| **图标语言样板** | 6–8 个跨页通用符号（生命 / 铜钱 / 槽位 / 破防 / 连击 / 元素 / 控场 / 蓄力） |
| **分支呈现方案** | 8 条分支怎么在视觉上区分（标题 + 分隔 / 泳道底板 / 层级缩进 —— 由你决定） |

> 方案确认后再进批量出图。**先出 P0 的 23 件**（§4），方向不对时返工成本最低。

## 5. 交付纪律

| # | 规则 |
|---|---|
| 1 | **按编号交付**，文件名 = 编号 + 语义名 |
| 2 | **素材 ID 按功能语义命名，不按画面描述** → 功能改了名，素材不用重做 |
| 3 | **图标只表达「类别 / 机制」，不表达具体数值 / 等级 / 关卡** |
| 4 | 节点标题用**文字**，不用素材 → 改名零成本 |
| 5 | 分支标识**可缺省** → 分支增减不阻塞实现 |
| 6 | 节点三态底图**全局共用一套** |
| 7 | 秘籍图标**按类别** → 新增秘籍不需新图 |
| 8 | 一切素材标 P0 / P1 / P2 → P2 可整体延期 |
| 9 | 交付时**建议用新文件名**（如 `talent_panel_v2.png`），由工程替换旧资产 —— 避免同名覆盖导致 GUID 变化、场景引用丢失 |
| 10 | 九宫格素材**在交付说明里写明切图边距** |

### 5.1 变更影响矩阵（功能改了先查这里）

| 分支重划 / 合并 / 拆分 | C 组 | 小（可缺省） |

## 6. 禁止项

- ❌ **不要把项目里现有的任何图标 / UI / 角色 / 场景 / 特效当作参考**
- ❌ 不要在图标里写**文字 / 数字**（价格、等级、+1、20→15）
- ❌ 不要用**现代物件**（现代枪械、眼镜、电池等）
- ❌ **不要柔光 / 厚涂 / 写实 / AI 插画感**
- ❌ 不要在图标里画**人物立绘**（图标是「效果符号」，不是角色）
- ❌ **不要白底 / 棋盘格 / 背景场景**
- ❌ 不要**自建平行的素材目录**（统一 `Assets/Sprites/UI/Talent/`）
