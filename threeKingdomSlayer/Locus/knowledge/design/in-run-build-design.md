## 0. 结论先行

| | 定位 | 局内获取方式 | 能不能叠 | 数值尺度 |
|---|---|---|---|---|
| **属性卡** | 纯数值，像"属性点" | **经验升级**（三选一） | **可无限叠**（有软上限） | **小**（+3~8%） |
| **影之武装**（主动） | 改变打法 | **精英敌人掉落**（三选一） | 占槽（2），**可替换** | 中（机制为主） |
| **饰品**（被动） | 改变**规则** | **精英敌人掉落**（三选一） | 占槽（2），**可替换** | **小**（+5~15%，靠条件制造差异） |

**一句话**：**数值卡负责"变强"，武器/饰品负责"变玩法"**。
数值卡做小、做多、可无限叠（软锁）；武器与饰品做"每一条都改变一条规则"，靠**替换**而不是叠加来成长。

> ★ **两条来源线（2026-11-17 用户定，已实施）**：
> “属性成长应该跟**经验**，装备饰品应该跟**精英敌人**”。
> ⇒ 局内奖励拆成**互不混**的两条线：**经验升级只出属性**；**装备 / 饰品只从精英敌人掉落**。
> 分类口径 = **占不占槽位**（与 `UpgradeEffectManager` 的槽位模型同源，判定集中在
> `UpgradeRewardClassifier`，见 `Assets/Scripts/Data/UpgradeRewardKind.cs`）：
>
> | 类别 | `UpgradeCategory` | 占什么槽 | 来源 |
> |---|---|---|---|
> | 属性 | `Numeric` | 不占槽（可无限叠） | 经验升级 |
> | 影之武装 | `ActiveSkill` | 主动槽（2） | 精英敌人掉落 |
> | 饰品 | `AttackPassive` / `TimedPassive` | 被动槽（2） | 精英敌人掉落 |
>
> ⇒ **Boss 锦囊并入精英掉落**（V2 下不再单独弹一次）：Boss 死 → 一次装备三选一（100% 掉）。
> 装备三选一内部按**影之武装 / 饰品两个子池交替**出牌，保证每次都能看到"武器 + 饰品"的组合。

## 1. 现状盘点：数值型奖励成长"有准备吗"

### 1.1 已经有地基的（可直接用）

| 载体 | 现状 |
|---|---|
| `UpgradeDefinition.numericLevels` | 逐级数值行（index 0 = Lv1）⇒ **品质可以复用等级行**（普通=1级 / 精良=3级 / 传说=5级） |
| `StatLayerModel`（2026-11-16 新增） | 分层乘算：固定值层 / 加法层 / 乘法乘区 / **转化器**（霸王血铠型）/ 固定求值顺序 / 结构防环 |
| `StatModifier`（Add / Multiply） | 已有类型区分（但**生效路径里 Multiply 曾被忽略**，现已统一进分层模型） |
| `TalentStatService` statId 体系 | 13 个 statId（max_health / revive_count / item_slot / active_slot / passive_slot / attack_poise_damage / kill_cooldown_reduction / choice_count / coin_gain / combo_threshold_delta / undying / **upgrade_level_cap**） |
| `UpgradeDefinition.defaultLevelCap` + `RegisterLevelCapProvider` | **局外解锁等级上限**的软锁机制已通（用户定："升级上限这种软锁，只能局外成长解锁"） |
| `UpgradeQuality`（普通/精良/传说） | 枚举已加（字段已就位，无内容） |
| 槽位 | 主动/被动**初始各 2**，局外天赋「巧思/博学」各 +1（已改） |

### 1.2 还缺的（四块，正好是本轮要做的）

| # | 缺口 | 为什么现在是硬伤 | 对应批次 |
|---|---|---|---|
| **G1** | **卡片实例模型** | 现在是 `Dictionary<upgradeId,int>`（一个条目一个等级）⇒ **抽到第二张同类卡不成立**、"两张 +2 饰品并存"也不成立 | **B1** |
| **G2** | **基础数值的 statId 不全** | 有伤害%（`damage_multiplier`）、攻速、CD；**没有**局内的生命上限卡 / 平砍攻击力卡 / 暴击 / 吸血 / 回复 | **B2** |
| **G3** | **转化器没有资产格式** | `StatLayerModel` 支持了（source/per/target/gain），但**没有资产能配出来**（霸王血铠写不进去） | **B2** |
| **G4** | **数值尺度与同类上限没有规范** | 现有 maxLevel 5~10、每级幅度各写各的（疾风 +10~18%/级，专注 −8~12%/级…）；**没有"同类最多 N 个"**（PBZ 饰品同类 ≤3） | **B2** |

## 2. 影之刃零的设计提炼（2026-11-16 实测）

### 2.1 饰品（66 种）的槽位规则

> 原文：「**饰品**是魂在战斗中最多同时装备六种的被动道具。魂初始饰品栏位为 **2**，通过**能力修行**最多可提升为 **6 栏**。**同类饰品最多同时装备三个**。」

⇒ **和我们已定的"主动/被动初始各 2、局外天赋解锁更多"完全同构** ✓（PBZ 的"能力修行"＝我们的天赋页）。
⇒ 多出一条：**同类上限 3**（我们没有这条）。
⇒ 饰品**按区域掉落**（悲泣溪谷 / 血色森林 / 陆家村 / 混沌之境…）⇒ 我们的"无尽关每圈一个主题"可以照抄：**每圈掉落偏向该圈主题的饰品**。

### 2.2 饰品的效果形状（9 类，这是我们要抄的"词汇表"）

| # | 形状 | 例子（实测数值） | 我们的对应 |
|---|---|---|---|
| 1 | **纯数值** | 筋力绑带：对敌人的伤害 **+5%** | 属性卡的数值尺度参照（+3~8%） |
| 2 | **条件乘区**（针对敌人状态） | 影动猎杀仪：对**攻击动作中**的敌人伤害与杀气削减 +7%；追杀令：对**破防状态**的敌人伤害 +7%；斩骑符：对**骑兵类**伤害 +25% | "对破防敌人 +X%" / "对骑兵 +X%" / "对持盾 +X%" |
| 3 | **状态转化器** | **古甲残片：生命值越高，获得的伤害减免越高，生命值全满时减伤 20%** | ★ **霸王血铠（每 100 生命 +20 攻击）就是这一类** |
| 4 | **窗口放宽** | 浑源经脉仪：**完美格挡/闪避的时间窗口 +15%** | 招架/完美格挡窗口（我们有 `parry` 窗口参数） |
| 5 | **资源节奏** | 正气凌然：杀气连招的**杀气消耗 −15%**；神机指环：按住格挡时消耗 −20% | ★ 我们的**暗源**消耗减免（我们还没做暗源） |
| 6 | **行为奖励**（做对了才给） | 反击护腕：完美格挡后 2 秒内伤害 +20%；百战魔躯：10 秒未受伤 → 免疫下一次伤害 | "完美格挡后 X 秒伤害 +Y%" / "连续 Z 秒未受伤 → 免伤一次" |
| 7 | **条件免伤** | 坚岩护腕：**自身未处于破防状态时**受到伤害 −15% | "未破防时受伤 −X%" |
| 8 | **装备联动** | 神器刀鞘：**切换主武器时**获得霸体 + 减伤 2 秒；刽子手头巾：处决后切换武器 CD −1 秒 | 与"局内换武器"绑定 ⇒ **等局内切换做了再上** |
| 9 | **按武器持法分档** | 妙手在握 / 妙手连环 / 妙手千均：单手 +10% / 双持 +10% / **双手 +18%** | 与"持法档位"绑 ⇒ 武器化后才有意义 |

### 2.3 影之武装（25~26 件）的定位

- 五类：**武学 / 破坏 / 奇门 / 远程 / 召唤**；
- 最多装备 **2** 件；共用**暗源**（用完只能在铃铛处恢复）；
- **反制 / 追击型**：敌人红光技能时、或敌人血量 <50% 且破防时才能用 ⇒ 我们可直接对应到 1012 霸体 / 109 冲锋 / 1021 盾卫；
- **可从强敌手里夺得** ⇒ 我们的"Boss 掉武器"同构。

### 2.4 三条可直接照抄的**结构性**结论

1. **数值小、机制重**：饰品数值都是 +5~7% 级别，差异来自**条件**（对谁、对什么状态）而不是大数字。
2. **槽位稀缺 ⇒ 替换才有意义**：同类型上限 3，满了以后新饰品只能替换 ⇒ 这正是用户要的"+3 换 +2"。
3. **与角色解耦**：影之武装/饰品都不绑角色（只有一个主角）⇒ 与"抛弃武将概念"方向一致 ✔。

## 4. 我们的方案

### 4.1 三类奖励的分工（最终口径）

| | 属性卡 | 影之武装（主动） | 饰品（被动） |
|---|---|---|---|
| 改变什么 | **数值** | **打法**（主动释放） | **规则**（条件 / 窗口 / 资源 / 联动） |
| **来源** | **经验升级** | **精英敌人掉落** | **精英敌人掉落** |
| 槽位 | **无槽位**（抽到就叠） | 2（局外天赋可加） | 2（局外天赋可加） |
| 叠加 | **可无限叠**（软上限） | 不叠，占槽 | 不叠，占槽 |
| 替换 | 不适用 | **抽到更好的 → 替换或跳过** | **抽到更好的 → 替换或跳过** |
| 品质 | 无（固定小数值） | 普通/精良/传说 | 普通/精良/传说（部分**只有单一品质**） |
| 局外解锁什么 | 哪些卡能进池 + **等级/张数上限** | 哪些能进池 + 槽位数 | 哪些能进池 + 槽位数 + 同类上限 |

### 4.2 属性卡（纯数值）清单草案

**数值尺度：+3~8%/张**（因为会叠很多张）。
**张数上限**：初始每类 2~3 张（**局外天赋可抬高**，同 `upgrade_level_cap` 机制）——
上限的具体数字**不是拍脑袋，是算出来的**，见 §4.2.1。

| 卡 | 每张效果 | 分类 | 初始张数上限 | 局外可抬到 | 备注 |
|---|---|---|---|---|---|
| 破军 | 伤害 **+6%** | 攻击 | 3 | 8 | 主乘区 |
| 疾影 | 攻速 **+5%** | 攻击 | 2 | 6 | 会压缩动作时长 |
| 鹰眼 | 暴击率 **+4%** | 攻击 | 2 | 6 | ⚠ 暴击系统不存在 |
| 厚甲 | 受到伤害 **−3%** | 生存 | 3 | 8 | |
| 铁骨 | 生命上限 **+12** | 生存 | 3 | 8 | 平值 |
| 迅足 | 移动速度 **+6%** | 辅助 | 1 | 3 | |
| 聚气 | 暗源获取 **+15%** | 辅助 | 2 | 5 | 与暗源系统咬合 |
| 破势 | 架势伤害 **+25** | 辅助 | 2 | 6 | 已有 `attack_poise_damage` |
| 收割 | 击杀后 1 秒内伤害 **+8%** | 攻击 | 2 | 6 | 条件乘区 |
| 惜血 | 吸血 **+2%** | 攻击 | 2 | 5 | ⚠ 吸血不存在 |
| 连击 | 连击阈值 **−1** | 辅助 | 1 | 3 | 已有 `combo_threshold_delta` |
| 回气 | 技能冷却 **−4%** | 辅助 | 2 | 6 | 已有 `cooldown_reduction` |

> **与现有资产的关系**：这 12 条**大部分能直接用现有 `UpgradeDefinition` 表达**
> （`DamagePlus` / `AttackSpeed` / `Focus` / `ChargeDamageReduction` 等），差的是
> ① **卡片实例语义**（G1：可重复持有、各算一次）② 生命上限 / 暴击 / 吸血 / 移动速度这四条 statId（G2）。

#### 4.2.1 ★ 上限怎么算出来的（2026-11-16 实测数据）

**输入（都是实测，不是估值）**：

| 量 | 值 | 来源 |
|---|---|---|
| 经验曲线 | **30 级**，Lv1=200 → Lv30=5,150，合计 **88,650** | `ExpCurve_30min` 实读 |
| 每圈敌人 | **267 只**（N1×2=14 + E0=49 + N3×3=204）+ J1/EV 生成波 ≈ 283 只 | 手写配置实读 |
| 每圈经验 | ≈ **15,400** | 283 只 × 平均 ~50 经验 |
| **每圈三选一机会** | **10 次**（经验升级带来的） | 15,400 经验 → 升 10 级 |
| 经验线可用圈数 | **3 圈**（88,650 ÷ 15,400） | ⇒ **第 4 圈起没有经验三选一** |
| 敌人每圈成长 | 杂兵 HP **×1.6**、BOSS HP ×1.25、攻速 ×1.06、伤害 ×1.04 | `EndlessRunController` 缩放口径 |

**推论（三条，都很干净）**：

1. **玩家追平敌人需要每圈 ~8.3 张纯伤害卡**（1.06^n ≥ 1.6 ⇒ n ≥ 8.3），
   而每圈只有 **10 次**机会 ⇒ **一圈里只要拿了任何一张非伤害卡，就必然落后**。
   ⇒ **取舍不是设计出来的，是算出来的** ✔
2. **纯数值 build 满配需要 ~3 圈**（初始上限总和 25 张 ÷ 10 张/圈），
   而敌人 3 圈涨 **×4.1** ⇒ 满配也追不上 ⇒ **局有尽头（除非走机制卡 / 装备 / 武器路线）** ✔
3. **第 4 圈起经验线用完** ⇒ 必须有第二个三选一来源 ⇒ **圈结算要固定给卡**
   （建议每圈 **10 次**，与经验段同量级；否则第 4 圈起玩家无 build 可加、只能挨打）。

**初始上限总和 = 25 张**（见上表）≫ 每圈 10 次 ⇒ **一圈最多吃满 40% 的种类** ⇒ 取舍成立；
局外天赋抬高每类上限 = **拓宽 build 面**（后期能同时养更多条线），但仍受"每圈机会数"与"敌人每圈 ×1.6"双重限制 ⇒
**局外成长提高上限，局内决定这一圈怎么填**。

> ⚠ 上述「每圈 10 次三选一」目前**还没实现**：现在三选一只由经验升级触发 ⇒ 第 4 圈起玩家拿不到卡。
> 这是**无限模式的硬缺口**，必须补（见执行计划 B6.12）。

### 4.3 饰品（被动）清单草案

**数值尺度：+5~15%（条件件更小）**；**每个饰品 = 一条"改规则"的句子**；**部分饰品只有单一品质**（用户定的"一次性复活"= 精良单档）。

| 饰品 | 品质 | 效果 | 类型 | 对应 PBZ 形状 |
|---|---|---|---|---|
| **霸王血铠** | 精良（**单档**） | **每 100 点生命上限 → +20 攻击力** | 攻击 | ③ 状态转化器（古甲残片） |
| 追猎令 | 普通/精良/传说 | 对**破防状态**的敌人伤害 +7/+12/+18% | 攻击 | ② 条件乘区（追杀令） |
| 疾影仪 | 普通/精良/传说 | 对**攻击动作中**的敌人伤害 +7/+12/+18% | 攻击 | ②（影动猎杀仪） |
| 破盾符 | 普通/精良/传说 | 对**持盾**敌人的伤害 +10/+16/+25% | 攻击 | ②（破盾符） |
| 斩骑符 | 普通/精良/传说 | 对**骑兵**伤害 +15/+25/+40% | 攻击 | ②（斩骑符） |
| 铁壁护腕 | 普通/精良/传说 | **未处于破防状态**时受到伤害 −8/−15/−25% | 生存 | ⑦ 条件免伤（坚岩护腕） |
| 稳息香盒 | 普通/精良/传说 | 释放影之武装的**暗源消耗** −10/−15/−25% | 辅助 | ⑤ 资源节奏（正气凌然） |
| 灵光腕 | 普通/精良/传说 | **完美格挡 / 完美闪避窗口** +10/+15/+25% | 辅助 | ④ 窗口放宽（浑源经脉仪） |
| 反击护腕 | 普通/精良/传说 | 完美格挡后 2 秒内伤害 +15/+20/+30% | 辅助 | ⑥ 行为奖励（反击护腕） |
| 不屈指环 | 普通/精良/传说 | 连续 8 秒未受伤 → 免疫下一次伤害 | 生存 | ⑥（百战魔躯） |
| 回魂铃 | 精良（**单档**） | **一次性复活**（触发后移除本饰品） | 生存 | 用户指定 |
| 疾风符 | 普通/精良/传说 | **切换武器**时获得 1 秒霸体 + 减伤 10/15/25% | 辅助 | ⑧ 装备联动 ⇒ **等局内切换做了再上** |

**同类上限**：攻击 / 生存 / 辅助**各最多 3 个**（照抄 PBZ）⇒ 装满同类后，新饰品只能"换掉一个或跳过"。

### 4.4 影之武装（主动）的品质怎么落地

**复用现有等级行，零新资产**：
- 现有主动技能的 `numericLevels` 有 5 级 ⇒ **普通 = 第 1 级 / 精良 = 第 3 级 / 传说 = 第 5 级**；
- 抽到更高品质 = 取更高一级的那套数值（伤害 / CD / 范围）；
- **替换规则**：槽位里已有同款且新卡品质更高 ⇒ 弹"替换 / 跳过"（复用 `ItemDiscardPopup`）；
  已有**不同款** ⇒ 两条路都走（替换 or 跳过）；空槽 ⇒ 直接进。

**暗源（用户定：进攻获取，防"按住防御纯用技能"；与大招能量**并存**）**：
- 每个主动技能有**暗源消耗**（新字段）；
- 暗源**只靠命中/击杀/破防**获得 ⇒ 防御姿态**不回**暗源；
- 暗源见底 ⇒ 放不出；
- **饰品「稳息香盒」**减消耗 ⇒ 与 PBZ 的"杀气消耗 −15%"同型；
- 数值标定铁律：**每点暗源的期望伤害必须低于同等时间的普攻** ⇒ 否则最优解仍是"用技能代替打怪"。

**暗源的显示位置（用户定：要有地方显示数量与充能）**：
- **主动技能栏（`FrontItemBar`）正下方一条细横条 + 数字**（与主动技能栏同区，因为它服务于它们）；
  理由：PBZ 的暗源就是全局一条；我们的大招能量已经有自己的环（`UltimateButtonUI`），不动它 ⇒ **两条资源各自可见、互不抢位置**；
- 条上有刻度（当前值 / 上限），见底时变红并轻微闪烁（提示"放不出技能了"）；
- 击杀/破防时飘 "+N" 小字（与铜钱飘字同风格）。

### 4.5 替换 / 跳过 / 重抽 流程

```
三选一弹出（3 张）
  ├─ 属性卡 → 直接入账（可叠，受软上限）
  ├─ 影之武装 / 饰品
       ├─ 槽位空 → 直接装上
       ├─ 同款更高品质 → 「替换 / 跳过」
       └─ 不同款 → 「替换哪个槽位 / 跳过」
跳过 = 本次三选一作废（不消耗这次机会）
重抽 = 用局内货币（暗源或铜钱）重掷三张（ARAM 式；我们目前没有，建议加）
```

### 4.6 品质 3 档的数值尺度（统一口径）

| 品质 | 数值系数 | 说明 |
|---|---|---|
| 普通 | ×1.0 | 基础形态 |
| 精良 | ×1.7 | 主要提升点 |
| 传说 | ×2.8 | 形态质变（通常伴随一条新机制） |

> 跨品质**不是**"同一句话乘 1.7/2.8"，而是**同一条规则在更高档位换更强的数值 / 多一条机制**
>（照抄 PBZ 的"高阶形态"思路）。
