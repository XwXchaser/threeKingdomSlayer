# in-run-build-archetypes

## Summary
当前局内三选一以蓄力流和位移流为两条主要构筑路线，并明确哪些异常配置属于有意保留。

## Content
# 局内三选一构筑主轴

## 用户确认的核心方向

当前局内三选一玩法优先理解为两套核心 Build，而不是所有奖励平均竞争。

### 蓄力流

- 核心招式：Pierce、Sweep 等蓄力攻击。
- 核心目标：将蓄力窗口的时间和受击风险转化为防御、积层与爆发收益。
- 已有组件：蓄力减伤、反伤盾、蓄力冲击波。
- 战斗节奏：主动承担蓄力窗口风险，积攒资源后集中释放。

### 位移流

- 核心招式：Stab、Slash 及高频攻击。
- 核心目标：通过击退、横向聚拢、阵型重排等方式控制敌人位置。
- 联动组件：击退波、聚拢波、地刺、烈焰喷射、箭雨及其他区域效果。
- 战斗节奏：持续调整阵型，将敌人送入有利位置或伤害区域进行收割。

## 当前调优边界

以下项目由用户有意配置或计划手动调整，暂不作为自动修复目标：

- 三选一池内的极端权重。
- Rare / Legendary 池暂时为空。
- AttackSpeed 等级数量与当前配置方式。
- 敌人对象池当前预热方式。
- Boss 104 当前只接入 Phase 1。

仍需要作为确定性问题继续关注：

1. 连击10层的攻击 Buff 可能尚未真正接入伤害计算。
2. Restart 对铜钱结算、飞行经验宝石、三选一队列等状态清理可能不完整。
3. 旋风落地伤害比例的配置单位可能与代码预期不一致。

## 后续体验调优原则

- 评价奖励时优先判断它服务于蓄力流、位移流，还是作为两者的通用补强。
- 调整关卡敌人和阵型时，需要同时给两条 Build 提供发挥空间。
- 不应仅以单项 DPS 衡量技能价值；蓄力流关注风险换爆发，位移流关注阵型控制与区域联动。
