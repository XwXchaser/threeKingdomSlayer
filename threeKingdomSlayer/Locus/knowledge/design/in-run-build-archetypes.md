# in-run-build-archetypes

## Summary
当前局内三选一以蓄力流和位移流为两条主要构筑路线，并明确哪些异常配置属于有意保留。

## Content
# 局内三选一构筑主轴（V2当前基线）

## 核心构筑

当前V2以两套主Build为核心，火系作为跨流派协同；奖励价值不按单项DPS平均衡量。

### 蓄力流

- 核心招式：Pierce、Sweep等蓄力攻击。
- 核心目标：将蓄力窗口的风险转化为减伤、积层与集中爆发。
- 核心技能：铁壁、被动冲击波、震荡、主动冲击波。
- 辅助技能：疾风缩短攻击节奏，其他通用输出补足蓄力间隔。
- 战斗节奏：先获得安全蓄力条件，再通过主动/被动层数强化下一次蓄力释放。

### 位移流

- 核心目标：以主动技能高频打断、击退、浮空和削韧，换取安全输出空间。
- 核心技能：海浪、旋风、专注。
- 辅助技能：拔苗助长扩大基础攻击覆盖；疾风提高技能间隙中的攻击频率。
- 海浪与旋风均为零HP伤害控制技能：命中计入Combo，可打断普通敌人的霸体攻击并播放受击反馈。
- 对未Stun Boss：不直接位移，改为按最大Poise百分比削韧并播放对应视觉；QTE、转阶段和非交战状态受保护。
- 对已Stun Boss：旋风可以执行击飞；击飞期间保存并消耗剩余Stun时间，落地后仅恢复仍未耗尽的Stun。

### 火系协同

- 蛇形烈焰喷射：被动、短间隔、蛇形范围喷火并施加灼烧。
- 火龙舌：主动、长CD、直线火焰；目标处于灼烧时必定暴击并造成200%伤害。
- 定位：跨流派通用组合，不单独作为第三条完整Build。

## 玩家成长边界

- 最多持有6个被动、4个主动。
- 约需42次有效技能升级将所持技能全部升满。
- 目标是在30分钟流程约70%处完成技能满级，后续升级候选转为立即回复20点生命。
- 前期升级快、后期逐步放缓；任意连续两波内应至少获得一次升级，避免成长断档。

## 敌人侧适配原则

- 101：基础割草杂兵。
- 103：仅使用CAttack的霸体教学杂兵。
- 106：固定轨迹远程单位，教学Parry处理箭矢。
- 105：随机轨迹的进阶远程单位。
- 104及变体107/108：综合霸体、QTE和阶段机制的Boss；Trial不使用102。
- 波次应同时给蓄力流提供可蓄力窗口，给位移流提供可重排、打断的阵型价值。
- Boss战以合理构筑45–90秒为目标；首次Boss仅1阶段，后续随难度增加至最多3阶段。

## 当前调优边界

- 池内同稀有度技能权重已归一化，临时测试权重不属于最终设计。
- 虚幻武器暂缓，不进入当前数值联调范围。
- 技能资产先作为玩家强度基准，敌人波次、HP、伤害和Boss阶段数值再按预期构筑倒推。
- 调整时必须区分伤害价值与控制价值：海浪、旋风的主要收益是安全、打断、阵型控制和Boss削韧，而非DPS。
