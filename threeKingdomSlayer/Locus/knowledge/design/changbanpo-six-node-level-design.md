# 长坂坡六节点关卡与战斗背景构造目标

## 1. 文档定位

本文记录长坂坡关卡的当前设计目标、六个节点的叙事语义、分支结构，以及战斗背景参考图的制作约束。

路线逻辑由战斗节点和选择节点组成。每个节点都是 `FakeRouteNodeConfig` 逻辑资产，不对应独立 Unity Scene；`Battle.scene` 是唯一运行场景。J 节点只是没有 `BattleEntry` 的路线选择节点，N 节点通常包含战斗内容。

## 2. 总体关卡目标

关卡主题为“长坂坡·血路突围”，表现刘备军民撤退、曹军追击、赵云救阿斗以及张飞长坂桥断后的连续战役。

玩家始终控制张飞。赵云、阿斗、刘备和曹军主力通过节点情景、背景、转场或剧情表现出现，不切换玩家操作角色。

关卡采用六个战斗节点和两个选择节点：

```text
N1 当阳乱军
└─ J1 官道/村落选择
   ├─ N2 官道断后
   │  └─ N4 山道救援
   │     └─ N6 长坂桥断后
   └─ N3 村落搜救
      └─ J3 救援/合围选择
         ├─ N4 山道救援
         └─ N5 曹军合围
            └─ N6 长坂桥断后
```

节点数量统计：

- 战斗节点：N1、N2、N3、N4、N5、N6，共 6 个；
- 选择节点：J1、J3，共 2 个；
- 总逻辑节点：8 个。

N1 是关卡起始战斗，不需要前置选择节点；N6 是唯一终点。N2、N4、N5 只有一个目标时直接进入目标战斗节点，不额外创建选择节点。所有路线最终汇合到 N6，保证长坂桥断后的历史高潮发生。

### 选择节点职责

选择节点不是战斗节点的附属 UI，但也不是独立 Unity Scene。它是由 `FakeRouteNodeConfig` 表达的非战斗逻辑阶段，负责：

- 承接上一个战斗节点的完成结果；
- 在 `Battle.scene` 中显示路线选择表现；
- 展示出口选项、路线预览和风险/奖励信息；
- 等待玩家确认后播放前往目标节点的移动演出；
- 演出完成后提交目标节点并开始下一场战斗。

选择节点不包含 `BattleEntry`、敌人波次或战斗奖励。J 节点与 N 节点没有独立的 Unity 场景类型差异；它们的区别只来自配置内容和运行时阶段。长坂坡段落的核心事件：

1. 刘备携民撤退，在当阳长坂被曹军追上。
2. 军民、部队与家眷在乱军中失散。
3. 赵云返回乱军寻找甘夫人与阿斗。
4. 赵云找到阿斗并杀出重围。
5. 曹军主力持续追击，曹操在高处观战并试图生擒赵云。
6. 刘备军撤过长坂桥，张飞留下断后，最终以威势阻退曹军。

游戏叙事需要将赵云救阿斗与张飞长坂桥断后作为同一战役中的两个高潮，但不让玩家角色在张飞与赵云之间切换。

## 3. 六个战斗节点语义

### N1：当阳乱军

**叙事语义**：刘备军民仓促撤退后留下的开阔荒地。张飞重新组织残兵，曹军追击将至。

**战斗功能**：开场与基础压力建立。敌人以普通追击部队为主，表现战线混乱和撤退中的第一次阻击。

**背景语义**：开阔黄土战场、远处低矮城墙或山脉、少量烟尘、边缘破车与断旗。中央和左右保持连续战斗空间，不画窄路，不让环境暗示玩家在移动。

### N2：官道断后

**叙事语义**：张飞选择留在主官道正面阻击曹军，保护百姓和辎重，为刘备主军及赵云争取时间。

**战斗功能**：正面追击战。敌人数量和推进压力高于 N1，可加入盾兵、重装兵或远程敌人。

**背景语义**：较宽的官道断后战场，两侧低矮土坡、断墙、枯树，远景增加曹军旗帜和烽火。道路不能收窄五列横向战斗区域。

### N3：村落搜救

**叙事语义**：张飞离开主官道，进入被战火波及的村落侧翼，寻找失散军民并吸引曹军注意，为赵云继续寻找阿斗制造机会。

**战斗功能**：侧翼/救援战。可采用夹击、远程压力或持续刷新，区别于 N2 的正面阻击。

**背景语义**：村落边缘空地。低矮茅屋、木篱笆、残墙和淡烟放在左右边缘或远景；中央仍是宽阔连续的战斗地面。

### N4：山道救援

**叙事语义**：赵云已经找到阿斗，正在山道中突围。张飞进入侧翼清理追兵，掩护赵云撤退。

**战斗功能**：中段精英/连续追击战，作为赵云救阿斗后的主要战斗高潮。

**背景语义**：山道中的开阔谷地。山壁只能作为远景或两侧低矮边界，不能形成狭窄通道或侵入敌人阵型区域；色调可偏灰蓝、土黄，增强压迫感。

### N5：曹军合围

**叙事语义**：张飞继续深入曹军侧翼，试图切断追击组织，结果进入曹军主力的包围范围。曹操或曹军主���可通过远景旗阵、营帐或高台暗示存在。

**战斗功能**：高风险路线和 Boss 前置压力战。敌人阵型更密集，可加入远程、重装、箭雨或精英组合。

**背景语义**：曹军主力军阵前沿或宽阔坡地。暗红军旗、低矮营垒、战鼓台、烽火和尘烟横向铺开，但全部保持低对比，不能遮挡五列五排战斗区域。

### N6：长坂桥断后

**叙事语义**：赵云已带阿斗与刘备军汇合并先行撤退。张飞留在长坂桥断后，最终面对曹军追兵。

**战斗功能**：全关卡终局战。可采用多阶段高压战斗：曹军试探、精英先锋、主力压境；清空后播放张飞喝退曹军的终点演出。

**背景语义**：战斗发生在长坂桥桥面，不是河床、浅滩或水中。桥面承载中央、左右和纵深战斗区域；桥栏只沿左右边缘出现；水面只在两侧下方露出窄条；桥头和曹军位于远景。桥不能作为远处横跨河面的风景主体，也不能让河流占据战斗地面。

## 4. 分支叙事

### 主路：N1 → N2 → N4 → N6

张飞选择继续在官道正面断后，服从撤退军令并保护百姓。随后得知赵云在山道突围，转入山道清理追兵。

叙事形象：稳重、正面承担压力、以断后换取全军撤退时间。

### 救援路：N1 → N3 → N4 → N6

张飞离开官道进入村落侧翼，寻找失散军民并主动接应赵云。N4 中表现张飞为赵云清理后方追兵。

叙事形象：主动、重视战友、承担救援风险。

### 高风险路：N1 → N3 → N5 → N6

张飞没有直接返回山道，而是继续深入曹军侧翼，试图打乱曹军追击组织，因此遭遇曹军主力合围。

叙事形象：激进、冒险、以攻代守，为全军争取更大的撤退窗口。

## 5. 选择节点与逻辑拓扑

选择节点不是战斗节点的附属 UI，而是由 `FakeRouteNodeConfig` 表达的非战斗逻辑阶段。正式关卡共 8 个逻辑节点：N1-N6 六个战斗节点，J1、J3 两个选择节点。所有节点都位于唯一的 `Battle.scene` 运行环境中，不创建独立 Unity Scene。

```text
N1 → J1 → N2/N3
N2 → N4
N3 → J3 → N4/N5
N4 → N6
N5 → N6
```

J1 和 J3 的表现只负责路线选择和节点间移动，不承担战斗背景职责。
## 6. 当前路线工程目标

当前 `route-fake-movement` 的测试拓扑和“Battle.scene 唯一运行场景、节点不是 Unity Scene、战斗结束直接显示当前节点路线选择”的方案，只能作为早期垂直切片，不能作为长坂坡正式关卡拓扑。

正式实现必须支持：

- 战斗节点与选择节点分离为逻辑阶段；
- 每个战斗节点完成后，有分支时进入指定选择节点，单一目标时直接进入目标战斗节点；
- 选择节点完成后再进入目标战斗节点；
- N4 可由 J3 汇入，N6 由 N4/N5 汇入；
- 选择节点使用 `FakeRoutePresentation` 等表现资产，不创建独立 Unity Scene；

## 7. 当前 FakeRoute 工程语义（历史切片）

当前实现中，`Battle.scene` 是唯一战斗运行场景，节点仍是 `FakeRouteNodeConfig` 资产；战斗节点直接显示路线选择 UI，并通过表现资产模拟节点间移动。这套实现仅用于早期垂直切片，不能直接承载正式长坂坡的 J1/J3 选择节点语义。

正式拓扑必须将战斗完成、进入选择节点、玩家确认出口、进入目标战斗节点拆成明确的流程阶段。选择节点的场景/表现、进入和离开演出、来源上下文以及安全存档边界需要在工程设计阶段重新定义。

## 8. 战斗背景制作目标

为了便于后续补图和调整，正式背景可按职责拆分为：

```text
天空层
远景/地平线层
战斗地面层
边缘叙事物件层
```

其中战斗地面层应优先满足敌人阵型和实际显示范围；天空与远景负责节点氛围；边缘物件负责剧情识别，不得侵入战斗区域。

## 10. 当前制作优先级

1. 恢复 N1 的正式背景引用，避免 N1 继续使用 N6 测试图。
2. 创建独立 `N6_Battle.asset` 并正式接入 N6。
3. 在 Unity 中逐个验收 N1-N6、J1、J3 的实际战斗/选择显示效果。
4. 基于已验收的静态图设计必要的路线转场视频，优先制作实际路线边而不是完整长视频。
5. 后续补充各节点的环境层拆分或视频素材时，继续保持战斗安全区、低机位和节点语义。

### 14. Plan B：Q版图片黑屏路线过场

为保留具体路线动画方案的同时提供低成本、可快速迭代的备用表现，路线出口表现支持两种可切换模式：

- `Video`：播放该出口独立配置的具体路线动画；
- `ChibiBlackout`：播放单块黑色遮罩横向滑动的Q版图片过场。

`ChibiBlackout` 的流程固定为：

```text
当前节点画面
→ 单块黑色遮罩从右向左滑入并覆盖画面
→ 黑屏阶段展示该出口独立配置的Q版角色/地点图片与移动或战斗提示
→ 单块黑色遮罩从左向右滑出
→ 提交目标节点并切换目标战斗背景
```

黑屏遮罩是单个横向移动的黑色UI遮罩，不采用左右两块遮罩合拢。Q版图片、标题、提示文字和音效均按路线出口独立配置，不由目标节点统一配置，以便表达不同路线的叙事差异。

表现模式只属于 `FakeRoutePresentation` 和 `FakeMovementPresenter`；`FakeRouteRuntime` 仍只等待表现完成后提交目标节点，不感知具体表现类型。视频方案与Q版黑屏方案可以在不同出口之间混用，并可通过Inspector切换观察效果。
