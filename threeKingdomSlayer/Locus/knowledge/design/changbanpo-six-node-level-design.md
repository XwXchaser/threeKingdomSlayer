# 长坂坡六节点关卡与战斗背景构造目标

## 1. 文档定位

本文记录长坂坡关卡的当前设计目标、六个节点的叙事语义、分支结构，以及战斗背景参考图的制作约束。

路线逻辑由战斗节点和选择节点组成。每个节点都是 `FakeRouteNodeConfig` 逻辑资产，不对应独立 Unity Scene；`Battle.scene` 是唯一运行场景。J 节点只是没有 `BattleEntry` 的路线选择节点，N 节点通常包含战斗内容。

## 2. 总体关卡目标

关卡主题为“长坂坡·血路突围”，表现刘备军民撤退、曹军追击、赵云救阿斗以及张飞长坂桥断后的连续战役。

当前六战斗节点版本只定义了主线骨架。后续正式关卡应扩充为“关键战斗节点为骨架、高频非战斗节点承载撤退过程”的结构：通过军民失散、整队、侦察、救援、护送、情报、抉择、短暂喘息与追兵逼近等可交互情景，表现持续撤退和战局演变。非战斗节点应多于战斗节点，但每个节点必须推进局势、人物关系、路线风险或玩家局内资源中的至少一项，避免成为纯文本停顿。

本关单次通关目标控制在 **10 分钟以内**。因此节点扩充应优先采用短时、可快速确认的非战斗情景与 1–2 段关键分支，不堆叠成长菜单或长对话；路线允许在后段汇合，确保终局长坂桥的节奏和资源压力稳定。

玩家始终控制张飞。赵云、阿斗、刘备和曹军主力通过节点情景、背景、转场或剧情表现出现，不切换玩家操作角色。

关卡采用六个战斗节点和两个选择节点：

```text
N1 当阳乱军
└─ J1 官道/村落选择
   ├─ N2 官道断后
   │  └─ N4 山道救援
   │     └─ N6 长坂桥断后
   └─ N3 村落搜救
      └─ J3 救援/合围选择
         ├─ N4 山道救援
         └─ N5 曹军合围
            └─ N6 长坂桥断后
```

节点数量统计：

- 战斗节点：N1、N2、N3、N4、N5、N6，共 6 个；
- 选择节点：J1、J3，共 2 个；
- 总逻辑节点：8 个。

N1 是关卡起始战斗，不需要前置选择节点；N6 是唯一终点。N2、N4、N5 只有一个目标时直接进入目标战斗节点，不额外创建选择节点。所有路线最终汇合到 N6，保证长坂桥断后的历史高潮发生。

### 选择节点职责

选择节点不是战斗节点的附属 UI，但也不是独立 Unity Scene。它是由 `FakeRouteNodeConfig` 表达的非战斗逻辑阶段，负责：

- 承接上一个战斗节点的完成结果；
- 在 `Battle.scene` 中显示路线选择表现；
- 展示出口选项、路线预览和风险/奖励信息；
- 等待玩家确认后播放前往目标节点的移动演出；
- 演出完成后提交目标节点并开始下一场战斗。

选择节点不包含 `BattleEntry`、敌人波次或战斗奖励。J 节点与 N 节点没有独立的 Unity 场景类型差异；它们的区别只来自配置内容和运行时阶段。长坂坡段落的核心事件：

1. 刘备携民撤退，在当阳长坂被曹军追上。
2. 军民、部队与家眷在乱军中失散。
3. 赵云返回乱军寻找甘夫人与阿斗。
4. 赵云找到阿斗并杀出重围。
5. 曹军主力持续追击，曹操在高处观战并试图生擒赵云。
6. 刘备军撤过长坂桥，张飞留下断后，最终以威势阻退曹军。

游戏叙事需要将赵云救阿斗与张飞长坂桥断后作为同一战役中的两个高潮，但不让玩家角色在张飞与赵云之间切换。

## 3. 六个战斗节点语义

### N1：当阳乱军

**叙事语义**：刘备军民仓促撤退后留下的开阔荒地。张飞重新组织残兵，曹军追击将至。

**战斗功能**：开场与基础压力建立。敌人以普通追击部队为主，表现战线混乱和撤退中的第一次阻击。

**背景语义**：开阔黄土战场、远处低矮城墙或山脉、少量烟尘、边缘破车与断旗。中央和左右保持连续战斗空间，不画窄路，不让环境暗示玩家在移动。

### N2：官道断后

**叙事语义**：张飞选择留在主官道正面阻击曹军，保护百姓和辎重，为刘备主军及赵云争取时间。

**战斗功能**：正面追击战。敌人数量和推进压力高于 N1，可加入盾兵、重装兵或远程敌人。

**背景语义**：较宽的官道断后战场，两侧低矮土坡、断墙、枯树，远景增加曹军旗帜和烽火。道路不能收窄五列横向战斗区域。

### N3：村落搜救

**叙事语义**：张飞离开主官道，进入被战火波及的村落侧翼，寻找失散军民并吸引曹军注意，为赵云继续寻找阿斗制造机会。

**战斗功能**：侧翼/救援战。可采用夹击、远程压力或持续刷新，区别于 N2 的正面阻击。

**背景语义**：村落边缘空地。低矮茅屋、木篱笆、残墙和淡烟放在左右边缘或远景；中央仍是宽阔连续的战斗地面。

### N4：山道救援

**叙事语义**：赵云已经找到阿斗，正在山道中突围。张飞进入侧翼清理追兵，掩护赵云撤退。

**战斗功能**：中段精英/连续追击战，作为赵云救阿斗后的主要战斗高潮。

**背景语义**：山道中的开阔谷地。山壁只能作为远景或两侧低矮边界，不能形成狭窄通道或侵入敌人阵型区域；色调可偏灰蓝、土黄，增强压迫感。

### N5：曹军合围

**叙事语义**：张飞继续深入曹军侧翼，试图切断追击组织，结果进入曹军主力的包围范围。曹操或曹军主���可通过远景旗阵、营帐或高台暗示存在。

**战斗功能**：高风险路线和 Boss 前置压力战。敌人阵型更密集，可加入远程、重装、箭雨或精英组合。

**背景语义**：曹军主力军阵前沿或宽阔坡地。暗红军旗、低矮营垒、战鼓台、烽火和尘烟横向铺开，但全部保持低对比，不能遮挡五列五排战斗区域。

### N6：长坂桥断后

**叙事语义**：赵云已带阿斗与刘备军汇合并先行撤退。张飞留在长坂桥断后，最终面对曹军追兵。

**战斗功能**：全关卡终局战。可采用多阶段高压战斗：曹军试探、精英先锋、主力压境；清空后播放张飞喝退曹军的终点演出。

**背景语义**：战斗发生在长坂桥桥面，不是河床、浅滩或水中。桥面承载中央、左右和纵深战斗区域；桥栏只沿左右边缘出现；水面只在两侧下方露出窄条；桥头和曹军位于远景。桥不能作为远处横跨河面的风景主体，也不能让河流占据战斗地面。

## 4. 分支叙事

### 主路：N1 → N2 → N4 → N6

张飞选择继续在官道正面断后，服从撤退军令并保护百姓。随后得知赵云在山道突围，转入山道清理追兵。

叙事形象：稳重、正面承担压力、以断后换取全军撤退时间。

### 救援路：N1 → N3 → N4 → N6

张飞离开官道进入村落侧翼，寻找失散军民并主动接应赵云。N4 中表现张飞为赵云清理后方追兵。

叙事形象：主动、重视战友、承担救援风险。

### 高风险路：N1 → N3 → N5 → N6

张飞没有直接返回山道，而是继续深入曹军侧翼，试图打乱曹军追击组织，因此遭遇曹军主力合围。

叙事形象：激进、冒险、以攻代守，为全军争取更大的撤退窗口。

## 5. 选择节点与逻辑拓扑

选择节点不是战斗节点的附属 UI，而是由 `FakeRouteNodeConfig` 表达的非战斗逻辑阶段。旧版六战斗节点与两个选择节点仅作为战斗语义基准保留；正式长坂坡拓扑以 5.6 的 `N` 战斗节点、`E` 情景节点和 `J` 分支选择节点为准。

```text
N1 → J1 → N2/EV
EV → N3
N2 → N4
N3 → E3 → EW → J3 → N4/N5
N4 → N6
N5 → N6
```

J1 和 J3 的表现只负责路线选择和节点间移动，不承担战斗背景职责。
## 5.5 节点扩充与叙事节奏方向

正式版本不应局限于六个战斗节点与两个选择节点。推荐保持 N1、N4/N5、N6 等关键战斗高潮，同时在其间增加更多情景节点，使整体节奏形成：

```text
突发追击
→ 整队与方向抉择
→ 局部救援／侦察／护送
→ 短战斗或危机脱离
→ 获得赵云与阿斗的战况
→ 追兵压迫升级与高风险决策
→ 撤退队伍汇合
→ 长坂桥最终断后
```

非战斗节点可提供简短对话、环境观察、有限资源或临时局内增益、路线风险预览、护送对象状态和叙事结果反馈。它们必须由当前路线、此前选择或战斗结果产生上下文差异；战斗与非战斗节点之间需要配置独立转场表现，以持续传达“撤退仍在进行、曹军仍在逼近”的空间和时间连续性。

节点总量、各节点具体内容、分支重合程度及转场视频脚本需在后续节点细化阶段确定；本节的六战斗节点语义仍作为现阶段主战斗锚点，不代表最终节点总量。
## 5.6 十分钟正式拓扑与节点内容草案（待评审）

单局目标时长为 8–10 分钟。正式图由战斗节点 `N`、情景节点 `E` 与分支选择节点 `J` 组成。任何节点（包括只有唯一出口的 `E` 和单出口战斗节点）均遵循同一流程：**抵达节点 → 播放该节点内容 → 显示出口 → 玩家点击出口 → 播放该边转场 → 提交目标节点**。不得将情景段做成自动串联的 `S` 过场。

`E` 节点没有战斗、奖励或多路线选择，但它是完整可抵达的逻辑节点：承载短对话、独白、环境观察或信息 UI，内容完成后仍显示唯一出口确认。只有 `J` 节点提供两个或更多出口，因此只有 J1、J2 需要让路线选择本身具有策略意义。开场演出不是节点，不显示路线选择；开场演出完成后直接进入 N1。

```text
N1 当阳乱军（战）
→ E0 战后余烬 → E1 残军集结 → J1 官道断后／村落搜救
├─ N2 官道断后（战）
│  → E2 辎重撤离 → E3 陷车改道 → E4 山脚急行 → N4 山道救援（战）
└─ N3 村落搜救（战）
   → E5 安置幸存者 → E6 民居线索 → E7 斥候急报 → J2 山道接应／侧翼扰敌
   ├─ E8 战痕引路 → E9 山隘传令 → N4 山道救援（战）
   └─ N5 曹军合围（战） → E10 杀出侧翼
N4／N5 → E11 撤军讯号 → E12 奔赴桥头 → N6 长坂桥断后（终局战）
```

| 节点 | 时长 | 叙事与交互 | 局内体验职责 |
|---|---:|---|---|
| N1 当阳乱军 | 45–60 秒 | 张飞在溃散军民间组织首轮阻击；结束后听到赵云折返寻人。 | 教学后的开场压力与第一笔成长收益。 |
| E0 战后余烬 | 10–15 秒 | 战场暂歇，确认刘备主队撤退方向；张飞从战斗转入护送任务。 | 叙事过渡；无战斗、无奖励、唯一出口。 |
| E1 残军集结 | 10–15 秒 | 残兵报告：官道有辎重和百姓，村落传来失散者呼救。 | 用简短对话明确两条路线的对象与风险；唯一出口。 |
| J1 | 10–15 秒 | 玩家确认走官道断后或转入村落搜救。 | 首次分支；路线卡只展示风险倾向与叙事预告，不展示精确数值。 |
| N2 官道断后 | 50–65 秒 | 曹军正面压来，张飞为辎重车队争取时间。 | 高敌量、正面压迫；偏稳定收益。 |
| E2 辎重受阻 | 10–20 秒 | 车轮陷泥、民夫受困；张飞命人绕山脚继续撤离，自己留下断后。 | 叙事反馈：官道路保护了车队，但撤退速度下降、追兵仍在逼近。 |
| N3 村落搜救 | 50–65 秒 | 张飞驱散追兵、救出失散军民；幸存者提供赵云去向。 | 夹击/远程压力；通过叙事信息确认赵云路线。 |
| E3 民居线索 | 10–15 秒 | 幸存者确认赵云已抱阿斗向山道突围，曹军主力正向侧翼合围。 | 将目标从搜救转为接应赵云，建立第二次选择。 |
| J2 | 10–15 秒 | 选择护送军民前往山道，或冒险深入曹军侧翼扰乱合围。 | 第二次分支；明确安全路线与高风险路线。 |
| E4 山道会合 | 10–15 秒 | 看见赵云留下的战斗痕迹与撤离信号，张飞接过后方追兵。 | 安全支路的情绪抬升和 N4 进入动机。 |
| N4 山道救援 | 60–75 秒 | 张飞掩护赵云与阿斗越过狭口、清理紧追不舍的精锐。 | 中段高潮；精英压力与较强成长回报。 |
| N5 曹军合围 | 60–75 秒 | 张飞突入侧翼扰乱曹军军阵，却被主力反向围住。 | 高风险替代 N4；密集组合敌人和更高回报。 |
| E5 撤军讯号 | 10–15 秒 | 远处号角与旗语确认刘备军已过桥，桥头需要张飞断后。 | 全路线汇合，清楚转入最终任务。 |
| N6 长坂桥断后 | 120–150 秒 | 张飞独守桥面，经历试探、先锋、主力逼近后喝退曹军。 | 最终多阶段战，完成本关叙事与结算。 |

### 分支的叙事与RPG定位

- **官道路**：正面承担压力。N2 敌量更高但路线明确；通过 E2 转入山道，适合想稳定推进的玩家。
- **救援路**：先救军民，再获得赵云情报。N3 可给一次有限恢复或资源补给，J2 才决定稳妥会合或冒险扰敌。
- **合围路**：以更高战斗风险换取更好的局内成长机会；N5 不应额外延长战斗时长，而以敌人组合和奖励质量提高风险。
- **汇合规则**：N4 与 N5 都经 E5 进入 N6。终局信息和目标一致，前序路线只改变张飞抵达桥头时的叙事回顾与已获得的局内构筑，不拆分终局内容。

### 现有系统内的奖励边界

本关第一版不新增独立 RPG 奖励或非战斗资源交互。E1、E2、E3、E4、E5 只提供简短对话、环境观察、路线风险预告和此前选择的叙事反馈；不发放金币、生命恢复、局内道具、三选一候选倾向，也不弹出成长面板。局内成长仅来自实际战斗节点及既有奖励流程。后续若需要补给或事件奖励，必须单独定义其资源边界、触发时机与数值。

### 路线转场视频／图片分镜清单

转场由来源节点的 `FakeRouteChoiceConfig.presentation` 独立绑定；玩家确认路线后播放，完成后才提交目标节点。建议每段 3–6 秒，可跳过，结构为“源节点残留构图 → 行进事件 → 目标节点入口构图”。

| 路线边 | 分镜核心 | 声音与文字重点 |
|---|---|---|
| N1→E1 | 烟尘散开，张飞转向聚拢的残兵与撤退人流。 | 杂乱脚步、呼喊；“先护住撤退的人！” |
| E1→J1 | 画面扫过前方官道辎重与左侧燃烧村落，停在分岔。 | 马嘶、远处喊杀；两条路线风险预告。 |
| J1→N2 | 镜头沿破损官道前进，辎车与百姓向后撤，曹军旗阵从烟尘中压近。 | 车轮、战鼓渐强。 |
