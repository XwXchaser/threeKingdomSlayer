# 局外成长与 Build 系统设计

## 概述

局外成长层解决两个核心问题：
1. **铜钱无处花** — 目前铜钱只攒不花，无消费出口
2. **每局开局完全一样** — Build 方向完全依赖局内随机，玩家是「被动的接受者」而非「主动的构建者」

设计目标：局外决定**你想怎么玩**（Build 方向），局内决定**你能走多远**（Build 深度）。两者都不依赖纯数值膨胀。

---

## 当前状态

```
局内：经验三选一（17 奖励池）、连击 Buff、总击杀里程碑
局外：铜钱（只攒不花）、关卡解锁（线性）
中间：无 Build 系统、无战前决策
```

---

## 三层局外 Build 体系

### Layer 1：天赋树（Talent Tree）— 永久机械性解锁

消耗天赋点（通关获得）解锁节点。三个分支，全部禁止直接加伤害。

#### 攻势分支 — 改变攻击行为

| 天赋 | 效果 | 与局内联动 |
|------|------|----------|
| 破阵 | 所有攻击造成 1 点架势伤害 | 降低对 Launch/Parry 削韧的依赖，眩晕流 Build 更易成型 |
| 追击 | 击杀敌人后攻击冷却 -0.5s | 配合攻速 Build 形成「越杀越快」节奏 |
| 穿透 | Pierce 波穿过首个敌人（多命中 1 个） | 与连锁弹射/回旋镖形成 Pierce 特化 Build |

#### 守势分支 — 改变生存规则

| 天赋 | 效果 | 与局内联动 |
|------|------|----------|
| 铁壁 | Parry 判定窗口 +0.1s | 招架流 Build 入门砖 |
| 不屈 | 血量 <30% 触发 2s 无敌（每局 1 次） | 高风险高回报 Build 的保险 |
| 闪避 | 新增手势：快速横划 → 短距闪避（无敌帧） | 与击退波配合：推远 → 闪避拉开距离 |

#### 谋略分支 — 改变资源和选择空间

| 天赋 | 效果 | 与局内联动 |
|------|------|----------|
| 运筹 | 三选一 → 四选一 | 更多选择 = 更容易凑出目标 Build |
| 识破 | BOSS 招架眩晕时长 +1s | BOSS 战特化，配合招架血量阈值机制 |
| 积粮 | 经验宝石 +20% | 更多升级次数 = Build 更早成型 |

**关键设计**：天赋树每个节点都是「机械开关」，改变「能做什么」而非「做了多疼」。

---

### Layer 2：战前 Loadout（Build 核心）

战前选择 Build 方向，影响本局初始状态和升级池。

#### A. 预载升级（Pre-loaded Upgrade）
- 局外解锁后，战前可选 1 个已有 `UpgradeDefinition` 开局携带（Lv.1）
- 例：选「牵引波」开局 → 第一波就能聚怪 → 后续优先选 AoE 类升级
- 直接定义本局 Build 主轴

#### B. 升级池定制（Pool Tuning）
- 战前 ban 掉 N 个不想要的 `UpgradeDefinition`，提高目标升级出现概率
- ban 位数量由天赋「运筹」等级决定
- 例：Pierce 特化 Build → ban 横扫/击退类升级 → Pierce 相关概率提升

#### C. 阶段词缀（Stage Modifier）
- 消耗铜钱购买一次性词缀，仅本局生效
- 「精英敌 +20%，经验 +30%」— 高风险高回报
- 「BOSS 架势值 -20%，铜钱 -50%」— BOSS 特化
- **铜钱的第一个消费出口**

---

### Layer 3：铜钱经济闭环

```
通关 → 获得铜钱 → 消费铜钱：
  ├─ 购买阶段词缀（一次性，本次战斗生效）
  ├─ 解锁新 UpgradeDefinition（永久加入随机池）
  └─ 升级天赋节点（配合天赋点，永久解锁）
      → 更强 Build → 更好通关 → 更多铜钱
```

## 与局内三选一的联动关系

```
┌──────────────────────────────────────────────────┐
│              局外 Build 层                        │
│  天赋树（永久机械解锁）                            │
│    ↓ 决定                                          │
│  战前 Loadout（预载升级 + 池定制 + 阶段词缀）        │
│    ↓ 注入                                          │
├──────────────────────────────────────────────────┤
│              局内 三选一层                         │
│  玩家按 Build 方向选择，形成协同效应                │
│  例：牵引波(开局) + sweep_range_boost + 回旋镖     │
│       = 「聚怪→横扫→折返」 combo Build            │
└──────────────────────────────────────────────────┘
```

---

## 设计约束

- **禁止直接伤害数值提升**：天赋/词缀只能改变机制、规则、资源
- **所有解锁项通过 Inspector 可追踪**：遵循 `anti-ghost-reference` 规范
- **天赋节点通过 Inspector 拖拽引用**：天赋 → 关联的 UpgradeDefinition/AttackSkillConfig 直接在 Inspector 中可见

---

## 实现优先级

| 优先级 | 内容 | 理由 |
|--------|------|------|
| P1 | 铜钱消费出口（阶段词缀） | 铜钱已积累但无处花，最紧迫 |
| P2 | 战前 Loadout（预载升级） | Build 表达的最小可行方案 |
| P3 | 天赋树 | 需要 UI 框架 + 多节点配置，工程量最大 |
| P4 | 升级池定制 | 依赖天赋树「运筹」节点 |
