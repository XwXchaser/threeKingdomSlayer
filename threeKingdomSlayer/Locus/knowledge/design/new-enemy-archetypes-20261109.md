## 2. 缺口：玩家现在做不了哪些决策

| # | 缺口 | 证据 | 玩家的可选动作 |
|---|---|---|---|
| G1 | **远程只有一个对策**：招架弹反 | 105/106 都是可弹反的箭矢 | 弹反 or 走位（105 落点随机 ±1.2 → 只能赌） |
| G2 | **近战只有射程 1** | 除远程外全部 `attackRange=1` | 第 1 排的敌人打不到玩家 → 玩家永远安全，直到它们补齐 |
| G3 | **防御键没有专属敌人** | `PlayerGuard` 的破防累积没有任何敌人专门去触发 | 防御键是"万能保险"，没有"该不该防"的判断 |
| G4 | **目标优先级没有决策** | 1013 督战不攻击 → 打它不痛 | 机器人/玩家都是"打最前排"，优先级恒定 |
| G5 | **"一波打完了"的节奏不可信** | 敌人都是配置即生成 | 清空一波 = 真的清空了 |
| G6 | **群体只有"共享血量"一种连携** | 102 的 sharedHealthGroup | 集中输出 or 分散，只有一种解法 |

## 3. 新兵种提案

> 每个提案都满足「**一个威胁 + 一个唯一对策**」，并标注复用哪些已有系统（避免为新机制写新代码）。

### 3.1 掷矛手（id 1014）· 补 G1 的"第二远程"

| 项 | 内容 |
|---|---|
| **威胁** | 远程，但**落点锁定玩家当前列**，且**投射物不可弹反**（抛掷矛，不是箭）→ 招架无效 |
| **唯一对策** | **防御键**（免伤）或**位移**（出手前离开那一列） |
| **为什么现在缺** | 现有远程都能弹反 → 玩家学会招架就无脑招架；掷矛手逼出"有 projectile 不一定能反"的判断 |
| **实现落点** | 新组件 `SlingerEnemy`（预判列 + 抛物线投射物）；投射物复用 `EnemyProjectile`，加一个 `unreflectable` 标记让 Parry 不反弹 |
| **数值草案** | HP 90 / 射程 3 / 架势 35 / 攻速 0.35（比弓手慢一点，给走位窗口）/ 伤害 8 |
| **美术成本** | 🔴 需新素材（持矛兵 + 投掷动作），可复用 1051 的体型与配色 |
| **波次位置** | 中期起，与 105/106 混编（先出可弹反的弓 → 再出弹不回来的矛） |

### 3.2 落石兵（id 1015）· 远程的第二档：范围 + 预警

| 项 | 内容 |
|---|---|
| **威胁** | 远程 **范围**伤害（落点周围 1 格），落点**随机但有地面预警圈**（1 秒） |
| **唯一对策** | **站位**（看到圈就挪开）或防御（圈在防御键范围外就防不住） |
| **为什么现在缺** | 现有远程都是"单点"，玩家只需要处理"打不打得到我"；落石兵引入"**位置**"维度 |
| **实现落点** | 新组件 `CatapultEnemy` + 预警圈表现（复用 `EnemyAttackTelegraph` 的预警层） |
| **数值草案** | HP 110 / 射程 4 / 架势 40 / 攻速 0.2（慢）/ 伤害 10 + 范围 1 格 |
| **美术成本** | 🟡 可复用 105 弓手体型 + 新投掷动作 |
| **波次位置** | 后期，与骑兵混编（远程压制 + 逼位移） |

### 3.3 破阵重锤（id 1016）· 补 G3：给防御键一个"错误对策"

| 项 | 内容 |
|---|---|
| **威胁** | 慢、架势极高（100）、攻击**削玩家架势并击退**；**格挡/防御会快速累积破防值** → 破防 = 短硬直不能行动 |
| **唯一对策** | **不能硬防** → 在它蓄力时**打断**（它慢，轻攻击就够）或**位移**拉开 |
| **为什么现在缺** | 防御键现在是无脑保险；重锤把防御变成"要付代价的选项" → 逼玩家读威胁 |
| **实现落点** | 复用 `Enemy` + `PlayerGuard` 已有破防累积；需要一个"攻击附带削玩家架势"的字段（`PlayerGuard` 侧加一条） |
| **数值草案** | HP 260 / 射程 1 / 架势 100 / 攻速 0.18 / 伤害 16 / 削韧 30 |
| **美术成本** | 🟡 可复用 1011 体型换配色 + 锤 |
| **波次位置** | 中后期，前排混编（重锤 + 杂兵），**教学关不要出** |

### 3.4 长枪突刺兵（id 1017）· 补 G2：引入"射程"维度

| 项 | 内容 |
|---|---|
| **威胁** | **射程 2 的近战** —— 它待在第 1 排就能戳到玩家（玩家在第 0 排），普通杂兵够不着 |
| **唯一对策** | **挑飞 / 位移**把它推离，或在它进第 1 排之前**先打掉**（它的前摇比杂兵长 → 有窗口） |
| **为什么现在缺** | 现在所有近战都得先补齐到第 0 排才能打 → 玩家的空间决策只有"打不打得到"；突刺兵让"第 1 排也不安全" |
| **实现落点** | `Enemy.attackRange` 的语义已实测：**「在第 N 排以内就能攻击玩家」**（`rowIndex < atkRange` → 进入攻击态，`Enemy.StateUpdate.cs:211` / `Enemy.Attack.cs:463`）。<br>⚠️ **但 `attackRange` 不决定它会不会补齐**：补齐的目标排来自**逻辑排队列**（`WaveMarchScheduler` → `AssignRushMoveOrder(targetRow = 逻辑排号)`），与 attackRange 无关 → **射程 > 1 的近战敌人照样会补齐到第 0 排被打死**（现役 1051 弓手射程 4 就是这么在第 2 排开火、被补齐带到第 0 排的）。<br>⇒ **长枪兵可以用 `attackRange = 2` 做**（2026-11-09 用户定）；代价是它站在第 1 排时**能打你、你打不到它**，直到前排清空它被带下来。 |
| **数值草案** | HP 140 / 射程 2 / 架势 45 / 攻速 0.35 / 伤害 11 |
| **美术成本** | 🟡 可复用 1011 体型 + 长枪（103 的素材可能能复用） |
| **波次位置** | 中期，后排（row2+）放 1~2 只 |

### 3.5 号令旗手（id 1018）· 补 G4：让"打谁"成为决策

| 项 | 内容 |
|---|---|
| **威胁** | 不攻击；给**周围 2 格内的敌人**加攻击（+30%）与移速（+20%） |
| **唯一对策** | **优先点杀旗手**（而不是"打最前排"） |
| **为什么现在缺** | 1013 督战只号令不攻击 → 打它不痛，优先级没有代价；旗手让"先杀谁"真的影响战果 |
| **实现落点** | 复用 `EnemyCommander`（改它的效果为范围光环）；⚠️ 需要 `EnemyCommander` 从"给谁加号令"改成"给周围加光环" |
| **数值草案** | HP 120 / 架势 60（比杂兵高一点，别太脆）/ 不攻击 / 光环 2 格 |
| **美术成本** | 🟡 可复用 1013 督战素材换配色 |
| **波次位置** | 后期，放在**后排中央**，与前排精英混编 |

### 3.6 结阵盾兵（id 1019）· 补 G6：群体连携的第二种

| 项 | 内容 |
|---|---|
| **威胁** | 2 个以上同时存在时**连成一条盾线**：正面格挡，且**伤害按盾线分摊**（打一个只掉一点） |
| **唯一对策** | **横扫**（打整排）或**从反侧**突破 |
| **为什么现在缺** | 102 的共享血量是"血池共享"；结阵盾兵是"**防御共享**" → 惩罚单点输出，逼玩家用范围技 |
| **实现落点** | 新组件 `ShieldWallEnemy`（同组判定 + 伤害分摊）；复用 `ShieldGuardEnemy` 的格挡判定 |
| **数值草案** | HP 120/个 / 射程 1 / 架势 50 / 正面完全免伤（分摊后） |
| **美术成本** | 🔴 新素材（举盾列阵）；或复用 1021 加"并排"表现 |
| **波次位置** | 后期，2~3 只一排 |

### 3.7 伏兵（id 1020）· 补 G5：让"清完一波"不可信

| 项 | 内容 |
|---|---|
| **威胁** | **不在配置里生成**；当前排全清后，从最后排**突然现身并突进** |
| **唯一对策** | **留一个位移/防御**（不能一清空就松手） |
| **为什么现在缺** | 现在波次是"配置即生成" → 清空 = 结束；伏兵制造节奏转折（长坂坡的"伏兵"意象） |
| **实现落点** | `WaveSpawner` 的"波次附加生成"通道（⚠️ 需新增）+ 一个从后排冲下来的移动表现（可复用 109 骑兵的冲锋位移） |
| **数值草案** | HP 100 / 射程 1 / 架势 40 / 现身时给 1 秒预警 |
| **美术成本** | 🔴 新素材；⚠️ **注意与"补齐/逻辑排队列"的耦合**（伏兵不是配置排 → 不进逻辑排队列） |
| **波次位置** | 后期，N2/N3 之类 |

### 3.8 爆裂卒（id 1022）· 给"击杀"加空间代价

| 项 | 内容 |
|---|---|
| **威胁** | 死亡时**范围爆炸**（对玩家），伤害中等 |
| **唯一对策** | **用挑飞把它打远**再杀 / 或用防御键硬吃 |
| **为什么现在缺** | 现在击杀是纯收益，没有"杀在哪里"的代价 |
| **实现落点** | 敌人死亡事件（`Enemy.OnDying` / `EnemyManager.OnEnemyDied`）→ 生成一个一次性 AoE 特效 + 伤害结算 |
| **数值草案** | HP 80 / 爆炸伤害 12 / 爆炸半径 = 1 格 |
| **美术成本** | 🟡 复用 1012 山贼体型 + 爆炸特效（现有火/雷特效可复用） |
| **波次位置** | 中期起，与密集小兵混编 |

### 3.9 精英化（零新机制，改编排 + 标记）

| 项 | 内容 |
|---|---|
| **威胁** | 同一个体身上**叠加两个需对策的窗口**（例：霸体前摇 + 远程；或破盾 + 击退） |
| **唯一对策** | **两个对策都要用**（组合技） |
| **实现落点** | **不改代码**：波次编排时把两个不同机制放在相邻位置，或给同一个体加一个 `elite` 标记（伤害/血量倍率 + 一个附加组件） |
| **数值草案** | 血量 ×2.5、伤害 ×1.2、架势 +30% |
| **美术成本** | 🟢 零（沿用现有素材 + 描边/光环标识） |
| **波次位置** | BOSS 前一波 |

## 5. 需要用户拍板 / 需要先确认的点

1. ✅ **已查清并已拍板（2026-11-09）**：`Enemy.attackRange` = **「在第 N 排以内就能攻击玩家」**，
   **且不影响补齐**（补齐目标排来自逻辑排队列）→ **长枪兵用 `attackRange = 2` 没问题**。
   代码位置：`Enemy.StateUpdate.cs:211`（`rowIndex < atkRange` → `StartAttacking`）、`Enemy.Attack.cs:463`、
   `Enemy.Movement.cs:127`（`reachedAttackRange`）、`WaveMarchScheduler`（补齐目标排 = 逻辑排号）。
2. **新兵种要不要真做美术**：P0/P1/P2 可以零/低美术先上；P3 之后都要新素材（当前素材管线是"视频→精灵"的人工流程，周期不短）。
   **美术产出顺序（2026-11-09 用户定）**：**① idle 形象 → ② 关键动作（攻击/技能）→ ③ 剩余通用动作**
   （已写入 `memory/art-production-workflow-entry.md` §0 铁律 11）。
3. **伏兵 1020 要不要动波次生成**：它不在配置排里 → 不进逻辑排队列 → 会踩"补齐只由整排清空触发"的规则边界，**建议等补齐规则稳定后再做**。
4. **关卡节奏 / 波次编排**：**2026-11-09 用户定：暂时只由用户调整** → 本文档只提供兵种与编队建议，**不代改 `Assets/RouteData/**` 的波次配置**。
