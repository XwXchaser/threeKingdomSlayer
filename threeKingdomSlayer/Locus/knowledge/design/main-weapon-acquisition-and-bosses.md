# 新主武器的获取方式与对应 Boss（草案）

> **状态：Boss 方向已确认，阶段细节与数值未定。**
> 本文记录三把新武器（双刀、单手剑、弓箭）的获取渠道与对应 Boss 机制。
> 已确认口径：
> - **双刀 Boss**：攻速快但脆弱；鼓励玩家在 Boss 进攻回合防守、等空档期再输出；二阶段会左右位移改变位置。
> - **单手剑 Boss**：主动进入格挡姿态，挡住攻击后反击，打出高伤害。
> - **弓**：**不做 Boss**；在某关固定场景的箱子掉落，获取后该位置的箱子改为掉金币等升级道具。

## 1. 主武器的获取渠道

| 渠道 | 适用 | 状态 |
|---|---|---|
| Boss 掉落 | 双刀、单手剑、大刀 | 与 104 大刀的既有做法一致 |
| **固定场景宝箱** | 弓箭 | **新增渠道** |
| 初始持有 | 长枪 | 已实装 |

⚠ **与权威文档的冲突**：`design/gameplay-progression-loop.md` §3.1 目前只写"Boss 有机会获得新的主武器"。
固定宝箱这一渠道需要补进该节，否则后续会按"只有 Boss 掉"来设计。

## 2. 双刀 Boss：双刃刺客

**设计目标**：让玩家完整经历一次"敌方回合防守 → 我方空档输出"的节奏，这正是双刀"高频但脆"的另一面。

| 项 | 内容 |
|---|---|
| 形象 | 轻甲、双短刀、贴脸 |
| 核心行为 | 一套 3～5 段连击，段间隔极短；连段结束后进入 1.5～2 秒空档 |
| 关键张力 | **连段期间不可打断**（霸体或极高韧性）；**空档期极脆**（受伤加成 + 长硬直） |
| 玩家该做的事 | 连段期间防御/招架，不贪刀；空档期集中输出 |
| 二阶段 | **左右位移**：每次空档结束时横移到相邻列（或随机列），下一套连段覆盖新列；玩家需重新调整目标列 |
| 三阶段（建议） | 连段中穿插一次换列假动作，制造"追不上"的错觉 |
| 玩家解法 | 防守等待空档是主解；招架可缩短空档；高削韧只在空档期有意义 |
| 复用 | `attackSequence` 多步、`maxPoise`、招架、列位移 |
| 新增 | 连段期霸体开关、空档期受伤加成、列间位移（横向） |

**必须确认的推导**：如果连段期可以被随意打断，玩家会选择"一直打断"而不是"防守等空档"，
所以"**进攻回合无敌、空档期极脆**"是这条设计的必要条件，不是可选项。

## 3. 单手剑 Boss：守剑校尉

**设计目标**：把"防御就是回合"演给玩家看，为单手剑的反击机制做预演。

| 项 | 内容 |
|---|---|
| 形象 | 中甲、单剑、盾步推进 |
| 核心行为 | 主动进入**格挡姿态**（限时，正面大幅减伤）；姿态中每受到一次命中累计计数 |
| 反击逻辑 | 计数达到阈值或姿态结束时，立刻打出一段**高伤害反击**；反击有可读的起手动作 |
| 关键张力 | 在它格挡时硬打 = 挨一次高伤反击；正确做法是破防、绕侧或招架反击 |
| 阶段 1 | 单次格挡 → 反击 |
| 阶段 2 | 边格挡边推进，把玩家往角落压；连续格挡两次 |
| 阶段 3 | 强力反击：必须招架或位移，不能硬吃 |
| 玩家解法 | 高削韧破防、破盾类效果、反侧攻击（不吃格挡）、招架反击起手 |
| 复用 | 1021 盾卫的正面格挡 + 破防后胆怯、`guardBreak`、招架 |
| 新增 | **格挡成功后主动反击**（现有盾卫只格挡、不反击） |

**与 1021 盾卫的区别**（避免变成同一个敌人）：

| | 1021 盾卫 | 守剑校尉 |
|---|---|---|
| 格挡 | 常驻正面格挡 | **主动进入的限时姿态** |
| 破防后 | 胆怯、逃跑 | **反击**（更危险） |
| 教学目的 | "用重攻击破盾" | "不要在它格挡时硬打" |

## 4. 弓：固定场景宝箱

不做 Boss，改为关卡里的固定获取点。

| 项 | 规则 |
|---|---|
| 位置 | 某关固定场景的箱子（具体关卡待定） |
| 首次开启 | 获得**弓**（主武器，永久拥有） |
| 之后开启 | 该位置的箱子改为掉**金币 / 局外升级道具** |
| 持久化 | 必须记录"该宝箱已领取"，否则重进关卡可反复获取 |
| 无尽关 | 循环内容里只应生效一次（全局标记，不随圈重置） |
| 视觉 | 需要与普通宝箱区分，玩家要知道"这是特殊的" |
| **本局可用性** | **本局不能装备**，需回局外选择更换（已确认） |
| **解锁演出** | 首次开启播放**解锁演出**，告知获得了什么与需要回局外装备（已确认） |

### 4.1 已确认的处理

1. **本局不直接换弓**：宝箱给的是"永久拥有"，玩家需回局外装备；同时用**解锁演出**弥足即时反馈。
2. **重复获得**：已有弓时开箱直接走"金币/升级道具"分支，天然处理重复，但仍需存档标记区分。
3. **与其他宝箱不混用**：现有 `EquipmentChest` 是敌人死亡掉落的装备三选一，属于本局装备；
   固定宝箱给的是**永久主武器**，两者是不同系统，不能共用表现与逻辑。

### 4.2 仍待定

- 固定宝箱的具体关卡与位置；不能放在"必须先有弓才能到达"的地方（否则死锁）。

## 5. 获取顺序与死锁检查

```text
长枪（初始）
  → Boss「双刃刺客」   掉 双刀
  → Boss「守剑校尉」   掉 单手剑
  → 固定宝箱           得 弓箭
  → 104（已有 Boss）   掉 大刀
```

- 每场战斗都必须**能用已有武器打赢**；Boss 的"玩家解法"一栏就是用来保证这一点的。
- 固定宝箱不能放在"必须先有弓才能到达"的位置，否则死锁。

## 6. 待定

1. 双刀 Boss 的连段段数、空档时长、二阶段换列频率。
2. 守剑校尉的格挡持续、反击计数阈值、反击伤害。
3. 三阶段是否需要（当前只有 1、2 阶段已描述）。
4. 弓的固定宝箱放在哪一关的哪个位置；解锁演出的具体表现形式。
5. 双刀 Boss 与 104 的战斗时长与难度递增关系。
6. 各 Boss 掉落主武器时的重复获得补偿（金币/素材）。
