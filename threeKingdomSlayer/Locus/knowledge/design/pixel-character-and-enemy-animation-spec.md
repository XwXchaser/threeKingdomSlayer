# 三国像素角色与敌人动画制作规范

## 1. 适用范围

本规范用于制作可部署到 Unity 的三国像素敌人角色、动作关键帧和动画视频素材。目标不是制作概念图或电影镜头，而是制作每一帧都可独立使用的游戏 Sprite。

## 2. 统一美术风格

- 高清 16-bit 像素街机风格。
- 东方三国武将感 + 幻想 RPG 厚重感。
- 参考街机、SFC、NeoGeo、GBA 后期高质量像素作品。
- Q 版约 2.5–3 头身：大头、宽肩、短腿、厚重。
- 粗黑或深色像素外轮廓，约 1–3px。
- 硬边色块明暗，有限色阶，最多两阶阴影；禁止平滑渐变。
- 金属使用锐利高光，皮革偏暖棕，布料对比稍低，宝石高饱和但受控。
- 深色主体搭配金色、银色或单一高饱和强调色。
- 必须保持清晰像素块、硬边和手工 Sprite 感。

禁止：油画、厚涂、柔光、模糊、AI 插画感、过度抗锯齿、现代二次元、美少女比例、写实人体、欧美骑士、西幻游侠、低质量简笔像素、场景背景、文字、UI 框和伪透明棋盘格。

## 3. 角色识别与朝向

角色缩小后仍必须能识别兵种、武器、阵营和职业。轮廓优先于内部细节，武器、盾牌、肩甲和头饰可以夸张，但不能破坏整体剪影。

所有敌人默认正面面向玩家/摄像机：

- 不得侧身、3/4 视角、横版朝左或朝右。
- 身体、肩膀和头部保持正面朝向。
- 画面左侧是角色右侧，画面右侧是角色左侧。
- 正面动作中的武器必须符合朝向和透视，不得出现方向矛盾。

## 4. Enemy2 盾兵基准

Enemy2 的角色身份以 `Assets/Sprites/Enemy/Enemy2/Enemy_2.png` 为准：

- 银灰色圆顶头盔和红色头巾飘带。
- 棕色护甲、银灰胸甲片和金属肩甲。
- 木制矩形大盾位于角色左侧，即画面右侧。
- 棕色护腿和靴子。
- 正面、警戒、凶狠但克制的 Q 版敌兵表情。

所有新动作都必须保留这些装备、配色、比例、像素密度和盾牌位置。动作参考图只能改变姿态，不能重设计角色。

## 5. 动画帧通用硬性要求

- 每帧必须是独立、干净的单角色 PNG。
- 透明背景 Alpha；不得把白底、灰底或棋盘格当成透明。
- 角色、武器、盾牌、四肢和配件必须完整在画布内。
- 任何轮廓都不得触碰或越过画布边界。
- 角色主体居中或保持统一锚点，不能逐帧漂移。
- 同一动作的画布尺寸必须统一。
- 所有帧保持装备、外轮廓、像素密度和描边语言一致。
- 不得出现肢体丢失、额外物体、重影、装备变化或武器变形。

## 6. 游戏 Sprite 的位置与比例锁定

制作视频时必须将其视为“固定画布上的原地 Sprite 动画”，而不是摄影机镜头：

- 摄像机、画布、构图、角色整体位置和绘制比例从头到尾不变。
- 脚底锚点保持在相同屏幕坐标。
- 只允许局部身体姿态变化。
- 禁止角色整体平移、前进、后退、靠近或远离摄像机。
- 禁止镜头推近、拉远、平移、跟随、旋转、震动、重新居中或重新构图。
- 按最大动作展开范围预留安全边距，建议四周至少 15%。
- 最大后仰、倒地或四肢展开时，头盔、手脚、盾牌和武器仍必须完整可见。
- 不得通过中途缩放或拉远镜头解决超框问题。

## 7. 动作语义

### Idle

双脚站稳，正面朝向玩家，武器自然持握。可有轻微呼吸或头巾变化，但不能迈步、攻击或产生尘土。

### Walk

身体正面、肩膀正对屏幕，只表现向玩家前进。左右腿交替，不能变成攻击动作。Enemy2 的盾牌仍保持原有持握方式。

### Attack

按“起手 → 蓄力 → 命中 → 收势”表现。前摇不能提前出现攻击判定特效；命中帧动作幅度最大；收势应能回到 Idle 或 Walk。

### Hitted

受击必须有明确身体反应，而不能只有表情变化：胸口和肩膀后仰，腰部参与变形，表情痛苦。Enemy2 盾牌保持在手中并随身体自然变化。若要求恢复，应从受击姿态通过局部关节动作回到完全相同的通常站姿。

### KnockUp

身体明显离地并后仰，腰、胸、头共同形成失控姿态，四肢展开。不得只做头部后仰，也不得横向翻飞。

### Dead

比普通受击更夸张：身体失力、四肢张开、头部后仰、武器可脱手。死亡是自身失力坠落，不等同于被击飞。

## 8. 推荐视频制作流水线

1. 阅读本规范、项目运行时接线和目标角色实际资源。
2. 准备身份/通常姿态参考图和动作姿态参考图。
3. 使用 Seedance 创建视频：只描述动作，不描述场景、地面、建筑或灯光。
4. 视频提示词明确“game sprite animation”“locked camera”“fixed position and scale”“fully visible”“no cropping”。
5. 生成后有限轮询并下载；验证 MP4 文件头和容器结构。
6. 实际观看或抽帧检查位置、比例、超框、装备一致性和动作语义。
7. 用 ffmpeg 提取原始帧，保留 `generated/` 中间产物。
8. 逐帧去背；视频并不保证 Alpha 透明，不能直接部署。
9. 统一画布、脚底锚点、像素比例和安全边距；不要逐帧按不同包围框缩放。
10. 通过 Unity 导入设置、Animator、Prefab 和运行时表现验证后，才替换正式资源。

## 9. 视频提示词限制

Seedance 支持参考图，但文档没有保证输出透明视频。应使用 `no background`、`no scenery` 等约束降低背景污染，之后仍需逐帧去背。

普通参考图流程中：

- 第一张参考图负责角色身份和通常形象。
- 第二张参考图负责目标动作姿态。
- 在 `input.content` 中使用多个 `reference_image`。
- 不要把 `reference_image` 与 `first_frame` / `last_frame` 混用。
- 创建任务前必须确认收费参数。

## 10. 质量检查清单

### 单帧

- [ ] 透明 Alpha 干净，无白边、灰块或棋盘格。
- [ ] 角色和全部装备完整，无超框或贴边。
- [ ] 角色位置、脚底锚点和尺寸正确。
- [ ] 像素轮廓、色阶和材质一致。
- [ ] 表情符合动作语义。

### 序列

- [ ] 动作从起始到结束递进清楚。
- [ ] 角色整体不漂移、不缩放。
- [ ] 镜头完全静止。
- [ ] 装备不增减，盾牌不消失。
- [ ] 起始和结束姿势能正确衔接。
- [ ] 同一动作画布和锚点统一。
