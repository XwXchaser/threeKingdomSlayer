# 《影之刃零》设计体系研究 + 与本项目对照

> 调研于 2026-11-09（用户玩过之后提出，想参考其 build 体验）。
> **资料来源**：中文攻略站 `phantombladezero.space`（整理自官方 State of Play 演示、制作人访谈、IGN/3DM/游民星空试玩报道）、
> B 站 WIKI `wiki.biligame.com/yingzhiren`、游民星空/游侠网图鉴。
> ⚠️ **不是官方文档**：PBZ 于 2026-10-29 发售，部分细节随版本/攻略实测修正；本文用于设计对照，不作为数值依据。

---

## 0. 一句话概括它的 build 结构

> **两把主武器（决定"近战怎么打"）+ 两件影之武装（决定"近战之外你还有什么手段"）+ 两瓶药剂 + 两件饰品**
> —— 四个格子**各解决一个问题，不重复**；换武器 = 换一套连段 + 回满资源。

---

## 1. 主武器 ≈ 我们的「输入手势 + 招式」

| 事实 | 细节 |
|---|---|
| 数量与来源 | 30 把主武器；原型全部取自**中国传统兵器**（剑 / 双剑 / 斧 / 长枪 / 锤 + 软剑、醉剑等特殊件） |
| **按持法分四档** | **单手最快 / 双持连段最长 / 双手破盾与清场最狠但出手慢 / 未标注** ← 与我们的「轻重攻击」是同一条轴，但它是**换武器**而不是蓄力 |
| 每把**自带机制** | 制作人明确：**不靠共享基础动作模板省事**；武器差异要在**操作和画面上都能读出来** |
| 每把 3 个招式名 | 例：黑伤 = 凝气于刃 / 瞬杀 / 行云；残钢刃 = 血刃 / 流血不止 / 血刃蓄力 |
| **升级解锁新招式** | 1–30 级；**5 / 10 / 15 / 25 级依次解锁新招式与新形态**，「强化到一定程度，操作与战斗策略会质变」 |
| **铸魂 = 变体** | 把武器升级成变体、**招式换一套**（黑伤双刃→绝影；乱莺剑→天邈·乱莺） |
| **无损重铸** | 洗点全额返还 → **换流派没有沉沉成本** |
| **战斗带 2 把，随时切换** | **切换主武器 = 瞬间回满杀气**；且是**唯一能取消必杀后摇**的手段 |
| 配装原则 | **第二把补第一把的短板**，不要两个格子解决同一个问题（例：日常用快剑，另一把留给"快剑拆不开"的塔盾/重甲） |

**几把机制特殊的武器（都对应一类威胁）**：醉剑（积攒醉意换闪避空间）、白蟒赤练双剑（一把甩出当远程）、灵蛇软剑（缠住并瓦解敌人防御、切空中丝线类攻击）、铁拳/巨锤（重型破防）、虎炮（轰散远处阵型 / 引燃自爆兵）、烈焰狮头（喷火清成群恶犬）、玉双环（远程收残血）、红妆鬼斩（破盾 + 铺石蒜花腐蚀）、亡命斩马刀（吸血续航 / 损血换重伤）。

## 2. 影之武装 ≈ 我们的「技能组」

| 事实 | 细节 |
|---|---|
| 数量与槽位 | 25~26 件；**最多同时装备 2 把** |
| **五类定位** | **武学 / 破坏 / 奇门 / 远程 / 召唤**（另一攻略站记为 力量 / 远程 / 奇术 / 武学，分类名有出入，**功能分层一致**） |
| **独立资源「暗源」** | 红色资源球，初始自带；**用完只能在传送点恢复**；部分能力/饰品可降低消耗或回复 |
| 每件 3 个形态 | 形态 I / II / III（名字如 巨凶斧：强行蓄力 / 厚甲护身 / 疾行斧） |
| **反制 / 追击** | 官方口径：**普通敌人发动远程红光技能时**，或**敌人血量 <50% 且处于破防状态**时，可用特定影之武装**反制或追击**；能力修行里还有"使这类反制/追击不消耗暗源"的效果 |
| **可从强敌手里夺得** | 击败 Coppermaul 得战锤、彭猛得斧、残钢得残钢刃 → **遭遇战本身成为配装循环的一部分** |
| 探索功能 | 部分影之武装**无须装备即生效**（斩铁链 / 勾锚点移动 / 熄灭火焰屏障 / 射落高处物品） |
| 官方定位 | 「它们解决的不是**打得疼**，而是**够不着**和**人多**」；主武器管近战，影之武装管远程压制、异常状态、场面控制 |

## 3. 饰品 ≈ 我们的「被动」

**62 件**，可同时装备多件（访谈口径每套 2 件）。**关键：绝大多数不是"攻击力 +10%"，而是"针对某个机制的开关"。**

| 饰品 | 效果（摘要） | 属于哪一类开关 |
|---|---|---|
| 影动猎杀仪 | 对**攻击动作中**的敌人伤害 +7%、杀气削减 +7% | 针对"敌人正在出手"这个窗口 |
| 追杀令 | 对**破防状态**的敌人伤害 +7% | 打开破防窗口的回报 |
| 浑源经脉仪 | **完美防御 / 完美闪避的时间窗口 +15%** | 直接放宽判定窗口 |
| 正气凌然 | 杀气连招的杀气消耗 -15% | 资源节奏 |
| 神机指环 | **按住格挡**时杀气消耗 -20% | 让"按住防御"从应急变成可用 |
| 破盾符 | 对**盾牌耐久条**削减 +50% | 针对"打不穿" |
| 斩骑符 | 对**骑兵类敌人**伤害 +25% | 针对具体敌人类型 |
| 妙手在握 / 妙手连环 / 妙手千均 | 单手 +10% / 双持 +10% / **双手 +18%** | **按武器持法分档加成** |
| 力士神像 | "破坏"类影之武装**多耗 1 暗源但伤害 +75%** | 改某一类技能的性价比 |
| 碧血云天 | 1 秒内连续命中两次后，2 秒内伤害 +15%（5 秒冷却） | 奖励连段节奏 |
| 百战魔躯 | 持续 10 秒未受伤 → 免疫下一次伤害 | 奖励不被打断 |
| 反击护腕 | **完美格挡后 2 秒内**伤害 +20% | 奖励读招成功 |
| 神器刀鞘 | **切换主武器**时获得霸体 + 25% 减伤，持续 2 秒 | 奖励换装时机 |
| 刽子手头巾 | **处决敌人后**切换主武器冷却 -1 秒 | 奖励处决 |
| 同心双鱼佩 / 绝地求生令 | 杀气越少伤害越高（≤+20%）/ 生命越少伤害越高（≤+25%） | 低资源换高收益 |
| 影魅面具 | 完美格挡/闪避触发鬼步后生成 3 个面具自动攻击 | 把一次成功放大成输出 |
| 食物防腐罐 / 辟火符 / 避雷符 / 防冰符 | 中毒/火焰/雷电/冰冻 伤害减免、异常积累速度 -30% | 抗性包 |

## 4. 敌人 ≈ 我们的「敌人机制」

### 4.1 统一信号（最值得抄的一条）

| 信号 | 含义 | 正解 | 代价/变体 |
|---|---|---|---|
| **蓝光** | 敌人的"杀气攻击" | **精防**（在被击中的瞬间点按防御键） | 成功精防 = 免伤 + 不耗己方杀气 + **削对方杀气** + 回自己杀气 + 自动触发**鬼步**接近敌人 |
| **红光** | 必杀技，伤害极高 | **只能闪避** | 完美闪避有特殊演出（把敌人扔的炸药丢回去）或直接触发鬼步贴身 |
| **黑光** | 第三种（彭猛开始出现） | 理论上可精防，但**一次精防吃掉大量杀气** → **默认答案是闪避** | "挡得住，但挡完你没什么本钱反击" |

- ⚠️ **信号是双向的**：玩家的重攻击带蓝光、必杀带红光 → **敌人同样在读玩家的出招**；**杂兵也会用红蓝光**（不是大人物专利）。
- ⚠️ **连按格挡不生效**：连续按键不会被判成格挡；一直按住也触发不了点按格挡 → 每次来袭按一次。

### 4.2 敌人形态与对策（从攻略与武器克制里读出来的）

| 敌人形态 | 威胁 | 正解 |
|---|---|---|
| **重盾 / 塔盾 / 重甲** | 轻薄刀剑拆不动 | 换**重型武器**（铁拳 / 巨锤）砸开 |
| **人偶型**（新娘阿花） | **出血无效**（拿着打了两个 Boss 的残钢刃，血条不动） | 换**黑伤系**武器 |
| **自爆兵** | 靠近就爆 | 虎炮**提前引燃** |
| **成群恶犬** | 扑上来群殴 | 烈焰狮头范围火焰 |
| **屋顶 / 远处弓手** | 够不着 | 远程影之武装（弓、飞刀、叉） |
| **长枪兵** | 召来伙伴轮番进攻 | 连续**鬼步**是生存核心 |
| **结阵剑士**（七星剑阵） | 六名弟子**各自独立血条**、**自损血量给大师兄续命**、二阶段大师兄化傀儡由三名弟子**红线操控**、合击从四面刺出 | 完美闪避；战斗对象从一条血条变成"维系血条的补给线" |
| **喝酒型**（剑痴花千笑） | 把杀气转成**护盾**，喝完震开玩家 | 节奏是**跑 → 等 → 破防 → 输出 → 再跑** |
| **红花场地型**（新娘阿花） | 旋转缩圈的红花是**延迟爆炸**；白花可挡，**挡完必瞬移贴脸** | 看到鲜艳红花就挪开；挡白花那一下就是你的输出窗口 |
| **锁链型**（追命） | 蓝光**藏在连段中间**，不是起手 | 等他打到中段再精防；竖落横跑，龙卷风远离 |

### 4.3 难度设计

高难度**不是加血加攻**，而是**敌人行为变难**：地狱行者档的敌人会**按玩家的距离、失误、重复出招实时调整反应**——总用同一套连段就会被针对。

## 5. 资源系统（最接近我们「架势/破防」的一条）

| 资源 | 规则 |
|---|---|
| 三条计量 | 血量（白条）/ **杀气（黄条）** / 必杀槽 |
| **杀气** | 重攻击消耗；**按住防御持续消耗**；闪避与轻攻击**不**消耗 |
| **杀气见底 → 破防** | 无法防御、无法触发特殊动作、**受击硬直变大、受到的伤害更深** |
| **破防 = 输出效率最高的窗口** | 磨、或用精防削；血量与杀气双降后可**处决**（终结技） |
| **换武器回气** | 切换主武器**瞬间回满杀气**，但**冷却与剩余杀气量挂钩**（越接近见底冷却越长）→ 鼓励**提前轮换**而不是见底才换 |

## 6. 与本项目逐条对照（差距清单）

| PBZ | 本项目对应 | 现状差距 |
|---|---|---|
| 主武器 = 换一套连段 | 输入手势 + 招式（张飞长枪一套） | **只有一个"角色/一套招式"**，没有"换武器=换连段"的维度；招式解锁有设计但未落地 |
| 影之武装 = 2 槽位 + 独立资源 + 反制/追击 | 主动技能组（三选一 / 技能池） | 技能**无槽位限制、无独立资源**；**没有"按敌人状态触发的反制/追击型技能"**；没有"从 Boss 手里夺得" |
| 饰品 = 机制开关式被动 | 三选一里的被动 | 我们的被动多为**通用数值倍率**（伤害/攻速/移速），缺**改手感/改判定窗口**的被动 |
| 统一信号（蓝/红/黑） | 敌人机制反制表（101/102/103/105/106/109/1021） | 我们**每种敌人有各自机制，但没有共同语言**；玩家要背"每个敌人的每一招"而不是"认光" |
| 杀气见底→破防→处决 | 架势值 → 破势眩晕 → 眩晕 | 我们有**架势/破防/眩晕**，但缺**"资源见底=明确惩罚"**与**"破防=处决级兑现"** |
| 4 格各解决一个问题 | 三选一（随机 2~3 候选） | 三选一目前是**随机发牌**，没有"你的 build 缺哪一格"的约束 |
| 高难度敌人会读你 | 无 | 我们没有难度维度的敌人适应 |
| 武器升级解锁新招式 | 三选一解锁新技能 | 我们的解锁在**局内**，它是**局外**（`design/out-of-game-growth-system.md`） |

## 7. 可借鉴方向（**建议，未实施**，供用户拍板）

1. **给敌人攻击做一套"信号"视觉语言**（我们的轻/重/远程/霸体各有信号）→ 玩家认信号而不是背招式；成本低、收益高。
2. **"换招式/换武器"作为一局的 build 维度**：换的不只是数值，而是**连段路线 + 节奏窗口**；并给"换装"一个资源回充回报（对应我们的"换招回气"）。
3. **技能组引入槽位 + 独立资源 + "反制/追击"型技能**（只在某两种敌人状态下可用）→ 技能组从"输出按钮"变成**答案库**。
4. **被动池改成"机制开关"**：扩大完美防御窗口 / 对破防敌人加伤 / 对某类敌人加伤 / 改资源回充节奏 —— **改手感而不是改数字**。
5. **三选一从"随机发牌"变成"补短板"**：给玩家已选的 build 一个"缺哪一格"的提示（对应 PBZ 的"第二把补第一把的短板"）。
6. **难度不是加数值，是让敌人适应玩家**（高难度档）。

> 以上 6 条都只是**建议**；按 `memory/user-preference.md`，未拍板前不落地。
