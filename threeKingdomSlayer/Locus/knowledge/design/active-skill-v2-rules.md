# 主动技能双版本规则

## 命名
- 后续对话中，“道具”默认指 V1 限次消耗品。
- “主动技能”默认指 V2 局内获得、可升级、永久占槽、具有独立冷却的主动能力。

## 版本隔离
- 通过 Inspector 在开局前选择 V1 或 V2；对局中不切换、不迁移运行态。
- V1 完整保留现有道具库存、使用次数、弃置替换、血包、普通敌人掉落和 Boss 道具三选一。
- V2 使用独立的主动技能库存、等级、冷却、候选过滤和 UI 数据源，不与 V1 运行态互相转换。

## V2 获取与槽位
- 主动技能并入玩家升级三选一池。
- 普通敌人不直接掉落主动技能。
- Boss 主动技能三选一只提供 Rare 与 Legendary。
- 槽位未满：可出现新主动技能，也可出现已持有且未满级技能。
- 槽位已满：仅出现已持有且未满级技能。
- 所有已持有技能均满级：主动技能不再进入普通升级候选；Boss 无合法候选时跳过该奖励。
- `damage_boost` 排除出 V2，避免可重复释放造成永久增伤无限叠加。

## V2 使用与 UI
- 技能使用后不消耗、不移除，成功释放后进入独立冷却。
- 同名技能再次获得只升级，不增加槽位，不重置当前冷却；后续释放使用新等级参数。
- QTE、对话和暂停期间禁止释放；冷却使用缩放时间并随暂停冻结。
- UI 使用冷却遮罩和剩余秒数；冷却结束隐藏倒计时并显示就绪光效。
- UI 图标不显示技能等级，等级仅用于效果计算和三选一描述。

## 资产边界
- V1 道具、V2 主动技能、现有被动技能必须使用独立的 `UpgradeDefinition` ScriptableObject 资产。
- 不在同一个资产内增加 V1/V2/主动/被动模式开关来复用配置。
- 可以复用底层效果执行代码、Prefab、图标和通用数值结构，但触发方式、等级表、冷却和候选身份由各自独立资产定义。
- 例如“被动倒计时直线喷火”若制作主动技能版本，应新建一个主动技能 `UpgradeDefinition` 资产；原被动资产保持不变。
