# 反推法：我们需要做怎样的新敌人

> 方法：**先盘"我们手上已有哪些系统"，再找"有这张牌、却没有对应敌人"的空位** —— 那个空位就是一个新敌人。
> 它逼玩家用我们**已有**的某张牌去解，**不需要新增按键/手势**（用户约束：小游戏方向、操作维度不能高）。

### 1.1 防御键的破防机制（2026-11-09 定 + 实测固化）

| 事实 | 细节 |
|---|---|
| 防御期间 | **完全免伤**：伤害不扣血，**全额转成破防值**（`PlayerGuard.TryAbsorbDamage`） |
| 破防阈值 / 回落 | 阈值 **120**（招架招式资产 `parryGuardBreakThreshold`）；回落 **30/秒**（`parryGuardDecayPerSecond`）→ 净累积 = **D/T − 30** |
| 破防后果 | 硬直 **1.5s**（`GameplayInputGate.RequestBlock(GuardBroken)` → 不能行动/技能/手势） |
| **破防后防御锁** | **3s**（`PlayerGuard.IsDefenseLocked`）：防御键**灰掉、按不了**，也**不能排队预输入** |
| 为什么必须锁 | 硬直期间玩法输入被拦，但**防御键是 UI** → 玩家可在硬直里按一下 → 防御键的**预输入**排队 → 硬直一结束**自动进防御** → 破防惩罚被抵消 |
| 附带修复 | 破防时**强制松开防御**（否则 `DefendHeld` 一直为真 → 玩家不松手就**出不了招**） |

### 1.2 敌人的破防数值能力（`Enemy.guardBreakBonus`，2026-11-09 新增）

| 敌人 | 伤害 D | 间隔 T | bonus | 每次命中破防贡献 | 单只速率 | 结果 |
|---|---|---|---|---|---|---|
| 1011 剑兵 | 20 | 2.5s | +45 | 65 | 26/s < 30 | **单只破不了**，2~3 只围攻能破 |
| 1012 山贼 | 10 | 2.5s | +45 | 55 | 22/s | 同上 |
| 1051 弓手 | 5 | 3.3s | +45 | 50 | 15/s | 同上 |
| 105 弓手 / 103 长枪 / 102 / 1021 盾 | 10~15 | 4~5s | +45 | 55~60 | 11~14/s | 同上 |
| **109 骑兵** | 冲锋 8~24 | 冲锋循环 | **+112** | **120~136** | — | **撞上必破防**（不防御时只吃 8~24 伤害，不会秒杀） |

- **为什么用独立字段而不是直接加伤害**：玩家基础 HP 只有 100；防御期间伤害转破防值（不扣血），但**不防御时是照扣的** → 直接把伤害拉到 120 会一击秒杀。`guardBreakBonus` 把「破防能力」与「伤害大小」解耦。
- **实测（机器人跑真实路线 N1→E0）**：破防条峰值 1.00、**8 次破防**（累积 123~165）、防御锁期间防御键按不动被正确拒绝。
- **注意**：`parryGuardDecayDelay`（3）这个字段在资产里存在但**代码里没有任何地方消费**（`PlayerGuard.Tick` 只用 perSecond）→ 死字段，要么删要么恢复语义。
- **遗留**：还没有真正的「重击型」新兵种（本次只是把 109 变成唯一能单次破防的敌人）；破盾款式的按钮表现待做。

## 4. 新敌人提案（按实现成本排序）

### A 类：零新系统（只靠数值 / 已有字段）

| # | 敌人 | 它逼玩家用哪张牌 | 成本 |
|---|---|---|---|
| A1 | **抗冻结精英**（`freezeResist=1`） | 挑飞 / 破防 / 位移 / 横扫，而不是一味冰雾 | **零**（字段与机制都已存在，只差配值 + 一个美术） |
| A2 | **重击型**（单次伤害巨大） | 不能无脑防御：防御时伤害全进破防条 → 一次打满 → 破防硬直动不了 | **零**（数值 + 攻击前摇时长） |
| A3 | **高韧肉盾**（减伤 70%+） | 削韧/破防/挑飞，而不是磨血 | **零**（数值） |
| A4 | **一串共享血池**（跨排共享） | 集中输出；分散打效率极低 | **零**（`sharedHealthGroup` 已是分组字段，改分组规则） |

### B 类：需要一个小扩展（一个字段 / 一个标记 / 一条回调）

| # | 敌人 | 逼玩家用哪张牌 | 需要什么 |
|---|---|---|---|
| B1 | **不可弹反的远程**（掷矛手 / 毒液） | 位移 / 防御 / 远程对远程 | 投射物加 `unreflectable` 标记 + 抛物线落点 |
| B2 | **假前摇诱导型** | 别乱招架；读招 | 敌人攻击序列加一步"延迟伤害" |
| B3 | **反伤型**（打它你掉血） | 防御不是免费选项；改用挑飞/位移 | 伤害结算加一条"攻击者反伤" |
| B4 | **破防反打型** | 破防不是免费的输出窗口 | 监听敌人架势破防事件 → 立即反击 |
| B5 | **抗性矩阵**（火抗/雷抗/病抗） | 选流派有对象 | 敌人加 2~3 个抗性字段（照抄 `freezeResist` 的模式） |
| B6 | **自身带火的近战**（灼烧你） | 别贴身；用位移/远程 | 玩家侧 StatusContainer 已有通道，缺"玩家版灼烧"状态类 |

### C 类：需要新的表现/机制（较贵）

| # | 敌人 | 逼玩家用哪张牌 | 需要什么 |
|---|---|---|---|
| C1 | **多段连招霸体敌人** | 读招 / 挑飞打断；不能硬吃 | 多段攻击序列（103 的 C 技是雏形） |
| C2 | **小 QTE 杂兵** | 把手势用到日常 | 复用 `QTEController` |
| C3 | **伏兵 / 入场即攻** | 别在最后一排放松 | SpawnEntry 扩展 |
| C4 | **补齐即增益**（每前进一层 +1 护盾） | 主动规划清场顺序 | 逻辑排队列挂增益回调 |
| C5 | **挑飞反噬**（挑飞它 → 你被拖过去） | 挑飞有代价 | 位移联动 |

## 5. 推荐首批（性价比排序）

1. **A1 抗冻结精英** —— 零代码、字段现成、立刻让"冰雾"这个技能有了取舍
2. **A2 重击型** —— 零代码，让**防御键**第一次有了代价（我们最缺"该不该防"的敌人）
3. **B1 不可弹反远程** —— 一条标记，就让"招架"从万能变成有条件
4. **B2 假前摇诱导型** —— 一段攻击序列，就让 0.8s 招架后摇有了意义
5. **A4 一串共享血池** —— 零代码，逼集中输出

> 这 5 个全部**不新增按键、不新增手势**，只用到已有的"挑飞 / 破防 / 位移 / 招架 / 防御"五张牌。

## 6. 编队原则（节奏仍由用户调整，这里只给原则）

- 每波 **1 个"需要对策"的敌人** + 若干杂兵；**一波最多 2 种空位**
- 同一空位反复出现要有**升级**（先纯 A2，再 A2+B1）
- Boss = **多空位汇总 + 一条独有机制**（对应 PBZ 七星剑阵：六条独立血条 + 自损续命 + 合击）
