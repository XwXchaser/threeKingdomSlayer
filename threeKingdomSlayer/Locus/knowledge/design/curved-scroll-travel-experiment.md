## 2. 产品目标与非目标

目标：固定玩家视点，通过地面和路侧纸片迎面接近、经过、退出，表达持续前进；远处地面逐渐下弯，内容自然显露；停下后能够保持稳定战斗构图。

参考是用户提供的三张雨林/海滩截图及运动描述。截图只能证明构图，不能证明原游戏使用何种 Shader、网格或运动算法；不把推测写成复刻事实。

首轮不做：开放世界、自由漫游、真实地球曲率、完整长坂坡制作、付费图片/视频生成、迁移存档、改战斗数值、删除旧路线系统、全项目材质替换。

## 3. 架构边界与待决策点

### 3.1 独立实验优先

建议后续使用 `experiment/curved-scroll-travel` 分支与独立实验场景。分支名和资产路径均为建议，未创建；新建分支不能自动隔离未提交文件。实现前保留本机工作并明确基础分支。

### 3.2 与两个路线方向的关系

- 旧 V2：可试验对环境表现增加弯曲，不改变 Head/Combat/Tail 与战斗对齐的逻辑契约；不以旧代码状态重写新文档。

- 本需求不宣布取代视频方向或旧 V2，不改正式拓扑与存档契约。

## 4. 推荐实现方向

### 4.1 分层

1. 远景层：天空、远山、树林轮廓；前进时固定或弱视差，不随地面冲向镜头。转向时可配置背景偏移/混合。
2. 环境层：细分地面、道路、两侧纸片；承担透视接近、纵向下弯和循环。
3. 战斗层：真实敌人、碰撞、攻击、血条和特效；保持现有逻辑坐标。
4. 前景/UI：武器、玩家表现、HUD；不参与环境弯曲，布局以 Prefab 为准。

### 4.2 弯曲规则

近处平直，超过弯曲起点后平滑下弯。距离以显式旅行参考 Transform 的水平前向计算，不写死世界 Z，不把相机俯角造成的深度误当路面距离。

可试验二次下沉关系 `drop = strength * max(0, distance - start)^2`，并添加可调过渡与显示边界；这是候选算法，不是最终实现锁定。

地面需要足够网格细分；纸片按脚底锚点整体下沉，默认保持竖直，不逐顶点弯折人物和武器。弯曲仅影响表现，不能挪动真实碰撞体或阵型。若采用 GPU 变形，要验证包围盒剔除、深度/透明排序、阴影及其他 Pass 一致性，不能只验证主颜色 Pass。

### 4.3 素材复用

复用现有 Sprite、动画与 UI；沿途展示纸片不直接启用完整 Enemy 行为、碰撞、血条和奖励回调。不修改共享 Enemy Prefab、材质和动画来满足实验。远处敌阵预览与真实波次分开，后续交接必须防止双份显示与重复注册。

### 4.4 旅行与战斗衔接

首轮只验证直路。后续为“选择 → 旅行 → 减速停稳 → 背景就绪 → 开始节点内容”，环境平直区覆盖阵型、Boss、位移和弹道所需范围。

循环走廊是可选第二阶段：以旅行进度驱动重复环境，到站后接固定环境；不强制制作真实连通大地图。转向、背景切换与战斗衔接通过后，再决定是否替换现有旅行表现。

## 5. 可调参数需求

以下是建议配置项，不是已经存在的序列化字段。资源、配置和参考点必须可在 Inspector 追踪，不通过字符串/全局缓存隐式寻找。

| 分组 | 参数 | 约束与用途 |
|---|---|---|
| 视点 | 高度、俯角、FOV | 首轮沿用选定基线，相机变量与弯曲变量分开比较 |
| 构图 | 道路宽度、背景偏移/缩放、战斗安全区 | 不遮挡敌人、武器和关键 HUD；地平线屏幕高度作为观察量 |
| 弯曲 | 开关、起点、强度、过渡长度、参考 Transform | 近区严格平直；强度为零必须等价平直模式；不重复暴露同义半径和强度 |
| 弯曲边界 | 最远显示距离、远端淡出 | 不暴露生成边界；最大值及错误配置需合理限制 |
| 纸片 | 脚底偏移、尺寸范围、朝向模式、倾斜比例 | 默认不弯折角色；不修改精灵源 Pivot |
| 运动 | 定速/定时模式、速度/时长、加减速时间和曲线 | 只有当前模式参数生效；到站精确，避免累计误差 |
| 转向 | 时长、曲线、背景偏移比例 | 后续阶段再启用；不能用数组索引决定出口语义 |
| 到站 | 停稳时间、背景交接方式 | 完成回调只触发一次；真实波次不提前开始 |
| 循环 | 路段长度、前后缓存、生成/回收距离 | 生成在不可见区；不穿过相机或出现接缝 |
| 排列 | 左右边距、间距、密度、固定随机种子 | 支持重复对照；避免堵塞战斗视线 |
| 排序 | 层级、透明排序与深度策略 | 远近遮挡一致；不全局改共享材质 |
| 远景 | 图像/材质引用、各层视差、雾色、混合时长 | 默认稳定，转向不露底 |
| 调试 | 暂停、单步、进度拖动、重置、参考网格、参数预设 | 实验控件不得向战斗输入穿透 |
| 暂停 | 明确的游戏暂停策略 | 暂停冻结旅行，UI仍可操作；不因 unscaled 时间继续移动 |

初始不锁定未经测量的世界单位或目标机性能预算。实现时按实际阵型边界确定平直区；测试预设需保存相机、参数、种子与分辨率。

## 6. 验收测试用例

所有用例初始状态为“未执行”。自动数据检查与实际视觉检查分开报告，不以编译通过代替玩法/美术验收。

| ID | 操作/条件 | 预期结果 |
|---|---|---|
| T01 基线 | 同一预设比较平直、弯曲、弯曲+分层三模式 | 相机/种子/速度一致；能独立评价弯曲贡献 |
| T02 前进 | 播放直路，追踪一组远近标记 | 物件连续接近、放大、两侧掠过；无整体背景拉伸；远景稳定 |
| T03 地平线 | 慢速和单步观察生成位置 | 物件自然显露，无凭空跳出、曲面折线或突然消失 |
| T04 纸片 | 展示不同尺寸敌人、长武器，切换动画 | 脚底贴地，比例稳定，武器不被弯折，无浮空/穿地 |
| T05 战斗平直区 | 开关曲率并对比逻辑 Transform、碰撞和屏幕投影 | 平直区内真实战斗对象位置与命中关系不变；装饰不挡关键区域 |
| T06 循环 | 连续运行至少10次路段回收 | 无道路裂缝、重复瞬移、漂移；对象和材质数量预热后有界 |
| T07 边界参数 | 强度0、速度0、最小正时长、配置边界 | 无 NaN、除零或跳变；零强度等价平直；无效配置有明确处理 |
| T08 暂停 | 旅行中暂停、等待、恢复，多次重复 | 进度冻结；恢复连续；调试/UI可操作且无战斗点击穿透 |
| T09 到站 | 加速/减速/重置，重复至少10次到站 | 最终位置/进度一致，无累计误差；完成通知恰好一次 |
| T10 战斗衔接 | 环境就绪后开始真实波次，清场并处理奖励 | 不提前生成、不吞奖励、不重复波次；到站画面无跳切；非终点等待选择 |
| T11 战斗回归 | 普攻、蓄力、击退、击飞、远程、Boss、QTE | 命中/阵型/特效/血条不因环境弯曲错位；与原基线比较 |
| T12 预览交接 | 如启用远处敌阵预览，抵达并替换 | 无双份敌人、重复注册/奖励、残留血条；失败恢复可清理 |
| T13 分辨率 | 9:16、项目目标竖屏比例及带安全区设备 | 道路和地平线构图可读；HUD不拉伸、不越界、不遮挡关键敌人 |
| T14 渲染 | 观察屏幕边缘、最远处、纸片重叠和阴影 | 无错误剔除、透明倒序、深度/阴影与曲面不一致；BIRP材质可用 |
| T15 转向 | 后续左右出口及多入边指向同节点 | 选择目标准确；背景转向平滑；不依赖旧空间锚点决定逻辑节点 |
| T16 中断恢复 | 后续旅行中退出、重新进入、节点安全点恢复 | 无临时视觉残留；存档不写旅行中间状态；无前置旅行也能建立目标背景 |
| T17 隔离性 | 退出 Play Mode，重新打开实验场景并查 Git | 正式场景/共享SO/Prefab/材质/GUID/存档未被污染 |
| T18 性能 | 相同条件比较三模式，预热后采集帧时、GC、DrawCall、对象/材质数 | 记录硬件和数据；无持续增长与实验 Update 可避免的逐帧分配；目标机预算另行确认 |

## 7. 通过门槛与决策

第一阶段至少完成 T01–T04、T06–T09、T13–T14、T17–T18，用户实际观看后确认旅行感和弧度方向，再进入真实战斗集成。

第二阶段补 T05、T10–T12，未启用预览则 T12 标为不适用并说明。正式路线集成再执行 T15–T16；未实现路径不得标为通过。

最终由用户决定：保留原表现、仅增强旧 V2、为 FakeRoute 增加经批准的实时卷轴 Presenter，或继续视频方向。文档完成不等于实验通过。
