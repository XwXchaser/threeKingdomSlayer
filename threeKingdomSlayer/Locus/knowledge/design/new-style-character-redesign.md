## 3. 新画风方向

本任务不是重新发明一个无关角色，而是以用户指定的概念图为唯一主要视觉来源，制作同一角色的新版视觉基准和动画生产基底。

### 必须继承

- 参考图的整体画风、轮廓语言、比例、服装结构、配色、材质表达和细节密度。
- 参考图的角色身份和持剑敌军设定。
- 角色的头身关系、装备关系和视觉重心。
- 画面应保持清晰、可读、适合游戏动画生产，不要向写实电影、3D渲染或另一套卡通风格漂移。

### 起始帧目标姿态

- 完全正面、正交前视、角色直接看向镜头。
- 头、眼、胸、肩、腰、髋、膝和双脚均朝向正前方。
- 肩线水平且对称，头部和躯干不旋转、不扭转、不侧倾。
- 放松、中立、动画起始帧姿态；双脚稳定落地并略微分开。
- 双臂自然下垂，与躯干保持可读间距，不进入攻击姿势。
- 全身完整入画，头顶、双脚、剑身和剑尖都不能裁切，轮廓四周保留安全留白。

### 武器与左右关系

- 解剖学右手持唯一一把剑。
- 角色正面面对镜头时，剑位于画面左侧。
- 解剖学左手位于画面右侧，完整可见、空置、自然放松。
- 禁止盾牌、副武器、额外道具、额外装备和整图镜像。
- 不得把角色左右关系写成模糊的“左手持剑”；提示词必须同时写清解剖学左右与画面左右。

### 背景和素材目标

- 目标是干净角色素材，而不是场景插画。
- 优先要求真实透明 Alpha、无地面、无阴影、无环境色溢出、无文字和 UI。
- “PNG”或提示词中的“transparent”不能代替 Alpha 验收。
- 如果编辑接口无法稳定返回透明图，必须明确采用哪一种替代方案：参考图编辑后纯色背景抠图，或先生成不透明基准再单独制作 Alpha。替代方案产生的文件必须标记为后处理结果，不能称为 API 原生透明。

## 4. 图片生成工作流：必须读取

开始任何新的角色图片生成、姿态编辑、风格统一或透明处理前，必须读取：

1. `skill/gpt-image-generation.md`
2. `skill/workflows/image-asset-generation.md`

这两个文档分别负责 API 技术调用和图片素材生成/验收流程。执行时必须遵循以下关键规则：

- 单图编辑使用 `POST https://api.muskapis.com/v1/images/edits`。
- 本地参考图必须通过 multipart 字段 `image[]` 上传，不能只把本地路径写入 prompt。
- 参考图职责必须写进 prompt；本任务优先使用 `sword_enemy_concept_v1_sunburst.png`，不要把失败 v1/v2 自动升级为主要参考。
- Key 只从环境变量 `MUSK_API_KEY` 读取，不写入脚本、日志、文档或回复。
- 每次收费请求使用版本化输出，同时保存原始 response JSON；超时或状态不明时不要盲目重复生成。
- 生成成功、文件落盘、PNG 可读、尺寸正确和视觉验收是不同阶段，不能用 HTTP 200 代替素材验收。
- 透明素材至少要验证 PNG、RGBA/有效 Alpha、透明像素和四角透明；随后还要在预览中检查脏边、光晕、棋盘格被绘入、地面阴影和背景色溢出。
- 当前 v2 已证明：编辑 API 成功并不等于返回透明 Alpha。后续应先核对当前接口能力，再决定是否付费重做。

## 5. 视频生成工作流：必须读取

视频工作流的适用边界：视频技术成功、MP4 下载完成和容器校验通过，只证明视频链路可用，不等于角色画风、位置锚点、动作语义或 Unity 动画素材已经通过。

### Seedance 关键规则

- 创建接口：`POST https://direct.reachapi.ai/v1/vids/create`。
- 参考文件先上传到 `https://file.reachapi.ai/file/uploads`，字段名为 `file`。
- 创建请求使用新版 `input.content`；不要使用已废弃的 `input.prompt`、`input.image_url`、`input.image_urls` 或 `negative_prompt`。
- 普通角色/动作参考使用 `reference_image`；首尾帧任务使用 `first_frame` 和 `last_frame`，两种模式不能混用。
- Key 只从环境变量 `REACH_API_KEY` 读取，不写入项目、脚本、日志、知识库或回复。
- 创建收费任务前必须确认模型、时长、分辨率、比例、音频、参考图和输出路径。
- 轮询必须限次、限总时长；下载使用 `.part`、断点续传和 MP4 容器校验，不得无限轮询或失败后自动重建收费任务。
- 服务端 `success` 不等于本地视频已下载；视频下载完成也不等于美术验收通过。

### 角色动画视频的固定画布规则

角色视频用于后续 Sprite 或动作参考时，默认遵循：

- 固定正交镜头、固定画布、固定角色位置、固定绘制比例和脚底锚点。
- 禁止镜头推拉、平移、旋转、跟随、抖动、重新构图和角色整体缩放。
- 禁止角色整体平移、靠近镜头、远离镜头、迈步或滑动，除非任务明确是位移动作。
- 动作只改变局部关节、躯干、手臂、头部和表情；最大动作范围必须预留安全空间。
- 全程检查剑、双手、双脚和头部是否完整入画。
- 透明视频不能由“no background”或 MP4 容器验证推断得到；后续透明帧制作是独立步骤，需要单独验收和授权。
