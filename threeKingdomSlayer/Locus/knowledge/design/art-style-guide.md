# 新画风美术概念与素材生产指南

> 本文是游戏后续角色、敌人、BOSS、场景、UI、HUD、技能图标、战斗特效和宣传图的共同美术方向。
> 新画风的权威参考只有：用户提供的两张概念图，以及已部署并验收的 1011 六帧 Idle。其他既有角色、场景、图标和 UI 素材均属于旧美术，只可作为技术接线参考，不能反向定义本风格。

## 1. 核心定义

**这是“高清像素化的三国战场动作美术”。**

它不是传统低分辨率复古像素，不是把普通插画套上马赛克滤镜，也不是照片式战争写实。它的核心是：

- 三国战争题材的明确身份；
- 短壮、厚重、具有战斗分量的角色；
- 用大体块和像素化色簇表现真实体积；
- 暖黄土战场衬托冷铁灰甲胄；
- 朱红军旗、围巾、缨带和血色作为强识别色；
- 金白色刀刃、火星、尘爆和斩击形成街机式爆发；
- UI 使用墨色笔刷、金属边缘和高可读字体，服务战斗节奏。

整体情绪是：**厚重、凶悍、明亮战场中的强烈冲突、直接、爽快。**

**统一画风要统一“形体、材质、用色关系和情绪”，而不是让所有素材拥有相同的像素密度、色数和明度比例。**

可直接交给美术或生产工具的核心描述：

> 三国战争题材的高清像素化动作美术。角色短壮结实、装备厚重，以清晰的大体块和像素色簇塑造金属、布料与皮革的体积；环境粗粝但不灰暗，以黄土、城墙、军旗、木制军械和尘烟建立战争空间。冷铁灰与暖土色形成对比，红色布料提供识别，金白色战斗特效制造猛烈的街机打击感。UI 结合墨色笔刷底、金属边框与高可读字体，整体凶悍、厚重、爽快，不走萌系、清新绘本或照片写实路线。

禁止将它理解为：

- 清新花园或明亮绘本；
- 软萌、圆润、玩具感 Q 版；
- 阴暗哥特或全画面黑灰；
- 仙侠水墨、欧美奇幻骑士或现代科幻；
- 纯照片写实；
- 只有碎像素、没有体积和结构的噪点画面。

## 3. 角色设计语言

### 3.1 比例和轮廓

1011 的角色语言可以概括为：**Q 化的是比例，严肃的是战斗感。**

- 头盔相对偏大，肩膀宽，身体紧凑；
- 手、前臂、膝甲和靴子都有明显分量；
- 腿较短，双脚分开，站姿稳定；
- 上半身宽于下半身，视觉重心偏高；
- 武器是主要剪影的一部分，不是附属装饰；
- 角色必须看起来“站得住、打得动、扛得住”。

制作新角色时，优先检查缩小后的整体剪影：

1. 是否一眼能分辨兵种；
2. 是否能看出武器和关键装备；
3. 是否有清楚的头、肩、躯干、手臂和腿部轮廓；
4. 是否避免细节堆满但轮廓松散；
5. 是否保留短壮、厚重和敌军压迫感。

不要把所有角色都做成相同装备。应共享比例、重量和绘制语言，再通过兵器、头盔、肩甲、盾牌、旗帜、颜色和姿态区分兵种。

### 3.2 装备与材质

角色不是“身体加几块装备贴片”，而是被装备结构完整包裹的战斗体。

| 材质 | 表现方式 |
|---|---|
| 金属甲胄 | 冷灰、蓝灰主体；深色缝隙；锐利银白反光；明确的甲片厚度和层叠关系 |
| 红色布料 | 大面积明确色块；通过折面、破边和明暗变化表现，不铺细密织纹 |
| 皮革 | 暖棕、黄褐；边缘厚，带扣、腰带和护腕结构清楚 |
| 木材 | 木板方向、破损边缘、铁件和铆钉共同表达，不使用随机脏纹理覆盖 |
| 土石尘烟 | 粗粝的块状纹理、受光颗粒和遮挡层次，避免均匀噪声 |

1011 的角色本体相对干净、装备关系清楚；场景可以更粗粝、更破损，但不能把同样的污渍和噪声铺满角色。

### 3.3 面部和情绪

1011 通过头盔、眼缝和姿态表达敌意，而不是依靠复杂的人脸表情。

- 眼部可以使用橙红或暖色发光作为视觉焦点；
- 眼缝、面罩和头盔轮廓必须清楚；
- 情绪来自眼睛、头部角度、握拳、站姿和武器方向的组合；
- 不使用独立漂浮的眼球、眉毛或卡通五官破坏甲胄结构；
- 新角色可以有不同面部设定，但必须保持战斗身份优先、表情简洁可读。

## 4. 像素化绘制语言

### 4.1 像素是组织方式，不是滤镜

本风格的像素感来自：

- 阶梯状轮廓；
- 成簇的明暗色块；
- 清楚的受光面与暗部；
- 经过控制的局部纹理；
- 在缩小后仍然可读的剪影。

大色块不是禁忌，而是形体可读性的基础。细节必须服务于头盔、肩甲、胸甲、武器、手、膝甲和靴子的体积。

禁止：

- 只增加随机碎像素；
- 对普通插画套用像素化滤镜；
- 以色数统计代替视觉验收；
- 为了“像素感”抹掉金属、皮革和布料的体积；
- 把所有素材压成相同色阶和相同明暗比例。

有立体感不等于必须制作真实 3D 模型。本文定义最终视觉效果，不把某一种建模、渲染或生成方式当成风格本身。

### 4.2 光影和边缘

- 角色外轮廓需要清楚、偏深，但不要求所有素材使用同一条纯黑线；
- 金属用锐利高光表达硬度；
- 布料用大面积受光面和折面表达重量；
- 斩击、火星和命中特效可以使用大面积白金高光；
- 边缘要干净，避免灰边、白边和无意义的柔化光晕；
- 场景可以有烟尘和大气透视，但不能让战斗主体失去轮廓。

## 5. 色彩关系

色彩不是固定色表，而是明确的冷暖组织关系。

### 5.1 场景主关系

- 暖黄土、赭色、沙色构成战场底色；
- 城墙、土坡、木栅、道路和尘土使用暖中低明度；
- 天空、远山和大气可以使用冷蓝灰；
- 朱红用于军旗、围巾、缨带、火光和危险识别；
- 金白色集中用于受光、刀刃、火星和战斗爆发。

参考中有蓝天、亮云、受光城墙和金黄色尘土。**暗部厚重，不等于世界昏暗**；不能靠整体压暗去伪造凶悍气质。

### 5.2 角色主关系

- 冷铁灰、蓝灰甲片构成角色主体；
- 近黑用于甲胄缝隙、轮廓和暗部；
- 红色布料和缨带作为强识别色；
- 皮革、腰带和木质部件使用暖棕、黄褐；
- 金属反光使用银白、灰白和少量暖金。

### 5.3 色彩控制

- 一张素材需要有明确的主色、辅助色和强调色；
- 不要求所有素材只使用一种高饱和色；战斗特效可以在命中瞬间扩大亮色面积；
- 高饱和色应承担识别、攻击方向或情绪功能，不要平均撒满画面；
- 场景与角色可以共享红色，但角色不能被背景的红旗吞没；
- 颜色变化应服务阵营、兵种、元素和战斗状态。

上述配色是当前战场与 1011 的组织关系，不是全游戏唯一色板。森林、山谷、夜景、水系技能和不同阵营可以改变颜色；需要继承的是冷暖对比、焦点主次和材质逻辑，不是所有素材都必须红色或黄土色。

## 6. 场景美术

### 6.1 场景不是装饰背景

场景必须让玩家理解“正在发生什么”。城门、城墙、望楼、旗阵、盾墙、军械、道路和尘土都应承担叙事或空间职责。

场景应形成三层空间：

- **远景**：城池、山体、远处军阵、天空和大气；降低细节与对比，提供世界尺度；
- **中景**：军旗、望楼、营地、城墙、木栅、敌阵，负责题材识别和路线方向；
- **近景**：盾牌、断木、碎石、武器、尘土和大型物件，负责速度、冲击和临场感。

### 6.2 战斗空间优先

- 中央战斗区域必须连续、开阔、可读；
- 大型建筑和叙事物件优先放在边缘、远景或道路两侧；
- 场景要有空间层次，但不能用装饰物堵住敌人、武器和特效；
- 战斗地面需要支持角色站立、敌人阵列和攻击表现；
- 场景概念图中的敌人、斩击、尘爆和 HUD 不能直接烘进正式背景素材。

### 6.3 场景制作要求

制作可部署素材时，应将概念图拆成：

- 天空与远景；
- 地面与道路；
- 建筑与大型结构；
- 中景侧景；
- 近景遮挡物；
- 可独立控制的旗帜、火盆、木箱、拒马、碎石和尘烟。

概念图负责构图和气氛，正式素材负责可摆放、可复用、可调整和不遮挡战斗。

## 7. UI 与 HUD

第二张概念图已经确立 UI 方向，UI 不需要和角色精灵使用完全相同的像素密度。

### 7.1 UI 气质

- 墨色、黑色的破边笔刷块作为信息承托；
- 金属、黄铜和金色作为边框、图标外圈和重要数值的质感；
- 红色用于连击、生命、危险和攻击确认；
- 普通数字和说明文字保持干净、高对比、易读；
- UI 与战斗画面共享厚重、战争和街机动作气质。

### 7.2 UI 构图

- 连击数字可以倾斜、放大、带笔刷飞溅和速度感；
- 金币、暂停和状态信息应占据固定、清楚的安全区域；
- 血条必须一眼看出当前值，不被背景纹理干扰；
- 技能按钮使用稳定圆形或明确几何轮廓，内部符号优先于装饰；
- UI 不应堆叠成厚重面板，避免遮挡战斗主体；
- 竖屏布局优先，所有关键操作需要适配安全区。

### 7.3 图标

图标不是完整小插画，而是一个小尺寸可识别符号：

- 单一视觉焦点；
- 轮廓优先；
- 武器、火焰、箭矢、旋风、水浪和护甲必须一眼可分辨；
- 透明背景、无多余文字和无无关边框；
- 元素色可以鲜艳，但必须服务技能类别和方向；
- 图标的具体新画风仍需以新一批验收样本继续校准。

菜单、奖励卡、对话面板和科技树等尚未在这两张概念图中展示的页面，可继承笔刷、金属和高可读信息的语言；这些属于后续设计推导，不能称为已经验收的具体界面。

## 8. 战斗特效

### 8.1 特效核心

特效的第一目标是让玩家看懂：**这一击从哪里来、打到了哪里、力度有多大。**

应优先使用：

- 清楚的斩击弧线和攻击方向；
- 金白色核心高光；
- 红色外缘、速度线和能量拖尾；
- 集中的命中火星；
- 尘土、碎甲、木屑和碎片补充实体重量。

### 8.2 特效限制

- 特效可以在瞬间大面积变亮，不适用“所有白色只能小面积”的绝对规则；
- 持续时间越长，越要降低遮挡和纹理密度；
- 视觉形状必须服务攻击类型，不能只生成泛用光团；
- 特效的方向、起点、终点和命中点要清楚；
- 常驻被动效果不能持续盖住角色、敌人和战斗 UI；
- 水、火、风、雷等元素可以拥有独立色彩，但要保留硬边、色簇和强方向感。

## 9. 各类素材的共同验收标准

### 视觉验收

- [ ] 不看文字也能识别素材用途、兵种、技能或状态；
- [ ] 大轮廓先成立，细节没有破坏剪影；
- [ ] 材质能被区分：金属、布料、皮革、木材和土石不混成同一种纹理；
- [ ] 暖土、冷铁、朱红和金白高光的关系成立；
- [ ] 素材有明确视觉焦点，没有所有元素同等抢眼；
- [ ] 战斗素材有方向、冲击和命中信息；
- [ ] UI 信息清楚，场景不遮挡战斗；
- [ ] 与概念图和 1011 Idle 并排查看后，能解释为什么属于同一世界。

### 技术验收

- [ ] 角色帧画布统一、脚底锚点统一、装备不变形、不丢失；
- [ ] PNG、Alpha、透明边缘和导入设置正确；
- [ ] 场景素材可以独立摆放、缩放、排序和复用；
- [ ] 概念图中的 HUD、角色和动态特效没有被错误烘入背景；
- [ ] Unity 实际 Game 画面中主体仍然清楚；
- [ ] 通过用户目视验收后，才进入正式资源目录。

## 10. 通用生产流程

```text
确定素材职责
→ 选定对应概念参考与 1011 基准
→ 先画构图 / 剪影 / 大色块
→ 确定材质、主色、强调色和光照方向
→ 制作角色、场景、UI 或特效细节
→ 检查游戏尺寸下的可读性
→ 机器检查尺寸、Alpha、锚点和文件格式
→ 导入 Unity 并回读实际表现
→ 用户目视验收
→ 记录正式资源与版本
```
