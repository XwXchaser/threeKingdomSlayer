# 新画风美术概念与素材生产指南

> 本文是游戏后续角色、敌人、BOSS、场景、UI、HUD、技能图标、战斗特效和宣传图的共同美术方向。
> 当前参考按职责区分：两张用户概念图负责世界与战斗气氛；原始 1011 六帧 Idle 保留短壮比例、战斗重量和部署参考；**2026-10-24 用户明确确认刀兵 v11“就是我们要的画风”，作为后续角色绘制的最新已验收样本**；已验收接入的 N1/J1/N3 指定素材负责角色与场景的材质协调对照。完整职责见 §2、§12，不能再把所有实验目录素材一概排除，也不能把 v11 的单个刀兵装备规定为全兵种制服。
>
> 本次确认的是角色画风。动画动作、帧间一致性、实际 Game 显示大小和部署效果仍按各自验收处理；不由静帧画风通过自动推定。UI、HUD、战斗特效沿用本文原有方向，本次不扩展其验收范围。

## 1. 核心定义

**这是“高清像素化的三国战场动作美术”。**

它不是传统低分辨率复古像素，不是把普通插画套上马赛克滤镜，也不是照片式战争写实。它的核心是：

- 三国战争题材的明确身份；
- 短壮、厚重、具有战斗分量的角色；
- 用大体块和像素化色簇表现真实体积；
- 暖黄土战场衬托冷铁灰甲胄；
- 朱红军旗、围巾、缨带和血色作为强识别色；
- 金白色刀刃、火星、尘爆和斩击形成街机式爆发；
- UI 使用墨色笔刷、金属边缘和高可读字体，服务战斗节奏。

整体情绪是：**厚重、凶悍、明亮战场中的强烈冲突、直接、爽快。**

**统一画风要统一“形体、材质、用色关系和情绪”，而不是让所有素材拥有相同的像素密度、色数和明度比例。**

可直接交给美术或生产工具的核心描述：

> 三国战争题材的高清像素化动作美术。角色短壮结实，以清楚的大体块、深色结构边和有方向、疏密变化的硬边色簇塑造体积；装备按兵种分级，轻装兵同样通过宽肩、厚手和稳固站姿体现重量。金属保留完整曲面、边缘厚度与集中锐光，布料用大褶皱、皮革和绳索用明确结构，皮肤简洁有骨点，不把全身铺成同一种碎面纹理。冷灰铁、暖麻布、棕色皮革和少量朱红在暖土战场里形成主次。环境粗粝而不灰暗，战斗特效金白猛烈，UI 使用墨色笔刷与金属边框，整体凶悍、厚重、爽快。

禁止将它理解为：

- 清新花园或明亮绘本；
- 软萌、圆润、玩具感 Q 版；
- 阴暗哥特或全画面黑灰；
- 仙侠水墨、欧美奇幻骑士或现代科幻；
- 纯照片写实；
- 只有碎像素、没有体积和结构的噪点画面。

## 3. 角色设计语言

### 3.1 比例和轮廓

原始 1011 的重量与已验收 v11 共同明确：**Q 化的是比例，严肃的是战斗感。** v11 的大头宽肩、紧凑躯干、短腿和厚靴是后续角色的目视参照，不用未经验证的固定头数或包围盒宽高比代替人体比例判断。

- 头盔相对偏大，肩膀宽，身体紧凑；
- 手、前臂和靴子都有明显分量；膝甲等加件按兵种需要，不把重量等同于全身装甲；
- 腿较短，双脚分开，站姿稳定；
- 上半身宽于下半身，视觉重心偏高；
- 武器是主要剪影的一部分，不是附属装饰；
- 角色必须看起来“站得住、打得动、扛得住”。

制作新角色时，优先检查缩小后的整体剪影：

1. 是否一眼能分辨兵种；
2. 是否能看出武器和关键装备；
3. 是否有清楚的头、肩、躯干、手臂和腿部轮廓；
4. 是否避免细节堆满但轮廓松散；
5. 是否保留短壮、厚重和敌军压迫感。

不要把所有角色都做成相同装备。应共享比例、重量和绘制语言，再通过兵器、头盔、肩甲、盾牌、旗帜、颜色和姿态区分兵种。

### 3.2 装备与材质

角色的衣服、装备与身体应有可信的穿戴、压叠和连接关系。轻装或简易胸牌可以成立，**不要求全身被甲包裹**；厚重感来自形体、站姿和材质厚度。

| 材质 | 表现方式 |
|---|---|
| 金属甲胄 | 冷灰、蓝灰主体；曲面整体连续，暗缝和边缘厚度清楚；亮面内用少量硬边色簇与集中银白反光解释曲率，不铺等大的方砖或石材切片 |
| 布料 | 麻色、土色或阵营色均可；肩袖、衣摆用成组大褶皱和有方向的硬边笔触解释，红布提供识别；不铺满织纹，不画成硬金属或多边形装饰片 |
| 皮革 | 暖棕、黄褐；腰带、肩带、鞋的厚边、转折、带扣和接缝清楚，反光比铁收敛，不使用塑料油亮高光 |
| 麻绳 | 编股沿绳方向组织，结与压叠清楚；细节集中在编股节奏，不将同一纹理铺到衣服或皮肤 |
| 皮肤与胡须 | 用简洁暖色色面表现额头、眉弓、颊、鼻、手指；深色眉眼与胡须形成身份，局部色簇服从骨点与握拳体积，不画成石雕、碎面马赛克或柔滑塑料 |
| 木材 | 木板方向、破损边缘、铁件和铆钉共同表达，不使用随机脏纹理覆盖 |
| 土石尘烟 | 粗粝的块状纹理、受光颗粒和遮挡层次，避免均匀噪声 |

1011 的角色本体相对干净、装备关系清楚；场景可以更粗粝、更破损，但不能把同样的污渍和噪声铺满角色。

### 3.3 面部和情绪

原始 1011 通过盔与眼缝表达敌意；v11 验证了完全露脸的敌兵也能保持同样的战斗身份。

- v11 战斗待机靠压低并内收的眉、集中注视的窄眼、紧闭的嘴、厚拳和持刀戒备构成；脸是成年人，不因大头比例变成儿童脸。
- 眉眼、鼻影和胡须长在完整脸面上，结构简洁，缩小仍有战斗感；不是平静肖像，也不靠歪嘴、加黑肤色或夸大表情补救。
- 橙红眼光、面罩不是通用要求，是否使用由角色身份决定；不得把原始 1011 的面罩强加给露脸兵。
- 情绪来自眼睛、头部角度、握拳、站姿和武器方向的组合，不使用漂浮卡通五官。
- 此处闭嘴是 v11 静帧参考；攻击动画的张嘴时机、幅度与动作匹配必须另行验收，不能把静帧约束直接套到所有动画。

## 4. 像素化绘制语言

### 4.1 像素是组织方式，不是滤镜

本风格的像素感来自：

- 阶梯状轮廓；
- 成簇的明暗色块；
- 清楚的受光面与暗部；
- 经过控制的局部纹理；
- 在缩小后仍然可读的剪影。

大色块不是禁忌，而是形体可读性的基础。细节必须服务于头盔、肩甲、胸甲、武器、手、膝甲和靴子的体积。

禁止：

- 只增加随机碎像素；
- 对普通插画套用像素化滤镜；
- 以色数统计代替视觉验收；
- 为了“像素感”抹掉金属、皮革和布料的体积；
- 把所有素材压成相同色阶和相同明暗比例。

有立体感不等于必须制作真实 3D 模型。本文定义最终视觉效果，不把某一种建模、渲染或生成方式当成风格本身。

### 4.2 光影和边缘

- 角色外轮廓需要清楚、偏深，但不要求所有素材使用同一条纯黑线；
- 金属用锐利高光表达硬度；
- 布料用大面积受光面和折面表达重量；
- 斩击、火星和命中特效可以使用大面积白金高光；
- 边缘要干净，避免灰边、白边和无意义的柔化光晕；
- 场景可以有烟尘和大气透视，但不能让战斗主体失去轮廓。

### 4.3 v11 已验收的笔触、边缘和细节层级

1. **先形体，后笔触。** 头盔、胸牌、臂、拳、袖和靴首先是完整的体积；在体积里使用不规则、大小变化的硬边色簇，笔触沿弧面、褶皱和材料方向组织。
2. **结构边深、细节边有主次。** 盔沿、腋下、袖口、胸牌与衣服交界、裤裆及鞋底用偏深边线或遮挡暗部拉开；内部不是每一笔都勾同宽黑线，不画柔化光晕。
3. **有角度，不等于积木。** 允许局部阶梯轮廓、斜向短笔触和折面；同一形体内部不铺规则方格、不画等大砖块，也不把所有材料切成同尺寸多边形。
4. **大面与局部细节共存。** 先看肩、躯干、袖子和裤腿的大明暗；再看眉眼、刀刃、带扣、甲边和绳结。疏处保留大面，密处集中在连接与转折，不能全身均匀颗粒化。
5. **硬边中仍有体积。** 通过成簇色面的组织形成光照变化；不靠大面积喷枪渐变，也不把色阶强行限制成两三阶。清晰不等于极低分辨率，细节多不等于密集噪点。
6. **材质各有画法。** 铁的集中锐光、布的大褶皱、皮的厚边、绳的编股、皮肤的骨点必须可辨；整体统一来自同样的塑形纪律，而非同一套纹理。

本轮失败对照保留用于识别边界：v5 头身偏高且细线过多；v6/v8 是过度规则方块；v7 是过度平滑卡通；v10 是只吸收暖色并把全身统一碎切面。**v11 的目标不是这些方向的统计平均值，而是按形体和材质组织笔触。** 这些版本号特指 `plan/enemy1011-style-locked-dao-generation-handoff.md`，不要与其他任务的 v5/v11 混用。

### 4.4 可复用的生成表达与参考分工

- 做同类新角色时，以已验收 v11 作为角色具体画法参考；角色身份、服饰、姿势由相应设计或单独参考提供，职责必须写清。
- 本次成功试验用 N1 破盾提供材质画法、v7 提供身份，不能推断任意道具参考都能同样成功。
- 已验收的英文提交文本如下，只作为画法表达的执行先例；`image 1` 是 N1 破盾，`image 2` 是 v7。后续更换输入时须重新说明职责，不盲用这两个编号。

## 5. 色彩关系

色彩不是固定色表，而是明确的冷暖组织关系。

### 5.1 场景主关系

- 暖黄土、赭色、沙色构成战场底色；
- 城墙、土坡、木栅、道路和尘土使用暖中低明度；
- 天空、远山和大气可以使用冷蓝灰；
- 朱红用于军旗、围巾、缨带、火光和危险识别；
- 金白色集中用于受光、刀刃、火星和战斗爆发。

参考中有蓝天、亮云、受光城墙和金黄色尘土。**暗部厚重，不等于世界昏暗**；不能靠整体压暗去伪造凶悍气质。

### 5.2 角色主关系

- v11 用麻色衣服与深棕裤建立轻装兵的大色块，冷铁灰、蓝灰用于盔、胸牌和护腕；重甲兵可增加金属面积，不规定所有兵都以金属为主体。
- 近黑或深棕用于轮廓、遮挡、衣甲压叠和眉眼，暗部深但仍能分出材质。
- 红色头巾、腰侧小布条等作为集中识别，不要求所有角色带缨或大面积披红。
- 皮革、靴子、绳与木质部件使用暖棕、黄褐；肤色保持有生气的暖色体积。
- 金属反光使用银白、灰白和少量暖金，集中在曲面与边缘。冷铁在暖土环境里可形成有效对比，不需全身染黄才算统一。

### 5.3 色彩控制

- 一张素材需要有明确的主色、辅助色和强调色；
- 不要求所有素材只使用一种高饱和色；战斗特效可以在命中瞬间扩大亮色面积；
- 高饱和色应承担识别、攻击方向或情绪功能，不要平均撒满画面；
- 场景与角色可以共享红色，但角色不能被背景的红旗吞没；
- 颜色变化应服务阵营、兵种、元素和战斗状态。

上述配色是当前战场与 1011 的组织关系，不是全游戏唯一色板。森林、山谷、夜景、水系技能和不同阵营可以改变颜色；需要继承的是冷暖对比、焦点主次和材质逻辑，不是所有素材都必须红色或黄土色。

## 6. 场景美术

### 6.1 场景不是装饰背景

场景必须让玩家理解“正在发生什么”。城门、城墙、望楼、旗阵、盾墙、军械、道路和尘土都应承担叙事或空间职责。

场景应形成三层空间：

- **远景**：城池、山体、远处军阵、天空和大气；降低细节与对比，提供世界尺度；
- **中景**：军旗、望楼、营地、城墙、木栅、敌阵，负责题材识别和路线方向；
- **近景**：盾牌、断木、碎石、武器、尘土和大型物件，负责速度、冲击和临场感。

### 6.2 战斗空间优先

- 中央战斗区域必须连续、开阔、可读；
- 大型建筑和叙事物件优先放在边缘、远景或道路两侧；
- 场景要有空间层次，但不能用装饰物堵住敌人、武器和特效；
- 战斗地面需要支持角色站立、敌人阵列和攻击表现；
- 场景概念图中的敌人、斩击、尘爆和 HUD 不能直接烘进正式背景素材。

### 6.3 场景制作要求

制作可部署素材时，应将概念图拆成：

- 天空与远景；
- 地面与道路；
- 建筑与大型结构；
- 中景侧景；
- 近景遮挡物；
- 可独立控制的旗帜、火盆、木箱、拒马、碎石和尘烟。

概念图负责构图和气氛，正式素材负责可摆放、可复用、可调整和不遮挡战斗。

## 7. UI 与 HUD

第二张概念图已经确立 UI 方向，UI 不需要和角色精灵使用完全相同的像素密度。

### 7.1 UI 气质

- 墨色、黑色的破边笔刷块作为信息承托；
- 金属、黄铜和金色作为边框、图标外圈和重要数值的质感；
- 红色用于连击、生命、危险和攻击确认；
- 普通数字和说明文字保持干净、高对比、易读；
- UI 与战斗画面共享厚重、战争和街机动作气质。

### 7.2 UI 构图

- 连击数字可以倾斜、放大、带笔刷飞溅和速度感；
- 金币、暂停和状态信息应占据固定、清楚的安全区域；
- 血条必须一眼看出当前值，不被背景纹理干扰；
- 技能按钮使用稳定圆形或明确几何轮廓，内部符号优先于装饰；
- UI 不应堆叠成厚重面板，避免遮挡战斗主体；
- 竖屏布局优先，所有关键操作需要适配安全区。

### 7.3 图标

图标不是完整小插画，而是一个小尺寸可识别符号：

- 单一视觉焦点；
- 轮廓优先；
- 武器、火焰、箭矢、旋风、水浪和护甲必须一眼可分辨；
- 透明背景、无多余文字和无无关边框；
- 元素色可以鲜艳，但必须服务技能类别和方向；
- 图标的具体新画风仍需以新一批验收样本继续校准。

菜单、奖励卡、对话面板和科技树等尚未在这两张概念图中展示的页面，可继承笔刷、金属和高可读信息的语言；这些属于后续设计推导，不能称为已经验收的具体界面。

## 8. 战斗特效

### 8.1 特效核心

特效的第一目标是让玩家看懂：**这一击从哪里来、打到了哪里、力度有多大。**

应优先使用：

- 清楚的斩击弧线和攻击方向；
- 金白色核心高光；
- 红色外缘、速度线和能量拖尾；
- 集中的命中火星；
- 尘土、碎甲、木屑和碎片补充实体重量。

### 8.2 特效限制

- 特效可以在瞬间大面积变亮，不适用“所有白色只能小面积”的绝对规则；
- 持续时间越长，越要降低遮挡和纹理密度；
- 视觉形状必须服务攻击类型，不能只生成泛用光团；
- 特效的方向、起点、终点和命中点要清楚；
- 常驻被动效果不能持续盖住角色、敌人和战斗 UI；
- 水、火、风、雷等元素可以拥有独立色彩，但要保留硬边、色簇和强方向感。

## 9. 各类素材的共同验收标准

### 视觉验收

- [ ] 不看文字也能识别素材用途、兵种、技能或状态；
- [ ] 大轮廓先成立，细节没有破坏剪影；
- [ ] 材质能被区分：金属、布料、皮革、木材和土石不混成同一种纹理；
- [ ] 暖土、冷铁、朱红和金白高光的关系成立；
- [ ] 素材有明确视觉焦点，没有所有元素同等抢眼；
- [ ] 战斗素材有方向、冲击和命中信息；
- [ ] UI 信息清楚，场景不遮挡战斗；
- [ ] 新角色与已验收 v11 在相近显示大小下对照：比例重量、结构边、硬边笔触和分材质处理成立，保留兵种差异。
- [ ] 与指定已接入 N1/J1/N3 样本并排，形体、边缘和材质协调；不靠统一暖色、颗粒密度或高频统计证明一致。
- [ ] 无规则方格、全身同尺寸碎切面、平滑卡通与塑料高光；允许服从体积的局部折面和色簇。
- [ ] 角色画风验收与动画、尺寸、Alpha、帧间一致性和 Game 实机验收分别记录。

### 技术验收

- [ ] 角色帧画布统一、脚底锚点统一、装备不变形、不丢失；
- [ ] PNG、Alpha、透明边缘和导入设置正确；
- [ ] 场景素材可以独立摆放、缩放、排序和复用；
- [ ] 概念图中的 HUD、角色和动态特效没有被错误烘入背景；
- [ ] Unity 实际 Game 画面中主体仍然清楚；
- [ ] 通过用户目视验收后，才进入正式资源目录。
