# 游戏整体循环：主武器、局内构筑与永久解锁

> 本文记录本轮讨论形成的**玩法方向与用户确认的规则**，用于统一主武器、全局成长、局内构筑和永久解锁的概念。本文不描述工程现状、实现方案、排期或数值配置。
>
> 旧文档 `design/weapon-system-design.md`、`design/in-run-build-design.md` 中与本文冲突的局内外归属、奖励来源和确认状态，以本文为准；旧文档中未被本轮讨论推翻的内容仍保留其原有状态。标为**待讨论**或**设计示例**的内容不是已确认需求。

## 1. 核心体验

玩家以选定的**主武器**为基础战斗，在一次无尽挑战中通过经验成长、影之武装和饰品不断建立、调整 Build；击败强敌、探索地图也会带来可永久保留的收获。回到局外后，玩家使用永久获得的资源成长、了解新内容，并可选择或更换主武器，开始下一局。

玩家希望经历的不是“填满四个装备槽就结束成长”，而是：

> **获得可用装备 → 使用并发现其特点 → 继续强化或比较新装备 → 更换过渡件 → 形成联动 → 随局势继续调整。**

一次一般挑战以**约 20 分钟**为体验目标，玩家在 **20～30 分钟**里应能感受相当于《影之刃零》通关过程中装备持续发现、更替和成长的压缩体验。这是体验方向，**不是 20 或 30 分钟强制结束**，也不是要求复制对方的物品数量、时长或数值。

## 2. 整体循环

```text
局外：选择、升级或更换主武器；进行全局成长
  ↓
开始本局，使用主武器与已有战斗能力面对敌人
  ↓
战斗与探索
  ├─ 经验升级 → 本局成长属性
  ├─ 精英 / Boss 的装备宝箱 → 本局使用的影之武装 / 饰品
  ├─ Boss → 可获得新的主武器，获得时立即永久拥有
  ├─ 精英 / Boss / 地图探索宝箱 → 可永久解锁部分影之武装 / 饰品
  └─ 获取金币与局外升级道具 → 获得时立即到账
  ↓
用当前成长与装备继续战斗、强化并调整本局 Build
  ↓
本局结束
  ├─ 本局成长属性、本局影之武装 / 饰品及其局内强化结束
  └─ 已永久获得的主武器、已到账资源和已解锁内容保留
  ↓
回到局外：更换 / 升级主武器、进行全局成长、了解已解锁内容
  ↓
开始下一局
```

**地图探索宝箱可以给予影之武装或饰品的永久解锁；它与精英 / Boss 的本局装备宝箱不必是同一种奖励。** 本文不预设探索宝箱会直接发放本局装备，也不预设每次遭遇一定给某种长期奖励。

## 3. 四种对象及各自边界

### 3.1 主武器：局外战斗身份

- 主武器与影之武装是不同概念。以长枪为例，主武器承载玩家主要招式及战斗身份；影之武装是局内获得的主动战斗手段，不能把两者统称为同一类武器。
- 玩家通过局内击败 Boss 有机会获得新的主武器。**获得时立即永久拥有**；本局随后失败或结束，不收回已经获得的主武器。
- 新获得的主武器需要**回到局外后**选择、更换装备，不在本局自由切换主武器。
- 主武器及其招式属于局外成长方向；连招不进入局内三选一。以主武器承担招式和绝技的方向，形成与本局随机构筑不同的长期战斗身份。
- Boss 对应的主武器已获得时，重复获得改为**金币、升级素材等其他奖励**；具体奖励种类、数量及分配方式待定。
- 以长枪说明概念，不预设本轮新增其他主武器的数量、名单或具体动作。

### 3.2 全局成长：跨局保留的主角成长

- 局外成长按两大类理解：**主武器成长**与**全局成长**。全局成长代表跨局保留的主角或通用能力成长。
- 玩家在局内获得金币及局外升级道具，**获得时立即到账**，用于局外的主武器升级或全局成长；之后死亡或结束本局，不收回已到账资源。
- 全局成长的具体节点、效果、强度、价格与路线，按玩法方向及强度继续讨论；不在本文预设。

### 3.3 本局成长属性：经验驱动，不可替换

- 成长属性来自**本局经验升级**，为本局角色能力提供积累；它们不占饰品槽。
- 获得的成长属性属于本局积累，不像饰品一样插拔或替换；本局结束后不跨局保留。
- 属性可以服务输出、生存、操作或影之武装，也可以被饰品转化、放大或作为联动条件。同一项属性在不同 Build 中可以有不同价值。
- 属性原则上可以持续叠加，但有软上限；软上限的抬升由局外成长解锁。哪些属性开放及各自上限、张数与等级如何区分，留待后续设计；“可叠加”不等于本局无任何限制。

### 3.4 影之武装与饰品：本局获得、成长和更替

- **影之武装**是本局获得与使用的主动战斗手段，可围绕它本身建立 Build，也可以辅助主武器战斗；在本局中可继续成长和更替，具体成长与更替规则待讨论。
- **饰品**是本局获得与装备的效果，可与操作、成长属性、影之武装或敌人状态联动。饰品可以插拔、替换；换掉饰品不移除玩家已获得的成长属性。
- 影之武装与饰品初始槽位各为 **2**；后续槽位成长属于局外全局成长的讨论范围。
- 装备品质分为**普通 / 精良 / 传说**三档，允许部分内容只有单一品质；品质与具体成长等级如何对应、如何获得及更替，仍待讨论。
- 影之武装相关的暗源遵循**靠进攻获取、防御姿态不回复**的设计边界；具体获取量、消耗与标定方式待讨论。
- 属性通过经验成长；本局使用的影之武装与饰品通过**精英 / Boss 掉落的装备宝箱**获得。三选一候选可能同时包含两类，但玩家是否选择影之武装由玩家决定。
- 大约进行到 **3 分钟**时，应提供一次**能选到影之武装的机会**；玩家可以在同次选择中选择饰品，因此不保证此时一定持有影之武装。奖励在波末选择，体验时点以玩家真正能选择为准。不开局免费赠送 Build。
- 一部分影之武装和饰品初始即已解锁；另一部分通过**击败精英、Boss 或探索地图宝箱**获得永久解锁。解锁后**立刻可以在本局后续装备宝箱中出现**，但不代表立刻自动装备、必定抽到或保证某个时间获得。
- 本局结束后，本局持有的影之武装 / 饰品及局内强化不保留；**永久解锁资格保留**，可在之后对局中出现。
- 局外提供一个界面，让玩家了解已解锁的影之武装和饰品；界面具体展示内容、布局和交互不在本轮讨论范围。
- 旧被动按实际玩法语义重新分流：一部分成为本局成长属性，另一部分成为可插拔、可替换的饰品；不因为旧名称或旧技术分类决定归属。逐项分类待讨论。

## 4. 三种 Build 方向

三种方向不是互斥职业或固定配方。玩家可以因局内获得的成长与装备形成其中一种，也可以交叉组合。

| 方向 | 主要乐趣 | 关系示例 |
|---|---|---|
| **操作提升** | 根据攻击、蓄力、招架 / 防御等时机，让操作获得额外收益 | 主武器招式 + 相关成长属性 + 操作联动饰品 |
| **影之武装 Build** | 围绕一件或多件影之武装决定战斗节奏和组合 | 影之武装 + 相关成长属性 + 影响其使用或效果的饰品 |
| **数值策略 Build** | 积累属性，并通过饰品让属性产生新的价值 | 生命成长 + “霸王血铠”类属性转化饰品 |

- 例如：前期为了生存积累生命，后来遇到生命转攻击的“霸王血铠”类饰品，玩家可能围绕已有生命成长调整本局方向。饰品换下后，生命成长仍在，饰品的转化效果不再生效。**这是机制形状示例，不是已确定数值或最终饰品表。**
- 也要保留**通用或过渡**影之武装与饰品：它们可以先解决眼前问题，玩家以后再决定是否替换；不是每个候选都必须依赖完整配方。
- Build 既可以围绕主武器操作，也可以围绕影之武装，不要求所有影之武装都只是基础攻击的附属。

## 5. 关卡、奖励与成长节奏方向

- 关卡应让基础操作、影之武装和饰品联动都获得表现机会：敌人威胁、站位及战斗节奏共同构成 Build 的使用场景。
- 玩家希望在一般局中感受到多次有效的**获得、比较、强化与替换**，而不是填满初始槽位后只剩少数变化。单纯规定装备选择次数无法证明体验成立。
- **设计示例**：一个节点配置约五波敌人，末波掉一个宝箱，约三分钟完成一次装备更替机会。节点内是否还有其他精英掉箱、单个宝箱提供几次选择、Boss 宝箱如何计入，以及不同玩家实际经历的次数，均未定。
- 装备机会、经验曲线、节点时长、敌人压力、品质分布和 20～30 分钟内的成长密度，属于后续数值配置与关卡策划讨论；本文不确定任何次数、掉率或最终时刻。
- 已积累的本局 Build 跨本局后续节点 / 圈继续保留，不因进入下一圈重置。本局结束后，临时构筑结束，永久获得物与已到账资源保留。

## 6. 参考方向与证据边界

### 《影之刃零》：战斗身份与装备分工

- 借鉴主武器承载战斗身份、影之武装提供不同战斗手段、饰品与行为 / 资源 / 状态产生联系的分工，以及持续获得、比较和更替装备的体验。
- 参考来源：[主武器（BWIKI）](https://wiki.biligame.com/yingzhiren/%E4%B8%BB%E6%AD%A6%E5%99%A8)、[影之武装（BWIKI）](https://wiki.biligame.com/yingzhiren/%E5%BD%B1%E4%B9%8B%E6%AD%A6%E8%A3%85)、[饰品（BWIKI）](https://wiki.biligame.com/yingzhiren/%E9%A5%B0%E5%93%81)。这些是社区维护资料；不将其数值或整套机制视为本项目规则。
- 不因参考对象存在闪避、自由切换主武器等行为，就把它们引入本轮方向。

### 肉鸽游戏：局内组合与跨局解锁

- 借鉴“局内随机选择形成组合，跨局解锁扩展未来选择”的关系；永久解锁资格与本局装备实例需要区分。
- [《死亡细胞》蓝图资料](https://deadcells.wiki.gg/wiki/Blueprints)：敌人或探索可获得蓝图，但蓝图需交付并支付细胞才能解锁；**交付前死亡会失去蓝图**。这不同于本项目已定的“新主武器获得时立即永久拥有”，不可照搬为本项目规则。
- [《吸血鬼幸存者》收藏界面](https://vampire.survivors.wiki/w/Collection)可参考局外回顾已发现内容；其收录条件不等同于本项目“展示已解锁的影之武装与饰品”。
- [《土豆兄弟》商店资料](https://brotato.wiki.spellsandguns.com/Shop)可参考随机候选与已有装备之间的关系；[《哈迪斯》官方页面](https://store.steampowered.com/app/1145360/Hades/)可参考在熟悉的动作基础上选择不同祝福形成构筑。二者的商店、操作、时间与数值不直接套用。

### LOL 装备与海克斯：条件和联动

- 借鉴装备与强化通过“属性、战斗行为、技能和触发条件”形成组合，让玩家在既有操作基础上选择不同节奏。
- [Riot 装备设计文章](https://www.leagueoflegends.com/en-us/news/dev/dev-2024-item-changes/)讨论装备与角色玩法的关系；[ARAM Mayhem 版本说明](https://www.leagueoflegends.com/en-us/news/game-updates/patch-25-21-notes/)说明其强化选择与装备共同构成玩法。两者仅作结构参考，不直接套用获得时点、数量或数值。

### 微信小游戏同品类：暂未核实

此前尝试检索微信小游戏及同类移动肉鸽的局内掉落、死亡保留和局外装备处理，但没有找到足以确认具体结算规则的可靠资料。**不据此声称某款微信小游戏采用“立即永久入账”或其他具体规则。**

## 7. 尚待后续讨论的设计问题

1. 主武器、金币和局外升级道具的具体掉落来源、种类、数量、Boss 重复奖励分配。
2. 影之武装 / 饰品的初始解锁清单、可永久解锁清单及精英、Boss、探索宝箱之间如何分配；其解锁资格本身的永久保存确认时点仍待明确，本局后续宝箱可立即出现的规则已确定。
3. 本局影之武装 / 饰品的获得、同款成长、品质、不同款替换、跳过与重抽规则；换下物品去向、已触发效果和层数如何处理。
4. 旧被动逐项归为成长属性还是饰品；初始池及各组合的独立价值和强度。
5. 局外主武器成长与全局成长的具体内容、按强度和流派的解锁路线，以及金币 / 素材经济。
6. 约 20 分钟一般局和 20～30 分钟完整装备成长体验下的具体波次、精英、宝箱、属性升级、难度和时间数值。
7. 局外已解锁影之武装与饰品的展示界面具体内容和交互；本轮不讨论。
