# 游戏整体循环：主武器、局内构筑与永久解锁

> 本文记录本轮讨论形成的**玩法方向与用户确认的规则**，用于统一主武器、全局成长、局内构筑和永久解锁的概念；染病构筑、相关饰品及收割成长型影之武装记录在 §4.1–§4.3，未确定的具体数值与边界单独标注。本文不描述工程现状、实现方案或排期。
>
> 旧文档 `design/weapon-system-design.md`、`design/in-run-build-design.md` 中与本文冲突的局内外归属、奖励来源和确认状态，以本文为准；旧文档中未被本轮讨论推翻的内容仍保留其原有状态。标为**待讨论**或**设计示例**的内容不是已确认需求。

## 1. 核心体验

玩家以选定的**主武器**为基础战斗，在一次无尽挑战中通过经验成长、影之武装和饰品不断建立、调整 Build；击败强敌、探索地图也会带来可永久保留的收获。回到局外后，玩家使用永久获得的资源成长、了解新内容，并可选择或更换主武器，开始下一局。

玩家希望经历的不是“填满四个装备槽就结束成长”，而是：

> **获得可用装备 → 使用并发现其特点 → 继续强化或比较新装备 → 更换过渡件 → 形成联动 → 随局势继续调整。**

普通关卡以**单条路线 10 分钟以内**为时长目标；无尽关卡以单局 **20～30 分钟**为体验目标，是长期运营游玩的内容，也是后期刷装备、素材与道具的核心内容。玩家在无尽关卡中应感受到相当于《影之刃零》通关过程中装备持续发现、更替和成长的压缩体验；20～30 分钟不是强制结束时间，也不是要求复制对方的物品数量或数值。普通关卡的成长与奖励节奏不预设照搬无尽关卡。

## 2. 整体循环

```text
局外：选择、升级或更换主武器；进行全局成长
  ↓
开始本局，使用主武器与已有战斗能力面对敌人
  ↓
战斗与探索
  ├─ 经验升级 → 本局成长属性
  ├─ 精英 / Boss 的装备宝箱 → 本局使用的影之武装 / 饰品
  ├─ Boss / 关卡固定宝箱 → 可获得新的主武器，获得时立即永久拥有
  ├─ 精英 / Boss / 地图探索宝箱 → 可永久解锁部分影之武装 / 饰品
  └─ 获取金币与局外升级道具 → 获得时立即到账
  ↓
用当前成长与装备继续战斗、强化并调整本局 Build
  ↓
本局结束
  ├─ 本局成长属性、本局影之武装 / 饰品及其局内强化结束
  └─ 已永久获得的主武器、已到账资源和已解锁内容保留
  ↓
回到局外：更换 / 升级主武器、进行全局成长、了解已解锁内容
  ↓
开始下一局
```

**地图探索宝箱可以给予影之武装或饰品的永久解锁；它与精英 / Boss 的本局装备宝箱不必是同一种奖励。** 本文不预设探索宝箱会直接发放本局装备，也不预设每次遭遇一定给某种长期奖励。

## 3. 四种对象及各自边界

### 3.1 主武器：局外战斗身份

- 主武器与影之武装是不同概念。以长枪为例，主武器承载玩家主要招式及战斗身份；影之武装是局内获得的主动战斗手段，不能把两者统称为同一类武器。
- 主武器有两条获取渠道：**局内击败 Boss**，以及**关卡内的固定宝箱**。两者都是**获得时立即永久拥有**；本局随后失败或结束，不收回已经获得的主武器。
- **固定宝箱**是一次性获取点：首次开启给予指定主武器；领取后该箱子改为发放金币、局外升级道具等普通奖励。领取状态必须持久化，重进关卡或无尽关循环都不重复发放。
- 固定宝箱给予主武器时播放**解锁演出**，明确告知获得了什么，以及需要回局外装备。
- 新获得的主武器需要**回到局外后**选择、更换装备，不在本局自由切换主武器；固定宝箱同样不例外。
- 主武器及其招式属于局外成长方向；连招不进入局内三选一。以主武器承担招式和绝技的方向，形成与本局随机构筑不同的长期战斗身份。
- 已获得的主武器重复获得时（Boss 掉落或固定宝箱），改为**金币、升级素材等其他奖励**；具体奖励种类、数量及分配方式待定。
- 以长枪说明概念，不预设本轮新增其他主武器的数量、名单或具体动作。

### 3.2 全局成长：跨局保留的主角成长

- 局外成长按两大类理解：**主武器成长**与**全局成长**。全局成长代表跨局保留的主角或通用能力成长。
- 玩家在局内获得金币及局外升级道具，**获得时立即到账**，用于局外的主武器升级或全局成长；之后死亡或结束本局，不收回已到账资源。
- 全局成长的具体节点、效果、强度、价格与路线，按玩法方向及强度继续讨论；不在本文预设。

### 3.3 本局成长属性：经验驱动，不可替换

- 成长属性来自**本局经验升级**，为本局角色能力提供积累；它们不占饰品槽。
- 获得的成长属性属于本局积累，不像饰品一样插拔或替换；本局结束后不跨局保留。
- 属性可以服务输出、生存、操作或影之武装，也可以被饰品转化、放大或作为联动条件。同一项属性在不同 Build 中可以有不同价值。
- 属性原则上可以持续叠加，但有软上限；软上限的抬升由局外成长解锁。哪些属性开放及各自上限、张数与等级如何区分，留待后续设计；“可叠加”不等于本局无任何限制。
- **经验升级三选一也有品质**：同一升级内容可以有普通、精良、传说等不同品质及相应效果数值，例如偶尔出现传说品质的最大生命值提升。品质的刷取概率**全局统一**，不随无尽内部圈数改变，不使用装备的抽取档或自走棋式池升级规则；具体概率和数值由用户填写，未在此预设。
- **同一次升级三选一不能出现同款内容**：例如普通与传说的生命上限提升不同时出现在同一组候选；不同品质不使同一内容变成不同种类。同一次去重不等于禁止之后的升级选择再次获得该属性；此前获得的本局属性不因之后选择、装备更换而被覆盖或移除。

### 3.4 影之武装与饰品：本局获得、成长和更替

- **影之武装**是本局获得与使用的主动战斗手段，可围绕它本身建立 Build，也可以辅助主武器战斗；通过本局获得不同品质 / 等级的装备进行比较和更替，**不存在抽到同款就自动升级或合成**。
- **饰品**是本局获得与装备的效果，可与操作、成长属性、影之武装或敌人状态联动。饰品可以插拔、替换；换掉饰品不移除玩家已获得的成长属性。
- 饰品不与单件影之武装强绑定：自身应有独立作用、可适用于多种玩法，只是和某些 Build 相性更好；持续伤害护符等可按一类通用伤害机制专精，不要求每件饰品都适合所有情况。
- 影之武装与饰品初始槽位各为 **2**；后续槽位成长属于局外全局成长的讨论范围。
- 装备品质分为**普通 / 精良 / 传说**三档，允许部分内容只有单一品质。**玩家看到的是品质和等级**；同品质不同等级、不同品质相同等级可以有各自效果数值。用户自行配置具体装备变体及其数值，不以显示等级推导池内档位。
- **装备池内抽取档位独立于玩家可见品质 / 等级**，可理解为自走棋棋子的“费用”，但不是货币价格。同一件装备的不同品质 / 等级变体由用户分别指定池内档位和权重；内部圈数决定各档抽取概率，越往后可通过配置提高高档机会。显示的“传说 Lv.1”与“普通 Lv.1”不会因都是 Lv.1 自动进入同一档。
- **没有共享库存或池内个数限制，也没有同款合成 / 自动升级**。一次装备三选一不出现同款装备的不同品质 / 等级；同一件影之武装或饰品不能同时装备两份。不同装备即使效果相近也不因此自动归为同款。
- **装备与替换在波末奖励选择中发生**：精英 / Boss 装备宝箱到达后排队，当前波敌人清空后与经验升级选择依队列处理。没有同款且有空槽 → 直接装备；已有同款 → 点击后直接在原槽换成新变体；没有同款且相应槽位已满 → 点击新装备后，下方出现该类别已装备名单，点击其中一件进行替换。新装备的品质、等级和效果是什么，替换后就是什么，不继承或自动增加旧等级。
- **装备三选一不保证同时出现主动和饰品**；主动与饰品在同一套装备抽取规则中选择，不按类型交替保底。池内没有可抽内容、档位或有效数据不满足配置时应明确报告配置问题；错误出现后的玩家态恢复行为尚待确定。
- 影之武装相关的暗源遵循**靠进攻获取、防御姿态不回复**的设计边界；具体获取量、消耗与标定方式待讨论。
- 属性通过经验成长；本局使用的影之武装与饰品通过**精英 / Boss 掉落的装备宝箱**获得。三选一候选可能同时包含两类，但玩家是否选择影之武装由玩家决定。
- 大约进行到 **3 分钟**时，应提供一次**能选到影之武装的机会**；玩家可以在同次选择中选择饰品，因此不保证此时一定持有影之武装。奖励在波末选择，体验时点以玩家真正能选择为准。**常规装备三选一不保底主动 / 饰品同时出现**；约 3 分钟的体验目标需靠奖励节奏与配置、实测共同评估，不能偷加每次保底。不开局免费赠送 Build。
- 一部分影之武装和饰品初始即已解锁；另一部分通过**击败精英、Boss 或探索地图宝箱**获得永久解锁。解锁后**立刻可以在本局后续装备宝箱中出现**，但不代表立刻自动装备、必定抽到或保证某个时间获得。
- 本局结束后，本局持有的影之武装 / 饰品及局内强化不保留；**永久解锁资格保留**，可在之后对局中出现。
- 局外提供一个界面，让玩家了解已解锁的影之武装和饰品；界面具体展示内容、布局和交互不在本轮讨论范围。
- 旧被动按实际玩法语义重新分流：一部分成为本局成长属性，另一部分成为可插拔、可替换的饰品；不因为旧名称或旧技术分类决定归属。逐项分类待讨论。
- 本轮新增内容的策划范围包括敌人 / Boss、天赋解锁、主武器及招式、影之武装和饰品；新增 Boss 或精英应与其掉落的影之武装、饰品或主武器相对应。具体敌人、奖励及发放方式待设计，仍需区分本局装备与永久解锁资格。

## 4. 三种 Build 方向

三种方向不是互斥职业或固定配方。玩家可以因局内获得的成长与装备形成其中一种，也可以交叉组合。

| 方向 | 主要乐趣 | 关系示例 |
|---|---|---|
| **操作型** | 扩展操作内容，根据攻击、蓄力、招架 / 防御等时机获得不同收益 | 以蓄力攻击或普通攻击为基础的构筑 |
| **影之武装 Build** | 围绕一件或多件影之武装决定战斗节奏和组合 | 影之武装 + 相关成长属性 + 影响其使用或效果的饰品 |
| **搭配型** | 通过本局属性积累，搭配饰品和影之武装获得数值或机制收益 | 生命成长 + “霸王血铠”类属性转化饰品 |

- 例如：前期为了生存积累生命，后来遇到生命转攻击的“霸王血铠”类饰品，玩家可能围绕已有生命成长调整本局方向。饰品换下后，生命成长仍在，饰品的转化效果不再生效。**这是机制形状示例，不是已确定数值或最终饰品表。**
- 也要保留**通用或过渡**影之武装与饰品：它们可以先解决眼前问题，玩家以后再决定是否替换；不是每个候选都必须依赖完整配方。
- Build 既可以围绕主武器操作，也可以围绕影之武装，不要求所有影之武装都只是基础攻击的附属。
- 操作型与搭配型可以重叠，重点分别在操作内容与属性 / 饰品 / 武装的组合。讨论内容制作时，影之武装型和搭配型可作为较快形成可玩内容的优先研究方向；操作型仍保留，不据此降低其长期地位。

### 4.1 饰品设计：染病及其他构筑的通用相性

> 以下四件为用户提出的饰品设计，彼此不与「染病」或其他单件影之武装强绑定。它们可以各自服务不同玩法；其中持续伤害护符按伤害机制专精，另外三件具有更广泛的搭配空间。效果等级、稀有度与品质如何对应，以及具体数值，均不在此预设。

| 饰品 | 已提出的效果与成长 | 染病中的价值 | 其他适用方向 |
|---|---|---|---|
| **持续伤害护符** | 所有持续伤害 +`{0}%`；**三级**，等级越高加成越高；**中等稀有度**。 | 直接提高疾病持续伤害，单层与多层均可受益。 | 灼烧及其他持续伤害；没有持续伤害来源时无该项收益。 |
| **冷却护符** | 影之武装冷却时间 -`{0}%`；**三级递增**；**普通稀有度**。 | 缩短染病冷却，提供更多释放、准备和施加疾病的机会；仍须实际使用武装并命中，资源消耗也需考虑。 | 所有有冷却的影之武装，包括伤害、控制与功能型。 |
| **嵌伤护符** | 敌人每次受到伤害，防御 -`{0}%`，最多 -`{1}%`；**三级**分别提高每次减防幅度和减防上限；稀有度待定。 | 疾病持续造成伤害，可作为多次受伤的来源，帮助叠加减防。 | 高频普通攻击、多段技能、灼烧等可连续造成伤害的玩法；减防可为其他攻击创造收益。 |
| **炼狱导管护符** | **方向已定、具体效果待讨论**：技能或攻击命中可为主动技能减冷却，附带百分比灼烧；**一级、传说级稀有度**，定位为非常强力的减冷却效果。 | 更频繁使用染病及其他武装，并可与持续伤害产生搭配；疾病跳伤是否触发减冷却尚未确定。 | 普通攻击、多段技能、范围伤害及其他影之武装玩法；具体受益范围取决于命中和减冷却规则。 |

**嵌伤的术语边界**：当前没有统一的敌人「防御值」概念，用户提出可按「减伤」方向理解。这里记录“反复受伤降低敌人防护”的设计意图，**尚未确定统一减伤公式**，也不预设零减伤敌人是否进入负减伤、盾牌减伤如何处理，或疾病 / 灼烧自身是否从减防中增伤。每次伤害如何计数、持续时间与叠层规则也待讨论。

**炼狱导管的参考边界**：方向参考《英雄联盟》海克斯「炼狱导管」，但本项目按用户提出的“技能或攻击命中为主动技能减 CD，并附带百分比灼烧”讨论，不把原作的具体触发、对象或数值直接当成本项目规则。参考来源：[海斗小助手 · 炼狱导管](http://lolhaidou.cn/augment/infernalconduit.html)，该第三方资料描述为灼烧造成伤害时缩短各基础技能冷却，与本项目提出的命中触发方向不完全相同。持续伤害跳伤是否算命中、百分比灼烧的计算基准 / 施加 / 叠加、受影响的冷却与触发频率等均待讨论；须注意多段、多目标和持续伤害可能产生强力循环。

**组合示例，不是固定配方**：持续伤害护符可同时加强疾病与灼烧；冷却护符可服务染病、海浪等不同武装；嵌伤护符可由多次伤害逐步削弱敌人；炼狱导管可与武装循环及持续伤害发生联动。初始两格饰品槽下，玩家需要比较并选择，而不是预设四件同时装备。

### 4.2 围绕「染病」的影之武装构筑

**定位与玩法**：以影之武装「染病」为核心，围绕疾病持续伤害、叠层和敌人死亡后的传播形成局内构筑。玩家使用染病后，通过下一次命中的戳击施加疾病；可以再次使用并命中同一目标以增加疾病层数。疾病在目标存活时持续造成伤害，目标在患病期间死亡时，可尝试向另一名符合条件的敌人传播。持续伤害、叠层与传播共同形成该武装处理单体及敌群的玩法；不要求单独靠疾病完成所有输出。

**与通用饰品的相性**：

- **持续伤害护符**直接提高疾病伤害；同样影响灼烧等持续伤害，不是染病专属。
- **冷却护符**缩短影之武装冷却，增加再次使用染病、通过戳击施加或积累疾病的机会；同样适用于其他带冷却的影之武装。
- **嵌伤护符**以敌人反复受到伤害来降低防护，疾病可提供持续的受伤次数；同样可由高频攻击、多段技能或灼烧等发挥作用。防御 / 减伤的具体公式，以及疾病自身能否因减防增伤，仍按 §4.1 待定边界处理。
- **炼狱导管护符**的设计方向是攻击或技能命中帮助主动技能减冷却，并附带百分比灼烧，可为染病及其他武装带来潜在相性；**疾病跳伤是否触发、灼烧具体规则等仍待讨论**，不能视为已确定的循环。

**构筑不是固定套装**：染病本身有持续伤害、叠层和传播作用；上述饰品也有各自的适用范围，可先后获得、替换并与其他武装搭配。初始饰品槽为两格，不预设四件必须同时装备。成长属性及具体数值尚未定，不预设染病依赖某一项属性或必然成型；无须强制配合灼烧才能发挥染病的基础效果。

**设计确认边界**：本节确认的是构筑方向与现有染病机制的玩法关系，不代表四件饰品已实装或平衡完成。染病的逐级数值、传播放大边界、稀有度及成长方式，以及 §4.1 所列各饰品的具体待定项，仍须分别设计和验证。

### 4.3 收割成长型影之武装（暂称「夺锋」）

**定位**：以单体收割换取本局长期成长的影之武装，具有类似“杀人剑”的投资与滚雪球体验。玩家需要观察最近目标的血量、把握释放时机并争取由这件武装完成击杀。前期获得通常有更多积累机会；允许后期获得时的投资价值较低，但仍需关注后期能否合理地完成第一次收割。

**核心效果**：

> 对最近的敌人造成 `{0}` 点伤害。若该次伤害击杀目标，则这件影之武装的伤害增加 `{1}`，同时玩家攻击力增加 `{2}`；两项成长均只持续至本局结束。

- **伤害与成长分开**：玩家通过升级等其他来源获得的攻击力，不直接提高这件武装的自身伤害；通过该武装击杀获得的玩家攻击力，也不反过来直接提高这件武装的自身伤害。它通过自身的击杀成长提高自身伤害；武装其他本局强化的具体规则仍待设计。
- **击杀归属**：需要该次武装伤害完成击杀；仅造成伤害但未击杀，不获得击杀成长。目标之后被疾病、灼烧或其他攻击击杀，不算该次武装击杀。
- **换下后保留与恢复**：换下时，已获得的玩家攻击力继续生效，已积累的该武装伤害成长保留在本局；本局之后重新获得并装备同款武装时，恢复此前积累的武装伤害成长。本局结束后两项成长均不跨局保留。这是该武装明确确定的规则，不预设其他装备的成长或效果也这样处理。
- **泛用搭配**：冷却护符可增加尝试收割的机会；嵌伤护符可能帮助扩大收割机会，但须以未来确定的减伤规则为准；染病等持续伤害既可能帮助压低目标生命，也可能先完成击杀，形成时机取舍。饰品不需要与该武装强绑定。

**待讨论 / 标定**：正式名称；基础伤害、每次击杀的双成长数值、冷却与暗源消耗；稀有度、品质及自身强化方式；是否需要成长上限；其他通用伤害加成和暴击是否影响武装伤害；最近目标选择的具体细节、击杀归属与特殊情况。需要分别考察普通关卡与无尽关卡中前期 / 后期取得的收割窗口，以及高频释放时的成长强度；不预设后期获得会补发先前击杀成长。

## 5. 关卡、奖励与成长节奏方向

- 关卡应让基础操作、影之武装和饰品联动都获得表现机会：敌人威胁、站位及战斗节奏共同构成 Build 的使用场景。
- 玩家希望在一般局中感受到多次有效的**获得、比较、强化与替换**，而不是填满初始槽位后只剩少数变化。单纯规定装备选择次数无法证明体验成立。
- **设计示例**：一个节点配置约五波敌人，末波掉一个宝箱，约三分钟完成一次装备更替机会。节点内是否还有其他精英掉箱、单个宝箱提供几次选择、Boss 宝箱如何计入，以及不同玩家实际经历的次数，均未定。
- 普通关卡单线在 **10 分钟以内**、无尽关卡以 **20～30 分钟**为体验目标；两者的装备机会、经验曲线、节点时长、敌人压力、品质分布与成长密度仍需分别讨论，不预设完全相同的节奏。
- 已积累的本局 Build 跨本局后续节点 / 圈继续保留，不因进入下一圈重置。本局结束后，临时构筑结束，永久获得物与已到账资源保留。
