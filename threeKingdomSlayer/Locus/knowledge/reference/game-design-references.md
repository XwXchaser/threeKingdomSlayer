# 同类 / 可借鉴游戏参考清单（2026-11-05）

> 用途：为敌人机制、局内成长、路线分支三类设计决策找外部参照。
> **取源方式**：全部为 2026-11-05 用 `web_fetch` 抓取 Wikipedia 的 `action=query&prop=extracts&explaintext=1`（纯文本 extract，无导航样板），下文"已核实"= 抓取到的原文事实；未标"已核实"的是分析推论。
> **边界**：本文只做机制参照，不引用任何未公开/逆向来源；游戏美术/音频资产不在讨论范围。

## 0. 结论先行

1. **没有"竖屏单手手势 + 三国割草"的直接同类可查**。最接近的品类（Survivor.io、Archero、Tap Titans 2、剑与远征等）公开资料极薄（Survivor.io / Archero 连 Wikipedia 条目都没有），**不足以作为设计依据**。
2. **可靠参照是"机制级作品"**——把我们缺的每块机制拆开，各找一本教科书：
   | 我们缺的 | 教科书 |
   |---|---|
   | 敌人机制库（每种一个对策 + 提示） | Left 4 Dead 2 |
   | 路线分支 + 三选一 + 局外解锁 | Slay the Spire / Hades |
   | 一局 30 分钟 + 叠层三选一 | Vampire Survivors |
   | 敌人意图预告 | Into the Breach |
   | 架势 → 破绽 → 处决 | Sekiro |
   | 割草 + 指挥官作为战场杠杆 | Dynasty Warriors |
   | 阵型与角色分工 / 阵营光环 | AFK Arena |
3. **项目内已有一份高价值参照**：`design/blades-architecture-benchmark.md`（《上古卷轴：刀锋》逆向测绘）——其中"**表现三段解耦：施法 / 弹道 / 命中**"正好可以用在 1013 的"施法动作"上；其**玩法层姊妹篇** `design/blades-gameplay-benchmark.md` 另含敌人变体模型、重攻击/破防的成长线、教学目标卡等可直接采纳项。
4. **三条可直接抄的改动**（详见 §2.1 / §3.3 / §4.3）：特殊敌人的**专属音效提示**、**时间闸门**、**处决（破防即必杀）**。

## 1. Left 4 Dead 2 —— 敌人机制的教科书（已核实）

### 1.1 八种特殊感染者，每个只有一种对策

| 特殊感染者 | 机制（已核实） | 对我们的映射 |
|---|---|---|
| **Boomer** | 吐胆汁把普通感染者吸引过来并致盲；死亡时爆开喷胆 | 我们缺的一类：**改变战场构成**（1013 督战是"增益型"，Boomer 是"召唤型"） |
| **Hunter** | 敏捷扑击，远处就能把人打残，需要队友推开或击杀 | ≈ 我们的 109 骑兵（打断/推开） |
| **Smoker** | 长舌远距离把人拽住持续窒息；死后放出烟幕遮视野 | 我们缺的一类：**控制型**（拉拽） |
| **Tank** | 力量极大，能把人击飞、扔汽车；单独打不过，要队伍配合 | ≈ 我们的 BOSS 104（霸体 + 处决） |
| **Witch** | 被伤害/声音/光照/靠近激怒后，**只攻击激怒她的人**，一击可秒 | ≈ 我们的 1021 盾卫（受击方向判定），但它有"仇恨转移"语义 |
| **Charger** | 巨大右臂，冲撞抓走一人，路径上把人撞飞并眩晕 | ≈ 我们的 109 骑兵（骑乘冲撞） |
| **Spitter** | 吐出酸球造成范围伤害；**死亡后地上残留酸液，留得越久伤害越高** | ≈ 我们的 105/106 远程（要优先处理） |
| **Jockey** | 跳到玩家背上操控玩家把人撞进敌群 | 我们缺的一类：**反制玩家操作** |

**共同点（这就是我们的反制表该有的样子）**：每种都只有**一个**明确的正确对策；其余打法要么无效要么更糟。

### 1.2 三条可直接抄的规则

1. **专属提示**：原文 —— "The presence of such Infected nearby is hinted at by sound effects or musical cues unique to each type."
   → **每种特殊敌人有专属音效/音乐提示**。我们目前只有描边 + 飘字 + 状态条（纯视觉）；加一条专属音效（1013 督战可以是鼓声/号角）比再加 UI 更省事、更直观。
2. **杂兵变体**：Uncommon Infected 按战役分化（防弹、防火、会吸引小怪）→ 与 Blades benchmark 采纳的"敌人原型 + 变体"是同一思路。
3. **AI Director 2.0**：按玩家表现在战局中动态生成敌人、投放补给、改变场景；并且**奖励玩家走更危险的路线**。
   → 我们现在是静态波次配置（难度表已定"一波 1 个门"）。Director 的思路是下一层价值：**门不该是固定的表，而该是对玩家表现的应答**。

## 2. Slay the Spire —— 路线分支 + 三选一 + 局外解锁（已核实）

| 已核实要点 | 对我们的映射 |
|---|---|
| 每层是一张**分支地图**，节点类型：普通战斗 / **精英（更高奖励）** / 篝火（回血或升级）/ 商店 / 宝箱 / 随机事件；每层末尾 Boss | 我们的卷轴路线就是这张图；**精英节点 = 我们的"有难度分支"** |
| 战斗结束给**三选一卡**（随机三张选一，可放弃） | 我们的经验三选一 |
| **遗物 = 整局永久生效**的被动（最大生命、能量、格挡等） | 我们的"永久、可叠加"加攻/减攻就是这个语义（1013 的 +10% 层数） |
| 元进度：每局贡献解锁角色/遗物/卡；**20 层 Ascension，每层叠加一条负面修正**（更低血、敌人更强） | 我们的局外天赋树 + 难度递增 |
| **敌人预告下一手**（打多少 / 格挡 / 给自己上 buff / 给玩家上 debuff） | 我们的 `EnemyAttackTelegraph` 预警；Slay the Spire 的预告是"信息完全公开" |

**可直接抄**：分支节点的**风险/收益要在选择面板上写清数字**（精英节点明说"奖励更好"）。我们的 `FakeRouteChoiceConfig` 现在只有 displayName / 按钮布局，没有任何风险收益信息。

## 3. Vampire Survivors —— "30 分钟一局 + 叠层三选一"（已核实）

| 已核实要点 | 对我们的映射 |
|---|---|
| 每局有**软性时限 15 / 20 / 30 分钟**；到点清场并刷最终敌人；**达成时限即算通关**并给奖励金币 | 我们文档里的"30 分钟、约 42 次升级"目前**只是目标，没有运行时约束** |
| 经验宝石升级 → **每次升级三选一**（武器或被动）；满 6 武器 + 6 被动后，升级只给金币或回血 | 我们的"满槽铜钱补偿"是同一思路 |
| 武器/被动**满级 + 特定条件 + 宝箱 → 进化形态** | 我们的技能有 5 级但**没有进化形态**；而我们的节点奖励里已经有"秘籍"这个载体 |
| 局外金币解锁角色与**永久强化** | 我们的铜钱 → 天赋树 |
| 源头：作者明说灵感来自 **2019 年手游 Magic Survival**（自动攻击） | 证明"竖屏 + 自动战斗 + 叠层成长"是被验证过的形态 |

**可直接抄**：加一个**时间闸门**——到点即结束本局并结算奖励（金币/经验），把"30 分钟"从文档目标变成玩家能感知的规则。

## 4. Into the Breach —— 敌人意图预告（已核实）

- 每回合展示敌人的**攻击方向**、可移动步数、剩余血量；玩家据此推、挡、拦截。原文："The player is shown the direction of the Vek unit's intended attack and information on the number of moves … and its remaining health."
- 关卡是分支结构：打完一个岛后选下一个岛，**更危险的条件给更高回报**。
- 核心不是歼灭，而是**位置控制与牺牲换优势**；8×8 网格。

**对我们的映射**：
- 我们的"5 列阵型"就是它的网格；"一波 1 个门"就是它的预告；**"危险换收益"就是支柱五分支差异该有的公式**。
- 我们的 1013 若按它的语言，应该在**出场前就给预告**（号令前摇 0.8s + 举旗预警 = 已经是这个思路，方向对）。

## 5. Sekiro —— 架势 → 破绽 → 处决（已核实）

- 原文："combat … revolves around using a katana to attack their **posture and balance** instead of [health points], as well as **deflecting** incoming enemy attacks, eventually leading to an opening that allows for a **single killing blow**."
- 敌人的**危攻（perilous attack）**有红色提示，必须格挡或闪避。

**对我们的映射**：
- 我们的"架势 → 破势 → 眩晕"与"招架窗口"就是这套（`EnemyPoise` / `Enemy.Combat`）。
- **我们缺的一环：处决**。我们的 1021 破盾后进入"胆怯"形态，只是受伤 ×1.5、不再攻击，**没有一击必杀**。Sekiro 的"破防 → 一击处决"是把"优先目标"变成**明确收益**的最有效手段 —— 这可能是下一个高价值机制方向。

---

## 6. Dynasty Warriors —— 割草母体与"指挥官"作为战场杠杆（已核实）

- 系列 2400 万+ 销量；Musou 模式 = 大批杂兵围攻 + 连段 + 处决 + 武器成长。
- **败北条件之一是"指挥官阵亡"**（defeat of the commander-in-chief）。
- Xtremo/Empires 扩展加入战略/战术要素与挑战模式。

**对我们的映射**：我们的 1013 督战是**敌方侧的指挥官**，是 Musou 结构的镜像——他们的指挥官活着你就输，我们的指挥官活着敌人变强、死了敌人变弱。两者都把"指挥官"当成战场的状态杠杆，而不是又一个血袋。可作为 1013 的主题与美术依据（帅旗手 / 鼓手）。

## 7. AFK Arena —— 阵型与角色分工（已核实）

- 5 人队伍按**预设站位**自动战斗，玩家手动触发技能；**阵营光环**、**某些英雄适合特定站位**（"Strategical positioning … is important, as there are combat buffs depending on hero faction, and certain heroes excel in specific positions"）。
- 角色有 Class / Type / Role 三层标签与各自优缺点。

**对我们的映射**：我们的 5 列阵型目前只有"选哪列打"；AFK 的"站位本身有增益"提示了一个后续方向——**列/站位可以成为增益载体**（正好和 1013 的"全场加攻"是同一个问题的两种解法）。

---

## 8. Hades —— 祝福三选一 + 房间奖励 + 自选难度（已核实）

- 每间房给奖励（变强或回血）；**Boons 每次三选一**，按神祇主题化（宙斯=雷伤、波塞冬=击退波）→ 我们的火系 / 位移系主题化技能同源。
- 房间顺序与敌人随机化；每区域末尾 Boss。
- 局外货币买永久升级；**Pact of Punishment** 让玩家自选额外难度（提高敌人攻击/血量/数量、给 Boss 加阶段）。
- **God Mode**：失败后角色永久变强，给弱势玩家兜底。

**对我们的映射**：
- 我们的"天赋树"= God Mode / 永久升级；我们的"铜钱经济"= 局外货币。
- 我们的**局外难度层**还没有；Pact of Punishment 提供了一种"玩家自选加难 + 给更好奖励"的成熟框架。

---

## 9. Dying Light —— 用时间轴调压（已核实）

- 昼夜循环：白天感染者迟钝可绕开，**夜里极凶**；安全屋可调整时间直接跳到白天。
- 敌人分层：Biters（慢）/ **Bombers（靠近自爆）** / Virals（会跑）/ Volatiles（只在夜里出现）。

**对我们的映射**：我们的"教学顺序 vs 实际配置不符"（`design/gameplay-pillars.md` §4.5）可以用"关内时段"解决——同一节点内前段像白天、后段像夜里，压力曲线由编排而不是由敌人数量堆出来。Bombers ≈ 我们可做的"自爆型/冲撞型"敌人。

## 10. 由此得到的敌人机制候选清单（结构来自 L4D2）

按"一种威胁 + 一个唯一对策"补齐我们缺的类别（L4D2 已证明这八类各自成立）：

| 候选 | 对应 L4D2 | 我们的对策动词 | 成本 |
|---|---|---|---|
| **督战/鼓手**（在做，1013） | Boomer（改变战场） | 击杀 / 打断号令 | 已设计完成 |
| **投掷/压制型** | Spitter（范围伤害 + 残留） | 定点清除 / 用盾卫挡 | 中 |
| **拉拽/定身型** | Smoker | 打断 / 立刻处决 | 中 |
| **自爆型** | Bomber | 远程点杀 / 拉开距离 | 中 |
| **召唤型** | Boomer 的吸引 | 优先点杀召唤者 | 中 |
| **嘲讽/仇恨转移型** | Witch | 换列 / 不打它 | 中高（要改仇恨逻辑） |

## 12. 三条建议按性价比排序的改动（供决策，不自动实施）

| # | 改动 | 来源 | 成本 |
|---|---|---|---|
| 1 | **特殊敌人专属音效提示**（1013 先做鼓声/号角） | L4D2 §1.2 | 极低（音效资产 + 一次播放） |
| 2 | **时间闸门**（到点结算，把 30 分钟变成规则） | Vampire Survivors | 中（流程 + 结算 UI） |
| 3 | **处决机制**（破防/破盾后一击必杀） | Sekiro | 中高（新结算分支 + 演出） |

中长期：**AI Director 式动态编排**（按玩家表现决定这一波出什么门）——L4D2 的 Director 是这类问题的成熟答案，比继续扩静态波次表更省力。
