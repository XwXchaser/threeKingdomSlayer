### 6.4 本轮踩到的坑（新增）

1. **prefab 与场景实例的修改顺序**：先改 prefab 再改场景实例。反过来做，**prefab 保存会把场景实例的改动冲掉**（本轮实测：血条宽度与棱形尺寸被回滚，只有场景专属的暂停键保住了）。
2. **prefab 原生子节点在实例里不重建网格**：`Background_bottom` / `Background_frame` 的 RectTransform 是满条，但运行时不绘制（只在中缝露出细条）。→ 改成**新建节点**（与新建的 `HealthFillLeft/Right` 同一套路）后正常。
3. **画布宽度随设备宽高比变化**：设计空间是 960×1920（对应 1080×2160 真机）。Game 视图若是 1080×1920，画布变成 960 宽 → 同样的 sizeDelta 占屏比例就变了。→ **抓图前把 Game 视图设成 1080×2160**。
4. **血量是事件驱动**：直接改 `PlayerState.currentHealth` 不会刷新 HUD，要同时广播 `OnHealthChanged`；想稳定取图用 `Time.timeScale = 0` 冻结。
5. 战斗会很快结束并回到落地页 → 抓图要在进战斗后立刻拍。

## 二之二、刀锋实机尺寸实测 vs 我们现状（2026-10-30）

> **新规则（用户 2026-10-30）**：**排布位置以我们游戏为主，UI 尺寸以刀锋为主**。
> 参照物：
> - 刀锋实机截图 `C:/Users/steam/Downloads/screenshot-20261030-154524.png`（**308×615**）
> - 我们自己的排布草图 `C:/Users/steam/Downloads/微信图片_20261029021456_39_223.png`（**200×400**）
>
> 换算：刀锋 308×615 → 我们 1080×1920（×3.506）；再除 1.125 得 canvas（960×1920）口径。

| 元素 | 刀锋实测（原图 px） | 刀锋当量（我们 device px / canvas） | 我们现在（canvas） | 我们现在（占屏） | 差异 |
|---|---|---|---|---|---|
| 左上「罗盘」 | 16×25 @ x17..33,y18..43 | **56×78 / 50×69** | 暂停块 197×178 | 20.5% 宽 / 9.3% 高 | **大 3.9×宽、2.6×高** |
| 左下大招菱形 | 29×50（含光晕）@ x13..41,y500..549 | 102×156 / 90×139 | 黄色棱形 72×139 | 7.5% / 7.2% | 宽几乎一致（我们窄 20%）、高一致 |
| 底通栏生命条（红芯） | 235×5 @ x38..272,y574..578 | 851×16 / 756×14 | 红血条 849×34 | 88.4% 宽 / 1.77% 高 | **宽 +12%、厚 2.4×** |
| 上行蓝/绿条（魔/耐力） | 各 113×5 / 60×5 @ y555..559 | 高 16 / 14 canvas | 我们没有这一行 | — | 刀锋特有 |
| 顶中敌人条 | 144×5 红段（白框 ~144×10） | 505×16 / 449×14 | `BossBars` 整宽 960×200 容器 | 100% / 10.4% | 刀锋的条是**居中且窄** |

### 两个关键总量

| | 刀锋 | 我们 |
|---|---|---|
| HUD 元件占屏面积比 | ≈ **2.4%** | ≈ **7.8%**（暂停 3.5 万 + 头像 1.7 万 + 菱形 4.0 万 + 血条 2.9 万 + 铜钱 2.0 万 / 184 万 canvas²） |
| 生命条可见红芯占屏高 | 0.81% | 1.77% |

→ **我们的 HUD 视觉重量是参考游戏的 ~3 倍**，画面显得挤、闷的直接原因就是它。

### 由此推出的三条尺寸结论（待用户拍板）

1. **暂停键**：刀锋那个 56×78 是**罗盘**（不是按钮，屏宽 5.2%）。直接照抄 → 暂停键只有 ~50×69 canvas，
   真机 ~56×78 px，**小于 44dp 的可点下限**。→ 建议取它的**形状语言**（菱形/小块），
   尺寸取 **≈88×88 canvas（≈99 device px）**，并把「鸽子+毛笔字」换成**单符号**。
2. **通栏红血条**：按刀锋当量 = **canvas 756×14**（含框 ≈ 34）。
   ⚠️ **25 canvas 高的条放不下现在的 22pt 数字**（刀锋的条上**根本没有数字**）。
   → 参考图必须先定：① 去掉数字（跟刀锋一致）② 数字移到条上方 ③ 条不缩厚、只缩宽。
3. **黄色棱形**：与刀锋大招菱形**几乎同尺寸**（我们 72×139 vs 它 62×125）→ 只微缩 ~10%，不必大改。
4. **头像 / 等级球 / 铜钱**：刀锋**没有对应物** → 尺寸只能我们定。
   建议按**整体缩放系数 ≈0.85** 处理（跟棱形/血条同档），而不是单独拍脑袋。
