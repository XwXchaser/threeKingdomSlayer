## 2. 会话已确立的结论（与本次中断无关，仍然有效）

### 2.1 落地页定位

**玩家已经站在关卡入口，场景占据主体，少量 UI 围绕「开始关卡」组织。** 整图同时解决构图、功能层级与材质语言，之后的单件素材才有统一依据。

关键构图校正（相对旧文档）：参考图的关卡入口在**右下角**、位于「家园」卡上方，主操作也在屏幕下半部；并非「右侧中部大关卡卡 + 中间开始按钮」。本项目继承的是这套构图关系，内容限定为六项。

### 2.2 六项 UI 与布局分区

| 元素 | 布局 | 视觉职责 |
| --- | --- | --- |
| 总铜钱 | 安全区右上 | 紧凑图标 + 数值，清楚但安静 |
| 开始关卡 | 水平居中，屏高约 68%–75% | 全界面最明确、最醒目的操作（唯一大面积高饱和红） |
| 任务条 | 左下，主按钮下方、四宫格上方 | 一条任务摘要 + 进度 + 奖励 |
| 关卡入口 | 右下，天赋卡上方 | 景色剪影 + 关卡名 |
| 天赋入口 | 安全区右下 | 比小按钮大，亮度对比低于开始按钮 |
| 四宫格 | 安全区左下 | 小尺寸置灰占位，无功能语义 |

继承参考图的三个特点：场景有贯通的视线；主操作拥有独特造型与尺度；底部采用不对称组合。

### 2.3 画风基线（`design/art-style-guide.md` 的延伸）

暖土战场为底，墨黑承托信息，冷铁与旧铜表现重量，朱红集中强调开始操作。

- **场景底图**：中央保留当前关卡空道路，两侧木栅、军旗、土坡或建筑建立三国战场身份；远景降对比，近景粗粝块面与像素色簇；天空与受光地面保持明亮，让墨色 UI 自然浮出；就绪态无武将与敌人。
- **开始按钮**：宽而有力的朱红笔刷形，边缘少量方向性破笔，局部暗铁/旧铜收轮廓；文字厚重、象牙白。
- **关卡入口**：从当前关卡裁下的景色剪影（道路、地形、标志建筑）形成不规则外轮廓，底部接短墨色名字带。
- **任务条**：横向墨色笔刷承托，正文区低纹理，普通状态克制，完成态再加局部暖金。
- **天赋卡**：深墨底 + 少量铜铁包边 + 清楚的分叉节点图案，装饰集中在边缘。
- **字体**：像素感放在图形轮廓、材质块面和高光，文字保持干净；全套共享边缘厚度、受光方向、金属色与阴影强度。

### 2.4 素材级结论

- **艺术字「开始关卡」**（`hub_start_title_zh_v2.png`，已导入场景）：固定主操作标题，保留专门设计的笔势，不交给 TMP；象牙白字面 + 深褐描边 + 短暗影。其余金额、任务、进度、关卡名仍由 TMP 显示。
- **长坂桥关卡图**（`hub_stage_changban_bridge_v2.png`，已导入场景）：统一名称「长坂桥」；主体为厚重破旧木板桥横跨一小段河流，桥身约占整体宽 2/3，稍俯视三分之四视角，两端接少量暖土岸地，辅以克制芦苇与残红军旗；剪影由景物形成，外围真实透明；缩小到 200–300 px 宽仍要读成「木桥横跨河流」。
- **其余九件仍缺**：开始底板（无字）、天赋横向卡底 + 独立节点图案、四宫格置灰键、任务底板、卷轴徽章、进度槽、铜钱墨条、关卡名字带。四组方案与提示词见 `plan/hub-ui-remaining-assets-generation-handoff-20261024.md`。

## 4. V4 断点（核心，未落盘的部分）

### 4.1 用户最后一次诉求（原文，转录 [355]）

> v1版比较贴合游戏场景画风但是太土了；v3版看着简洁合适但是底框色全是灰色的与当前游戏画风还是有点不搭（我知道可能是因为你参考三国无双ui，但他们的UI是在背景图而不是实机画面上的）；可能你需要找三国无双起源这种UI在实际画面上的UI设计配色参考？分析我所描述的实际问题所在。

转录 [375]：**「请根据当前新理解发起新参考图的生成」** —— 这是 V4 的生成授权。

### 4.2 问题诊断（转录 [374] 的结论）

- **V1 与场景共享材质和色彩，但装饰过量；V3 简化了造型，却把「干净」处理成「所有组件套灰壳」，失去界面色彩活力。** 描边改善可读性，没有解决主矛盾。
- **灰色从承托变成整套 UI 的主体色**：资源条、任务条、名字带、四个底部按钮都占大面积灰黑；第一印象变成「灰色东西很多」。
- **实机背景比参考菜单更亮更活**：我们的天空高明度蓝白、地面明亮黄赭，红旗木箱军械有明确受光；V3 灰底是中间明度、低饱和、近似厚度的「组件壳」。**有对比不等于协调。**
- **层级被处理得过于相似**：资源/任务、导航键、商城礼包活动、天赋大入口、开始按钮，职责不同却共享近似灰底与白字。
- **材质统一 ≠ 界面美感**：这是两条独立要求；继续加纹理/暖色高光/描边只会得到「更精细的灰色按钮」。
- **《起源》实战 HUD 的正确参照点**：灰黑只是基础层，青绿/黄橙/红蓝承担大量状态识别；底板不包住所有东西，需要承托的文字才用局部深色背景且边缘常淡出；鲜明颜色集中在小面积信息上。要学的是**「深色承托退后、有效信息向前」**的关系。

### 4.3 V4 设计方向

1. **保留 V3 的布局、简洁结构与轮廓**；**恢复 V1 中「图标本身有颜色、有材料」的特点**；同时**压低底框存在感**。
2. **灰黑承托缩到文字附近，减少整块面板**；资源和任务使用更薄、更局部的深色承托；商城、礼包、活动通过布料、纸面或明确形象形成颜色焦点；四个小键同系列但减少整块灰色铁牌面积。金属只服务结构，局部暖色可以保留。
3. **逐件改造（V4 方案原文要点）**
   - 商城：米白布 + 红色封签；不复制旧木箱/红棚。
   - 首充礼包：朱红结绳 + 冷灰礼匣。
   - 活动：分层剪影（战士剪影），不要具体人物。
   - 天赋：短红战旗 + 少量银白兵刃；去掉大方底；轮廓随图形收束。
   - 底部四键：保留无字占位，不增加功能含义；备选形制为「深炭细描边 + 象牙白符号 + 深红棕小牌」，符号可有米白/青玉/宝石红/暗绿等不同色相以增加辨识度。
   - 开始按钮：朱红斩痕 + 艺术字，补深红块面与短暗轮廓。
   - 资源与任务条：中性深墨灰承托，边缘适量厚度与破笔。
4. **生成范围收窄**：仍做 1 张 1024×2048 完整候选；位置、功能数量、文字与图标形象基本沿用 V3；不新增装饰、入口、人物或场景内容；强调「按场景绘法重绘 UI」，避免模型只做统一锐化或全图像素滤镜；不强求 UI 与场景相同像素密度。
5. **验收三问**：商城/礼包/活动/天赋是否终于像同一套素材；底部按钮是否有厚度而没有重新变成暗金古董框；UI 与中央木箱、红旗并排时边缘与光影是否协调。
