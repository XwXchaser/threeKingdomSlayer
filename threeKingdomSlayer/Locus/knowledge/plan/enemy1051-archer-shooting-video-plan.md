## 0. 三条结论

1. **射箭动作的规格来源 = 工程内旧 105 弓手**（`Assets/Sprites/Enemy/Enemy5/enemy5_attack1/2/3.png` + `Assets/Animations/Enemy_105_Attack.anim`）：**搭箭 1.5s → 满弓 1.23s → 放箭 1 帧**。新 1051 的 attack 动画按这三拍做。
2. **上一支 1051 射箭 take（`enemy1051_attack_v1_10s.mp4`，2026-10-19）不能直接用**：它**没有放箭拍**（拉满后直接回 idle），满弓静止了 5.5 秒，弓放横后几乎顶到画幅左缘；而且是旧形象（蒙面 + 发光眼）。
3. **推荐路线 = 替换视频工作流**（`reference_image` = 新身份图 + `reference_video` = 一支**含放箭拍**的弓手动作母片）。理由是项目既有实测：动作幅度只能靠母片继承，靠文字形容词必失控（1012 hitHeavy v3 放大 4.5 倍、1013 cast v2 放大 30 倍）。若不另做母片，退回首尾帧路线，则**必须先出「放箭末帧图」并像数量测通过**才烧视频。

## 2. 动作要点（逐帧读出来的三拍）

| 拍 | 旧帧 | 画面内容 | 工程时长 | 要点 |
|---|---|---|---|---|
| ① 搭箭 / 举弓 | `enemy5_attack1` | 弓**竖直**举在身前偏右，右手把箭搭上弦，箭头朝下指在胸前；双腿分开、屈膝 | **0 → 1.5s**（= `drawDuration`） | 慢、稳、无位移；箭在弓上但**还没拉开** |
| ② 满弓 / 瞄准 | `enemy5_attack2` | 弓**放平**（近水平），左臂前伸、右手把弦拉至脸侧，箭头指向前方；咬紧牙关、眉压低 | **1.5 → 2.733s**（≈1.23s） | 动作峰值前的**定住**；脸是唯一可读发力通道 |
| ③ 放箭 | `enemy5_attack3` | 右手**甩向前方**（手指张开＝"抚平弓弦"的收势），弓回到竖直；手边一圈金色火花；**张嘴怒吼** | **2.733 → 2.767s（1 帧）** | 只有 1 帧；是"命中判定/投射物生成"的瞬间 |

**另有两张**：`enemy5_hitted`（受击）、`enemy5_launch`（被击飞，带受击特效）。

> **结论**：旧实现的射箭是「**举弓 1.5s → 满弓 1.2s → 放箭 1 帧**」的三拍。新的 1051 视频要能在这三拍上**选帧**（参照 1012 的 attack 选帧法），而不是给一整段自由发挥。

## 3. 新 1051 与旧 105 的差异（决定哪些能照搬）

| 项 | 旧 105（Enemy5） | 新 1051（组图裁切） | 影响 |

| 放箭时的嘴 | **张嘴怒吼（露齿）** | **下半脸被布巾遮住，无法张嘴** | ❌ **放箭拍不能靠嘴表达发力** → 改由眉眼/眼神承担；且这正好是「奸邪」方向 |
| 脸 | 眉压低、露齿凶相 | 眉压低的**怒视**（不是定稿的「奸邪」斜睨） | ⚠ 见 §5.4 与 `plan/enemy1051-bandit-archer-redesign-handoff.md` §9.5 |

### 5.2 路线 A（推荐）：替换视频

- 输入：`reference_image` = 5.1 的**身份图**；`reference_video` = **一支含放箭拍的弓手动作母片**。
- **母片从哪来**：工程与磁盘上**没有**现成的含放箭拍的弓手母片（旧的 `enemy1051_attack_v1_10s.mp4` 缺放箭拍且是旧形象）。可选：
  - A1 用 `enemy5_attack1/2/3.png` 三帧**合成一支 3s 母片**（把旧 105 的三帧做成 30fps 的关键帧片）→ 作为 reference_video，让模型按这三拍节奏生成新形象的动作；
  - A2 先用 1012/1013 已验证的**首尾帧路线**做一支「搭箭→放箭」的动作基准片，再用它当母片做替换（两段视频，成本高一倍）；
  - A3 直接拿 `enemy1051_attack_v1_10s.mp4` 当母片（**有放箭拍缺失的风险，不推荐**）。
- 提示词只写**形象/表情层**（身份、装备锁定、表情与节拍对齐），**不写动作幅度**。

### 5.3 路线 B（备选）：首尾帧 + 末帧图

- `first_frame` = idle 锚图（已备），`last_frame` = **「放箭」姿态图**（需新出一张：单图编辑，输入 = 身份图；写**位置类**措辞：弓回到竖直、右手甩向前方、脸是发力的峰值、身体只略前倾）。
- **出片前必须先量末帧图**（右手 y/弓的角度/身体高比/是否出框），不合格不烧视频。
- ⚠ 注意 `plan/enemy-commander-buff-unit-plan.md` §2.15.10.4 第 4 条的教训：**不要为了凑一张末帧而把首尾帧都设成同一张 idle 图**；这里首=idle、末=放箭，两张图语义不同，是合法用法。

### 5.4 表情：这一支和 idle 不一样

- idle 用**眉眼四拍弧线**（冷 → 斜视 → 眯缝峰值 → 收敛），因为半蒙面没有嘴可用。
- 射箭片的**峰值拍 = 放箭**，旧 105 那里是"张嘴怒吼"，新 1051 **嘴被布巾遮住** → 峰值必须改写成**眉眼发力**（眉压低、眼眯紧、视线锁定前方），并明确写"布巾不动、布下不画嘴形"。
- **起手表情必须等于游戏内 idle 的实际长相**（1012 铁律）。而当前 idle 形象的脸是**怒视**（§3），不是定稿的「奸邪」 → **出片前需要先把脸定下来**，否则 idle↔attack 两头都会跳变。
  - 选项：① 先做一次眉眼精修（单图编辑，仿 1051 的 T3/T5 流程）修出「左挑右压、眼神算计」，再出 idle + attack；② 接受怒视作为 1051 的最终脸（放弃「奸邪」要求）。

### 5.5 验收闸门（量化，提交后逐项量）

| 闸门 | 阈值 |
|---|---|
| 脚底（地线） | 全帧恒定，漂移 ≤2 px |
| 画幅 | 1:1 / 720p；**出框 0 帧**（弓尖、箭羽、头顶都不贴边） |
| 人物本体高 | 与锚图一致，变化 ≤3%（防深蹲/拉伸，见案例 1） |
| 三拍存在 | 必须能切出「搭箭 / 满弓 / 放箭」三段（每段 ≥3 帧，放箭段 ≥1 帧） |
| 放箭收势 | 存在"右手甩向前方"的收势帧（上一支 take 缺的就是这个） |
| 循环 | 末帧 ≈ 首帧（IoU ≥0.99，仅 idle 要求） |

### 10.4 走路的教训（可复用）

1. **别用两帧母片**：母片只有两个姿势，模型会直接跳过去，中间不补。
2. **躯干要锁正**：模型容易把走路做成“边走边转身”，看着就是斜着走；要写明“肩膀/胸/胯始终正对镜头，只有腿和手臂动”。
3. **别写“朝镜头走来”**：那会让它真的走过来（脚底线漂 103px、身体变大）。要写“原地踏步、不靠近镜头、尺寸逐帧不变”。
4. **走路必须固定 k + 统一偏移**：逐帧对位会把水平摆动抹掉。
5. **选帧要按**步态相位**而不是时间等距**：等距抽会全落在同一相位（本次踩到：六帧五个都在“并腿”相位）。先出**相位尺**（逐帧腿部带）目视定位 contact/pass/swing，再按经典六相抽，并让**首尾同相位**保证接缝顺。
6. **源片本身可能有闪回**：生成片里可能混入“步态倒退/重放”的帧（本例 t≈1.0s），选帧前必须**先整片分段看相位尺**，避开闪回段；否则抽出来的帧会把闪回带进动画。
