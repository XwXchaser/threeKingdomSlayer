> **执行纪律**：`memory/art-production-workflow-entry.md`（铁律 1/2/3/4/6）、`skill/gpt-image-generation.md`。


## 1. 画风口径（★ 最重要的一条澄清）

**产物是「3D 建模参考图」，不是游戏精灵。** 所以：

| 要落 | 不落 |
|---|---|
| 形体语言：厚重、剪影优先、部件分区清楚 | 像素色簇 / 阶梯轮廓（那是 2D 精灵的语言） |
| 材质分区：金属 / 布 / 木 / 皮革各自分明 | 「高清像素化」的渲染方式 |
| 配色关系：冷暖对比、主色/辅色/强调色 | 把所有素材压成同一色阶 |

**配色以已部署的 3D 长枪为准**（实测 `Assets/Models/Weapons/FantasySpear/Textures/FantasySpear_BaseColor.png`）：

| 角色 | 色 | 用途 |
|---|---|---|
| 主 | **鎏金 / 黄铜** | 金属配件、箍件、装饰 |
| 主 | **朱红** | 缠握布、缨带、流苏（**强识别色**） |
| 主 | **冷银灰 / 白** | 刃面、锋口高光 |
| 辅 | **暖棕 / 橙褐** | 木杆、皮革 |
| 点缀 | 少量翠绿 | 极小面积 |

> ⚠ **修正需求文档的一处偏差**：`design/weapon-3d-art-spec-axe-and-chain.md` §4/§5 写的是「写实偏硬的金属 + **深色木** + **局部旧金**」。实测已部署长枪是**金比"局部旧金"重得多、朱红是主识别色、木杆是暖棕橙不是深色**。⇒ 以本节为准。

**不采用**的路线（会毁掉 3D 建模价值）：像素画风、卡通描边、照片写实、鲜亮高饱和。

## 2. PBZ 造型口径（知识库能确证的 + 必须靠实拍图补的）

### 2.1 能确证的（`design/pbz-reference-analysis-20261109.md` §1/§2）

| 武器 | 确证事实 | 对我们造型的约束 |
|---|---|---|
| **巨凶斧** | 破坏型影之武装，评级 **A**；伤害 309 / 破防能力 208；卡牌标注「**高破盾能力**」；三形态 = **强行蓄力 / 厚甲护身 / 疾行斧**；铸魂后蓄力速度 +30%；击败驿站 BOSS 获得，前期最实用的破盾利器 | ⇒ **宽厚、单刃、破坏型**的重斧；**取「强行蓄力」形态的视觉**（举起时的体量与蓄势感），因为我们的技能就是「抡起 → 劈下」 |
| **猎人的追命锁镰** | 武学型，评级 **B**；伤害 247 / 破防能力 213；**攻击范围覆盖中远距离**；铸魂后「**锁链的伤害与刀刃相同**」并造成流血；卡牌「钩索可**勾住远处的锚点**」；击败剧情 BOSS「追命」获得 | ⇒ **单刃弯钩镰 + 长链**，**链是武器本体的一部分**（不是挂饰）；取「甩出钩索」的画面感 |
| 联动 | PBZ 的 BOSS「**追命**」本体就是**锁链型敌人**（蓝光藏在连段中间） | ⇒ 锁镰天然是「反制追命」的道具，造型可带一点对抗意味 |

### 2.2 ★★ 已取到官方立绘：**真实造型与本文初稿出入很大**（2026-11-14 实测）

知识库里原本**只有玩法数据、没有剪影描述** ⇒ C0 抓到官方立绘后，发现初稿的造型描述**基本是错的**。
已下载 2048×2048 原图（第三方素材，只留本地）：

| 文件 | 来源 | sha256 前 12 |
|---|---|---|
| `SkillWeaponsArtSource/01_Reference/pbz/juxiongfu_axe.png` | `wiki.biligame.com/yingzhiren/巨凶斧` | 见 `references.csv` |
| `SkillWeaponsArtSource/01_Reference/pbz/zhuiming_suolian.png` | `wiki.biligame.com/yingzhiren/追命锁镰` | 同上 |

#### 巨凶斧（实测造型）

- **不是月牙形** —— 是**宽厚的扇形/半弧单刃斧头**，刃口朝上，刃面宽而厚。
- **斧头根部一个向下的尖喙刺**（初稿完全没有）；**柄尾一组倒钩尖刺**（像撬棍头）。
- **长柄**：柄约占全长 **58%**，斧头占 42%；近斧头处与杆身中段各有一道浅色缠握。
- 斧头与柄连接处有**金属环箍 + 交叉皮带**。
- 刃面是裂纹/层叠的旧铁质感，**刃缘是磨损的银白**；整体配色是**深褐铁 + 近黑柄**（不是金红）。
- 官方描述：「斧身厚重，一击可开山裂甲，破盾能力强」「曾为**斧老大彭猛**所用的厚刃巨斧」。

#### 追命锁镰（实测造型）

- 官方描述：「曾为猎杀者追命所用的**一双**锁链镰刀」⇒ **PBZ 是一对镰刀**。
- **内侧开刃的弯钩镰**，镰尖朝上；**镰刃根部一个带缺口的上扬爪形头**（像爪/兽头）。
- **分叉的握杆**，杆上缠**深红色粗绳**，绳上串几枚小金属环与新月形小片。
- 握杆**下端收细**、数道金属箍，**末端一个小挂环**（链子挂点）。
- 官方描述：「盘绕、牵拽、收割」「利于中远距离攻击，也能钩住远处锚点进行移动」。

#### ★★ 我们的两个技能在 PBZ 里的**原型锚点**（比初稿精确得多）

| 我们的技能 | PBZ 原型 | 依据 |
|---|---|---|
| **抡斧劈砍**（抡起→劈下，无视盾减伤 + 必破盾） | 巨凶斧 **5 级「强行蓄力」**（连按两次额外耗 1 暗源，直接进行**满蓄力斩击**）＋ **25 级「千钧之势」**（奔跑中满蓄力后释放，施展**凌空一劈**） | wiki 升级特性表 |
| **追命锁链**（锁定最远最弱 → 拖到面前） | 追命锁镰 **5 级「如影附形」**（连招可接重/轻攻击，**将锁定的敌人拖拽到面前**；若目标处于霸体或大体型，则把自己牵拉到敌人面前） | wiki 升级特性表 |

⇒ ⇒ 这两条把「抡斧 = 满蓄力斩击」「锁链 = 把锁定目标拖到面前」的出处钉死了。

#### 实测比例（与我们的尺度规范对照）

从 2048² 原图量出的包围盒：

| | PBZ 实测 | 换算到我们的尺度 | 我们的规范 | 结论 |
|---|---|---|---|---|
| 巨凶斧 总长 : 总宽 | 1064 : 510 = **2.09** | — | — | — |
| 巨凶斧 头宽 : 总长 | 429/1064 = **0.40** | 3.2 × 0.40 = **1.28** | 刃宽 1.15 | ✔ 基本一致 |
| 巨凶斧 柄径 : 总长 | 50/1064 = **0.047** | 3.2 × 0.047 = **0.15** | 握把径 0.14 | ✔ 基本一致 |
| 巨凶斧 头长 : 总长 | 447/1064 = **0.42** | 3.2 × 0.42 = **1.34** | 未写 | — |
| 追命锁镰 总长 : 总宽 | 948 : 665 = **1.43** | — | — | — |

⇒ **我们的尺度规范（斧 3.2 / 刃宽 1.15 / 柄径 0.14）本来就是按 PBZ 比例写的，尺度不用改。**
⇒ ★ 但 `design/weapon-3d-art-spec-axe-and-chain.md` §4.1 写的「**不是长柄斧**」与 PBZ 实测（柄占 58%）**矛盾** ⇒ 已按 PBZ 改为长柄（见 §4 决策点）。

### 4.3 提示词

正文已外置到 `Tools/visual_brief/prompts/`（见 §4.0）；要点：

### 4.4 C1 验收标准

- [ ] 一眼能认出是**斧** / **镰+链**，剪影成立，缩到 1/4 仍可分辨
- [ ] 材质分区清楚：金属 / 布 / 木 / 链环不混成同一纹理
- [ ] 配色关系成立：冷银刃 + 鎏金件 + 朱红布 + 暖棕木，金不是"一点旧金"而是**主金属色**
- [ ] 厚重、凶悍、爽快；**不是**卡通 / 照片写实 / 像素画
- [ ] 白底、主体完整不出画、四边留白足够
- [ ] 无人物 / 手 / 场景 / 文字 / 尺寸线
- [ ] ★ **形态对得上 PBZ**：斧 = 宽厚单刃破坏型；镰 = 单刃弯钩 + 长链

⇒ **结论**：这类"外部产品造型参考"不要走图片检索，**直接去官方 wiki / 图鉴页拿立绘直链**。这补上了 `memory/art-production-workflow-entry.md` §3「外网图片检索在本项目基本无效」的一条具体反例与替代做法。
