## 1. 画风口径（★ 最重要的一条澄清）

**产物是「3D 建模参考图」，不是游戏精灵。** 所以：

| 要落 | 不落 |
|---|---|
| 形体语言：厚重、剪影优先、部件分区清楚 | 像素色簇 / 阶梯轮廓（那是 2D 精灵的语言） |
| 材质分区：金属 / 布 / 木 / 皮革各自分明 | 「高清像素化」的渲染方式 |
| 配色关系：冷暖对比、主色/辅色/强调色 | 把所有素材压成同一色阶 |

**配色以已部署的 3D 长枪为准**（实测 `Assets/Models/Weapons/FantasySpear/Textures/FantasySpear_BaseColor.png`）：

| 角色 | 色 | 用途 |
|---|---|---|
| 主 | **鎏金 / 黄铜** | 金属配件、箍件、装饰 |
| 主 | **朱红** | 缠握布、缨带、流苏（**强识别色**） |
| 主 | **冷银灰 / 白** | 刃面、锋口高光 |
| 辅 | **暖棕 / 橙褐** | 木杆、皮革 |
| 点缀 | 少量翠绿 | 极小面积 |

> ⚠ **修正需求文档的一处偏差**：`design/weapon-3d-art-spec-axe-and-chain.md` §4/§5 写的是「写实偏硬的金属 + **深色木** + **局部旧金**」。实测已部署长枪是**金比"局部旧金"重得多、朱红是主识别色、木杆是暖棕橙不是深色**。⇒ 以本节为准。

**不采用**的路线（会毁掉 3D 建模价值）：像素画风、卡通描边、照片写实、鲜亮高饱和。

#### 巨凶斧（实测造型）

> ★★ **2026-11-14 三次修正后的最终结论**（反复放大官方立绘的头部才看准）：
> **PBZ 巨凶斧 = 一整块实心厚重的铁块，从柄端向一侧张开成宽扇形/倒三角；
> 刃口是一条斜着的长边（不是弧）；上侧是厚钝的斧背；靠柄处只有一个小浅内凹。**
> ★★ **形状的唯一权威** = `SkillWeaponsArtSource/01_Reference/pbz/juxiongfu_axe_head_zoom.png`（930×810 头部特写）。
> ⚠ **「弧」的错觉来自刃缘那条裂纹银白带，不是轮廓。** 轮廓是接近直线的斜边 + 实心质量。
> ⚠ **v2~v6 反复做成「月牙铲」的根因是提示词措辞**（一直写「月牙形 / 凸弧 / 月牙缺口」），
> **不是参考图错了** —— 图是对的（文件名就是 `巨凶斧.png`，取自 wiki 影之武装图鉴 + 词条页直链）。

- **斧头**：**一整块实心厚重的巨大铁块**，从柄端**向一侧张开**成**宽扇形 / 倒三角**；
  一侧**厚钝的实体斧背**，另一侧**一条斜着的长刃边**（银白磨损只在这条边上）；
  靠柄处**一个小的浅内凹**；断面是**上厚下薄的楔形**（厚背薄刃）。
  ★★ **不是月牙形 / 弯月 / 镰刀 / 钩镰 / 薄片**。
- **柄端下方单独垂着一根长尖喙刺**（像鸟喙 / 倒钩，约占头宽一半）。
- **柄尾一组小的倒钩尖刺**（像撬棍头）。
- **长柄**：柄约占全长 **58%**，斧头占 42%；近斧头处与杆身中段各有一道浅色缠握。
- 斧头与柄连接处有**暗铁环箍 + 交叉皮带**。
- 刃面是裂纹/层叠的旧铁质感，**刃缘是磨损的银白**；整体配色是**深褐铁 + 近黑柄**（不是金红）。
- 官方描述：「斧身厚重，一击可开山裂甲，破盾能力强」「曾为**斧老大彭猛**所用的厚刃巨斧」。

#### 追命锁镰（实测造型）

- 官方描述：「曾为猎杀者追命所用的**一双**锁链镰刀」⇒ **PBZ 是一对镰刀**。
- **内侧开刃的弯钩镰**，镰尖朝上；**镰刃根部一个带缺口的上扬爪形头**（像爪/兽头）。
- **分叉的握杆**，杆上缠**深红色粗绳**，绳上串几枚小金属环与新月形小片。
- 握杆**下端收细**、数道金属箍，**末端一个小挂环**（链子挂点）。
- 官方描述：「盘绕、牵拽、收割」「利于中远距离攻击，也能钩住远处锚点进行移动」。

#### ★★ 我们的两个技能在 PBZ 里的**原型锚点**（比初稿精确得多）

| 我们的技能 | PBZ 原型 | 依据 |
|---|---|---|
| **抡斧劈砍**（抡起→劈下，无视盾减伤 + 必破盾） | 巨凶斧 **5 级「强行蓄力」**（连按两次额外耗 1 暗源，直接进行**满蓄力斩击**）＋ **25 级「千钧之势」**（奔跑中满蓄力后释放，施展**凌空一劈**） | wiki 升级特性表 |
| **追命锁链**（锁定最远最弱 → 拖到面前） | 追命锁镰 **5 级「如影附形」**（连招可接重/轻攻击，**将锁定的敌人拖拽到面前**；若目标处于霸体或大体型，则把自己牵拉到敌人面前） | wiki 升级特性表 |

⇒ ⇒ 这两条把「抡斧 = 满蓄力斩击」「锁链 = 把锁定目标拖到面前」的出处钉死了。

（★ 不能用平均值 —— 单独生成的左侧视图在它自己的原图里占得更高，用平均值会超出画布被裁断）。

- 输入参考：`image[1]` = **已验收的 C1 概念图**（唯一形状参考）；`image[2]` = 1011 Idle（画风，可选）。
- 提示词直接用 `design/weapon-3d-art-spec-axe-and-chain.md` §6.1 / §6.2 的四视图正文（那两段已经写好了），把「输入参考图」的定义换成「已验收的概念图」。
- 尺寸 `1024x1536`、`quality=max`、`input_fidelity=high`，**逐视图一次一张**（一次出多视图会把比例带歪）。
- 产出规格（需求文档 §2.1）：单图 384×1024 ×4、无字合图 1536×1024、中文标注版 1856×1440。
- ⚠ **每张失败先分析、不自动重试**（铁律 4）；参数或提示词实质变化要**重新报批**（铁律 2）。

### 7.1 ★ 实测：为什么弃用 Bing 图片检索

`Tools/visual_brief/fetch_image_refs.py` 在本任务上的表现（2026-11-14）：

| 查询 | 结果 |
|---|---|
| `影之刃零 巨凶斧` / `追命锁镰` / `巨凶斧` / `追命锁镰` | **0 命中**（该端点对中文词解析失败） |
| `影之刃零` | 35 命中，但**全是无关内容**（手机壳、摩托、头盔、赛博朋克 2077 宣传图、军舰） |
| `Phantom Blade Zero Great Axe` / `Chain Sickle` / 另两组英文词 | 各 11 命中，但**三组查询返回的是同一批无关图**（手机壳、摩托、Discord 图标……） |

⇒ 66 张候选图里**没有一张是 PBZ 武器**；拼出的 contact sheet 两件武器完全一样。
⇒ **结论**：这类"外部产品造型参考"不要走图片检索，**直接去官方 wiki / 图鉴页拿立绘直链**。这补上了 `memory/art-production-workflow-entry.md` §3「外网图片检索在本项目基本无效」的一条具体反例与替代做法。
