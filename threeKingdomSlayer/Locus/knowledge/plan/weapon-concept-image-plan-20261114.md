# 抡斧 / 追命锁链：概念图生成方案（2026-11-14）

> **本轮目标**：为两个武器模型准备**概念图**（造型定稿图），造型参考《影之刃零》(PBZ) 的「巨凶斧」与「猎人的追命锁镰」，画风落到本项目。
> **上游需求**：`design/weapon-3d-art-spec-axe-and-chain.md`（四视图需求 + 3D 制作规范）。
> **执行纪律**：`memory/art-production-workflow-entry.md`（铁律 1/2/3/4/6）、`skill/gpt-image-generation.md`。
> ⚠ **本方案未获批准前不提交任何付费生成**；以下提示词为**草案**，要改词就改这里，改完重新报批。

---

## 0. 结论先行：链路与闸门

```
C0 取参考（不花钱）      → 用户挑参考
   ↓
C1 概念图 2 张（花钱 2 次）→ ★用户验收★ ★闸门★
   ↓
C2 四视图 8 张（花钱 8 次）→ 用户验收
   ↓
C3 合图 + 标注版 + 交付记录
```

**为什么必须先有概念图**：四视图提示词（需求文档 §6）原文是「**根据输入参考图**，画同一把…的正交单视图」——**现在根本不存在这张"输入参考图"**。概念图就是它，且要承担三件事：锁**造型**、锁**配色**、锁**静止姿态**。

---

## 1. 画风口径（★ 最重要的一条澄清）

**产物是「3D 建模参考图」，不是游戏精灵。** 所以：

| 要落 | 不落 |
|---|---|
| 形体语言：厚重、剪影优先、部件分区清楚 | 像素色簇 / 阶梯轮廓（那是 2D 精灵的语言） |
| 材质分区：金属 / 布 / 木 / 皮革各自分明 | 「高清像素化」的渲染方式 |
| 配色关系：冷暖对比、主色/辅色/强调色 | 把所有素材压成同一色阶 |

**配色以已部署的 3D 长枪为准**（实测 `Assets/Models/Weapons/FantasySpear/Textures/FantasySpear_BaseColor.png`）：

| 角色 | 色 | 用途 |
|---|---|---|
| 主 | **鎏金 / 黄铜** | 金属配件、箍件、装饰 |
| 主 | **朱红** | 缠握布、缨带、流苏（**强识别色**） |
| 主 | **冷银灰 / 白** | 刃面、锋口高光 |
| 辅 | **暖棕 / 橙褐** | 木杆、皮革 |
| 点缀 | 少量翠绿 | 极小面积 |

> ⚠ **修正需求文档的一处偏差**：`design/weapon-3d-art-spec-axe-and-chain.md` §4/§5 写的是「写实偏硬的金属 + **深色木** + **局部旧金**」。实测已部署长枪是**金比"局部旧金"重得多、朱红是主识别色、木杆是暖棕橙不是深色**。⇒ 以本节为准。

**不采用**的路线（会毁掉 3D 建模价值）：像素画风、卡通描边、照片写实、鲜亮高饱和。

## 2. PBZ 造型口径（知识库能确证的 + 必须靠实拍图补的）

### 2.1 能确证的（`design/pbz-reference-analysis-20261109.md` §1/§2）

| 武器 | 确证事实 | 对我们造型的约束 |
|---|---|---|
| **巨凶斧** | 破坏型影之武装，评级 **A**；伤害 309 / 破防能力 208；卡牌标注「**高破盾能力**」；三形态 = **强行蓄力 / 厚甲护身 / 疾行斧**；铸魂后蓄力速度 +30%；击败驿站 BOSS 获得，前期最实用的破盾利器 | ⇒ **宽厚、单刃、破坏型**的重斧；**取「强行蓄力」形态的视觉**（举起时的体量与蓄势感），因为我们的技能就是「抡起 → 劈下」 |
| **猎人的追命锁镰** | 武学型，评级 **B**；伤害 247 / 破防能力 213；**攻击范围覆盖中远距离**；铸魂后「**锁链的伤害与刀刃相同**」并造成流血；卡牌「钩索可**勾住远处的锚点**」；击败剧情 BOSS「追命」获得 | ⇒ **单刃弯钩镰 + 长链**，**链是武器本体的一部分**（不是挂饰）；取「甩出钩索」的画面感 |
| 联动 | PBZ 的 BOSS「**追命**」本体就是**锁链型敌人**（蓝光藏在连段中间） | ⇒ 锁镰天然是「反制追命」的道具，造型可带一点对抗意味 |

### 2.2 ★ 知识库里**没有剪影描述** ⇒ 必须靠 C0 的实拍/图鉴图

`pbz-reference-analysis-20261109.md` 全是**玩法数据**（伤害、评级、形态、获取），**没有一个字描述斧头/镰刀的形状**。所以：

> ⚠ **不能凭文字编 PBZ 的造型**。C1 生成时必须挂真实的 PBZ 参考图；拿不到图就只能做「三国重斧 / 锁链镰」的原创设计，并明确告知用户**这不是 PBZ 造型**。

## 3. C0 取参考（不花钱）

### 3.1 PBZ 参考

- 工具：`Tools/visual_brief/fetch_image_refs.py`（Bing 图片异步接口 → 下载缩略图 → 写 `references.csv` → 拼编号 contact sheet）。
- 查询词建议（三组分别抓，避免混）：
  - `影之刃零 巨凶斧` / `影之刃零 影之武装 大斧`
  - `影之刃零 追命锁镰` / `影之刃零 锁镰 影之武装`
  - `Phantom Blade Zero Great Axe` / `Phantom Blade Zero Chain Sickle`
- 产物落 `SkillWeaponsArtSource/01_Reference/pbz_<slug>/`，带编号的 contact sheet 交用户挑。
- **来源优先「游戏实机截图或图鉴立绘」**；Wikimedia 等实拍照片库对本项目无参考价值。
- ⚠ **第三方参考图只留本地、不进仓库**（`.gitignore` 按 `EnemyXXXXArtSource` 的白名单写法处理：只放行 `README.md` / `00_Index/` / 台账，参考图本体忽略）。
- ⚠ **外网图片检索在本项目基本无效**（`memory/art-production-workflow-entry.md` §3 教训）⇒ contact sheet 必须让用户挑，不要自动选第一张。

### 3.2 我们自己的画风参考

| 用途 | 素材 | 路径 |
|---|---|---|
| 厚重感 / 材质分区 / 配色关系 | 1011 已验收 Idle（**唯一已部署的新画风基准**） | `Assets/Sprites/Enemy/Enemy1_1/Enemy_1011_idle1.png` |
| 3D 武器的配色语言（**文字描述为主，图只作补充**） | 长枪 BaseColor | `Assets/Models/Weapons/FantasySpear/Textures/FantasySpear_BaseColor.png` |

> ⚠ 长枪 BaseColor 是 **UV 图集**，直接当编辑参考图有让生成器"照着画色块"的风险 ⇒ **只作为文字描述的来源，不作为 `image[]` 输入**。

## 4. C1 概念图（2 次提交）

### 4.1 参数（沿用项目既有链路）

```
endpoint   POST https://api.muskapis.com/v1/images/edits
model      gpt-image-2.6-sunburst
size       1024x1024
quality    max            ← 铁律 3：GPT Image 一律 quality=max，不降档
input_fidelity  high      ← 编辑类（挂参考图）再叠
output_format   png
n          1
image[]    多图，顺序有意义
不传 background（要白底纯不透明，不是透明）
超时 900s / 自动重试 0
```

工具形态照 `Tools/visual_brief/submit_1013_identity.py`：提示词正文与参考图清单**外置**在 `Tools/visual_brief/prompts/`（唯一真源），脚本只做提交与留痕。

### 4.2 参考图清单（C1）

| image[] | 内容 | 职责（写进 refs json） |
|---|---|---|
| 1 | PBZ 巨凶斧 / 追命锁镰 实拍图（**各一件一张，单独提交**） | **只锁造型**：宽厚单刃破坏型斧 / 单刃弯钩镰 + 长链。不复制其配色、纹样、徽记、材质 |
| 2 | 1011 已验收 Idle | **只锁画风**：短壮厚重、部件分区清楚、冷铁灰 / 朱红 / 金白高光 / 暖棕皮革。不复制其角色造型 |

⇒ 两件武器**分开提交**（参考图职责不同，不能混在一张里）。

### 4.3 提示词草案

**抡斧 · 概念图（中文）**
```text
画一把【单手破坏型大斧】的 3/4 侧展示图，纯白不透明背景，用于 3D 建模前的造型与材质定稿。

输入参考图 1 只负责【巨凶斧式的宽厚破坏型大斧造型】：单刃、宽厚的大斧头，刃口朝上，柄短粗，重心靠近斧头，蓄势感强。不要复制参考图的具体纹样、配色、徽记或装饰。
输入参考图 2 只负责【本项目的画风】：短壮厚重、部件分区清楚、剪影优先；金属冷银灰、布饰朱红、木杆暖棕橙、金白高光点缀；凶悍、厚重、爽快，不要卡通、不要照片写实、不要像素画。

本把斧：不对称月牙形单刃，刃宽约 1.15、刃厚约 0.22、握把直径约 0.14，全长约 3.2。金属箍与皮革缠握在斧头与柄的连接处，柄尾有穿孔挂环。刃口方向为 +Y，握持点在握把末端。
刃面冷银灰、斧背与金属箍鎏金偏黄铜、缠握布朱红、木杆暖棕橙；高光是锐利的银白，不是大面积高饱和。

输出一张 1024×1024 纯白不透明 PNG，只含一把完整大斧，3/4 侧、竖直摆放、居中，刃口、柄尾、挂环全部可见，四边留至少 64 像素。柔和中性光照，干净边缘。
```

**追命锁链 · 概念图（中文）**
```text
画一把【链镰】的 3/4 侧展示图，纯白不透明背景，用于 3D 建模前的造型与材质定稿。

输入参考图 1 只负责【猎人的追命锁镰造型】：单刃弯钩镰，钩背带配重环/挂孔，长链从镰头根部垂下，链身是多节可辨识的闭合椭圆环（有交叠关系，不是实心粗绳）。不要复制参考图的具体配色、纹样、装饰。
输入参考图 2 只负责【本项目的画风】：部件分区清楚、剪影优先；金属冷银灰、布饰朱红、链环旧铁偏鎏金点缀；凶悍、厚重、爽快，不要卡通、不要照片写实、不要像素画。

本把链镰：镰头长约 0.9、刃宽约 0.85、刃厚约 0.16，镰尖朝上（+Y 方向）；链身 8~9 节，单节外径约 0.26、厚约 0.09，链尾有大连接环。链身自然下垂略带弧度，不要笔直绷紧、不要缠绕成一团。
旧铁与鎏金的链环、朱红缠握、镰刃冷银灰。

输出一张 1024×1024 纯白不透明 PNG，只含一把完整链镰，3/4 侧、竖直悬挂（镰尖朝上、链尾在下）、居中，全部可见，四边留至少 64 像素。柔和中性光照，干净边缘。
```

**负面词（两件通用，中英各一份）**
```
人物、手、场景、文字、标签、尺寸线、坐标轴、边框、光效、残影、多视图合集、透视缩短、倾斜、镜像复用、改变比例、悬空零件、塑料感、卡通描边、发光、像素风。
characters, hands, scenery, text, labels, dimension lines, axes, borders, glow, motion trails, multi-view sheet, perspective foreshortening, tilt, mirrored reuse, changed proportions, floating parts, plastic look, cartoon outline, emissive, pixel art.
```

### 4.4 C1 验收标准

- [ ] 一眼能认出是**斧** / **镰+链**，剪影成立，缩到 1/4 仍可分辨
- [ ] 材质分区清楚：金属 / 布 / 木 / 链环不混成同一纹理
- [ ] 配色关系成立：冷银刃 + 鎏金件 + 朱红布 + 暖棕木，金不是"一点旧金"而是**主金属色**
- [ ] 厚重、凶悍、爽快；**不是**卡通 / 照片写实 / 像素画
- [ ] 白底、主体完整不出画、四边留白足够
- [ ] 无人物 / 手 / 场景 / 文字 / 尺寸线
- [ ] ★ **形态对得上 PBZ**：斧 = 宽厚单刃破坏型；镰 = 单刃弯钩 + 长链

## 5. C2 四视图（8 次提交）

- 输入参考：`image[1]` = **已验收的 C1 概念图**（唯一形状参考）；`image[2]` = 1011 Idle（画风，可选）。
- 提示词直接用 `design/weapon-3d-art-spec-axe-and-chain.md` §6.1 / §6.2 的四视图正文（那两段已经写好了），把「输入参考图」的定义换成「已验收的概念图」。
- 尺寸 `1024x1536`、`quality=max`、`input_fidelity=high`，**逐视图一次一张**（一次出多视图会把比例带歪）。
- 产出规格（需求文档 §2.1）：单图 384×1024 ×4、无字合图 1536×1024、中文标注版 1856×1440。
- ⚠ **每张失败先分析、不自动重试**（铁律 4）；参数或提示词实质变化要**重新报批**（铁律 2）。

## 7. 已知风险

| 风险 | 应对 |
|---|---|
| PBZ 实拍图抓不到 / 抓错 | 退化为原创三国重斧 + 锁链镰，**明确告知用户这不是 PBZ 造型**；不硬凑 |

| 生成器把长枪 UV 图集当画风 | 长枪 BaseColor **不进 `image[]`**，只写成文字描述 |
| 链环被画成实心粗绳 | 负面词 + 提示词里「有交叠关系，不是实心粗绳」；需求文档 §8 第 3 条 |
| 左手视图用镜像冒充 | 需求文档 §8 第 2 条；链环交叠关系 / 斧背铆钉能区分 |
| 成本 | 先 C1 两张验收再决定要不要走 C2；每个视图一次一张，不批量 |
