## 2. 造型口径：**照刀锋，别加戏**

### 2.1 刀锋（Blades）技能页的实测数据（硬参考）

对 `BL-icon-Skill_Frame.png`（256×256）实测：

| 项 | 实测值 |
|---|---|
| 节点框边宽 | 左右 **33–36px（≈13%）**，上下 **56–59px（≈22%）** |
| 框的颜色 | **单色暖铜**（约 `#DDA674`），alpha 只有 0 / 255 两档 |
| 渐变/浮雕 | **没有**：无渐变、无高光、无内阴影 |
| 图标 | 黑色镂空剪影，压在框内 |
| 连线 | 细线，无装饰（关节处可略加粗） |
| 文字 | 一种字体、小号、两色（亮/暗区分状态） |

**结论：平面 + 单色描边 + 剪影图标。成本极低。**

### 2.2 已经走过的弯路（别重复）

上一版做成"青铜铭牌 + 铆钉 + 朱红印章 + 笔刷纸纹 + 竖向金属渐变"，被明确否掉：**过度设计，不像参考图**。
现在程序化版已回退到"单色描边 + 平面内部"，但自评仍不够像，需要美术接手。

### 2.3 能用 / 不能用

**可以**：平面深色底、单色暖铜描边、剪影图标、细线、小号两色文字、极轻微噪声。
**不要**：浮雕/斜面、金属渐变高光、花纹/藤蔓、印章、铆钉、纸纹/笔刷纹理、3D 渲染、萌系、仙侠水墨。

### 3.1 三个节点状态怎么区分（只靠颜色，不做两套造型）

- **锁定**：冷灰描边（约 `#6B6764`），内部最暗
- **可解锁**：暖铜描边（约 `#D9A674`）
- **已解锁**：亮铜描边（约 `#E8C88E`），可略加一点内亮

> 三张图共用同一张线稿，只换描边色 —— 这样最省，也最像刀锋。

## 6. 接入与验收

**接入**：把图拖到 `TalentTreePanel` 对应槽位 → 如果想让美术图完全接管，把这两个开关关掉：
- `preferProceduralNodes = false`（节点用槽位图）
- `useProceduralPanel = false`（面板/遮罩用槽位图）

**验收清单**：
1. 在 1080×2160 竖屏下打开天赋页，节点框在 132px 显示尺寸时**一眼能看出边界**；
2. 三态在灰度下也能区分（打印成黑白看）；
3. 连线在深色面板上**清晰可见**（这是上一轮的失败点：压到 4px 后几乎看不见）；
4. 面板、页签、详情卡、按钮**同一套材质语言**（不能新旧混搭——上一轮就是面板还是旧 `TT_Panel` 导致风格断层）；
5. 拉伸到 16:9 / 20:9 不糊角（九宫格生效）；
6. 与 `design/art-style-guide.md` 的边界一致（不萌、不水墨、不写实）。
