## 1. 任务目标与当前阶段

游戏玩法循环方向已经形成；用户希望继续完善到上限版本前的内容，包括：

1. 新增普通敌人、精英和 Boss；**Boss 或精英要与其掉落的影之武装、饰品或主武器相对应**。具体对应关系、来源与概率尚未设计。
2. 设计天赋解锁内容。
3. 设计新增主武器及其招式、性能、效果。
4. 设计新增影之武装与饰品。
5. 补充**本局经验升级的具体属性内容与数值**：用户指出此前漏提，这部分也尚未定案。

当前不是要求立即列完上述所有内容或做工程排期。用户更重视先理解已有玩法、确认机制，再逐项讨论内容；未获明确实现指令不得动工程。

## 2. 最新玩法方向：不可沿用的旧口径

### 2.1 体验目标与关卡时长

- 游戏体验方向：**《影之刃零》的动作、武器 / 饰品与敌人互动 + 肉鸽三选一的局内 Build**。
- **普通关卡：单条路线 10 分钟以内。**
- **无尽关卡：20～30 分钟体验目标**，是游戏长线运营游玩、后期刷装备 / 素材 / 道具的核心内容；不是 20 或 30 分钟强制结束。两种模式的成长和奖励节奏是否相同尚未定。
- 持续体验目标是：获得装备 → 试用 → 比较 / 强化 → 更换过渡件 → 形成联动 → 按局势继续调整，而不是填满槽位后停止成长。
- 无尽关「刷装备」与当前“本局装备实例结束后清除、保留解锁资格”的具体关系仍需后续厘清，**不可据此自行改成所有装备跨局保留**。

### 2.2 局内外边界

- **主武器**定义长期战斗身份和主要招式；Boss 有机会掉落，获得时立即永久拥有，本局之后失败不收回；只能回局外选择 / 更换，连招不进入局内三选一。重复主武器改为其他奖励，奖励细节未定。
- **全局成长**与主武器成长是两条局外成长方向；金币和局外升级道具获得时立即到账、失败不收回。节点、路线和经济待设计。
- **本局成长属性**来自经验升级，不占饰品槽，不像饰品一样替换，本局结束清除；原则可叠加、有软上限，局外成长可抬升软上限。具体属性、数量和数值未定。
- **影之武装与饰品**是本局装备，初始槽位各 2；本局使用及强化随对局结束清除。装备品质为普通 / 精良 / 传说三档，可有单品质内容；品质、等级和稀有度如何对应待定。
- 本局影之武装 / 饰品通过**精英 / Boss 装备宝箱**选择；约 3 分钟时应有一次**能够选到影之武装**的机会，波末实际选择时点为准，也可选饰品，不能保证此时一定拥有武装；**不开局免费送 Build**。
- 一部分影之武装 / 饰品初始解锁，部分由精英、Boss 或地图探索宝箱获得**永久解锁资格**；解锁后立刻可在本局后续装备宝箱出现，但不自动装备、不保证抽到。解锁资格的永久保存确认时点**尚待明确**；不能与“新主武器立即永久拥有”混为一谈。
- **暗源靠进攻获得，防御姿态不回复**。具体获取量、消耗和标定待讨论。
- 老文档里“局内临时主武器 / 自由换主武器”“更多武器不做”“旧的 3+3 / 4+6 槽位”“20 分钟一般局”等冲突说法不得覆盖最新规则。`design/gameplay-progression-loop.md` 是局内外循环裁决依据；较早文档中没被推翻的内容保留原状态。

### 2.3 三类 Build 与饰品原则

1. **操作型**：扩展操作内容，围绕普攻、蓄力、招架 / 防御与时机等形成玩法。
2. **影之武装型**：围绕一件或多件主动武装决定打法及战斗节奏。
3. **搭配型**：通过本局属性、饰品和武装的关系获得数值或机制收益；与操作型可重叠，但关注点不同。

用户认为操作型制作更难；**影之武装型与搭配型是更快形成可玩内容的优先研究方向**，不是废弃操作型，也不是批准商业变现方案。

**饰品必须有独立作用，适配多种玩法，与某些 Build 相性更好；禁止只围绕一件指定武装生效的强绑定设计。** 可以针对“持续伤害”等通用机制专精，不要求每件饰品适合所有构筑。切忌为了证明联动，给每件影之武装配专属饰品或把组合写成必须集齐的套装。

## 3. 已确认内容：染病 Build 与四件饰品

权威正文 `design/gameplay-progression-loop.md` §4.1–§4.2。状态是**玩法方向与机制形状确认**，不是全部数值确定，也不代表新饰品已实装。

### 3.1 染病构筑

- 已有主动技能「染病」：释放后由下一次命中的戳击施加疾病；可重复施加叠层，疾病造成持续伤害，患病敌人死亡时尝试向另一名合格敌人传播。
- 以**持续伤害、叠层、死亡传播**为核心，既可针对单体，也可利用敌群；染病单独要有作用，**不依赖灼烧或某一饰品才能使用**。
- 现有代码口径：疾病每 0.5 秒结算；Boss 可染病，但当前 Boss 不作为传播目标且 Boss 死亡不传播，Boss 非应战 / QTE / 转阶段期间暂停 DoT。具体后续玩法若需调整须由用户确认。

### 3.2 四件饰品（原名与确认状态）

| 饰品 | 已讨论的效果 | 等级 / 稀有度 | 边界 |
|---|---|---|---|
| 持续伤害护符 | 所有持续伤害 +`{0}%` | 三级递增；**中等稀有度** | 染病、灼烧等都可受益；具体数值、换装时已有状态是否立即更新待定。 |
| 冷却护符 | 影之武装冷却 -`{0}%` | 三级递增；**普通稀有度** | 不限定染病；与其他冷却缩减如何叠加、已在冷却中的处理待定。 |
| 嵌伤护符 | 敌人每次受到伤害，防御 -`{0}%`，最多 -`{1}%` | 三级，逐级提高每次减防及上限；稀有度未定 | 用户表示防御可往“减伤”理解；但现无统一敌方防御值 / 减伤公式，零减伤目标、盾牌、DoT 是否从减防获益、受伤计数和持续时间均未定。 |
| 炼狱导管护符 | **方向已定、具体效果待讨论**：技能或攻击命中为主动技能减 CD，附带百分比灼烧 | 一级；传说级；非常强的减 CD | DoT 跳伤是否算命中、影响哪些冷却、灼烧比例基准 / 施加 / 叠加、多目标计数、触发间隔及自触发等未定。 |

- **不要将“中等稀有度”自行写成已定“精良”，也不要将三级效果等同于三档品质**；具体数字均未确定。
- LOL 第三方参考：[海斗小助手 · 炼狱导管](http://lolhaidou.cn/augment/infernalconduit.html) 描述的是技能施加灼烧、灼烧造成伤害时缩短各基础技能冷却；用户项目提出的是**攻击或技能命中减主动技能 CD，附带百分比灼烧**。二者不同，以用户方向为准，不照搬原作数值。
- 曾提出的绞军轮专属「钉魂佩」「追刃环」因强绑定已撤回，不要当成既定内容。

## 4. 已确认内容：新影之武装「夺锋」（暂名）

权威正文 `design/gameplay-progression-loop.md` §4.3；这是**设计，不是已实装资产**。

> 对最近的敌人造成 `{0}` 点伤害。若该次伤害击杀目标，这件影之武装的伤害增加 `{1}`，同时玩家攻击力增加 `{2}`；两项成长只持续至本局结束。

- 定位是**类似杀人剑的单体收割、投资和滚雪球**：玩家观察最近目标生命，创造并把握收割窗口；允许前期获得投资价值高、后期获得较低，但后期能否合理完成第一次收割仍需标定。
- **武装伤害与玩家攻击力分开**：玩家升级获得或夺锋击杀获得的攻击力，均不直接提高夺锋自身伤害；成功收割给予的**武装自身伤害成长**可提高之后的武装伤害。其他通用伤害加成、暴击如何作用待统一设计。
- **必须由该次武装伤害完成击杀**才得双成长；只命中未击杀没有成长，随后被疾病 / 灼烧等杀死不算该次武装击杀。
- **换下并重新获得**：已获得的玩家攻击力继续生效；已积累的夺锋伤害成长本局保留，之后重新获得并装备同款时恢复。两项在本局结束均清除，不是跨局永久成长。此规则是该武装已确认的特殊边界，**不预设其他武装也这样**。
- 与冷却护符、嵌伤、染病自然存在相性 / 抢最后一击的取舍；不是专属配件。
- 待定：正式名称、基础伤害和双成长的具体数值、冷却 / 暗源、稀有度、品质与自身强化、上限、最近目标平局裁决、特殊击杀归属与多目标 / Boss 场景。初步演算数字均未拍板。不要默认补发后期未获得时的积累。

## 6. 重要现状 / 设计边界

- **敌方减伤已有局部计算、没有统一防御体系**：`Assets/Scripts/Enemy/Enemy.Combat.cs` 的部分敌人普通形态使用伤害倍率 ×（1 − 减伤比例）；`Assets/Scripts/Enemy/ShieldGuardEnemy.cs` 的盾卫按条件有固定值减伤及最低伤害。这两者并非同一个防御公式。
- 当前 `Assets/Scripts/Enemy/EnemyStatusDisease.cs` / `Assets/Scripts/Enemy/EnemyStatusBurn.cs` 的 DoT 使用 `ignoreDamageModifiers`，会绕过部分敌方伤害修正与盾判定；不要未经设计裁定就说嵌伤已经提高疾病伤害。
- 疾病可叠层，但当前同一敌人的多层疾病按单次跳伤汇总结算；是否计为一次「受伤」触发嵌伤仍待用户确认。
- 灼烧当前每秒一跳，重复施加会刷新并重置跳伤计时；若炼狱导管未来高频刷新灼烧，须研究可能一直重置而延迟跳伤的问题。不能预设导管的刷新 / 叠层方案。
- 10 个主动技能资产 / 8 个池内的现状不是交付宣称“全玩法闭环已按新设计实现”；新版装备替换、永久解锁资格、四护符和夺锋仍要区分策划与工程。

## 7. 尚待策划的问题与可继续方向

按用户后续指令选择，不视为自动派工：

1. **炼狱导管具体效果**：什么算命中，直接命中与 DoT 如何计数，影响哪些冷却；百分比灼烧按什么数值计算、如何施加和叠加，如何避免递归及高频多目标失控。
2. **嵌伤 / 敌方减伤模型**：防御含义、百分比口径、无减伤目标是否可进入负值、盾牌与 DoT 交互、叠层持续与计数。
3. **本局属性体系**：攻击力及各种伤害来源的作用范围、持续伤害与通用伤害加成的关系、其他属性与软上限；不能假定所有多段每跳获得相同固定攻击力收益。
4. **夺锋平衡与呈现**：前中后期首次取得时的收割窗口、双成长和换装收益、冷却 / 暗源、品质 / 等级、自身强化和是否上限；具体数字未定。
5. **敌人与掉落**：普通兵、精英、Boss 的威胁 / 对策，以及和其掉落内容的对应；不能预设每个敌人必给永久解锁，也不能让对策只来自于击败该敌人才可能取得的专属装备。
6. **新增主武器、招式与天赋、更多影之武装 / 饰品**：先沿三类 Build 和泛用相性建立定位，再由用户讨论决定；普通关与无尽关分别考虑成长节奏。
7. **持久化和掉落细节**：永久解锁资格保存确认时点、重复获得、宝箱概率、替换 / 重抽 / 跳过、已触发效果的边界均未定；夺锋 §4.3 例外已经确认。
