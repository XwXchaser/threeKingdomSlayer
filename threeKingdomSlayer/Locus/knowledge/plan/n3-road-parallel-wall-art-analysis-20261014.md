# N3 沿路石围墙：卷轴构造与素材生成分析

## 本轮范围与结论

用户验收G2后指出缺少与主干道平行的围墙，随后要求“思考沿路围墙该如何生成美术素材，了解当前场景构造和卷轴化场景设计思考这个问题”。首次分析时仅做只读调查。用户随后明确授权根据现有素材部署N3，选择灰色黑边墙片并对首轮N3构图回复“已验收，效果不错”。N3灰墙几何及布景现已部署到Y场景。**当前这段补充只分析下一步石墙贴面如何生成；没有生成图片或修改场景/源码，Editor保持MainMenu.scene编辑状态。

**短段、有真实宽度的灰黑描边墙体已经部署并获用户观感验收。下一步保留灰墙几何、 UV、接段和沿路姿态，只为各个面生成可替换的高清像素化正交粗石贴面。** 图片负责石块、泥缝、明暗色簇和像素细节；现有几何继续负责长度、厚度、道路朝向、透视、轮廓描边和卷轴贴地。当前建议不再生成新的透视整墙，也不重做已验收布局。

已验收G2 B1/B2继续承担房前横墙、院门两侧短墙和零散残墙。沿路连续墙使用独立模块，不能把G2美术验收视为其朝向/接缝表现验收。固定斜透视的左右长墙图不建议用于需要接近、经过与转向的卷轴路线。

灰墙原型已实装，用户对N3首轮构图和灰墙方向已回复验收。当前原型网格未采样贴图：`YVillageWallPrototype.shader`只读Color/Outline属性；要接石材色图，还需新增Shader采样和侧/顶/端面的材质引用。后续只需替换面材质，保持灰墙几何和已验收场景位置。

### 路线与构图

`YScrollSample.Evaluate`：J1=190开始分叉，半径28.1595573、角度45°，左转在约212.118结束；EV225及N3=266.1165同在-45°直线尾段。村墙放在左转后显露的村庄侧，不加进已验收J1组。

N3是村落边缘的开阔战斗地面。墙按短院落段落形成两侧边界，在院门、破口、草簇处断开，不把两侧围墙做成一直夹住五列阵型的窄通道。EV外围更疏，N3边缘增加生活/战损信息。房屋与墙段、道路转弯和最终停点构图仍要一起验收。

### 三种投影职责

| 当前类型 | 实际处理 | 对连续围墙的意义 |
|---|---|---|
| 地面`YGroundJ1Branches.shader` | 每个顶点减去旅行位置，按航向旋转，depth>18开始下弯 | 连续空间基准 |
| 普通`YScrollSceneryE0Route.shader` | 只投影脚点；图内X/Y固定叠到屏幕横轴/竖轴，整体下沉 | 适合树/房外立面与横墙，物件Y旋转不能变成真实沿路墙 |
| `YOrientedSceneryE0Route.shader` | 投影脚点，再按作者X轴与观察方向构造卡片横轴，整体下沉 | 已用于11个篱笆，能表现沿路倾向，但不是固定世界墙面或连续几何 |

定向Shader没有像地面那样将作者X轴按`_YSPose.w`转换成同一个路线观察空间，还使用每个锚点到相机的方向。这个方式服务已验收的篱笆视觉，不代表应改变篱笆；沿路连续墙不能直接依赖它保持各段端点一致。

`YRouteSurface.shader`虽然有逐顶点路线位姿变换，但没有地面的下弯函数，加载场景中使用该Shader的Renderer=0，是未接入草稿；不能直接当生产墙材质。`ScrollProjection.cginc`使用另一套`_Scroll*`参数，也不是当前Y路线投影契约。

|---:|---:|---:|
| 203 | -26.45° | 16.68° |
| 212.118 | -45° | 24.00° |
| 225 | -45° | 28.50° |
| 235 | -45° | 36.80° |
| 240 | -45° | 45.96° |

这是指定位置和既有篱笆作者轴的算例，不是G2实际运行截图或全部朝向的统一误差，不能据此否定已验收J1视觉。它说明“看起来沿路”与“保持可接段的空间轴”是两个不同要求。

2. 假定朝向已经正确，一段4米长墙若只按中心锚点下沉，端点相对解析地面的最大高度差：depth10=0、20≈0.097、30≈0.468、40≈0.828米。在depth30附近，两个邻段仅按各自中心下沉的接点高度差可达0.864米。长墙用整体下沉会放大此问题；不应靠脚点Y补偿逐帧修。

3. 当前地面mesh为161×201采样，作者步长1，XZ scale6，实际网格间距6米。模拟EV225时在道路左偏6米的三个点：route240/255/266.1165的地面三角插值与解析下弯差约0.0013/0.0843/0.1289米。墙逐顶点使用同一公式也不保证完全贴当前粗网格；后续须检查三角插值、墙根有限埋入/遮挡、必要的局部匹配，不能自动改地面细分来解决。

代码与数值说明机制限制；本轮没有对G2新图做实际定向试摆，也没有完整墙体Game视觉测试。

## 方案比较

| 方案 | 长处 | 当前任务的限制 | 建议 |
|---|---|---|---|
| G2卡片接定向材质 | 复用成本低，适合短散片 | 方向随视点变化、无实际顶面/厚度、中心下沉与端点不匹配、重复墙端明显 | 仅短零散段或远景候选 |
| 左/右侧固定透视长墙Sprite | 固定停点可直接画出体积 | 远近大小和消失点烘死，推进/转弯再投影可能产生双重透视；镜像也改变光照 | 不作主路线连续墙 |
| 立面/顶面/端面组成短立体段 | 朝向、长度、厚度由空间统一生成；易接段与制造院口 | 网格及灰黑原型已实现并获用户验收，当前Shader还未采样色图 | 保留该方案，仅继续制作石材面图 |
| 每块石头完整3D建模 | 全角度几何充分 | 工作量大，非当前视点必要条件，风格/批次管理成本高 | 不需要作为首批目标 |

## 推荐美术拆分

先做一族完整墙面，复杂破损作为独立后批，防止同批请求既要精确UV又要大量自由破口。

| 编号 | 生成内容 | 必须锁定 | 后续贴面 |
|---|---|---|---|
| L01 | 正交长墙面A | 水平基线、石层3–4、长度方向不收缩、不画侧厚/顶面/尽头墩 | 道路朝向的长侧面 |
| L02 | 同尺寸长墙面B | 与A同石块量级与层高，排列自然变化，接段边缘结构兼容 | 同一面随机替换/内侧使用 |
| L03 | 正交俯视窄墙顶 | 全长粗石顶层、条带矩形、真实顶面材料，无俯视完整墙体 | 水平窄顶面 |
| L04 | 正交短端面 | 宽=墙厚、高=墙高、同层高；不是缩窄的完整长墙，不能把石块压扁 | 仅实际墙头/院口/转角暴露处 |

早期建议以相对比例讨论造型；当前以用户已验收网格为准：长4m、可见高1.7m、总面高1.88m（含基线下0.18m）、厚0.55m。Side A/B尺寸相同；Top长度与长墙面相同，End高度与长墙面相同。纹理像素密度按同一米制比例统一，不按图集里填格面积定真实大小，不重新选择墙段尺寸。

各模块使用规则矩形的满幅贴面区：长度接缝不能画成圆头或独立石墩，顶沿轮廓沿用已验收实体网格，不增加alpha裁切。石块小范围起伏用面内色簇表现。贴面内不得留透明边框；若原始生成结果带留白，应先确认完整纹理区并在派生贴图中裁去留白，原始回包保留。

已验收主墙Mesh为4m长，横截面厚0.55m，墙底局部嵌入基线0.18m、墙面高1.88m；沿长度细分8段，使曲率投影可追踪。组件包含双长侧、窄顶面、可选首/尾端面。每张面图的UV覆盖该整面，`uv2`存面尺寸，顶点色区分侧面/顶面/端面明暗；当前Shader尚未读取贴图。不要为换贴图而改尺寸、UV分段或已验收Transforms。

左右道路侧不要求生成镜像两整条墙：通过相反的几何法线/UV建立墙的内外面，实际透视由相机生成。不要把图左右镜像后的光照差异当成正确左右墙。保持粗石暖灰褐、泥缝适量、上方偏暖亮、暗部冷灰褐；不烘长投影或强烈只适合一个方向的远近渐变。

### 破损与转角

- G2 B2继续用于独立残墙。沿路连续墙若需缺口，应制作几何高度下降/中断的完整结构，其顶面、端面和侧面遵循同一断口；只将侧图挖透明会留下悬空完整顶板。
- 门口可先把连续墙截断，与已验收院门组合；近墙根碎石/草少量遮缝，不用装饰掩盖错误朝向。
- 转角首轮用共享材质的短段转向与真正端头形成；必要的L形转角作为后批，不先生成烘透视整角图。
- 主村墙在EV/N3直尾段上，不必沿J1圆弧建城墙。村庄接近仍经历-26°到-45°视点变化，不能因为停点直线就采用唯一固定透视。

## 对应贴面规格与UV约束

现有网格每个4m段把每种表面的本地UV完整映射到0–1；长面纵向由8段网格在UV的0–1区间连续插值。`uv2`面尺寸已经分别是长侧(4,1.88)、顶面(4,0.55)、端面(0.55,1.88)。因此推荐三类独立、满幅矩形、**不透明PNG/RGB色图**，比例分别约2.13:1、7.27:1和0.29:1。统一400px/m时可取Side=1600×752、Top=1600×220、End=220×752作为本地工作纹理示例；这不是API画布参数，正式生成时还需明确画布和有效材质区，避免为配合画布比例拉伸石块。不要给有效贴面区加透明padding或投影。

实际回读四个Mesh均只有**一个submesh**，Side、Top、End全部在其中，当前每个Renderer只引用一个灰色Prototype材质。更合适的首版接入是：分别生成/审阅各面图片，本地合成带挤边padding的Atlas；新贴图Shader从现有`uv2`面尺寸识别Side(4,1.88)、Top(4,0.55)、End(0.55,1.88)，通过材质中显式配置的采样区域取色。**原uv0保留为面内0–1坐标，仅采样时映射到Atlas；描边继续用原uv0计算。** 因而不需要改变已验收Mesh、Transform或添加材质槽，也不会把Atlas区域边界误当几何边界。贴图与各区域通过Inspector可追踪；绘制批次仍以实际测量为准，不保证仅用同一材质就能合批。分成三个submesh/材质槽也能实现，但会增加材质绑定，当前无必要。此处是后续Shader与贴图接入方案，尚未实施。

第一版生成素材：

- **Side A**：完整长侧墙面，以G2的三层主要粗石加少量填缝小石为基线，不画规则砖网；左右边的石层高度、接边颜色与纹理连续，方便每4m段交接。避免特意加一条贯穿整高的竖砂浆缝。不要整件alpha轮廓，不画转角或墙厚。
- **Side B**：同尺寸、同石层高度与相同左右接缝结构的石块变化。优先在Side A验收后，以A为结构参考生成；首轮只需A，B是减重复的扩充项，不必为了凑四格提前制作。
- **Top**：正上方真实顶面窄条，横截面0.55m，纵长4m；表示顶层不规则石头与泥缝，不画完整墙、不带侧立面。对应网格UV纵向和横向都使用0–1。
- **End**：正对墙端的窄端面，0.55m宽、1.88m高，石层高度和Side完全对齐。只有墙链起止或院门断口处可见，网格开口段不应错误加端帽。

色图应作为**不透明手绘颜色图**，石块内的暗部保留；当前是自定义Unlit画风，不需额外生成Normal/Metallic/Roughness整套PBR图。现有顶点色已经把两侧面染为约0.83/1.0，顶面约1.15，端面约0.9；素材应避免强烈单一方向的 baked light 或黑描边，否则会和代码生成的描边重复。保持中性偏暖灰褐像素色簇、明确石块体积和泥缝。后续接图时不能无条件沿用灰面Tint=.58再整图相乘而造成整体变暗；需以中性色Tint或显式颜色强度匹配G2。先保留已验收轮廓描边宽度，再做同机位灰墙/石墙对照。

主轮廓的接缝由4m实体模块处理。Side A先保证A-A水平重复，石层和边缘色相匹配；不要用贯穿整高的粗竖黑缝强化每4m分段。Top同样保证长度两端可接；End与Side石层高度对齐。以后扩充B时必须复用A的边缘结构，检查A-B/B-A，不能只验证各自能自循环。先验收Side A，再以A为参考派生Top/End；B后置。G2 B1/B2只作粗石色簇/块面参考，不能直接当无缝贴图；参考应裁石墙局部并附灰墙各面职责示意，不上传完整场景去让模型重画透视。

## 如何组织生成

形体以正交技术示意限定各贴面区，材料以**已验收G2 B1/B2石块局部**为主要参考；用户村庄图石院墙局部辅助石料与尺度；G1局部/项目权威概念图仅校准绘制语言与光照。不把整幅村庄道路图当构图输入，也不从G2现有图直接宣称已获得无缝贴图。

推荐分两步生成：先单张Side A，验收粗石风格、缩小可读性和A-A重复；再以认可A的石料和层高制作Top/End，B留作后续变化。生成请求的画布尺寸与最终使用的纹理区不是同一个概念：细长Top/End应提供明确有效区域示意，按几何比例裁取完整材质区，不能为填方格拉伸石块。不要让模型直接画最终GPU Atlas，准确排版、挤边和UV采样区域由本地确定性处理。

正向约束：严格正交的各表面；层高与单位石块尺寸一致；暖灰褐粗石、土泥缝、厚实体块、高清像素色簇；长面左右接边兼容；底边水平；顶面是真顶视；端面窄而竖直。材质缺陷适量，A/B不同但同族。

负面约束：消失点、近大远小、斜透视整墙、等距立体示意作为成品、道路、泥地底卡、公共阴影、草树、房屋、门、标签、网格线、军用城垛、额外高墩、端部装饰、石块拉伸、镜像重复、外圈黑框和透明洞。有效纹理区为不透明满幅，保留石缝暗色；未来Atlas的隔离区域由本地排版处理。

后续若正式准备请求，依既有偏好仍提交完整中英文正/负面词、输入职责和参数再批准；`quality=max`、参考编辑`input_fidelity=high`、PNG，背景采用opaque，与本任务有效纹理区要求一致。当前没有新提示词文件、prepared request或付费请求，不把本分析当生成授权。

## 后续最小验证应证明什么

用已验收G2材质局部或中性占位贴面做两段短墙加一个真实墙头的技术样例，先验证空间再付费补细节。这是后续建议，不是本轮执行。

- 近/中/远推进与左转接近：不绕脚点转向，不像门板侧身追镜头，纹理不过度压缩。
- 两段接点：先检查A-A重复，再检查Top长度重复；未来B扩充还要查A-B/B-A。两长面、窄顶面、基线连续，段间不出现透明缝、错层端帽或高度跳变。跨Side/Top/End的石层高度一致不等于每块角石天然对齐，需用展开图和贴模预览核对；AI提示词不能保证精确接缝，必要本地边缘修整另存派生图。
- 贴地：采用与地面相同的逐顶点位姿/下弯并核对当前地面三角网格差；短段连接边共享位置，细分和墙根处理以实际画面决定。
- 厚度：近端能看见正确短端面，顶面不悬浮，门口是真空，不在墙内露天空。
- 遮挡：旧篱材质Queue3000、ZWriteOff；新实体墙不能只靠Sprite sortingOrder。主体可考虑墙专用Alpha Clip+深度写入（BIRP支持），轮廓边缘与透明排序单独验收，不改共享树草材质。
- 路线绑定：墙使用当前`_YSPose/_YSToLocal/_YSToWorld`相机作用域，按路线采样与横向偏移摆放，Mesh资产、材质和纹理Inspector可追踪，Renderer登记到scenery并检查剔除。
- 视野：J1停点不露村庄建筑；EV稀疏院落、N3中央阵型开阔，不因沿路墙收窄战场。也不以移动Battle相机或改路线半径修素材。

建议样本包含J1=190、转中203、转完212.118、EV225、途中240/255、N3=266.1165，再针对一段墙取得远/中/近三样本。过去J1截图只证明既有篱笆效果，不能代替新石墙验证。
