# 抡斧 3D 模型贴图修复（2026-11-15，只改贴图）

> 任务：用户已在 Blender 里修好斧头顶部（`battle axe 3d model_re` = 修复后，`battle axe 3d model` = 修复前），
> 要我「根据修复前和修复后去处理一下贴图（只改贴图）」。本文件是执行记录。

## 1. 结论

- 贴图问题定位清楚并已修复：**修复版有 34 个 UV 面积为 0 的面**，全部在斧头顶端（z 0.9224~0.9321），
  是用户新增的面沿用旧顶点 UV、导致 UV 边被压成一条线，贴图采样拉成污痕。修复后退化为 **0**。
- 几何**一个顶点都没动**：只改了 UV（顶盖重排到独立图集岛）与贴图像素。
- 最终形态（用户拍板）：**斧眼盖改成钢质**，不再用木色。
- ⚠ 过程中我把 Blender GUI 搞崩了（我的脚本在 GUI 里跑全图集栅格化 + 2048² 像素读写）。
  用户的未保存场景在崩之前已被 `save_as_mainfile(copy=True)` 备份，**修复成果没丢**。
- ⚠ **前两版交付（v3/v4）都被用户否掉**，两个根因（§3、§4）+ 一个覆盖不���（§5）都已修掉。
  最终版六视角逐像素比对：除顶盖与钢箍顶沿外，与用户修复版原样完全一致。

## 2. 诊断证据

| 项 | 修复前 `battle axe 3d model` | 修复后 `battle axe 3d model_re` |
|---|---|---|
| 顶点 / 面 / 三角面 | 1897 / 1996 / — | 1867 / 1972 / 3730 |
| 世界包围盒 | x[-0.1743,0.1748] y[-0.0543,0.0568] z[0,0.9965] | **完全相同** |
| UV 面积 = 0 的面 | **0** | **34** |
| 非流形边 / 边界边 | — | 0 / 0（闭合流形，修复干净） |
| 几何差异区 | 修复前独有 48 个顶点，bbox z 0.924~0.997 | 顶部那截**冒出来的木柄头**被削平，改为 z≈0.930 的钢盖 |

即：用户的修复＝削平斧头顶端冒出的木桩；新生成的面没重算 UV → 贴图坏。

## 3. 方案迭代（含两个我自己造成的错误）

| 版本 | 做法 | 结果 | 采用 |
|---|---|---|---|
| v1 | 沿面法线朝修复前模型射线投射 + 重心外插 | 退化面归零，但 119/119 个环都落在命中三角形**之外**，采样被甩到图集别处 → 顶盖出现橙白三角乱纹 | ✗ |
| v2 | BVH 最近表面投射 | 退化面归零，但顶盖 UV 散布到图集 0.19~0.95 的**多个岛**，没法整块重绘 | ✗ |
| v3 | 顶盖单独一个图集空位（用 12×12 采样点判空）+ 重排 49 个朝上面的 | **★错误交付**，见下 | ✗ |
| v4 | 空位改为**逐像素边函数精确栅格化 + 积分图**判空；**只重排 UV 面积=0 的 34 个面** | 退化面 0、六视角干净，但**用户指出顶盖只涂到中间一块**（见 §5） | ✗ |
| v5/v6 | 重排**整个斧眼口面组**（43 个面）→ 整块重绘钢色 | 顶盖整块覆盖为钢；六视角比对仅顶盖区域变化 | ✓ 采用 |

**v3 的两个错误**

1. **空位判定漏检**：Tripo 的 UV 展开是细长条带，穿过空位的细条带被 12×12 采样点漏掉，
   于是我涂的 128×128 矩形压到了**刃背的 UV** 上 → 刃背变成一块块灰白碎片。
   （精确占用显示真正空位在 (1804,1712)，而 v3 用的 (1628,1616) 根本不空。
   注：v5 把 43 个面一起重排后，(1628,1616) 确实变成真空位。）
2. **多搬了面**：筛选条件「法线朝上且 z>0.920」抓到 49 个面，把 15 个本来正常的老面也搬进了新岛，
   还混进了**斧刃顶端**（z≈0.99 的朝上面）。

## 4. 第二个根因：法线图色彩空间（v3 交付里同样存在）

- 症状：刃背出现成片硬边「面片」（一开始我误判成 UV 问题）。
- 隔离实验：v4 的 blend（UV 已修、贴图仍是 .blend 里打包的原始图）渲染**完全干净** ⇒ 问题在贴图文件而非 UV。
- 根因：Tripo 导入时法线图被标为 **Non-Color**；我另存成 PNG 后 Blender 按 **sRGB** 读取，
  sRGB→线性转换改掉法线值 ⇒ 着色出现硬边面片。
- 修法：加载法线图后显式 `img.colorspace_settings.name = 'Non-Color'`（base color 保持 sRGB）。

## 5. 顶盖覆盖不全与最终改为钢质（用户两轮反馈）

- 用户第一轮反馈：「木纹只覆盖了一部分」。根因：顶盖实际由 **43 个面**组成，
  而 v4 只重排了 UV 退化的 34 个面 → 其余面仍挂原图集 UV，所以只涂到中间一块。
- 修法：面集口径改为「**朝上 + 落在斧眼口 XY 窗口内**」（窗口由退化面顶点范围推出再放宽 6mm：
  x[0.0203,0.1006]、y[-0.0421,0.0518]），共 43 个面整块重排进同一图集岛。
  ⚠ 不能只用「朝上且 z>0.920」：会把斧刃顶端（z≈0.99）的朝上面一起抓走。
- 用户第二轮反馈：「不如把这个盖子修成铁的材质」⇒ **最终改为钢质**：
  钢色取自图集「冷蓝灰钢」像素统计（中位 `[0.353,0.361,0.451]`，p25 `[0.259,0.263,0.337]`，
  p75 `[0.431,0.439,0.533]`），中心略亮、边缘压暗、低频锻打斑驳（不用规则网纹）。
- 木色版本已删除（只涂到中间一块，且木纹与握柄不搭）。

## 6. 顶盖新岛

- 图集是**密集条带布局**（Tripo 自动展开，不是紧凑岛）；精确占用占 62.7%，空位零散。
- 顶盖投影：平面 +Z，圆心 (0.0633, 0.0055)，半径 0.0410 m，占岛内 76%，四周留边。
- 木料色取自**握柄杆身**的 UV 采样（147 个暖色样本）：中位 `[0.424, 0.200, 0.180]`，
  p25 `[0.351,0.165,0.149]`，p75 `[0.447,0.227,0.196]`。
  （第一版用全局暖色像素中位 `[0.635,0.361,0.196]`，太橙太亮，与握柄不搭。）

## 9. 崩溃与恢复

- 崩因：在 GUI 进程里做 2048² 图像 `pixels.foreach_get/foreach_set` 与全图集三角形栅格化。
- 现象：MCP 先报 `Connection closed`，再报 `Not connected`；`tasklist` 里 blender.exe 消失，无崩溃日志。
- 恢复：现场副本 `Library/Locus/tmp/axe-texture-fix/scene_backup_before_texture_fix.blend`。
- 后续重活全部改在 `--background` 无界面 Blender + Blender 外的 PIL/numpy 完成。
