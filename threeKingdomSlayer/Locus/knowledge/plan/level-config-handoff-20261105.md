### 1.1 霸体机制（`Enemy.Combat.cs`）

- 霸体窗口 = `isCFrame`（C 技那一段）**或** `isSuperArmor`（**仅 BOSS 阶段**）。
- **霸体不减伤，只免疫打断**：
  - 轻攻击（戳 / 斩 / 枪突）：霸体期**打不断**，且**架势伤害 = 0** → **完全无效**。
  - 重攻击（`isHeavy=true`）：霸体期也能打断（拆前摇）。
  - 招架：只在**出伤窗口**能格开（前摇打不断）。
- **破霸体的唯一稳定手段 = 蓄力招的架势伤害**（削韧 → 归零 → 破势眩晕 + 解除霸体）：
  | 招式 | 伤害 | 架势伤害 | 重攻击 |
  |---|---|---|---|
  | 挑飞 Launch | 2 | 50 | 是 |
  | 蓄力上挑终结技 LaunchFinisher | 60 | 80 | 是 |
  | 穿刺 Pierce | 20 | 30 | 是 |
  | 指向突刺 StabR2 | 35 | 30 | 是 |
  | SlashC2 | 35 | 30 | 是 |
  | 横扫 Sweep | 5 | 25 | 是 |
  | **轻攻击（戳/斩/枪突1-3）** | 20~37 | **0** | 否 |
- 敌人 `maxPoise`：普通 50 / 弓箭手 40 / BOSS 100；破势硬直：普通 5s、盾卫 1.5s、弓箭手 2s。
- 104 阶段：阶段1（100%~70%）无阶段霸体、QTE 权重 2；阶段2（<70%）**开启阶段霸体（整阶段）**、QTE 权重 0.5、QTE 后冷却 5s。

## 5. 改动与实测方法

### 5.1 改法

- **敌人基础值**：`Assets/Resources/EnemyPrefabs/Enemy_10XX.prefab`（用 `unity_execute` 改 SerializedProperty；**不要手改 YAML**）。
- **波次编成/倍率**：`Assets/RouteData/ChangbanpoScroll/Battles/Formal_*_Battle.asset`。
- ⚠️ `enemyIds` 在 YAML 里是 **int32 小端、每个 8 个 hex 字符**（`0` = `00000000`、1011 = `f3030000`、1012 = `f4030000`）→ **文本 grep 搜不到 "1011"**，别用 grep 找。
- ⚠️ **绝不直接 `edit` .meta**（Tuanjie 引擎 GUID 是加密的 → 手改会触发引用断裂）。导入设置一律走 `unity_execute` API。

### 5.2 实测（机器人）

```csharp
var go = new GameObject("BattleAutoPlayer(测量)");
var bot = go.AddComponent<BattleAutoPlayer>();
bot.autoStart = true; bot.useAreaAttacks = false;
bot.bossQTEMode = BattleAutoPlayer.BossQTEMode.Suppress;
bot.preferredRouteChoiceId = "";
var route = AssetDatabase.LoadAssetAtPath<FakeRouteStageConfig>(
    "Assets/RouteData/ChangbanpoScroll/changbanpo_ScrollRoute.asset");
FakeRouteRuntime.Instance.Begin(route);
```

- 埋点 → `Library/Locus/telemetry/run-*.jsonl`；分析 → `Tools/analyze_level_telemetry.py`。
- 难度表 → `Tools/build_first_level_difficulty_table.py`（⚠️ 内置基线已漂移，重跑前先对资产）。
- 机器人**不会走位/招架** → 它是「下限探针」，不代表玩家打不过。
- 跑机器人前先备好天赋节点（没有 C2 会卡在带霸体的单位上）。

### 5.3 已知坑

- 机器人**不吃 adb 注入点击** → 涉及菜单/按钮的验证要人手点。
- 教学关用 `TutorialFlowDriver.StartInPlayMode()`；**重跑教学必须先退出 Play Mode 再进**（同会话重跑会污染采样）。
- 跑自动化会改存档 → **跑前备份 `player_save`（`Library/Locus/tmp/player_save_backup.txt`）、跑完还原**。
