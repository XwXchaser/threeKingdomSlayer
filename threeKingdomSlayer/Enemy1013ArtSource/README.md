## 04_IdleFrames（已验收 6 帧）

待机循环：取自 idle 源片。**取法不是「固定周期等距取帧」**——idle 片的旗布是连续模拟的飘动、不是可重复的周期，按固定间隔取帧必然在接缝处跳旗形。

**正确取法**：先在**运动区**（全片逐帧 XOR 的并集＝只有旗布在动）里找**旗形最接近的一对首尾帧**，再在两者之间等距取 6 帧。本片最佳对 = **f040 ↔ f060**（运动区差异 0.100，随机配对约 0.38）。

|---|---|---|
| 01 | idle | f040 |
| 02 | idle | f044 |
| 03 | idle | f048 |
| 04 | idle | f052 |
| 05 | idle | f056 |
| 06 | idle | f060 |

> 源片人物身高 633px，与 Cast 源片（632px）几乎一致 → 两组帧的**像素密度相同**，落位后不会出现 idle 与 cast 精细度不一致的观感差。

## 硬规矩（摘自 1012 管线经验）

1. **表情**：起手态必须等于游戏内 idle 的实际长相；负向词只留四条不可违反的；脸是镜头里的主动作。
2. **母本**：只认「用户验收的那支 take」，用 IoU 对拍确认，不要信文件名与台账。
3. **落位**：按**可见底行**对齐（不是几何底）；同一动作共用一组 k 与偏移。
4. **写精灵**：必须保留 alpha；只覆盖 PNG 字节、保留 `.meta`；写完回读核对。
5. **量位移**用靴子锚点，不要用 bbox 中心。
6. **动作幅度不能靠文字里的数字控制**——模型只服从「位置类」约束；百分比与角度会被放大，峰值要写「穿过去」而不是「定住」。
