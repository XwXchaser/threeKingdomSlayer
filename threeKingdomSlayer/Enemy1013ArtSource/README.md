## 动作母本

母本（动作出处）沿用 1012 的 9 支动作源片，见 `00_Index/videos.csv`。
**1013 不需要 attack**（它不攻击）→ 少一支视频。

## 硬规矩（摘自 1012 管线经验，踩过的坑）

1. **表情**：起手态必须等于游戏内 idle 的实际长相；负向词只留四条不可违反的；脸是镜头里的主动作。
2. **母本**：只认「用户验收的那支 take」，用 IoU 对拍确认，不要信文件名与台账。
3. **落位**：按**可见底行**对齐（不是几何底）；同一动作共用一组 k 与偏移。
4. **写精灵**：必须保留 alpha；只覆盖 PNG 字节、保留 `.meta`；写完回读核对。
5. **量位移**用靴子锚点，不要用 bbox 中心（刀伸出画面会把 bbox 拉偏）。
